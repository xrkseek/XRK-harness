# example-shell-pet

> **读者**：插件作者（XRK Plug · client 金样）

在 `conversation.session.header.utilities` 挂一颗示意芯片。该槽宿主已升为 `data-slot-layout="row"` 并给子项 `nowrap` 基线，但芯片仍自带 `flex: none` / `nowrap` / `max-width`——窄列自保是控件责任，宿主兜底不能代替。

```bash
xrkh plugin add ./extensions/example-shell-pet
```

Settings → 插件 → **重载**。

# example-shell-pet

> **Audience**: Plugin authors (XRK Plug · client gold sample)

Registers a demo chip on `conversation.session.header.utilities`. The host lifts that seat to `data-slot-layout="row"` with a `nowrap` baseline, but the chip still ships `flex: none` / `nowrap` / `max-width` — narrow-column self-defense stays on the control.

```bash
xrkh plugin add ./extensions/example-shell-pet
```

Settings → Plugins → **Reload**.
