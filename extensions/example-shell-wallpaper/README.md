# example-shell-wallpaper

> **读者**：插件作者（XRK Plug · client 金样）

在 `shell.overlay` 挂一层全屏淡色洗底（`pointer-events: none`），不挡点击。

```bash
xrkh plugin add ./extensions/example-shell-wallpaper
```

Settings → 插件 → **重载**。
