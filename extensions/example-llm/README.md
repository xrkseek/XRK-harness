# example-llm

Gold sample for process plugin `kind: llm`.

Registers brand id `example-llm-sample` (invalid endpoint on purpose). Use it to learn `wireCompositionLlm`, not for live chat.

```bash
xrkh plugin add ./extensions/example-llm
xrkh restart
```

See [docs/llm-provider-registry.md](../../docs/llm-provider-registry.md).
