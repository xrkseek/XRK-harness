# Plan → Build（同会话）

大活或需求模糊时走这个：先计划，再建，**同一会话**内完成。

```
- [ ] 1. 进入 plan 模式（`/plan` 或 Plan 徽章）
- [ ] 2. 写 headed plan（`#` 标题开头），`exit_plan_mode` 提交审批
- [ ] 3. 批了 → 同一会话开工；有反馈 → 修 plan 再提交，不要边写代码边改方向
- [ ] 4. 小问直接做，不要为了流程走流程
```

**别做的**：plan 还没批就写代码；一个 plan 拆成多个会话；简单问题套大流程。
