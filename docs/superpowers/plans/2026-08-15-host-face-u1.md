# Host Face U1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@xrkseek/server-face` — DeepSeek-compatible unary RPC + dual downlink WebSockets — wired beside existing REST, enough for conversation main path (U1 methods in [host-face.md](../../host-face.md)).

**Architecture:** New server package owns RPC envelope, method dispatch, seq assignment, mux/host fan-out. It calls `core-session` / `AgentHandle` / drain hub / `@xrkseek/llm-registry` — it does **not** block on `/api/chat`. Existing `@xrkseek/server-http` REST stays. `server-host` mounts Face on the same `node:http` server (upgrade + POST routes) or Face wraps/extends listen.

**Tech Stack:** TypeScript · Vitest · `node:http` · `ws` · existing session/agent · Registry R0

**Specs:** [docs/host-face.md](../../host-face.md) · [docs/learn/u0-prompt-mux-map.md](../../learn/u0-prompt-mux-map.md) · [docs/learn/deepseek-web-ui.md](../../learn/deepseek-web-ui.md)

**Depends on:** Registry R0 plan ([2026-08-15-llm-provider-registry-r0.md](./2026-08-15-llm-provider-registry-r0.md)) for `session.models` / `llm.providers`. Tasks 1–5 can start before Registry; Task 6 needs Registry.

**prompt algorithm (must match host-face.md):**

```ts
async function handlePrompt(runtime, rpcId, payload): Promise<FaceRpcResult<{ accepted: true; command?: { kind: "success"; text?: string } }>> {
  const { sessionId, mode, content } = payload as {
    sessionId: string;
    mode: "queue" | "steer";
    content: Array<{ type: string; text?: string }>;
  };
  if (mode !== "queue" && mode !== "steer") {
    return { ok: false, error: { code: "invalid-mode", message: "mode must be queue|steer" } };
  }
  if (content.some((p) => p.type === "image")) {
    return { ok: false, error: { code: "not-implemented", message: "image parts" } };
  }
  const text = content.filter((p) => p.type === "text").map((p) => p.text ?? "").join("");
  // slash: single text part starting with /
  if (content.length === 1 && content[0]?.type === "text" && text.startsWith("/")) {
    // U1: return success with text acknowledging; wire real slash resolver if easily reachable from presets
    return { ok: true, value: { accepted: true, command: { kind: "success", text: `slash:${text.slice(1).split(/\s/)[0]}` } } };
  }
  const agent = await runtime.resolveAgent(sessionId);
  const delivery = mode; // queue | steer
  const receipt = agent.admit(text, { delivery });
  runtime.rpcAdmitMap.set(rpcId, receipt.admitId);
  runtime.drain.wake(sessionId);
  // publish queue snapshot
  runtime.bus.publishMux({
    type: "session/queue",
    sessionId,
    items: agent.pendingAdmits().map((a) => ({ id: a.admitId, placement: a.delivery ?? "queue" })),
  });
  return { ok: true, value: { accepted: true } };
}
```

**Append → mux:** After createRuntime, wrap `store.append` or poll: when events grow, for each new event `publishMux({ type: "session/event", sessionId, event, seq: seq.next(sessionId) })`. On drain start/end publish `host/session-status` running true/false.

**cancel:** `await runtime.drain.cancel(sessionId)`; also `agent.abort()` if resolveAgent available.
