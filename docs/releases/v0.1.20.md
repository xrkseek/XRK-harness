# v0.1.20

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.19](./v0.1.19.md)：Codex 式会话投影分层收口——冷侧边栏不 fold 全日志；翻页 history 零投影；淘汰前写 list checkpoint。

Relative to [v0.1.19](./v0.1.19.md): Codex-style session projection tiers — cold sidebar skips full-log folds; history pages omit projections; list checkpoints flush before LRU eviction.

---

## 完善 / Improved

* 完善 Face 投影分层：`session.list` / history 尾页 / `loadOlder` / mux 各自有明确 fold 预算（见 [session-projection](../modules/session-projection.md)）
* 完善冷 `session.list`：持久化 `{sessionsDir}/projection-list-cache.json`（仅 `title` · `sessionListMetadata`），淘汰前写入、打开 history 尾页时刷新
* 完善 SQLite LRU：在丢弃内存日志**之前**回调淘汰钩子，避免 checkpoint 再 `get` 把会话加载回来形成递归

---

## 修复 / Fixed

* 修复 `session.history` 带 `beforeSeq`（翻页）仍 fold 投影块：现与 api-proxy 一致，**整段不带** `projections`
* 修复 `contextTimeline` 在缺少 `shadowedTokenCount` 时不记录压缩事件，上下文页事件列表漏点

---
