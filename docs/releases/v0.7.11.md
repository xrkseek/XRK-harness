# v0.7.11

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

## 中文

相对 [v0.7.10](./v0.7.10.md)：Computer-use 与浏览器代理链路落地（agent-desktop / agent-browser-session CLI 解析、fetch-pack 代理支持），桌面 Host 进程与 runtime 准备流程加固；Seat titles 模块化与 settings credentials 加固；status snapshot cache；Voice/TTS 代理 fetch 与 WebSocket agent；UI 交互与布局改进；文档同步。

### 主要变更

* **Computer-use / 浏览器代理**：`exec/computer-use` 新增 `agent-desktop.ts` / `resolve-cli.ts`，`exec/web` 新增 `agent-browser-session.ts` / `resolve-agent-browser.ts`，CLI fetch-pack 支持代理；桌面 Host 进程与 prepare-runtime 加固。
* **Seat titles & 凭据**：`face/src/seat-titles.ts` 模块化；settings-credentials 加固；status snapshot cache。
* **Voice / TTS**：`proxy-fetch.ts` / `proxy-ws-agent.ts`；TTS 卡片与控制器重构。
* **UI**：seat-caption、PreviewTabs、Menu、WorkspacePicker、ConversationRoot 等交互与布局改进；BrowserCard / ComputerUseCard / PluginCard 更新。
* **文档**：settings-fields、status、configuration、computer-use、web-tools 同步。
