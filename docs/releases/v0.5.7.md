# v0.5.7

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.6](./v0.5.6.md)：用户消息可**编辑并重新发送**、可**删除该条及之后**（含工作区回退）；发送队列补 **steer 插队**与附件；每轮文件拆成「产出 / 改动 / 删除」；工作区可**置顶**；空白新会话**有未发送草稿时侧栏仍可见**；Overview 表情球可收为芯片；Canvas 加 `callout` / `tone`；自动审查真正放行审批；流式 idle 看门狗与重试黑名单；Stop 不再留下「重试已取消」条；桌面端安全区 / 焦点环 / 暗色工具条一批观感修复。

Relative to [v0.5.6](./v0.5.6.md): **edit and resend** / **delete this and after** (with workspace revert); **steer** and attachments in the send queue; created / changed / deleted file lanes; pinnable workspaces; blank New Session rows **stay visible with an unsent draft**; collapsible Overview presence ball; Canvas `callout` / `tone`; auto-review really releases approvals; stream idle watchdog and retry blacklist; Stop no longer leaves a cancelled-retry banner; desktop safe-area, focus-ring, and dark-mode toolbar fixes.

### 新增

* 新增用户消息悬浮动作「**编辑并重新发送**」：原文装回输入框，发送前三选一（取消 / 不回退文件 / 回退文件）；编辑期有提示条与「取消编辑」，被编辑气泡高亮，`Esc` 或清空草稿退出编辑态。
* 新增用户消息「**删除此消息及之后**」：确认后 fork 截断到该条之前的新会话并切换；选「回退文件」则对原会话发 `/rollback seq:N`。
* 新增发送队列 **steer（插队）** 动作：每行一按钮，忙碌时禁用并给 Tooltip。
* 新增排队消息附件：编辑队列条目保留原附件，也可追加图片 / 文件。
* 新增工作区**置顶 / 取消置顶**：图钉 + 置顶组排最前，顺序持久化并经 `host/pinned-workspaces-changed` 广播。
* 新增 Canvas `callout` 强调块与 `tone` 语义色（neutral · good · warn · bad · accent）；`markdown` 段落新增 `md` 别名。
* 新增流式**每事件 idle 看门狗**（默认 5 分钟，每条事件重启）：provider 静默不再挂死；Anthropic / Gemini / OpenAI-compatible / OpenAI-responses 均接线。
* 新增轨迹行常显 **Inspect** 控件（`InspectAction`）：工具 / 技能展开体下一键打开对应轨迹记录。
* 新增设计系统契约自检 `scripts/check-design-tokens.mjs`：未定义令牌、文本 WCAG AA、focus-ring，违规退出码 1。
* 新增 `skills-lock.json`，钉住 8 个第三方 skill 的来源与 hash。

### 完善

* 完善侧栏空白新会话：输入框仍有**未发送草稿**时，切走后该行仍可见可点回（清空草稿或会话 engage 后恢复原隐藏规则）。
* 完善每轮产出文件：拆成「产出 / 改动 / 删除」三行芯片，同一路径按**最后一次**归类。
* 完善 Overview 表情球：可收成芯片（单行标签 + 悬停全文），折叠状态落盘；只在情绪内容变化时推渲染，流式 tick 不再重置动画。
* 完善自动审查：`/auto-review approve N` 与 HTTP `/auto-review/approve` **真正放行待处理 Face 审批**，回传 allowed / clearedRecentDeny / note；统计补 `fallbacks` / `neverRejects` / 平均分类耗时。
* 完善分类器容错：技术故障或非法协议输出降级为一次 Face 人工审批（`onClassifierError` 可切 deny）；会话 LLM 审查器注入带来源角色的历史，剔除助手文本与工具结果。
* 完善评审顺序：Auto-review 装到 pipeline 最前置；Code Mode 运输层 `run_code` 不评审，程序内每次 `await tools.*` 各评一次。
* 完善 LLM 重试：**黑名单**策略，仅排除确定性失败码；传输 / 超时 / 5xx / 限流 / 空响应 / 工具 JSON 截断 / 未知异常一律重试。
* 完善子代理标题：弱标签（如纯数字「1」）优先用会话耐久标题，面包屑不再裁成「/ 1」。
* 完善执行反馈：失败后台任务输出截断**保头**；子进程自然 exit 后 2 秒强制结算；已结算 shell 任务默认最多保留 8 条，列表不再无限堆。
* 完善后台任务区：任务列表与终端输出提高可视高度上限并独立滚动（containment overscroll）。
* 完善轮次产出排版：改动卡与「产出 / 改动 / 删除」车道合并为统一栈，去掉双重外边距。
* 完善附件契约：附件 id 即持久地址，写进工具描述与文档。
* 完善子代理：长答案超 12 KB 落盘只回路径 + 首尾预览；中断原因可读；活动判定按整棵后代树。
* 完善侧栏契约：活跃判定与 Overview 共用同一谓词。
* 完善统计：TTFT 计入 reasoning 首 token；短于 50 ms 的解码窗口丢弃。
* 完善编辑器与工作区：工作区行长按 420ms 才进拖拽；输入框 / 命令面板 / 重命名框统一品牌色焦点光环。
* 完善移动端与暗色：`--ds-safe-*` 安全区；暗色工具条浅色半透明。
* 完善滚动：工具输出 / Diff / 面板独立吃掉 overscroll。
* 完善对话框焦点陷阱与 slot 失败占位摘要。
* 完善编辑重发 fork：`beforeSeq` 继承父会话当前模型。
* 完善发送队列：排队 / 插队行直接显示待发附件芯片；队列镜像复用附件块，排队图片不再每帧重建 objectURL。
* 完善对话渲染：骨架 / 输入栏 / 轮次状态只订稳定布尔；运行中助手步骤与轮尾关闭 `content-visibility` 跳过。
* 完善文档口径：Auto-review 三档、附件溯源、委派活动信号、Code Mode PTC 边界；配套侧栏建议 **`xrkh-better-sidebar@0.18.32`**。

* 修复发送队列幽灵行与中途消失：Host 队列与本地回显统一进 dock，认领后才升正文；插队回显与 Host 下一步行合并。

### Added

* **Edit and resend** a user message: original text returns to the composer; three-way confirm offers cancel / resend without reverting / resend and revert. Edit mode shows a hint banner, highlights the bubble, and exits on Esc or clearing the draft.
* **Delete this message and after**: confirms, forks a session truncated before that point, and switches; “revert files” runs `/rollback seq:N` on the original session.
* A **steer** action on every queued row, disabled while busy with a tooltip.
* Attachments for queued messages: edit keeps them; new images / files can be added.
* **Pin / unpin workspaces**: pin control, pinned group first, order persisted and broadcast via `host/pinned-workspaces-changed`.
* Canvas `callout` blocks and `tone` colors (neutral · good · warn · bad · accent); `md` aliases `markdown`.
* Per-event streaming **idle watchdog** (5 minutes default, restarted per event). Wired in all four adapters.
* Always-visible trajectory **Inspect** control (`InspectAction`) under expanded tool / skill bodies.
* `scripts/check-design-tokens.mjs` for undefined tokens, WCAG AA text contrast, and the focus-ring contract.
* `skills-lock.json` pinning eight third-party skill sources and checksums.

### Improved

* Blank New Session rows with an **unsent composer draft** stay visible and clickable after navigation away until the draft is cleared or the session engages.
* Per-turn file chips split into **created / changed / deleted**, classified by final state.
* Overview presence ball collapses to a chip, remembers fold state, and only re-renders when mood content changes.
* Auto-review approve paths **really release** the pending Face approval and report allowed / clearedRecentDeny / note; stats gain fallbacks / neverRejects / real average classify time.
* Classifier faults degrade to one Face approval (`onClassifierError` can deny); session-LLM reviewers get role-tagged history without assistant text or tool results.
* Auto-review runs at the front of the pipeline; Code Mode reviews each `await tools.*`, not the `run_code` transport.
* LLM retries use a **blacklist**; only certain-to-fail codes are excluded.
* Subagent titles: weak labels (e.g. bare `1`) prefer the durable session title so breadcrumbs no longer read as `/ 1`.
* Failed background job truncation keeps the **head**; natural exit settles after 2s; settled shell jobs retain at most eight by default.
* Background job list and terminal output use taller capped scroll areas with contained overscroll.
* Turn deliverables share one stack so the changes card and created/changed/deleted lanes drop stacked outer gaps.
* Attachment ids are durable addresses in tool copy and docs.
* Subagents spill answers over 12 KB to disk; cancel reasons are readable; liveness walks the descendant tree.
* Sidebar liveness shares Overview’s predicate.
* TTFT counts reasoning first tokens; decode windows under 50 ms are dropped.
* Workspace drag needs a 420 ms long-press; composer / command palette / rename share one branded focus ring.
* `--ds-safe-*` clears notches; dark-mode toolbar buttons are light translucent.
* Tool output, diff, and panels contain their own overscroll.
* Dialogs trap focus; failed slots show a one-line crash summary.
* Edit-resubmit forks inherit the parent session’s selected model.
* The send dock paints pending attachment chips; the queue mirror reuses attachment blocks.
* Conversation skeleton / composer / turn status subscribe to stable booleans; running steps skip `content-visibility`.
* Docs aligned for auto-review tiers, attachment tracing, delegation liveness, Code Mode PTC bounds, and recommended **`xrkh-better-sidebar@0.18.32`**.

### Fixed

* Stop during a retry backoff no longer leaves a **cancelled-retry** banner: never-started cancels are not rendered.
* Retry failure text no longer shows `provider: [object Object]`; unknown errors stringify via message / cause / JSON.
* Queued messages no longer become ghost rows or vanish: host queue and local echo share one dock; steering merges with the host next-step row.
* Running no longer clears on `turn/end` while queued or steering work remains.
* Pending-send rpcId is not stolen by durable injects (duplicate bubble + stuck waiting card).
* One Stop kills every running / stopping background job in the session.
* A failed `continueTurn` no longer swallows later inbox work.
* Large-session Overview no longer borrows another session’s cache; Status stops re-deriving on every tab switch.
* The repeated-failure counter resets when it trips; text-only success clears the streak.
* Compaction no longer re-attaches shadowed images as image blocks (named `attachmentId` pointers + on-demand `read_image`).
* Compaction summarizer `head` only folds events since the last swap and caps at 24k tokens.
* Anthropic honors per-request `temperature`.
* Local-storage write storms: 120 ms debounce, identical-content skip, oversized drafts truncate.
* Conversation image objectURLs are capped at 96.
* Overview fold / shortcuts / content-width preferences stop synchronous localStorage reads on every event.
* Sidebar no longer auto-opens an empty terminal panel by default.
* Guardian `additional_context` rows stay hidden in Chat.
* Turn rail anchors to the bottom of the reading band.
* Jumping to an unloaded turn no longer parks on the oldest loaded row.
* Image numbers are session-wide instead of restarting at 图1 per message.
* New sends with a host backlog land in the dock first (no transcript flash).
* Stop clears the running latch before the cancel RPC.
* Steered / queued echoes keep their own preview object URLs.
* Composer and skeleton no longer re-render on every streamed chunk.
* `content-visibility` no longer skips a running step or turn-tail (no ghost change card after Stop).
* Chain selectors treat `undefined` like `null` (no crash on `matched.modified`).
* Dialogs prefer explicit `autoFocus` over the close button; Diff toolbar no longer overlays the path header.
* Terminal cards keep a single scrollport; turn waiting clocks survive session switches.
* Windows “reveal in Explorer” no longer opens an extra blank window when selecting a file.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.7`** (owns npm `@latest`); npmjs keeps **0.5.7** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.7**; root / `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
