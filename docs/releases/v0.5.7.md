# v0.5.7

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.6](./v0.5.6.md)：用户消息可**编辑并重新发送**、可**删除该条及之后**（含工作区回退）；发送队列补上 **steer 插队**与附件；每轮文件拆成「产出 / 改动 / 删除」三行；工作区可**置顶**；Overview 表情球可收起为芯片；Canvas 加 `callout` 与 `tone` 语义色；自动审查真正能放行待处理审批；模型流加 idle 看门狗与重试黑名单；桌面端安全区 / 焦点环 / 暗色工具条 / overscroll 一批观感修复。

Relative to [v0.5.6](./v0.5.6.md): **edit and resend** user messages and **delete this message and after** (with workspace revert); **steer** and attachments in the send queue; per-turn files split into created / changed / deleted lanes; pinnable workspaces; collapsible Overview presence ball; Canvas `callout` blocks and `tone` colors; auto-review approval now actually releases a pending prompt; model streams get an idle watchdog and a retry blacklist; desktop safe-area, focus-ring, dark-mode toolbar, and overscroll fixes.

### 新增

* 新增用户消息悬浮动作「**编辑并重新发送**」：把原文装回输入框，发送前弹三选一（取消 / 不回退文件 / 回退文件）；编辑期间输入框有提示条与「取消编辑」，被编辑气泡高亮描边，`Esc` 或清空草稿即退出编辑态。
* 新增用户消息「**删除此消息及之后**」：确认后 fork 出截断到该条之前的新会话并自动切换；选「回退文件」则对原会话发 `/rollback seq:N` 改回工作区。
* 新增发送队列 **steer（插队）** 动作：每行一个按钮，忙碌时禁用并给 Tooltip 说明原因。
* 新增排队消息的附件能力：编辑队列条目不再丢原附件，也可给队列条目追加图片 / 文件。
* 新增工作区**置顶 / 取消置顶**：图钉按钮 + 置顶组排最前，顺序持久化并经 `host/pinned-workspaces-changed` 广播。
* 新增 Canvas `callout` 强调块与 `tone` 语义色（neutral · good · warn · bad · accent）：KPI 数值、callout、图表条形图都可着色；`markdown` 段落新增 `md` 别名。
* 新增流式**每事件 idle 看门狗**（默认 5 分钟，每条事件重启）：provider 静默不再永远挂死，长答案照常写；四家适配器（Anthropic / Gemini / OpenAI-compatible / OpenAI-responses）全部接线。
* 新增设计系统契约自检脚本 `scripts/check-design-tokens.mjs`：未定义的 `--dsw-*` / `--ds-*` 令牌、文本令牌 WCAG AA 对比度、focus-ring 契约三道检查，违规退出码 1。
* 新增 `skills-lock.json`，钉住 8 个第三方 skill 的来源与 hash。

### 完善

* 完善每轮产出文件：拆成「产出 / 改动 / 删除」三行芯片，同一路径多轮改动按**最后一次**归类（先建后删的文件只出现在「删除」行）。
* 完善 Overview 表情球：可收起成小芯片（单行标签 + 悬停全文），折叠状态落盘、重进保留；只在情绪内容真正变化时推给渲染引擎，不再每个流 tick 重置眨眼 / 旋转动画。
* 完善自动审查：`/auto-review approve N` 与 HTTP `/auto-review/approve` **真正放行待处理的 Face 审批**（此前只清统计），并回传 allowed / clearedRecentDeny / note；统计新增 `fallbacks` / `neverRejects` / 平均分类耗时（Face 投影改用持久计数，不再恒按 1 样本折算）。
* 完善分类器容错：技术故障或非法协议输出时降级为一次 Face 人工审批（`onClassifierError` 可切 deny 硬拒），不再静默硬拦或放行；会话 LLM 审查器拿到带来源角色的历史注入（human-instruction / direct-parent-instruction / constraint / checkpoint / fact），助手文本与工具结果被剔除。
* 完善评审顺序：Auto-review 装到 pipeline 最前置，先于 hardline / policy / read-only 等软地板，配合 `defer-ask` 让后续 deny / ask 可替换它。
* 完善 Code Mode：运输层 `run_code` 不评审，程序内每次 `await tools.*` 各经同一 pipeline 评审一次（与独立调用口径一致）。
* 完善 LLM 重试：改为**黑名单**策略，默认只排除确定性失败码；传输 / 超时 / 5xx / 限流 / 空响应 / 工具 JSON 截断 / 未知异常一律重试。
* 完善执行反馈：失败后台任务的输出截断改为**保头**（`Error:` / 堆栈头 / `npm ERR!` 等真实错误不再被尾部截断吃掉）；子进程自然 exit 后 2 秒强制结算，孤儿孙进程占住管道时后台任务不再永远显示「运行中」。
* 完善附件契约：附件 id 即持久地址，写进工具描述、seed 文案与文档，任何图片 / 文件都能按 id 溯源与重开，禁止满盘搜索。
* 完善子代理：长答案超过 12 KB 落盘并只回 `read_file` 路径 + 首尾预览；中断原因不再显示 `[object Object]`（改为 `aborted by user` / `aborted by parent` / `session disposed` / `aborted by hook: …`）；活动判定按整棵后代树，孙代理在跑时父节点不再显示「已完成」。
* 完善侧栏契约：活跃判定与 Overview 共用同一谓词（drain latch 活跃**或**外部 acp / app-server 忙），任务板不再把 ACP 子代理画成已完成。
* 完善统计口径：首字延迟（TTFT）把 reasoning 首 token 也算作边界，解码窗口短于 50 ms 的样本被丢弃，不再报出几十万 tok/s 的假速度。
* 完善编辑器与工作区：工作区行长按 420ms 才进入拖拽排序（触屏可排序且不再误触展开子会话）；输入框 / 命令面板搜索框 / 重命名框获得统一品牌色焦点光环，全局补焦点环兜底；弹出菜单层级改用 `--ds-z-popover/scrim/surface` 令牌。
* 完善移动端与暗色：新增安全区变量 `--ds-safe-*`，固定面板与弹层不再把关闭按钮藏进刘海、页脚不再压在小白条下；暗色模式工具条按钮从深灰改成浅色半透明。
* 完善滚动：工具输出区、Diff 区、滚动面板独立吃掉 overscroll，滚到底不再把整页 / 聊天日志带着一起滚。
* 完善对话框与 slot：对话框补上焦点陷阱，关闭后焦点回到触发按钮；slot 失败占位面直接显示崩溃摘要一行。
* 完善编辑重发式 fork：`beforeSeq` 继承父会话当前选中的模型，换过 API key 后重试能把选择带进子会话。
* 完善文档口径回填：Auto-review 三档与 `resolveDenyAction` / `onClassifierError`（`docs/configuration.md`）、附件溯源契约（`docs/modules/attachment.md`）、委派活动信号不变量（`docs/session-latch.md`）、Code Mode PTC 评审边界（`docs/code-mode.md`）、侧栏建议版本（`docs/community-plugins.md`）。

### 修复

* 修复发送队列「幽灵行」与中途消失：Host 队列行与本地「发送中」回显统一进 dock，Host 认领 FIFO 后本地回显才升进正文；插队回显与 Host 下一步行合并成一条，「插队中」徽章不再乱闪。
* 修复还有排队 / 插队工作时 `turn/end` 提前清掉「运行中」态（Stop 按钮误显示为空闲）。
* 修复用户发送回显的 rpcId 被 skill-catalog / agent-instructions 等 durable inject 抢位，导致**双气泡 + 蓝色等待卡死**的问题。
* 修复点 Stop 一次不能杀净后台任务（需反复点、且飘「后台任务完成」toast）：现在一次即杀掉本会话所有 running / stopping 任务。
* 修复一轮 `continueTurn` 失败后**后续 inbox 消息永久失声**：失败时退出循环，abort 仍正常上抛。
* 修复大会话重进 Overview 借用别的会话的缓存 status；Status 面板合并 live `contextTimeline` 投影导致切换 tab 抖动。
* 修复失败触顶后计数不复位、提示语报的是硬编码值；纯文本成功也能清空连败。
* 修复压缩换窗后图片消息被一并挤掉（最多回填 8 条带图用户消息，老图仍走 durable offload）。
* 修复 Anthropic 请求级 `temperature` 只吃适配器默认值、从不生效。
* 修复本地存储写入风暴：去抖 120ms + 跳过相同内容，超大草稿截断而非撑爆配额 / 卡死主线程；菜单在保持关闭时不再每次父级重建就 setState（React #185 抖动）。
* 修复长会话滚动后越用越卡：对话图片 objectURL 缓存设软上限 96 张。
* 修复 Overview 折叠状态 / 快捷键覆盖 / 内容宽度偏好每次事件同步读 localStorage：改为读盘去抖 + 内存镜像，ResizeObserver 抖动不再读盘。
* 修复侧栏底部默认自动弹出终端面板（首次打开文件不再先闪一块空底部面板）。
* 修复 context-fragments 的 Guardian review provider 与 `guardianFragments` 开关：移除后 `additional_context` 行在 Chat 里隐藏，不再每轮刷屏。

### Added

* **Edit and resend** a user message: the original text loads back into the composer and a three-way confirm offers cancel / resend without reverting files / resend and revert files. While editing, the composer shows a hint banner with a cancel button, the target bubble gets a highlight outline, and Esc (or clearing the draft) exits edit mode.
* **Delete this message and after** (user messages only): confirms, then forks a session truncated before that point and switches to it; “revert files” also rolls the original session's workspace back with `/rollback seq:N`.
* A **steer** (jump the queue) action on every queued row, disabled while busy with an explanatory tooltip.
* Attachments for queued messages: editing a queued row keeps its attachments, and files can be attached to a queued message.
* **Pin / unpin workspaces**: a pin button, pinned rows first, order persisted and broadcast via `host/pinned-workspaces-changed`.
* Canvas `callout` blocks and `tone` colors (neutral · good · warn · bad · accent) for KPI values, callouts, and chart bars; `md` joins `markdown` as a paragraph alias.
* A per-event streaming **idle watchdog** (5 minutes by default, restarted by every event): a silent provider fails the turn instead of hanging forever, while long answers keep streaming. Wired in all four adapters.
* `scripts/check-design-tokens.mjs`, a design-system self-check: undefined `--dsw-*` / `--ds-*` tokens, WCAG AA contrast on text tokens, and the focus-ring contract — exit code 1 on violation.
* `skills-lock.json` pinning the source and checksum of 8 bundled third-party skills.

### Improved

* Per-turn file chips split into **created / changed / deleted** lanes, classified by their final state (a file created then deleted shows only as deleted).
* Overview presence ball: collapsible to a compact chip (single-line label, full text on hover), remembered across reloads, and re-rendered only when the mood actually changes — its animation no longer restarts on every stream tick.
* Auto-review: `/auto-review approve N` and HTTP `/auto-review/approve` **actually release the pending Face approval** (they previously only cleared the counter) and report allowed / clearedRecentDeny / note. Stats gain `fallbacks`, `neverRejects`, and real average classify time (the Face projection no longer divides by one sample).
* Classifier failure tolerance: a technical fault or malformed classifier output degrades to one normal Face approval prompt (`onClassifierError` can fail closed with deny) instead of silently blocking or allowing. The session-model reviewer receives role-tagged history (human-instruction / direct-parent-instruction / constraint / checkpoint / fact) with assistant text and tool results stripped.
* Review order: auto-review runs at the very front of the pipeline, ahead of the hardline / policy / read-only soft floors, and `defer-ask` lets a later deny / ask replace it.
* Code Mode: the `run_code` transport itself is not reviewed, while every `await tools.*` inside the program goes through the same pipeline exactly once.
* LLM retries use a **blacklist**: only certain-to-fail codes are excluded; transport errors, timeouts, 5xx, rate limits, empty responses, truncated tool JSON, and unknown exceptions all retry.
* Execution feedback: failed background jobs now truncate output from the **end** so the real error (`Error:`, stack head, `npm ERR!`) survives, and a child that exits naturally is settled after 2 seconds even when an orphaned grandchild still holds the pipe.
* Attachment contract: an attachment id is its own durable address, documented in tool descriptions, seed copy, and docs, so any image or file in chat can be traced and reopened by id alone.
* Subagents: answers over 12 KB spill to disk and come back as a `read_file` path plus a head/tail preview; cancel reasons read as `aborted by user` / `aborted by parent` / `session disposed` / `aborted by hook: …` instead of `[object Object]`; liveness is judged across the whole descendant tree so a busy grandchild no longer marks its parent completed.
* Sidebar contract: liveness shares Overview's predicate (drain latch active **or** external acp / app-server busy), so the task board stops showing ACP subagents as completed.
* Stats: time-to-first-token now counts a reasoning first token as its boundary and drops decode windows shorter than 50 ms, so throughput numbers stop being fictional.
* Editing and workspaces: a 420 ms long-press arms workspace drag reordering (touch sortable, no accidental child-session expand); the composer, command-palette search, and rename box share one branded focus ring with a global fallback; popover layers use `--ds-z-popover/scrim/surface` tokens.
* Mobile and dark mode: `--ds-safe-*` variables keep fixed panels and overlays clear of notches and home indicators; dark-mode toolbar buttons are light translucent instead of near-black.
* Scrolling: tool output, diff, and panel areas contain their own overscroll so they no longer scroll the page behind them.
* Dialogs and slots: dialogs trap focus and return it to the trigger on close; a failed slot shows a one-line crash summary.
* Edit-resubmit forks (`beforeSeq`) inherit the parent session's selected model.
* Documentation brought in line: auto-review tiers and `resolveDenyAction` / `onClassifierError` (`docs/configuration.md`), the attachment tracing contract (`docs/modules/attachment.md`), delegation liveness invariants (`docs/session-latch.md`), Code Mode PTC review boundaries (`docs/code-mode.md`), and the recommended sidebar-plugin version (`docs/community-plugins.md`).

### Fixed

* Queued messages no longer turn into ghost rows or vanish mid-flight: the host queue rows and the local “sending” echo share one dock, and the local echo only moves into the transcript once the host claims it FIFO. The steering echo merges with the host's next-step row so the “steering” badge stops flickering.
* The running indicator no longer clears early on `turn/end` while queued or steering work is still outstanding (Stop used to look idle).
* The pending-send rpcId is attributed only to the user's own message; skill-catalog / agent-instructions durable injects no longer take the slot (which produced a duplicate bubble and a stuck blue waiting card).
* One click on Stop kills every running / stopping background task in the session — no repeated clicks, no stray “background task finished” toasts.
* A failed `continueTurn` no longer silently swallows every later queued message; the loop exits on failure while abort still propagates.
* Reopening a large Session's Overview no longer borrows another session's cached status, and the Status panel no longer re-derives context on every tab switch (which caused jitter).
* The repeated-failure counter resets once it trips and reports the real limit, and a text-only reply clears the streak.
* Image messages survive a compaction window swap (up to 8 recent user messages with images are restored; older images still go through durable offload).
* A per-request `temperature` is honored on Anthropic instead of silently using the adapter default.
* Local-storage write storms: 120 ms debounce with identical-content skipping, oversized drafts truncate instead of exhausting the quota or freezing the main thread; a closed menu no longer `setState`s on every parent render (React #185 jitter).
* Long sessions stop slowing down as you scroll: conversation image objectURLs are capped at 96 entries.
* Overview fold state, shortcut overrides, and content-width preferences use a debounced read plus an in-memory mirror, so ResizeObserver jitter no longer reads localStorage synchronously.
* The sidebar no longer auto-opens a terminal panel by default (the first file open no longer flashes an empty bottom panel).
* The context-fragments Guardian review provider and `guardianFragments` switch are gone, and `additional_context` rows are hidden in Chat instead of repeating every turn.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.7`** (owns npm `@latest`); npmjs keeps **0.5.7** and rollback pin **0.3.11**.
* Desktop private shell version aligned to **0.5.7** (`package:desktop` artifact names follow); root / `apps/cli` / `apps/desktop` / `packages/sdk` versions move together, and the README plus docs `@latest` pointers follow this release.
