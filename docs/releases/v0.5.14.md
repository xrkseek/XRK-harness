# v0.5.14

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.13](./v0.5.13.md)：Desktop 自动更新改走产品内对话框与下载进度，发现新版本即开始预下载；Settings 底栏与 Host 重连同一槽位提示更新。

Relative to [v0.5.13](./v0.5.13.md): Desktop auto-update uses the in-app dialog and a download meter, and starts fetching as soon as a newer build is on the feed; Settings foot shows the notice in the same slot as Host reconnect.

### 新增

* Desktop 更新确认与进度使用产品 `Modal`（安装百分比、稍后 / 安装并重启），不再依赖系统消息框。
* 未签名测包可嵌入测试更新源（`XRK_DESKTOP_UNSIGNED_UPDATE`），generic feed 指向 AGT `harness-download`。

### 完善

* 完善更新安装：feed 一旦报有新版本即开始下载；点「安装并重启」立即进入进度态，下载完成后重启。
* 完善 Settings 底栏：宽栏且 Host 未在重连时，用与重连相同的 `ConnectionIndicator` 显示当前版本或「有更新」。

### 修复

* 修复 Windows 无应用菜单时无法从界面检查/安装更新：更新入口落在 Settings 底栏芯片。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.14`**（接管 npm `@latest`）；npmjs 保留 **0.5.14** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.14**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.14
xrkh web
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.14-*-unsigned`（或签名）安装包。

## 验证

* 装低于 feed 的 Desktop 测包，Settings 旁出现「有更新」芯片；点开对话框可见进度，点安装并重启后应用换到 feed 版本。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.14`。

---

### Added

* Desktop update confirm and progress use the product `Modal` (percent, Later / Install and restart) instead of the OS message box.
* Unsigned test builds can embed a test feed (`XRK_DESKTOP_UNSIGNED_UPDATE`) aimed at the AGT `harness-download` generic origin.

### Improved

* Update install: download starts as soon as the feed reports a newer build; Install and restart enters the progress state immediately and restarts when the file is ready.
* Settings foot: on the wide rail, while Host reconnect chrome is idle, the same `ConnectionIndicator` shows the installed version or an available update.

### Fixed

* Windows had no application menu path to check or install updates: the Settings-foot chip is the entry.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.14`** (owns npm `@latest`); npmjs keeps **0.5.14** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.14**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.14
xrkh web
```

Then hard-refresh the client half. Desktop: install this release's `xrk-harness-0.5.14-*-unsigned` (or signed) package.

## Verify

* Install a Desktop test build older than the feed: the Settings-foot chip offers the update; the dialog shows progress; Install and restart lands on the feed version.
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.14`.
