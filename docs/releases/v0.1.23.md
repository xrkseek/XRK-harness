# v0.1.23

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.22](./v0.1.22.md)：纯 HTTP LAN 访问 Web UI 不再因 `crypto.randomUUID` 缺失而崩溃。

Relative to [v0.1.22](./v0.1.22.md): Web UI on plain HTTP LAN hosts no longer crashes when `crypto.randomUUID` is unavailable.

---

## 修复 / Fixed

* 修复 **`http://192.168.x.x:端口`** 等非 secure context 下 Web UI 报 `crypto.randomUUID is not a function`、无法发 RPC 的问题
* 修复草稿图片附件 id 在纯 HTTP 访问时同样触发上述错误

---

## 完善 / Improved

* 完善客户端 UUID：`randomUuid()` 在 HTTPS / localhost 仍优先原生 `crypto.randomUUID()`；LAN HTTP 回退 `crypto.getRandomValues()` 生成 RFC 4122 v4，熵源与原生一致

---

