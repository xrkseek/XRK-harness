# v0.8.7

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.6](./v0.8.6.md)：手机折叠行恢复类型图标；工作台刷新不再重复下载；划词/右键菜单与贴边跟滚；手机表情球偶发「只剩眼镜」；协作乒乓 framing。

### 完善

* **对话折叠行**：思考 / 命令 / 工具 / Skill 左侧固定类型图标，展开状态只走右侧 › / ∨；手机不再整行变成下角 ∨。
* **划词与右键**：选区菜单更矮、优先贴选区上方；触屏贴边跟滚速度更稳；选区不再顶进对话顶栏。
* **侧栏工作台（better-sidebar）**：薄壳自动下载同一会话路径只触发一次，刷新 / Overview 互切不会反复存盘。

### 修复

* **回到底部按钮**：折叠过程后贴底时不再把「回到底部」粘在中间跟着上移。
* **手机下载完成 sheet**：普通文件下载标题改为「文件已保存」，不再误用导出日志的「日志已保存」。
* **手机顶栏表情球**：Android WebView 不再因挂载透明度丢掉球体 `url(#gradient)` 填充；薄壳改用实色球体，眼镜/装扮仍正常。
* **协作会话**：对端互发 framing 收紧，减少乒乓误判。

### 其他变更

* 公开线版本号对齐 **0.8.7**（npm / Desktop / 手机 / 官网下载同号）。
* 第一方侧栏插件 **xrkh-better-sidebar 0.20.28**（含一次下载 latch）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.6](./v0.8.6.md): phone disclosure rows keep type icons; workbench refresh no longer re-downloads; selection / context menus and edge scroll; phone presence ball no longer loses its sphere body; peer-collab framing.

### Improved

* **Chat disclosure rows**: think / command / tool / Skill keep a leading type icon; expand state is only the trailing › / ∨ — phones no longer turn every row into a lone down-chevron.
* **Selection & context menu**: shorter menu, prefer above the selection; steadier touch edge-follow scroll; selection chrome stays out of the chat header.
* **Workbench (better-sidebar)**: thin-shell auto-download fires once per session path; refresh / Overview handoff no longer re-saves the same file.

### Fixed

* **Back-to-bottom control**: after a fold collapse at the floor, the sticky button no longer rides mid-column upward.
* **Phone download sheet**: ordinary file downloads title as “File saved”, not the session-export “Log saved”.
* **Phone header presence ball**: Android WebView no longer drops `fill: url(#gradient)` when the mount fades; thin shell uses a solid sphere body while kits still paint.
* **Peer collab**: tighter framing so cross-session handoffs mis-classify less often.

### Other

* Public line version **0.8.7** (npm / Desktop / phone / site download share the same number).
* First-party sidebar plugin **xrkh-better-sidebar 0.20.28** (once-per-path download latch).
