# v0.4.6

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.5](./v0.4.5.md)：发送后「排队 / 插队」不再被工作区快照拖死；会话列表对坏行更容错。

Relative to [v0.4.5](./v0.4.5.md): Queue/Steer no longer stalls on workspace snapshots; session list soft-parses bad rows.

### 完善

* 完善回合前工作区影子 git 快照：与模型调用**并行**，仅在工具执行前汇合；大仓不再长时间占住「排队 / 插队」。
* 完善快照 staging：额外排除 `node_modules/`、`dist/` 等重目录；drain 软预算约 5s，超时跳过该点、不挡回合。
* 完善 `session.list`：按行 soft-parse，单行坏数据不再拖垮整表侧栏。

### 修复

* 修复 Linux CI 上 `package:desktop --check` 因 deferred 目标在 try 外抛错导致门禁失败。
* 修复非 Windows 环境下 computer-use 真实 PowerShell 超时测因 `powershell.exe` ENOENT 误失败。

### 其他变更

* 无。

---

### Improved

* Pre-turn workspace shadow-git snapshot now **overlaps the model call** and joins only before tools run, so large worktrees no longer pin Queue/Steer chrome.
* Snapshot staging excludes heavy trees (`node_modules/`, `dist/`, …); drain soft budget ~5s skips the point on timeout without blocking the turn.
* `session.list` soft-parses each row so one bad item cannot empty the whole sidebar.

### Fixed

* Fix `package:desktop --check` on Linux CI throwing on deferred packaging targets outside the catch path.
* Fix computer-use real-PowerShell timeout test failing with `powershell.exe` ENOENT on non-Windows runners.

### Other changes

* None.
