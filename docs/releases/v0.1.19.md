# v0.1.19

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.18](./v0.1.18.md)：修复历史会话打开后 **上下文** 页（`dsh-context`）一直停在「正在读取会话日志…」。

Relative to [v0.1.18](./v0.1.18.md): fixes the **Context** tab (`dsh-context`) stuck on “Reading the session log…” when opening existing sessions.

---

## 修复 / Fixed

* 修复 `session.history` 尾页未 fold `contextTimeline` / `contextHeaders`：历史会话的上下文浏览器无法从投影 store 播种，实时新会话不受影响
* 修复 `loadOlder` 分页仍只带轻量投影 key，避免 v0.1.12 式长会话 OOM 回归

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.19
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`
