# v0.7.19

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.18](./v0.7.18.md)：壳 LayoutInsets 补上概况「打开」位；手机概况与侧栏工作台互斥；插件安装/更新路径与侧栏 cwd 围栏加固；插件清单多端密度；建议侧栏 **`xrkh-better-sidebar@0.20.9`**。

### 新增

* 壳 `LayoutInsets.detailsOpen` / `data-xrk-layout-details-open`：手机全屏概况不占桌面条时，浮动工作台仍能知道概况已开。

### 完善

* 手机概况与社区侧栏：打开概况时收起/隐藏展开 FAB 与 panel host，关闭键不再与侧栏展开钮抢同一角。
* 设置 → 插件清单：窄屏 / 手机壳密度与更新徽章更清晰；包名与安装路径校验收成单真源。
* AppFrame 对 LayoutInsets 改为单路发布，避免列宽与底栏高度两条 effect 互相覆盖。

### 修复

* `/sidebar/api` 的 `cwd` / `repoRoot` 越界覆盖被忽略，仍用会话工作区作围栏（含嵌套 worktree → 仓库根）。
* 插件 `fetch-pack` / mutate 在 Windows 上不再经 `shell:true` 拼命令；包名不允许路径穿越。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.19
xrkh web
xrkh plugin add xrkh-better-sidebar@0.20.9
```

桌面安装包见 GitHub Release `v0.7.19` 与站点下载页（AGT 上线后）。手机 APK 见对应 `XRK-harness-mobile` Release（若同发）。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.18](./v0.7.18.md): shell LayoutInsets gains an Overview-open bit; phone Overview and the sidebar workbench mutually exclude; plugin install/update paths and sidebar cwd fences harden; plugin inventory density improves on multi-end; prefer sidebar **`xrkh-better-sidebar@0.20.9`**.

### Added

* Shell `LayoutInsets.detailsOpen` / `data-xrk-layout-details-open` so floating workbenches know Overview is open even when phone sheets keep details px at 0.

### Improved

* Phone Overview vs community sidebar: hide/collapse the expand FAB and panel host while Overview is open so the close control is not contested.
* Settings → Plugin inventory: clearer narrow/phone density and update badges; package-name and install-path checks share one source of truth.
* AppFrame publishes LayoutInsets on a single path so column ticks and bottom-height mirroring no longer overwrite each other.

### Fixed

* `/sidebar/api` `cwd` / `repoRoot` overrides outside the session workspace are ignored (nested worktree → repo root still allowed).
* Plugin `fetch-pack` / mutate no longer use `shell:true` on Windows; package names cannot path-escape.

## Install

```bash

xrkh web

```

Desktop installer: GitHub Release `v0.7.19` and the site download page (after AGT publish). Mobile APK: matching `XRK-harness-mobile` Release when shipped together.
