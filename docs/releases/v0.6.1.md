# v0.6.1

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

**`0.6.x` 线首个补丁**：相对 [v0.6.0](./v0.6.0.md)，这一轮把 **终端壳 `xrkh tui` 加厚**、**ACP 服务端补齐 `session/load` / `session/cancel`**、**Desktop 接管全局 `xrkh` 命令**、**权限档热切换不再重建 Agent**、**会话锁占用给出可执行的报错**，并修掉对话面一批观感错位。npm dist-tag **`@latest`** 由 `@xrkseek/harness-cli@0.6.1` 接管。

**The first patch on the `0.6.x` line**: relative to [v0.6.0](./v0.6.0.md), this round thickens the **`xrkh tui` shell**, completes the **ACP server with `session/load` / `session/cancel`**, lets **Desktop own the global `xrkh` command**, makes **permission tiers apply without rebuilding the agent**, turns **session-store lock contention into an actionable error**, and fixes a batch of conversation-chrome misseats. npm dist-tag **`@latest`** now points at `@xrkseek/harness-cli@0.6.1`.

### 新增

* **TUI 本地 slash 命令面**（对齐社区 dsh-tui 的命令习惯，仍走 Face unary，不另起运行时）：`/model [provider/]model [effort]` 切模型与推理档、`/resume [sessionId]` 列会话或续会话、`/details` 摘要（badge · 权限 · 工具 · 待审批）、`/approve` · `/deny` · `/whitelist` 审批响应、`/thinking on|off` 是否打印 reasoning、`/status` 与 Overview 同源；未识别的 `/xxx` 原样交给 Face slash。忙时输入普通行自动转 **steer**，不再排队干等。
* **TUI 16 色 ANSI 调色板**（`tui-style.ts`）：dim / accent / success / warning / error 角色化，尊重 `NO_COLOR` 与 `FORCE_COLOR`，非 TTY 自动降级无色；工具轨与流式渲染重排，长回合可读性明显改善。
* **TUI 自动附着 Desktop 内置 Host**：未指定 `--port` 时，从 `~/.xrk/run` 的 `host-<port>.pid.json` 锁里挑**最新且进程仍存活**的一条来连（`listHostLocks` / `newestLiveHostLock`），否则回落 `8787`。为此 `@xrkseek/harness-cli` 导出 `./host-lock` 子路径供桌面壳复用。
* **Desktop 全局 `xrkh` 命令开关**：Settings → 通用新增一行 Switch，打开后把 `xrkh` shim 放进桌面自管的 bin 目录并确保它在用户 PATH 最前（Windows 用 `[Environment]::GetEnvironmentVariable/SetEnvironmentVariable('Path','User')`；POSIX 侧合并 `~/.profile` · `~/.bashrc` · `~/.zshrc`）。关掉即解除链接。
* **Desktop 启动写 Host 锁**：打包壳起 Host 后写 `host-<port>.pid.json`、退出清理，因此上面那条 TUI 自动附着在「只开了桌面 App」的场景即可生效。
* **ACP 服务端补齐**：`initialize` 声明 `loadSession: true`；新增 `session/load`（仅恢复本进程仍持有的 `sessionId`，未知 id 返回 `-32002` 让调用方改走 `session/new`）；`session/cancel` 同时支持通知与带 id 的请求；`session/update` 只推**尚未推送过**的文本，重放不重复。
* **回合开头注入片段可作为注入文档读取**：`skill.list` / `skill.read` 新增 `session://capability` · `session://posture` · `session://collab-board` 三条会话层文档，内容与模型真正看到的完全同源（badge、权限档、协作板都是活数据）。
* **`session.tools` 披露计数**：新增 `surface` 分组 `system`（skill / memory / cron / lsp 等产品系统工具）与 `workspace`；每行带 `onModel`（当前是否已在模型工具线上）；信封带 `disclosure`（直连 / 延迟 / 已展开计数）——渐进披露在运行时目录页一眼可核。
* **工作区锚点带会话策略段**：注入的 workspace 锚新增 `## Session policy`（badge 与权限标签各一行），模型不再靠猜自己这一轮的档位。
* **cron 任务目录上移到会话顶栏**：与 对话 / 轨迹 / 注入 / 运行时 并列；agent 任务按创建时 `workspaceId` 只显示本工作区，script 任务留在 Settings 的全局账本视图。
* **技能目录页重组**：按来源分筛选片（工作区 `.xrk` / 工作区 `.agents` / 主目录 `.xrk` / 主目录 `.agents` / 其他供应商），供应商识别覆盖 xrk / agents / cursor / claude / codex，正文预览与搜索分组一并加厚。

### 完善

* **权限档与可写根改为活读取**：`exec/fs` 的 `pathAccessMode` · `extraWritableRoots` · `hostReadableRoots` 可传 getter，每次 resolve 现读——`/permission` 切换或 Settings 改可写根**不再需要重建 Agent**，也不再有「界面已切、工具还按旧闸」的窗口期。
* **编排工作区 shell 与路径闸对齐**：IM / 向阳空间的 `readSandboxMode` 直接给 `danger-full-access`，不再套 shell confine（此前权限行显示完全访问、shell 仍被钉在 workspace 的矛盾消失）；向阳迁移会把历史遗留的 `workspace-write` 钉升级成完全访问。
* **会话锁占用报错可操作**：锁住时消息带上锁文件路径、持有者 PID 以及**该进程是否还活着**，并给出对应下一步（退出其它 Host / 删除陈旧锁）；发现持有者已死会自动清一次陈旧锁再重试。
* **本地 echo 到持久化用户消息同一组件同一 key**：回合标签与动作条不再因日志写入而重挂载闪动；只有句柄文本、没有读者可见内容的用户行（如模型侧图片说明）不再额外长出一个回合标签和动作条。
* **侧栏会话 hover 卡**加一行支线（sideline）与 badge（agent preset），主线信息同卡展示；轨迹图空态文案改为可本地化（不再硬钉 "No timing data"）。
* **划词翻译给出可见结果**：翻译是异步取回、手势窗口早已关闭，原先只静默写剪贴板；现在同时以 toast 展示译文（剪贴板照旧写入）。
* **图片卡不再复读模型信封文本**：`read_image` 结果里的 sha256 / 尺寸信封是给模型的说明，工具卡正文清空，只留图与句柄；预览尺寸按**解码后真实位图**取大者，展开查看不再卡在缩略图尺寸。
* **cron 启动失败原因不再被吞**：桌面壳调度器重试后如实抛出首个错误（会话锁 / 缺 node 等原因可见），此前会被替换成一句泛化文案。

### 修复

* **修复打包桌面把 `resources/host` 当工作区**：桌面启动时把工作区解析到向阳空间（`~/.xrk/xiangyang-workspace`），不再在 `resources/host` 里建编码工作区、也不再让新建会话落进 Host 安装目录。
* **修复已翻到最早仍显示「加载更早」**：`session.loadOlder` 的 `hasMore` 现在同时要求 `baseSeq > 1`，会话头部的本地回声不再被当成还有历史可翻。
* **修复欢迎公告停在 0.1.x**：Desktop 与 Web 的 welcome notice 版本戳刷新到本轮，正文改为「当前公开版本是 0.6」，不再引导用户去读三个大版本前的缺口清单。
* **修复 Windows 全局 PATH 被写坏**：早期用 `reg query` 读用户 Path，长值会被控制台宽度折行，回写时整条 Path 被碎片覆盖。现改用 .NET Environment API 读写，且只前置自己的 bin 目录、保留其余原值。
* **修复 `session/search` 与注入目录在切会话后串用旧根**：skill 文档与注入列表按 `resolveSessionCwd` 的**会话**根解析，多工作区下不再列出别的工作区的注入文档。
* **修复协作板在没有任何主线钉时空无一人**：无钉窗口时改为列出**未挂钉的父会话**对等行（最多 8 条，标出自身 `*`、支线、running），`thread_message` 仍不要求双方挂钉。
* **修复若干对话面锚点/样式错位**：插话 pending 气泡分组、回合尾引用最早 turn、注入行 pending 态、上下文菜单手势窗口与键位路由。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.6.1`**（接管 npm dist-tag **`@latest`**）；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。
* Desktop 更新源同步 **win-x64 未签名测试包** `xrk-harness-0.6.1-win-x64.exe`（先传 exe/blockmap 再传 `nightly.yml` / `latest.yml`）。
* 教科书同步：`docs/acp.md`（`session/load` · `session/cancel`）· `docs/cron.md`（会话顶栏任务目录）· `docs/host-face.md`（`session.tools` 披露 / 会话层注入文档）· `docs/status.md` · `apps/cli/README.md`（TUI 命令面与自动附着）。

## 验证

* 只开桌面 App → 另开终端直接 `xrkh tui`：应自动连到桌面内置 Host 端口，`/details` 打出 badge 与权限档，`/model` 可切模型，忙时输入立刻变插话。
* Settings → 通用：打开 `xrkh` 命令开关后新开终端 `xrkh --version` 可用；关掉后链接解除且用户 PATH 其余条目未被破坏。
* 会话顶栏：出现「任务」页，只显示本工作区的 agent 定时任务；Settings → 插件里的全局任务目录仍在。
* 注入目录：能看到 `session://capability` / `session://posture` / `session://collab-board` 并可读正文，内容与 Trajectory 里实际注入的一致。
* 权限：在编码会话 `/permission` 从 workspace-write 切到 danger-full-access，立刻用 `read_file` 读工作区外绝对路径应直接放行，无需重启 Host。
* 两个 Host 抢同一数据目录：第二个进程的报错里能看到锁文件绝对路径与「PID 是否存活」。
* ACP：`session/load` 未知 id 返回 `-32002`；`session/cancel` 带 id 的请求同样能中止进行中的回合。

### Added

* **Local slash commands for `xrkh tui`** (command habits aligned with community dsh-tui, still Face unary — no second runtime): `/model [provider/]model [effort]`, `/resume [sessionId]`, `/details` (badge · permission · tools · pending approvals), `/approve` · `/deny` · `/whitelist`, `/thinking on|off`, `/status` sharing the Overview source; unknown `/xxx` passes through to the Face slash. While a turn is running, a plain line becomes a **steer** instead of queueing silently.
* **16-color ANSI palette** (`tui-style.ts`): dim / accent / success / warning / error roles, honoring `NO_COLOR` / `FORCE_COLOR` and dropping color on non-TTY; tool rail and stream layout reworked for long turns.
* **TUI attaches to the Desktop-embedded Host**: without `--port` it picks the **newest still-alive** lock under `~/.xrk/run` (`listHostLocks` / `newestLiveHostLock`), else falls back to `8787`. `@xrkseek/harness-cli` now exports the `./host-lock` subpath so the desktop shell can reuse it.
* **Desktop-owned global `xrkh` command**: a Settings → General switch installs the `xrkh` shim into a desktop-managed bin dir and keeps it first on the user PATH (Windows via `[Environment]::GetEnvironmentVariable/SetEnvironmentVariable('Path','User')`; POSIX merges `~/.profile` · `~/.bashrc` · `~/.zshrc`). Turning it off unlinks.
* **Desktop writes a Host lock** on boot and clears it on exit, so the auto-attach above works with only the desktop app running.
* **ACP server completed**: `initialize` declares `loadSession: true`; new `session/load` resumes only ids this process still holds (unknown ids → `-32002` so callers fall back to `session/new`); `session/cancel` accepts notification **or** request with id; `session/update` emits only text not already streamed.
* **Turn-start fragments are readable inject documents**: `skill.list` / `skill.read` gain session-layer entries `session://capability`, `session://posture`, `session://collab-board`, rendered from the same live data the model actually receives.
* **`session.tools` disclosure counts**: new `surface` groups `system` (skill / memory / cron / lsp …) and `workspace`; every row carries `onModel`; the envelope carries `disclosure` (direct / deferred / expanded) so progressive disclosure is checkable on the Runtime tab.
* **Workspace anchor states session policy**: injected anchor now includes a `## Session policy` block (badge + permission label) so the model stops guessing its tier.
* **Cron directory promoted into the session header** beside Chat / Trajectory / Inject / Runtime; agent jobs filter by the `workspaceId` stamped at creation, script jobs stay in the global Settings ledger.
* **Skills catalog reshaped**: filter chips by origin (workspace `.xrk` / workspace `.agents` / home `.xrk` / home `.agents` / other vendors) with vendor detection covering xrk / agents / cursor / claude / codex, plus thicker grouping, search and body peek.

### Improved

* **Permission tier and writable roots read live**: `exec/fs` accepts getters for `pathAccessMode`, `extraWritableRoots`, `hostReadableRoots`, re-read on every resolve — `/permission` flips and Settings root edits **no longer rebuild the agent**, closing the window where the UI had switched but tools still enforced the old gate.
* **Orchestration workspaces align shell with the path gate**: IM / Xiangyang `readSandboxMode` returns `danger-full-access` (no shell confine); the Xiangyang migrator upgrades leftover `workspace-write` pins.
* **Session store lock errors are actionable**: the message now names the lock file path, the holder PID and **whether that process is alive**, with the matching next step; a dead holder's stale lock is cleared once before retrying.
* **Local echo and the durable user node share one component and key**, so the round label and action strip no longer remount and flicker; caption-only user rows (model-facing handle text with nothing reader-visible) stop growing a second bubble.
* **Sidebar hover card** gains sideline and agent-preset lines plus 主线 in the same card; Trajectory empty-state copy is now localizable instead of a hard-coded "No timing data".
* **Selection translate shows its result**: the fetch is async and the gesture window is long gone, so the translation now also surfaces in a toast (clipboard still written).
* **Image card stops echoing the model envelope**: the sha256 / size text meant for the model is dropped from the card body, and the preview sizes itself to the **decoded bitmap** so expanding is no longer stuck at thumbnail scale.
* **Cron start failures are no longer swallowed**: the desktop scheduler rethrows the first real cause (session lock, missing node) after retries instead of a generic line.

### Fixed

* **Packaged Desktop no longer treats `resources/host` as a workspace**: boot resolves the workspace to the Xiangyang home, so New Session does not land inside the Host install directory.
* **"Load older" no longer sticks at the very beginning**: `session.loadOlder` now requires `baseSeq > 1` for `hasMore`, so the local echo at the head of a session is not mistaken for more history.
* **Welcome notice no longer describes 0.1.x**: the Desktop and Web welcome stamps move to this round and the body says the current public release is 0.6, instead of pointing at gaps three majors old.
* **Windows user PATH is no longer corrupted**: reading Path via `reg query` wrapped long values at console width and writing the fragments back replaced the whole value; the .NET Environment API is used now and only the desktop bin dir is prepended.
* **Session search / inject catalog no longer leak another workspace's root** after switching sessions: skill documents resolve through the **session** cwd (`resolveSessionCwd`).
* **Collab board is never empty when peers exist**: with no pins it lists unpinned parent sessions (max 8, marking self `*`, sideline and running); `thread_message` still requires no pins.
* **Conversation chrome misseats**: pending steer bubble grouping, turn-tail citation of the earliest outline turn, inject-row pending state, context-menu gesture window and key routing.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.6.1`** (takes over npm dist-tag **`@latest`**); `apps/cli` / `apps/desktop` / `packages/sdk` move together.
* Desktop update feed synced with the **win-x64 unsigned test build** `xrk-harness-0.6.1-win-x64.exe` (exe/blockmap first, then `nightly.yml` / `latest.yml`).
* Textbook sync: `docs/acp.md` (`session/load` · `session/cancel`) · `docs/cron.md` (session-header Tasks) · `docs/host-face.md` (`session.tools` disclosure / session inject docs) · `docs/status.md` · `apps/cli/README.md` (TUI command surface and auto-attach).

## Verify

* Launch only the desktop app, then run `xrkh tui` in a terminal: it should attach to the embedded Host port; `/details` prints badge and permission, `/model` switches, a plain line while busy becomes a steer.
* Settings → General: enable the `xrkh` command switch, then `xrkh --version` works in a fresh terminal; disable it and the link is removed while the rest of the user PATH survives.
* Session header: a **Tasks** tab appears showing only this workspace's agent jobs; the global ledger stays in Settings → Plugins.
* Inject catalog: `session://capability` / `session://posture` / `session://collab-board` are listed and readable, matching what Trajectory shows as actually injected.
* Permissions: flip a coding session from workspace-write to full access with `/permission`; `read_file` on an absolute path outside the workspace works immediately, no Host restart.
* Two Hosts on one data folder: the second one reports the lock file path and whether the holder PID is alive.
* ACP: `session/load` on an unknown id returns `-32002`; `session/cancel` as a request with an id also aborts the in-flight turn.
