# v0.0.8

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.7](./v0.0.7.md)：工作区注入改为可对账的会话事件；产品 skills / 笔记分层更清晰；PTY 误用聊天 session id 时提示更明确。

### 新增

* 新增工作区站立上下文持久注入：skill 目录与 assistant/rules 等写入带 `source` 的 `user/message`（`skill-catalog` · `agent-instructions`），聊天「上下文注入」与 Trajectory 可对账
* 新增 skill frontmatter：`disable-model-invocation` · `user-invocable`（对齐 DSH；非法布尔则丢弃该 skill）
* 新增教科书 [skills-layers](../skills-layers.md)：笔记 / 产品 rules / 产品 skills 分层说明

### 完善

* 完善三层 assemble：产品 inject 不再塞进 system，persona 前缀更稳，利于 prompt cache
* 完善 Face：`user/message.source` 透传；标题 / lastPrompt 只认人类 `source.kind=user`
* 完善 PTY：工具说明与 `NO_SESSION` 提示区分 `pty-N` 与聊天 `sess_…` id
* 完善本仓 `.cursor/skills`：标记为不可模型调用 / 不可斜杠，避免以本仓为 workspace 时灌进产品 Agent

### 修复

* 修复模型把 volatile 聊天 session id 当成 terminal sessionId 时只报裸 `unknown PTY session`、缺少纠正提示的问题

```bash
npm install -g @xrkseek/harness-cli@0.0.8
xrk-harness web
```
