# v0.1.18

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.17](./v0.1.17.md)：对话流式 Think 即时可见；断线重连与排队插话反馈更清晰；取消后 Stop 与插话门控对齐 Host 运行态。

Relative to [v0.1.17](./v0.1.17.md): streaming Think paints live; reconnect and queue-steer feedback are clearer; Stop vs steer gates follow Host running vs drain latch.

---

## 完善 / Improved

### 对话壳

* 完善重连：顶栏重连条；重连期间锁定输入并提示
* 完善排队：dock 行可聚焦 Enter 插话（与行内插话按钮同操作）；插话窗口关闭时提示消息仍保留在排队中
* 完善繁忙输入提示：有草稿且智能体运行时，placeholder 标明 Enter / Cmd+Enter 的排队与插话配对
* 完善会话回放：settling 阶段保留 composer 可见，避免输入区闪没

### 协议 · Session

* 完善 `llm/retry`：流式 chunk 实时落库；折叠/修复打开 turn 时只采最近一次 retry 之后的 chunk，避免把失败尝试画进最终回复

---

## 修复 / Fixed

* 修复流式 Think / 正文被 `invokeLlmWithRetry` 整段缓冲，复杂任务长时间只显示 idle「Deep diving」类文案
* 修复主会话取消后 `running` 已清但 partial / 工具尾仍在时，主按钮过早变回发送（现与 Stop drain latch 对齐）
* 修复子代理会话在输入区仍可粘贴图片、直到发送才失败（intake 即拒绝）
* 修复整队列插话遇已领取行时整段中止，后续排队项不再 flush
