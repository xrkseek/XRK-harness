# v0.6.14

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.13](./v0.6.13.md)：**会话跑完可桌面提醒**；**Host 升级后提示刷新壳**；**限时提问 + 超时后补答可 steer**；**有活任务时拒绝静默归档**；**子代理长答落盘可再读**；侧栏 **Plugins / 发行说明改紧凑双格**；**概况委派图线 / 幽灵节点 / 文案密度**。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.14`（发包后）。

Relative to [v0.6.13](./v0.6.13.md): **OS notify when a session finishes**; **reload prompt when Host version drifts**; **timed ask_user with late-answer steer**; **archive refuses while work is live** (force to override); **long subagent answers spill to disk**; sidebar **Plugins + release notes share a compact strip**; **Overview graph edges / ghost nodes / copy density**. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.14` (after publish).

### 新增

* **会话完成桌面通知**：后台跑完、窗口未聚焦时提醒（聚焦中不打扰）。
* **Host / 壳版本错位检测**：重连后 `host.describe` 与壳 stamp 不一致时提示刷新，避免旧壳挂新 Host。
* **限时 `ask_user`**：`mode: "timed"` 可设超时；超时后工具先结案，晚到的回答改走 steer。
* **归档准入**：回合 / 作业 / 子代理仍在跑时拒绝静默归档，需显式 `force`。
* **子代理长答 spill**（ADR-0011）：超长末条答案落 `~/.xrk/spill/tool-outputs/`，父会话拿预览 + 路径，要全文再读文件。
* **侧栏 `sidebar.utility.compact`**：Plugins 与发行说明并排紧凑格，不再占满 utility 行。

### 完善

* **会话列表组装让路**：Host 侧列表按工作切片（约 16ms）让出事件循环，取消不返回半截列表。
* **流式工具参数预览**：工具卡可从未闭合 JSON 前缀读已闭合字符串字段，不必等整段 args。
* **压缩 / 表面估计 / SQLite journal**：长会话落盘与压缩路径更稳；维护者可跑 `pnpm perf:gate`。
* **概况委派图**：只画委派树（不画 sibling peer 乱弧）；线与节点对齐；文案本地化（运行中 / 终态 / 并发槽），去掉 `live` · `4n/5e` · `q=` 调试腔。

### 修复

* **提问等待与 drain**：限时提问与 wait-drain-idle 边界用例补齐，避免超时与晚答抢结案。
* **工作区 Face**：归档活动收集与相关测例对齐，减少「看起来没活却归档失败」的歧义。
* **委派图幽灵节点**：已关闭子会话不再以「观察方」挂在图上；Status 只投影仍在 store 的节点。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.6.14
xrkh web
```

或 `npm i -g @xrkseek/harness-cli@latest`（发包后）。

## 验证

* 未聚焦窗口跑完一轮：出现完成通知；聚焦中不弹。
* Host 升版后重连：壳提示刷新；硬刷后 stamp 对齐。
* `ask_user` timed 超时后补答：模型侧收到 late-answer steer，而非二次阻塞。
* 子代理有活 turn 时 archive：拒绝并列出活动；`force` 可停并归档。
* 超长子代理答案：父会话可见 spill 预览路径，`read_file` 可读全文。

---

### Added

* **Desktop completion notify**: fires when a session stops running and the window is unfocused.
* **Host/shell release mismatch**: after reconnect, prompt reload when `host.describe` disagrees with the shell stamp.
* **Timed `ask_user`**: `mode: "timed"` with timeout; late answers steer instead of re-blocking the tool.
* **Archive admission**: refuse silent archive while a turn / job / subagent is live; require `force`.
* **Subagent answer spill** (ADR-0011): long final answers land under `~/.xrk/spill/tool-outputs/` with preview + path for the parent.
* **`sidebar.utility.compact`**: Plugins and release notes share a compact two-up strip.

### Improved

* **Fair list assembly**: Host list building yields on ~16ms work slices and never returns a partial list on cancel.
* **Streaming tool-arg preview**: tool cards can read closed string fields from an incomplete JSON prefix.
* **Compaction / surface estimate / SQLite journal**: steadier long-session persistence; maintainers can run `pnpm perf:gate`.
* **Overview delegation graph**: paint the delegates tree only (no sibling peer arcs); edges stay aligned with nodes; localized copy (running / outcomes / slots) instead of debug chips.

### Fixed

* **Timed ask vs drain**: timeout and late-answer settlement no longer race each other.
* **Workspace Face archive activity**: clearer refusal when work is still live.
* **Ghost graph nodes**: closed children no longer linger as observers; Status only projects nodes still in the store.
