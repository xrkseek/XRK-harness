# v0.4.0-rc.3

> **读者 / Audience**：终端用户 · 插件与集成者（发行说明）

相对 [v0.4.0-rc.2](./v0.4.0-rc.2.md)：概况栏与侧栏工作台互斥；终端打开可见；策展记忆与站立计划会话隔离。

Relative to [v0.4.0-rc.2](./v0.4.0-rc.2.md): overview and sidebar workbench no longer fight for the right chrome; terminal opens paint; curated memory stays out of the session todo queue.

---

## 完善 / Improved

* 概况栏（`details`）与 `xrkh-better-sidebar` 互斥：开概况时侧栏收起并让出右上角关闭控件
* 策展记忆系统提示始终带策略段：`MEMORY.md` 只留跨会话事实；未完成工作用会话内 `todo_write`
* 概况栏去掉与标签重复的说明文案，标题与关闭控件更易点

## 修复 / Fixed

* 仅开终端标签时右侧工作台不再留空白 chrome（终端打开也展开面板）
* 新会话不再把上一会话写进 `MEMORY.md` 的进度笔记当成「接着干」的任务队列

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.4.0-rc.3
xrkh web
```

也可 `npx @xrkseek/harness-cli@0.4.0-rc.3 web`，或 `@rc`。预览线不覆盖 `@latest`：日常安装仍用 `npm install -g @xrkseek/harness-cli@latest`（v0.3.11）。

侧栏请升级：`xrkh plugin add xrkh-better-sidebar@0.18.6`，然后硬刷新 Web。

SDK：`pnpm add @xrkseek/harness@0.4.0-rc.3`

GitHub Release 资源：`xrkseek-harness-cli-0.4.0-rc.3.tgz` · `xrkseek-harness-0.4.0-rc.3.tgz`
