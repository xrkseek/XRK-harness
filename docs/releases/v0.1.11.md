# v0.1.11

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.10](./v0.1.10.md)：修复工作区 inject 与 `session.list` 导致的严重卡顿与上下文膨胀；inject 预算与缓存对齐 DSH / Codex 渐进披露。

Relative to [v0.1.10](./v0.1.10.md): fixes severe stalls and context bloat from workspace inject and `session.list`; inject budget and caching aligned with DSH / Codex progressive disclosure.

---

## 完善 / Improved

* 完善 workspace inject：跨 turn 复用 injector 与磁盘指纹缓存，digest 未变且文件未改时跳过整轮 inject 扫描
* 完善 skill 发现：目录 mtime 指纹缓存、仅读 `SKILL.md` 前 16KiB 取 frontmatter、跳过 `node_modules` / `.git` 等目录
* 完善 inject 预算：统一 `injectMaxChars` 池；durable skill catalog（XML）单独计入预算，preview 用 markdown 不占模型上下文
* 完善 ecosystem 指令收集：单文件 256KiB 上限、目录深度与 budget 耗尽时早停

---

## 修复 / Fixed

* 修复 v0.1.10 每轮全量扫描 `~/.agents/skills`（数百个 skill）导致分钟级等待与 OOM 的问题
* 修复 skill catalog 未裁剪时把全部 skill 写入 XML inject、挤爆上下文并截断回复的问题
* 修复 skill catalog 与 preview markdown 双重占用同一 inject 预算的问题
* 修复 `session.list` 为每个会话加载完整 events 导致内存与列表接口变慢的问题（冷会话走 `listHints` 轻量路径）

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.11
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.1.11 web` · `npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后开**新会话**；工作区指向具体项目目录，勿用 Desktop 根目录作 cwd。
