# v0.8.13

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.12](./v0.8.12.md)：等待可软脱离、技能 / 延迟工具渐进披露，以及壳浮层、装扮同步与若干前缀缓存收口。

### 新增

* **停止等待**（`session.yieldWait`）：`wait_agent` / 对端同步等待 / 前台 `subagent` 等待可软脱离——**只结束等待，子任务与对端继续跑**，完成后仍走 steer handoff；插队 admit 同效。硬 Stop / `session.cancel` 仍整轮 abort。输入区 dock 按钮文案即「停止等待」。
* **`skill_search`**：站立技能目录改为**仅名**；模糊搜返回 blurb，再 `skill` 拉正文（与 `tool_search` 对称）。
* **壳 Escape 层栈**：嵌套 Modal / 面板按「后开先关」消费 Escape，不再依赖监听注册顺序。
* **主题容器名 + z-index 阶梯**：`containers.css` 具名 `@container`；`interaction.css` 提供 `--ds-z-*` 浮层阶梯（插件开发教科书已写）。

### 完善

* **延迟工具默认不上站立 `tools[]`**：`browser_*` / vault、`terminal_*`、`computer_use`、`job_*` / `cronjob` / `propose_skill` 标 `deferred`，经 `tool_search` 再展开；浏览摘要更短，关键字可部分匹配（与 `skill_search` 共用 fuzzy）。`tool_search` 描述只写多数席位共有包（**不**把向阳专属 `settings_*` 写进全局文案）。
* **协作看板渐进披露**：干员名册 turn-start 只注 spawn-id（brief 走 `team_list`）；空闲窗**不再倾倒**未钉主线的 peer 表（找球走 `session_search`，`session_*` 保持 Direct）。
* **上下文占用**：Status 时间线按 provider prompt 等比对齐各色段；圆环工具行保留启发式，差额进对话消息（总数跟上游）。
* **工作区约定注入**：`.agents/context/**` 不再站立灌入（按需经 skill / AGENTS 指针）；经理席才注 `.cursor/rules/**`；站立 `AGENTS` / `SOUL` / `XRK` 种子收薄。
* **工具结果**：写入剪枝保留 spill 全文路径；去掉未接线的 token 预算死路径（只留字节上限）。
* **`request/header`**：系列内后续条目优先写 `systemTokens` / `systemHash` / `toolsTokens`，少落整段 system 正文；进程内缓存有界。
* **Stop 结算**：工具 mid-flight 忽略 signal 时，取消后不再把晚到的成功写成正常 `tool/result`；chunk 路径遇 abort 早退。
* **定时任务**：有 Face 时按老板身份 `session.prompt` 入队 drain，与点发送同路径。
* **壳浮层锚定**：统一 `useAnchoredPosition`（作业菜单、上下文环、Tooltip 等 portal + 视口 clamp）；手机作业菜单不再误让概况 inset。
* **IME**：Goal 编辑 / 提问框 Enter 经 `isComposingKeyboardEvent`，组字中不误提交。
* **确认对话框**：清除 Goal、删除干员成员改为 Modal 确认。
* **装扮同步**：名册 live look **整表替换**；清贴纸走空串上线，概况 / 左轨不再残留旧 overlay。
* **模型设置**：保存 / 删提供方后 `load({ soft: true })`，不再整卡 loading 冻死默认模型选择；删除对话框始终可关。
* **槽位窄列**：header / composer 座位 `data-slot-layout`；金样 `example-shell-pet` 示范控件自保（`flex:none` / nowrap）。
* **投影 / 列表**：session-projection 视图浅比较；checkpoint / context / turn-outline 等投影路径收紧。

### 删除

* 站立 system 里的 `tool:skill` 长讲义（契约落在工具描述 + skill-catalog 页脚）。
* Spill / agent-loop 的 `maxInlineTokens`（从未接线的假配置）。
* 未使用的 `createDefaultOutbound` 默认链组装入口。

### 修复

* 前台 `subagent` 等待时输入区也会出现「停止等待」（与 Face `WaitYieldHub` 对齐）。
* 「停止等待」dock 跟 `host/session-wait-yield` 专帧，不再靠工具名猜测；硬 Stop 的 `running:false` 不会误清 dock。
* 干员装扮改贴纸后概况 / 侧栏仍显示旧自定义脸。
* 设置里改默认模型或删提供方时整段 UI 像卡住。

### 其他变更

* 公开线版本号对齐 **0.8.13**（npm / Desktop / 手机 / 官网下载同号）。
* 教科书：`workspace-inject` / `skills-layers` / `session-delivery` / `session-optimize` / `client-plugin-development` / `status` 已跟本版行为。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.12](./v0.8.12.md): soft-detach waits, progressive skill/deferred-tool disclosure, shell overlays, dress sync, and more prefix-cache hygiene.

### Added

* **Stop waiting** (`session.yieldWait`): soft-detach for `wait_agent` / peer sync wait / foreground `subagent` wait — **ends the wait only; children and peers keep running**, then report via steer handoff; steer admit does the same. Hard Stop / `session.cancel` still aborts the turn. Input-dock label is **Stop waiting**.
* **`skill_search`**: standing skill catalog is **names only**; fuzzy search returns blurbs, then `skill` loads the body (symmetric with `tool_search`).
* **Escape layer stack**: nested Modals/panels consume Escape last-opened-first; no longer depends on listener registration order.
* **Theme container names + z-index ladder**: `containers.css` named `@container`s; `interaction.css` `--ds-z-*` tokens (documented for client plugins).

### Improved

* **Deferred tools off standing `tools[]`**: `browser_*` / vault, `terminal_*`, `computer_use`, `job_*` / `cronjob` / `propose_skill` are `deferred` until `tool_search` expand; shorter browse blurbs; partial keyword matches (shared fuzzy with `skill_search`). `tool_search` copy names only packs common across seats (**no** global advertising of 向阳-only `settings_*`).
* **Collab board progressive disclosure**: turn-start roster is spawn-ids only (briefs via `team_list`); idle boards **omit** unbound peer dumps (find via `session_search`; `session_*` stay Direct).
* **Context occupancy**: Status timeline scales category bars to provider prompt; ring tools row stays heuristic with residual in messages (totals match upstream).
* **Workspace convention inject**: `.agents/context/**` no longer standing-injected (on-demand via skill / AGENTS pointers); `.cursor/rules/**` only for manager seats; thinner standing `AGENTS` / `SOUL` / `XRK` seeds.
* **Tool results**: write-time prune keeps spill full-text paths; remove unwired token-budget path (byte ceiling only).
* **`request/header`**: later series entries prefer `systemTokens` / `systemHash` / `toolsTokens` over full system bodies; bounded in-process caches.
* **Stop settlement**: late tool success after cancel is not persisted as a normal `tool/result`; chunk path bails on abort.
* **Cron jobs**: with Face present, admit as boss via `session.prompt` + drain (same path as composer send).
* **Anchored overlays**: shared `useAnchoredPosition` (job menu, context meter, Tooltip, …); phone job menu ignores Overview inset.
* **IME**: Goal edit / question Enter uses `isComposingKeyboardEvent` (no submit mid-composition).
* **Confirm dialogs**: clear Goal and delete team member require a Modal.
* **Dress sync**: roster live look **replaced wholesale**; clearing stickers sends empty strings so Overview / left rail drop old overlays.
* **Models settings**: post-save/delete `load({ soft: true })` avoids freezing the default-model select; delete dialog always dismissible.
* **Narrow slot seats**: header/composer `data-slot-layout`; `example-shell-pet` shows control self-defense.
* **Projections**: shallower session-projection view equality; tighter checkpoint / context / turn-outline paths.

### Removed

* Standing system `tool:skill` lecture (contracts live on tool descriptions + skill-catalog footer).
* Spill / agent-loop `maxInlineTokens` (never-wired dead config).
* Unused `createDefaultOutbound` default pipeline helper.

### Fixed

* Foreground `subagent` waits also show **Stop waiting** in the input dock (aligned with Face `WaitYieldHub`).
* **Stop waiting** dock follows `host/session-wait-yield` (not tool-name heuristics); hard Stop’s `running:false` no longer clears it.
* Team dress edits no longer leave a stale custom face on Overview / the left rail.
* Changing default model or deleting a provider no longer freezes the Models settings UI.

### Other

* Public line version **0.8.13** (npm / Desktop / phone / site download share the same number).
* Textbook updates: `workspace-inject` / `skills-layers` / `session-delivery` / `session-optimize` / `client-plugin-development` / `status`.
