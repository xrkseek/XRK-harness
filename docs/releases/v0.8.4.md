# v0.8.4

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.3](./v0.8.3.md)：把「主会话 Git worktree」设置卡钉回插件配置；MCP 工作区选择与其它设置统一 Menu；门禁补齐侧栏公告与 CLI 版本对齐，并不再写死本机 Node 盘符。本版接 npm **`@latest`**（**v0.8.3** 仅 Desktop / 手机，未发 npm）。

### 完善

* **MCP 工作区选择**：Plugins → MCP 工作区下拉改产品 `Menu`（与 0.8.3 其它设置选择一致；触控 / 嵌入 WebView 不再依赖原生 `<select>`）。
* **向日葵免费通道 README**：CLI 捆绑说明写清 Bun 查找顺序与无 Bun 时的 Kilo 回落，减少集成踩坑。

### 修复

* **主会话 Git worktree 卡**：库存刷新滞后或行短暂缺失时，插件配置页不再整卡消失；开关在库存可用前保持只读失败态，行回来后可继续开关。
* **侧栏版本公告测例**：不再钉死历史 `0.7.21`；`RELEASE_NOTES[0]` 与 `apps/cli` 版本由 `pnpm check` 新闸校验，避免公告停在旧号。

### 其他变更

* **`pnpm check`**：Windows 子进程 PATH 改为探测本机非 Cursor-helper 的 `node` 目录（不写死盘符）；新增 `verify-release-notes-version`；第一方 plug 闸跳过 gitignore 的本机联调树（如 `xrkh-better-sidebar`），避免误杀门禁。
* 公开线版本号对齐 **0.8.4**（npm / Desktop / 手机 / 官网下载同号）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.3](./v0.8.3.md): keep the main-session Git worktree Settings card mounted; MCP workspace picker uses the product Menu; check gates sidebar notes against the CLI version and stops hard-coding a Node drive letter. This build takes npm **`@latest`** (**v0.8.3** was Desktop / phone only — no npm).

### Improved

* **MCP workspace picker**: Plugins → MCP workspace control uses the product `Menu` (parity with other 0.8.3 Settings selects; no native `<select>` in touch / embedded WebView).
* **Sunflower-free README**: CLI-bundled docs spell out Bun lookup order and the no-Bun Kilo fallback.

### Fixed

* **Main-session Git worktree card**: no longer vanishes from Plugins → configuration when inventory refresh lags or the row is briefly missing; the switch stays non-writable/failed until inventory is healthy.
* **Sidebar release-notes test**: no longer pins historical `0.7.21`; `pnpm check` verifies `RELEASE_NOTES[0]` matches `apps/cli` so the bell cannot stall on an old version.

### Other

* **`pnpm check`**: Windows child PATH probes the first non-Cursor-helper `node` (no hard-coded drive); adds `verify-release-notes-version`; first-party plug gate skips gitignored local checkout trees (e.g. `xrkh-better-sidebar`).
* Public line version **0.8.4** (npm / Desktop / phone / site download share the same number).
