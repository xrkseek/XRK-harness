# v0.5.4

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.3](./v0.5.3.md)：概况栏按会话记住开合与宽度（刷新仍在）；表情球补工具失败 / 空闲待机；DeepSeek 默认目录收敛到 V4.1 Flash；会话切模型不再牵连他会话 remount；子代理可钉模型。

Relative to [v0.5.3](./v0.5.3.md): Overview open/width remembered per Session across reload; presence ball gains tool-error / idle cues; DeepSeek catalog defaults to V4.1 Flash; session model switch no longer remounts other sessions; subagents can pin provider/model/effort.

### 新增

* 新增子代理工具可选 **`provider` / `model` / `reasoning_effort`**：可钉子会话 LLM（仅 `model` 时继承父会话提供方）。
* 新增开文件路由 **`routeWorkspaceOpenFile`**：有 `xrkh-better-sidebar` 时先 `openTab` 再 Host `openPath`；未装则只走系统打开。

### 完善

* 完善概况栏记忆：开合与**宽度**均按会话写入 `localStorage`（`xrk.layout.overview.v1`），刷新后恢复；与更好侧栏工作台状态互不影响。
* 完善表情球：工具失败情绪（可带工具名）、空闲 standby / sleep、tipKey 文案与可选强调、会话 tip 边沿动效。
* 完善 DeepSeek 默认目录：Settings / Face / Registry 默认 **`deepseek-flash`**（DeepSeek-V4.1-Flash，text+image）与 **`deepseek-v4-pro`**；退役 Flash / Vision-Exp 别名仍走兼容视觉路由，不进默认种子。
* 完善会话模型选择：`selectSessionModel` 只写本会话 sidecar，**不**改 Settings `agent-default-model`，避免牵连他会话 remount。
* 完善概况「改动」回退、Jobs 列表操作、插件清单安装会话与交付物 UI。

### 删除

* 删除 Settings 默认 DeepSeek 目录中的退役 id（`deepseek-v4-flash` · `deepseek-v4-flash-vision-exp`）；请求仍可带这些 id。

### 修复

* 修复概况 Status 槽因 `presenceCues` 快照引用不稳导致的无限重渲染（「Slot details failed to render」）。
* 修复刷新后概况被关掉、各会话共用同一宽度的问题。
* 修复打开中的会话切模型时，其它会话被 `invalidateAgents` 牵连 remount / 中断的问题。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.4`**（接管 npm `@latest`）；npmjs 保留 **0.5.4** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.4**（`package:desktop` 产物名随版本）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.4
xrkh web
```

侧栏（可选）：

```bash
xrkh plugin add xrkh-better-sidebar@0.18.20
xrkh restart
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.4-*-unsigned`（或签名）安装包。

## 验证

* 会话 A 打开概况并拖宽 → 切无关会话 B → 回 A：仍开且为 A 的宽度；硬刷新后 A 仍恢复。
* 概况 Status：工具失败后球有失败 tip；空闲足够久进入 standby / sleep。
* Settings → DeepSeek：默认目录为 `deepseek-flash` · `deepseek-v4-pro`。
* 会话 A 切模型时，会话 B 对话不中断 remount。
* 子代理工具可带 `model`（可选 `provider` / `reasoning_effort`）钉子会话。

---

### Added

* Subagent tools accept optional **`provider` / `model` / `reasoning_effort`** to pin the child session LLM (`model` alone keeps the parent provider).
* Open-file route **`routeWorkspaceOpenFile`**: with `xrkh-better-sidebar`, `openTab` then Host `openPath`; otherwise OS open only.

### Improved

* Overview memory: open bit **and width** per Session in `localStorage` (`xrk.layout.overview.v1`), survives reload; independent of better-sidebar workbench state.
* Presence ball: tool-error mood (optional tool name), idle standby / sleep, tipKey copy + accents on session tip edges.
* DeepSeek default catalog: Settings / Face / Registry seed **`deepseek-flash`** (V4.1-Flash, text+image) and **`deepseek-v4-pro`**; retired Flash / Vision-Exp aliases stay on compat vision routing but out of the seed.
* Session model selection: `selectSessionModel` writes only the session sidecar — **not** Settings `agent-default-model` — so other sessions are not remounted.
* Overview Changes fallback, Jobs list actions, plugin-inventory install session, and deliverables UI polish.

### Removed

* Retired DeepSeek ids (`deepseek-v4-flash` · `deepseek-v4-flash-vision-exp`) from the Settings default catalog; requests may still send those ids.

### Fixed

* Overview Status slot infinite re-render from unstable `presenceCues` snapshot identity (“Slot details failed to render”).
* Overview closing on reload and sharing one width across Sessions.
* Switching models in one open session no longer remounts / interrupts other sessions via `invalidateAgents`.

### Other changes

* Public line **`@xrkseek/harness-cli@0.5.4`** takes npm `@latest`; npmjs keeps **0.5.4** and rollback pin **0.3.11**.
* Private Desktop shell version aligned to **0.5.4**.

* Overview Status: tool failure shows failure tip; long idle reaches standby / sleep.
* Settings → DeepSeek catalog defaults to `deepseek-flash` · `deepseek-v4-pro`.
* Model switch in session A does not remount session B.
* Subagent tools can pin `model` (optional `provider` / `reasoning_effort`).
