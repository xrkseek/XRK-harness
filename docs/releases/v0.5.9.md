# v0.5.9

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.8](./v0.5.8.md)：表情球默认奶油色（非纯白）并可在 Settings 自选配色；加载态改为静默转圈；概况开合与侧栏 toggle 共处主区；顶栏 Presence 与 shell 过渡对齐。

Relative to [v0.5.8](./v0.5.8.md): presence ball defaults to cream (not pure white) with Settings color pickers; loading is a quiet spinner; Overview and sidebar toggles share the main-column seam; header Presence motion aligns with the shell curve.

### 新增

* Settings → 通用：**表情球外形**与**表情球颜色**（奶油 / 雾蓝 / 蜜桃 / 鼠尾草 / 丁香 / 岩灰）；浅色与深色界面各用一套球身+眼睛，写入 Host `ui-presence`（live）。

### 完善

* 完善表情球默认绘色：球身 `#F3F0EA`、暗色眼睛；强制配色时引擎默认眼睛不再落成纯白。
* 完善表情球加载：去掉「表情引擎加载中…」文案，舞台内转圈，引擎就绪后淡入。
* 完善顶栏 PresenceDock 与概况开合：时长/缓动与 shell / 侧栏推挤对齐（约 380ms），去掉模糊闪动。
* 完善社区侧栏（`xrkh-better-sidebar@0.19.0`）：toggle 始终按概况 inset + workbench 宽度停在主对话列右缘。

### 修复

* 修复会话表情球被主题色刷成「白球白眼」发飘：命名色板显式带 `eyeColor`，引擎缺省眼睛改为深色。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.9`**（接管 npm `@latest`）；npmjs 保留 **0.5.9** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.9**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。
* 推荐侧栏插件 **`xrkh-better-sidebar@0.19.0`**（概况共存布局）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.9
xrkh web
```

侧栏（可选）：

```bash
xrkh plugin add xrkh-better-sidebar@0.19.0
xrkh restart
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.9-*-unsigned`（或签名）安装包。

## 验证

* Settings → 通用可选外形与颜色；改色后顶栏/概况球立即换色，深色主题用更深一档。
* 球首次出现不显示「加载中」长文，仅短暂转圈后淡入。
* 打开概况：侧栏两个 toggle 停在主区右缘，不叠在概况顶栏；展开工作台时继续向左让位。
* 关掉概况：顶栏 Presence 芯片平滑回到 header。

---

### Added

* Settings → General: **presence shape** and **presence color** palettes (cream / mist / peach / sage / lilac / slate); light and dark chrome each get body+eye paints; Host `ui-presence` (live).

### Improved

* Default ball paint is cream `#F3F0EA` with dark eyes; engine no longer defaults themed eyes to pure white.
* Presence load state: no “loading…” copy — spinner only, then fade-in when the engine mounts.
* Header PresenceDock ↔ Overview handoff uses the same ~380ms shell / sidebar motion curve (no blur flash).
* Community sidebar (`xrkh-better-sidebar@0.19.0`): toggles always sit on the main-column seam via details inset + workbench width.

### Fixed

* Session ball no longer washes out as white-on-white: named palettes pass `eyeColor`; engine fallback eyes are dark.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.9`** (owns npm `@latest`); npmjs keeps **0.5.9** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.9**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
* Recommended sidebar plugin **`xrkh-better-sidebar@0.19.0`** (Overview coexistence layout).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.9
xrkh web
```

Sidebar (optional):

```bash
xrkh plugin add xrkh-better-sidebar@0.19.0
xrkh restart
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.9-*-unsigned` (or signed) package.

## Verify

* Settings → General offers shape + color; changing color remounts the ball; dark chrome uses the deeper tint.
* First paint shows a brief spinner, not a long loading sentence.
* Open Overview: sidebar toggles stay on the main-column right edge, not on the Overview tab strip; opening the workbench pushes them further left.
* Close Overview: header Presence chip returns smoothly.
