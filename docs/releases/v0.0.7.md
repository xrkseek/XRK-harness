# v0.0.7

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.6](./v0.0.6.md)：Agent 主路结算 / 重试 / 取消更可预期；DeepSeek 视觉 catalog；投影状态与视图分离。

### 新增

* 新增步内 LLM 可恢复错误自动重试（Face `agent-loop.llmRetryMaxRetries`；`0` 关闭），并放出 `llm/retry` · `llm/retry-started`
* 新增工具取消结构化码：`ABORTED`（body 已开跑）与 `ABORTED_BEFORE_DISPATCH`（未开跑）
* 新增 `concludesTurn` / `extras.concludeTurn()`（可选 `extras.deferContext`）：工具成功后可在本步结束本轮，不再开下一步 LLM
* 新增 `isConcurrencySafe` 并行 settle（只认精确 `true`）与 Face `agent-loop.toolSettle` / `maxParallelToolCalls`
* 新增 MCP `annotations.readOnlyHint === true` → 并发安全；否则独占
* 新增 DeepSeek catalog 模型 `deepseek-v4-flash-vision-exp`（`text+image`；官方 Flash/Pro 仍 text-only）
* 新增投影驱动缝 `@xrkseek/session-projection`：双表状态/视图、可选 `wire`、冷读 `restoreFloor` / `viewCheckpoint` / `restore`

### 完善

* 完善崩溃修复结算：`TOOL_NOT_STARTED` / `TOOL_OUTCOME_UNKNOWN` 与取消路径区分
* 完善取消原因：`turn/end.reason` 写入 `AgentCancelCause`（`user` / `parent` / `hook` / `disposed` / `legacy`）
* 完善 DeepSeek thinking / `reasoningEffort`、toolOrder、Anthropic `cache_control`、工具流式 `tool-call` chunk 进 session
* 完善 HTTP LLM 失败分类（含 gemini / openai-responses）供步内重试决策
* 完善 Face 默认投影单元迁到新缝（`snapshot` 只出客户端视图；`stateOf` / `checkpoint` 可读 host 折叠态）

### 修复

* 修复取消 settle 把已开跑调用误标成「未 dispatch」的情况
* 修复晚返回成功在取消后仍写入成功结果的问题（覆盖为 `ABORTED`）
* 修复同轮 LLM 重试耗尽后未再露出 `turn-error` 的情况
