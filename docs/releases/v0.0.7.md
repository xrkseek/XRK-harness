# v0.0.7

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.6](./v0.0.6.md)：Agent 主路对齐 DSH 结算 / 重试 / 取消码，取消与并行工具更可预期。

### 新增

* 新增步内 LLM 可恢复错误自动重试（Face `agent-loop.llmRetryMaxRetries`；`0` 关闭），并放出 `llm/retry` 事件
* 新增工具取消结构化码：`ABORTED`（body 已开跑）与 `ABORTED_BEFORE_DISPATCH`（未开跑）
* 新增 `concludesTurn`：工具成功返回后可在本步结束本轮，不再开下一步 LLM
* 新增 `isConcurrencySafe` 并行 settle（只认精确 `true`）与 Face `agent-loop.toolSettle` / `maxParallelToolCalls`
* 新增 MCP `annotations.readOnlyHint === true` → 并发安全；否则独占

### 完善

* 完善崩溃修复结算：`TOOL_NOT_STARTED` / `TOOL_OUTCOME_UNKNOWN` 与取消路径区分
* 完善 DeepSeek thinking / `reasoningEffort`、toolOrder、Anthropic `cache_control`、工具流式 `tool-call` chunk 进 session
* 完善 HTTP LLM 失败分类（含 gemini / openai-responses）供步内重试决策

### 修复

* 修复取消 settle 把已开跑调用误标成「未 dispatch」的情况
* 修复晚返回成功在取消后仍写入成功结果的问题（覆盖为 `ABORTED`）

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.7
xrk-harness web
```
