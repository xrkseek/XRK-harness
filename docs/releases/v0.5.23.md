# v0.5.23

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.22](./v0.5.22.md)：回合结束行只出现在真正收尾的位置；已经画出来的聊天节点不再「凭空消失」把对话冻住；工具调用中途不再误闪「已停止」。

Relative to [v0.5.22](./v0.5.22.md): the turn-end row only lands where a turn really settles; a painted chat node never vanishes and freezes the conversation; no more stray 已停止 flashes while tools are still running.

### 修复

* 修复回合结束行位置：结束行改锚在 `turn/end` 事件。以前贴在最后一条文本回复后，文本 → 工具 → turn/end 的回合里，复制 / 赞 / 用时会被夹在中途的工具行之间。
* 修复「已停止」误闪：仅当回合本身以 Stop 收尾时才打停止角标。单个 step 结束、或回合仍 `completed` / `error` 但 Host 还在同一回合跑时，不再误画停止态——这正是实时会话里那个一闪而过的假「已停止」。
* 修复顶端回合仍在跑时提前画结束态：Host 的运行闩锁在事件时间线之外，只有最顶端那个回合的页脚会等；此前已收尾的历史回合页脚照常显示。`wait_agent` / 子代理 drain 会留下「回合已 closed 但 Overview 说回合进行中」的组合，这条就是治它的。
* 修复同回合尾部显示赞：结束行之后还有同回合节点（steering / 尾工具）时，页脚保留但 赞 不显示——结束评分只属于已收尾回合的尖端。
* 修复对话卡死：节点一旦画出来就不再返回空（那会触发「撤回已具现目标」，表现为聊天冻结到刷新）。数据尚未就绪或需要隐藏时（模型重试、命名空间暂态、工具名迟到），改为沿用上一个节点的锚点与数据以隐藏态保留。

### 完善

* 完善开放回合：`turn.status !== 'closed'` 时不渲染结束行，旧数据泄漏的座位保持空白；结束就绪校验（`data` + `closed`）收敛到统一入口。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.23`**（接管 npm `@latest`）；npmjs 保留 **0.5.23** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.23**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 验证

* 文本 → 工具 → turn/end 的回合：复制 / 赞 / 用时出现在 turn/end 之后，不夹带在工具行之间。
* 长回合跑工具时不再闪「已停止」；真按停止时才显示。
* 顶端回合还在跑时无结束行；Host 空闲后页脚出现；历史回合页脚不受影响。

* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.23`。

---

### Fixed

* Turn-end row position: the footer now anchors on the `turn/end` event. It used to sit after the last text reply, so in text → tools → turn/end turns the copy / rating / timing row landed between mid-turn tool rows.
* Stray 已停止 flashes: the stop badge is now stamped only when the Turn itself ends as Stop. A bare step end — or a `completed` / `error` `turn/end` while the Host is still on the same Turn — no longer paints stop chrome. That was the false 已停止 blink in live sessions.
* End chrome on a still-running tip turn: the Host’s busy latch lives outside the event timeline, so only the tip turn’s footer waits. Already-closed prior turns keep their footers. This is the fix for “turn closed but Overview says 回合进行中”, which `wait_agent` / subagent drain produces.
* A mid-turn tail no longer shows a rating: with same-turn nodes after the end row (steering / trailing tools), the footer keeps rendering minus the rating — ending feedback belongs on the tip of a settled turn.
* Frozen conversation: once a node is painted it never returns null again (that threw “withdrew materialized target”, showing as a chat frozen until refresh). While data is not ready or the row should be hidden (model retry, provisional step, late tool name), it keeps the previous node’s anchor and data in a hidden state.

### Improved

* Open turns: no end row while `turn.status !== 'closed'`, and a leaked stale seat stays blank. The readiness check (`data` plus `closed`) is consolidated at one entry point.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.23`** (owns npm `@latest`); npmjs keeps **0.5.23** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.23**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.23`.
