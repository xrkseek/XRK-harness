# v0.7.0-rc.2

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.0-rc.1](./v0.7.0-rc.1.md)：第二过程号。产品面补齐 **DeepSeek 网页搜索**、**交付物永不进过程折叠**、**模型列表冷开手感**；Host 允许 **`0.0.0.0` 公网听**（带免责）；并收口 **会话缓存回收**、**跨平台文件打开**、**读图/生图信封**、**better-sidebar 手机下载**，以及 **上下文软预算对齐 Codex（留空仍主动压）**。npm dist-tag **`@rc`** 指向本号（**不**接管 `@latest`；`@latest` 仍为 **0.6.23**）。

Relative to [v0.7.0-rc.1](./v0.7.0-rc.1.md): second process number. Product surface adds **DeepSeek web search**, **deliverables never fold into process groups**, and a **cold-open model menu**; Host allows **`0.0.0.0` public bind** (with disclaimer); also lands **session-cache reclaim**, **cross-platform file open**, **image envelope**, **better-sidebar mobile download**, and **Codex-aligned soft budget (blank still proactive)**. npm dist-tag **`@rc`** points here (**does not** take `@latest`; `@latest` stays **0.6.23**).

### 新增

* **DeepSeek Search 提供方**：`web_search` **仅钉选** DeepSeek 时走 `POST /v1/tools/search`（与对话同一 Bearer；**不进 Auto**）。Settings → Plugins → Web search 增 DeepSeek 项与凭据槽 `web.deepseek`（`XRK_DEEPSEEK_SEARCH_API_KEY`）；缺专用槽时 Host 复用 `llm.deepseek` / `DEEPSEEK_API_KEY`。Auto 仍为：Tavily → Brave → parallel-free → DuckDuckGo。
* **`web_search` 可选 `proxy`**：与 `web_fetch` 同形（如 `http://127.0.0.1:7897`）；未传时沿用进程 `HTTP_PROXY` / `HTTPS_PROXY`（Host 已装 undici Env 代理时）。Tavily / Brave / DeepSeek / parallel-free / DuckDuckGo 均走同一 ProxyAgent 路径。
* **过程折叠「独立 transcript 工具」**：`present` · `ask_user_question` · `todo_write` · `image_generate` · `video_generate` · `propose_skill` 不进「过程」组，始终平铺可见。
* **`present` 行强制展开**：交付物 IN/OUT 不再被 ToolRow 默认收起；不可点收。
* **Modal `layout="inset"`**：短确认（编辑重发等）用贴底内容卡，避免移动端整屏「雷霆」大 UI。
* **委托子席位 `delegate.childSeat`**：Face 回报 `manager` / `agent` / `sunflower`；预览球 / 预览页标题前缀跟真席位，不再把干员硬标成「经理」。
* **影子 git 快照闸**：同工作区重叠 snapshot 串行 + 可观测诊断（失败 / 成功时刻），减少 `index.lock` 互踩。
* **向阳免费出口探针**：sidecar / ensure 可发现本机代理并写入 egress 设置（Kilo 等路径共用）。
* **会话缓存回收**：Face `sessions.reclaim` + 设置「会话缓存」卡；可按空闲/体量驱逐投影缓存，长会话占用更可控。
* **Host `canOpenPath`**：回环 / GUI / Termux 才走本机打开；无头 Linux / 公网 Host 软跳过 OS open，仍可唤醒社区侧栏预览。

### 完善

* **公网绑定**：`--host 0.0.0.0`（及非回环）允许启动；非回环武装访问 PIN。教科书声明：**不保证**面对公网的安全——宜反代 + TLS + 自管防火墙；PIN / `XRK_API_KEY` 仅为闸。
* **模型选择菜单**：冷开不再把第一项画成 hover；指针移动后才启用 `:hover`；长目录在菜单内滚动（`.groups` 获 `flex: 1`）；宽度约 280px，长模型名少被挤。
* **编辑重发确认**：移动端 inset 布局；撤销菜单去掉 autofocus 白边（Menu 焦点样式）。
* **截断后投影**：`ProjectionValueStore.clear()`，truncate 后先清空再同步 history，避免删消息后「轮次」虚增。
* **上下文溢出恢复**：软压策略 `off` 仍对上游 `ContextOverflowError` 做一次 prune→summary；社区/目录同步在窗口口径冲突时取更紧的一侧（避免 256k 被抬成 1M 导致软压过晚）。
* **Web search 设置卡**：提供方枚举与文案含 DeepSeek；凭据热刷新含 `XRK_DEEPSEEK_SEARCH_API_KEY`。
* **xrkh-better-sidebar@0.20.6**：下载改 fetch→blob（手机可落盘）；窄屏全宽抽屉 + 安全区 + 44px 触控；插件清单推荐/安装行手机纵向堆叠。
* **`xrkh plugin add --proxy`**：仅本条 `npm pack` 走 HTTP(S) 代理（`--proxy` / `--https-proxy`），不改进程 env、不波及其他功能；Settings 安装可选同参。
* **Host / Desktop 听口优先**：先 listen 再跑 sunflower / prewarm 等可选预热；Desktop CLI 路径同步不挡首屏。
* **教科书**： [web-tools](../web-tools.md) · [configuration](../configuration.md) · [plugin-loader](../plugin-loader.md) · [seams](../seams.md) · [troubleshooting](../troubleshooting.md) · [getting-started](../getting-started.md) · [security-checklist](../security-checklist.md) · [session-compaction](../session-compaction.md) · [status](../status.md) 同步 DeepSeek Search、`proxy`、公网绑定免责、`plugin add --proxy`、软预算 Codex 口径。
* **软预算对齐 Codex**：模型软预算**留空**时按 `floor(上下文窗口 × 90%)` 仍主动压缩（不再「留空不压」）；用户更严听用户；有提供方圆环时有效软上限再与窗的 90% 取更紧。获取模型填空白软预算同公式。
* **软压触发不二次打折**：当软上限已是窗的 90%（留空推导或圆环强制线）时，不再再乘 `softBudgetTriggerPercent`，避免压到约 81% 窗。
* **上下文圆环 / 软压共用提供方压力**：压缩后仍保留 usage 投影（DSH）；软压取 `max(本地 denser 估价，提供方投影)`；无 usage 且有窗时圆环回退本地分项并注明近似。
* **自动压缩行提示**：主动压缩标记旁提示到 Settings → 模型核对窗口与软预算（手动 `/compact` 不打扰）。

### 修复

* **编辑重发 / 再生成假失败**：`ISessions.truncate` 为 `Promise<void>`，成功路径不再误读 `.ok` 弹「操作失败」。
* **软压过晚 / 压完又假撑满**：压缩后清空提供方压力曾迫使软压只信 chars/4（常只见工具量级），现保留投影并在同一步换窗后改信本地估价直至下次 usage。
* **删除尾消息后轮次累加**：截断后投影残留导致状态条 / 轮次显示偏大。
* **右键撤销白边**：菜单首项 autofocus 轮廓过亮。
* **干员误标经理**：子会话预览 / 球标题读 `childSeat`。
* **概况 / 手机球未挂支线**：Presence 球接上会话支线；空闲时多数相位显示支线、偶尔切状态 tip；忙时状态仍优先。
* **模型列表假选中 / 列表被裁切**：冷开首项伪 hover；长列表无内部滚动被 `overflow: hidden` 压扁。
* **读图 / 生图无图**：`IMAGE_ENVELOPE` 统一 LF 拼接；图卡不再因 CRLF 信封门控丢预览。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.7.0-rc.2`**（npm dist-tag **`rc`**；`@latest` 仍为 **0.6.23**）。
* Desktop 私有壳对齐 **0.7.0-rc.2**（与 `apps/cli` / `packages/sdk` 同号）。
* DeepSeek Search 按成功请求计费（官方价目）；空结果 / 失败不计费——产品侧不代计账，仅接线。

# v0.7.0-rc.2

> **Audience**: End users · Integrators · Maintainers (release notes)

Relative to [v0.7.0-rc.1](./v0.7.0-rc.1.md): second process number. Adds **DeepSeek web search**, **deliverables that never fold into process groups**, and a **cold-open model menu**; Host allows **`0.0.0.0` public bind** (with disclaimer); also lands **session-cache reclaim**, **cross-platform file open**, **image envelope**, **better-sidebar mobile download**, and **Codex-aligned soft budget (blank still proactive)**. npm dist-tag **`@rc`** points here (**does not** take `@latest`; `@latest` stays **0.6.23**).

### Added

* **DeepSeek Search provider**: `web_search` uses DeepSeek `POST /v1/tools/search` **only when pinned** (same Bearer as chat; **not in Auto**). Settings → Plugins → Web search gains a DeepSeek option and credential slot `web.deepseek` (`XRK_DEEPSEEK_SEARCH_API_KEY`); when unset the Host reuses `llm.deepseek` / `DEEPSEEK_API_KEY`. Auto stays: Tavily → Brave → parallel-free → DuckDuckGo.
* **Optional `proxy` on `web_search`**: same shape as `web_fetch` (e.g. `http://127.0.0.1:7897`); omit to use process `HTTP_PROXY` / `HTTPS_PROXY` when Host installed undici’s env agent. Tavily / Brave / DeepSeek / parallel-free / DuckDuckGo share the ProxyAgent path.
* **Standalone transcript tools**: `present` · `ask_user_question` · `todo_write` · `image_generate` · `video_generate` · `propose_skill` stay flat — never join a process fold.
* **`present` force-expanded**: deliverable IN/OUT stays open; the row cannot collapse.
* **Modal `layout="inset"`**: short confirms (edit-resubmit) use a bottom content card instead of a mobile fullscreen sheet.
* **`delegate.childSeat`**: Face reports `manager` / `agent` / `sunflower`; preview ball / tab titles follow the real seat (no more hard-coding 干员 as 经理).
* **Shadow-git snapshot gate**: overlapping snapshots on one workspace serialize with diagnostics (failure / success marks) to cut `index.lock` races.
* **Sunflower-free egress probe**: sidecar / ensure can discover a local proxy and write egress settings (shared by Kilo paths).
* **Session cache reclaim**: Face `sessions.reclaim` + Settings “Session cache” card; idle / size eviction keeps long-session footprint in check.
* **Host `canOpenPath`**: native open only on loopback / GUI / Termux; headless Linux / WAN Host soft-skips OS open and can still wake the community sidebar preview.

### Improved

* **Public bind**: `--host 0.0.0.0` (and other non-loopback) may start; non-loopback arms the access PIN. Docs state: **no security guarantee** on the open internet — prefer reverse proxy + TLS + your firewall; PIN / `XRK_API_KEY` are gates only.
* **Model select menu**: cold open no longer paints the first row as hovered; `:hover` arms after pointer move; long catalogs scroll inside the menu (`.groups` gets `flex: 1`); width ~280px so long model names truncate less.
* **Edit-resubmit confirm**: mobile inset layout; context-menu autofocus outline toned down.
* **Post-truncate projections**: `ProjectionValueStore.clear()` before history resync so deleting a message does not inflate turn counts.
* **Context overflow recovery**: soft strategy `off` still runs one prune→summary on provider `ContextOverflowError`; community/catalog sync picks the tighter window when sides disagree (avoids lifting 256k to 1M and delaying soft compact).
* **Web search settings card**: provider enum and copy include DeepSeek; credential refresh watches `XRK_DEEPSEEK_SEARCH_API_KEY`.
* **xrkh-better-sidebar@0.20.6**: downloads use fetch→blob (mobile can save); narrow full-bleed drawer + safe-area + 44px hit targets; plugin inventory recommend/install rows stack on phone.
* **`xrkh plugin add --proxy`**: HTTP(S) proxy for **this** `npm pack` only (`--proxy` / `--https-proxy`); no process env; Settings install can pass the same.
* **Host / Desktop listen-first**: bind before optional sunflower / prewarm; Desktop CLI path sync does not block first paint.
* **Textbook**: [web-tools](../web-tools.md) · [configuration](../configuration.md) · [plugin-loader](../plugin-loader.md) · [seams](../seams.md) · [troubleshooting](../troubleshooting.md) · [getting-started](../getting-started.md) · [security-checklist](../security-checklist.md) · [session-compaction](../session-compaction.md) · [status](../status.md) cover DeepSeek Search, `proxy`, public-bind disclaimer, `plugin add --proxy`, and Codex soft-budget posture.
* **Soft budget (Codex)**: **blank** soft budget still proactive at `floor(contextWindow × 90%)`; stricter user soft wins; with a provider ring the effective soft is also `min`’d to 90% of the window. Fetch-models fills blank soft the same way.
* **No double trigger discount**: when soft max is already window×90% (blank-derived or ring force), `softBudgetTriggerPercent` is not applied again (avoids ~81% of window).
* **Ring / soft share provider pressure**: keep usage projection across compaction (DSH); soft path uses `max(local denser estimate, projected)`; no-usage + window falls back to heuristic rows marked approximate.
* **Auto-compact settings hint**: proactive compaction markers nudge Settings → Models; manual `/compact` stays quiet.

### Fixed

* **Edit-resubmit / regenerate false failure**: `ISessions.truncate` is `Promise<void>` — success no longer misreads `.ok` into an error toast.
* **Soft compact too late / post-compact false full**: clearing provider pressure after compact forced soft path onto chars/4 alone; projection is kept, and after an in-step window swap soft trusts local estimate until the next usage.
* **Turn count after delete**: stale projections after truncate no longer inflate the turn strip.
* **Context-menu white edge**: first-item autofocus outline was too bright.
* **干员 labeled 经理**: child preview / ball titles read `childSeat`.
* **Overview / phone ball missing sideline**: Presence balls take the session sideline; idle phases show it most of the time and flash the status tip occasionally; busy tips still win.
* **Model list fake selection / clipped list**: cold-open pseudo-hover; long lists crushed by `overflow: hidden` without an inner scroller.
* **Read-image / image-generate blank**: `IMAGE_ENVELOPE` joins with LF; gallery cards no longer drop preview on a CRLF envelope gate.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.7.0-rc.2`** (npm dist-tag **`rc`**; `@latest` stays **0.6.23**).
* Private Desktop shell aligns to **0.7.0-rc.2** (same number as `apps/cli` / `packages/sdk`).
* DeepSeek Search bills per successful request (vendor pricing); empty / failed calls are free — the product wires the API and does not meter for you.
