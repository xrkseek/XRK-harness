# v0.1.13

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.12](./v0.1.12.md)：Agent 投递与工具体感（mid-step steer · 子代理完成通知 · 路由提示）；费用估算对齐 V4 定价；Sidebar 沙箱插件 HTML 与「在文件夹中显示」修复。

Relative to [v0.1.12](./v0.1.12.md): agent delivery and tool comfort (mid-step steer · subagent completion notices · routing prompts); cost estimates aligned with V4 pricing; sandbox plugin HTML and reveal-in-folder fixes.

---

## 完善 / Improved

* 完善 **steer 投递**：长 turn 内 tool-step 边界可 claim 待处理 steer（`promotePendingSteers`），不必等整轮结束
* 完善 **子代理**：系统提示注册 `tool:subagent`；后台 continuable 子代理 drain idle 时向父会话 inbox 队列通知（与 job 完成同 wake 预算）
* 完善 **工具路由提示**：FS / Shell / Jobs / Subagent 分层注入；Shell 默认 pwsh（Windows）与 UTF-8；模型面仅 `job_*`（无 `bash_jobs` 别名）
* 完善 **FS 工具**：`read_file` offset/limit 与行号窗口；`write-intent` 守卫与可操作的 deny 文案
* 完善 **`ask_user` schema**：暴露 `detail` · `intent`（plan-review 留给 `exit_plan_mode`）
* 完善 **费用估算**：DeepSeek V4 Flash/Pro 与 cache 分档计价；加载 ledger 时迁移并重算历史会话费用
* 完善 **Sidebar 社区插件**：`GET /sidebar/html/…` 为沙箱 iframe 提供真实 HTML/MIME，避免 SPA fallback 导致插件加载失败

---

## 修复 / Fixed

* 修复 Context / 今日费用明显偏高（V3 cache 单价误用于 V4 · input 重复扣 cache · reasoning 重复计费）
* 修复「在资源管理器中显示」/workspace 根路径解析（`cwd/.` 误指工作目录而非 workspace 根）
* 修复 `web_fetch` 超时与跨域错误文案不够诚实、缺少 Location 提示的问题

---

## 删除 / Removed

* 删除无调用点的 stub：`createSandboxArgvWrapGuard` · `createFsToolsForRoot`；Host 不再重复 bind `ask_user`（Face `resolveAgent` 单点绑定）

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.13
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.1.13 web` · `npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：旧 ledger 首次打开会按 V4 重算费用；长会话 steer 可在工具多步执行中插话，queue 仍按 turn 边界 FIFO。
