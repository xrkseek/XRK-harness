# v0.7.5

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.4](./v0.7.4.md)：Desktop **临时分享**可真给手机 / 穿透用（本机与局域网双地址、PIN、跳过主机专用网卡）；概况与发版本机产物约定收紧。

Relative to [v0.7.4](./v0.7.4.md): Desktop **temporary share** works for phone / tunnel access (loopback + LAN URLs, PIN, skip host-only NICs); Overview and local packaging layout tightened.

### 新增

* **Desktop 临时分享网关**：Settings 开关拉起 `0.0.0.0` 分享端口；界面给出**本机地址**与**局域网地址**；过滤 VirtualBox 等主机专用网段；关分享即停。
* **分享 PIN**：分享开启后，除 Desktop 壳标外（含 `127.0.0.1`）一律要 PIN；`trustProxy` / `X-Forwarded-Host` 正确抬升局域网与穿透访客。

### 完善

* **向日葵 / OFM 产品面**：免费车道与目录挂载边角继续打磨（与 0.7.4 同线）。
* **本机发版落点**：桌面包与 tgz 固定目录、本地版本备份 ≤5（`pnpm prune:local`）；发版顺序见 [publishing](../publishing.md)「流水线顺序」。

### 修复

* **分享 URL 不可达**：假局域网 IP / 未把 `lanShareEnabled` 传到 dsh-compat wire 导致手机打不开。
* **分享开时 API 误 401**：测例与壳标对齐，避免 Electron 壳自身被 PIN 挡。
* **社区插件装后需重启**：Market / Settings 安装·更新后改为 `liveApply` Host 半；仅 apply 失败才 `restartRequired`。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.5
xrkh web
```

亦可 `npm i -g @xrkseek/harness-cli@latest`（发包后指向本版）。
