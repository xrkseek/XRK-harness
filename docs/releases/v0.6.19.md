# v0.6.19

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.18](./v0.6.18.md)：**会话列表索引化 · Turn 内过程折叠 · 过程详情偏好 · 图片输入放宽**。性能落在列表与 WAL 热点；对话面把过程收成可读的一组，并修几处「看起来还在跑」的假象。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.19`（发包后）。

Relative to [v0.6.18](./v0.6.18.md): **indexed session list · in-Turn process folding · process-detail preference · relaxed image intake**. Performance work targets list/WAL hot paths; the transcript folds process into one readable run and clears a few “still running” illusions. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.19` (after publish).

### 新增

* **Turn 内过程折叠**：已关闭 Turn 里连续的思考 / 工具行折成一组摘要头。视口内正在读的不折；折叠后视线里的内容不跳（补偿走滚动账本，不当作人手滚动）；`prefers-reduced-motion` 下无过渡。折叠行保持挂载，避免锚点序被当成「行删了」。
* **设置 · 过程详情**：General 增加「过程详情」（精简 / 标准 / 详细 / 始终展开），控制已完成轮次是否分组、是否自动收起、摘要是否点名工具与思考。

### 完善

* **会话列表索引化（schema v4）**：`sessions` 增加列表提示列，与事件同事务维护；`session.list` 一次索引读。约 205 会话的旧库冷列表从约 **7s** 到毫秒级；sqlite **3 → 4** 自动迁移回填。
* **WAL 空闲回落**：按阈值 + 最小间隔 TRUNCATE checkpoint，长期运行的 `-wal` 不再停在历史峰值。
* **列表缓存写盘 debounce**：投影缓存 500ms 合并落盘，避免每次 RPC 同步重写整份 JSON。
* **自动续写中的上限提示**：撞输出上限且仍在自动「继续」时，对话里显示「正在自动继续」，而不是只在终态才出现上限标识。
* **工具行展开更轻**：折叠态不解析/打印整段参数体；工具标题走统一本地化。

### 行为变更

* **图片输入放宽**：text-only **路由**不再拒图入库；组装时投影成占位符。会话里已有图片也不再阻止切到文本模型（仍校验 provider / model 可路由）。Host intake 无 `image` 时依旧拒。openai-compatible「有 `image` 才发 `image_url`」不变。

### 修复

* **被后续 step 顶替的流式工具行**：自动续写或下一步已开始时，停掉仍在闪的 running 扫光（`wait_agent` 仍可活着）。
* **Overview 卡在「正在读取概况」**：Strict Mode / 软刷新重挂时释放 `session.status` 的 in-flight latch，Status 能落盘。
* **发消息幽灵注入行**、**翻页丢阅读锚点**、**折叠吃掉阅读位置**：过程折叠与 pending chrome 一并收干净。
* **删掉每行 480ms settle 定时器**：`usePostStreamLive` 已去，可见性跟折叠 / 锚点走。

---

### Added

* **In-Turn process folding**: consecutive reasoning / tool rows in a **closed** Turn collapse behind one summary header. Never folds inside the viewport you are reading; after a fold lands, content under the eye stays put (compensation goes through the scroll ledger, not a raw `scrollTop`). No transition under `prefers-reduced-motion`. Folded rows stay mounted so anchor order is not read as deleted rows.
* **Settings · Process detail**: General gains a process-detail control (Compact / Standard / Detailed / Always expanded) for whether completed turns group, auto-fold, and name tools vs reasoning in the summary.

### Improved

* **Indexed session list (schema v4)**: list-hint columns on `sessions`, maintained in the event write transaction; `session.list` is one indexed read. ~205-session cold list drops from ≈**7 s** to milliseconds; sqlite **3 → 4** auto-migrates with a one-pass backfill.
* **Idle WAL reclaim**: TRUNCATE checkpoint on size + minimum interval so `-wal` does not park at its historical peak.
* **List-cache write debounce**: projection cache merges to disk on a 500 ms window instead of rewriting the whole JSON on every RPC tail.
* **Max-tokens cue while auto-continuing**: when output hits the cap and auto-「继续」is still running, the transcript shows that it is auto-continuing instead of waiting for a terminal notice.
* **Lighter tool expand**: collapsed rows skip pretty-printing argument bodies; tool titles use shared localization.

### Behaviour changes

* **Relaxed image intake**: a text-only **route** no longer rejects images at admission — they are stored and projected to placeholders at assembly. Images already in the session also **no longer block switching to a text model** (provider / model must still be routable). Host intake without `image` still rejects. openai-compatible still emits `image_url` only when `image` is present.

### Fixed

* **Streaming tool rows superseded by a later step**: once auto-continue or the next LLM step starts, dangling shells stop the running sweep (`wait_agent` may still stay live).
* **Overview stuck on “Loading overview”**: Strict Mode / soft-refresh remounts release the `session.status` in-flight latch so Status can paint.
* **Ghost injected row on send**, **reading anchor lost after repaging**, **fold eating the reading position**: cleaned up with process folding and pending chrome.
* **Dropped the 480 ms per-row settle timer**: `usePostStreamLive` is gone; visibility follows fold / anchor logic.
