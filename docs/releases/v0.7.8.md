# v0.7.8

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

## 中文

相对 [v0.7.7](./v0.7.7.md)：桌面端本机语音随包修复——安装包里终于带上 sherpa-onnx-node，下完 SenseVoice 模型不再报 `Cannot find module`；模型下载代理不再静默失效；概览装扮保存后热更；新增配置字段全表文档。

### 修复

* **桌面端本机语音（关键）**：`@xrkseek/exec-voice` 新增 `optionalDependencies: sherpa-onnx-node@2.0.1`。此前桌面包用 `pnpm deploy --prod` 组装，只装**声明过的**依赖，sherpa-onnx-node 从未进包——用户下完 230 MB SenseVoice 模型后报 `Cannot find module 'sherpa-onnx-node'`，本机 STT 完全不可用。平台子包带 `os`/`cpu` 限制（Windows 只拉 `sherpa-onnx-win-x64`）。**桌面包体积 +≈23 MB（win-x64）**。
* **模型下载代理不再静默失效**：`parseProxy` 容错 `http:host:port`、裸 `host:port`、完整 URL 三种写法；只接受 http(s)（socks 明确报错）；非法地址抛错，不再静默改走直连。`SenseVoicePreparer` 新增 `proxy` 失败码；`voice.inspect` 回传 `{text, valid, error, target}` 诊断；设置卡片红字提示。`AsrConfig` 补声明 `downloadProxy`（此前未声明的键在保存时被 schema 剥离，表现为「填了地址但仍直连」）。
* **概览装扮热更**：保存干员外观后按 Host 实际返回的 `saved.id` 重打乐观补丁并清理旧 id 键——修复 id 规范化后概览读不到补丁、只能等 5 秒 Face 轮询才变的问题。

### 文档

* 新增 `docs/settings-fields.md`：32 个 namespace 全字段表，由 `scripts/dump-settings-fields.mjs` 从 `settings-schemas.ts` 生成。
* 新增 `.agents/context/settings-help.md`：配置求助流程（项目经理席位）。

# Release Notes

> **Audience**: End users · Maintainers

## English

Relative to [v0.7.7](./v0.7.7.md): the desktop installer finally ships the local-voice engine; the model-download proxy no longer fails silently; overview dressing applies on save; new settings field dump.

### Fixed

* **Desktop local voice (critical)**: `@xrkseek/exec-voice` gains `optionalDependencies: sherpa-onnx-node@2.0.1`. The desktop bundle is assembled with `pnpm deploy --prod`, which only carries **declared** dependencies — sherpa-onnx-node never made it into the package, so after a 230 MB SenseVoice download users hit `Cannot find module 'sherpa-onnx-node'` and local STT was completely unusable. Platform subpackages stay behind `os`/`cpu` gates (Windows pulls only `sherpa-onnx-win-x64`). **Desktop package size +≈23 MB (win-x64)**.
* **Download proxy no longer fails silently**: `parseProxy` tolerates `http:host:port`, bare `host:port`, and full URLs; only http(s) is accepted (socks errors explicitly); an unusable address throws instead of quietly going direct. `SenseVoicePreparer` gains a `proxy` failure code; `voice.inspect` echoes `{text, valid, error, target}` diagnostics; the settings card shows a red hint. `AsrConfig` now declares `downloadProxy` (undeclared keys were stripped on save — the address looked saved while every byte went unproxied).
* **Overview dressing hot-apply**: after a save, the optimistic paint is re-stamped under the id the Host actually returned (`saved.id`) and the stale key is cleared — fixes the case where an id normalisation made the Overview wait the full 5 s Face poll.

### Docs

* `docs/settings-fields.md`: full field table for all 32 settings namespaces, generated from `settings-schemas.ts` by `scripts/dump-settings-fields.mjs`.
* `.agents/context/settings-help.md`: config-help flow for the project-manager seat.
