# v0.1.1

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.1.0](./v0.1.0.md)：修复 `npx @xrkseek/harness-cli web` 在干净安装下因 context 包 exports 指向未发布的 `src/*.ts` 而启动失败。

### 修复

* 修复 `@xrkseek/xrk-file-reference` · `xrk-file-reference-local` · `xrk-session-reference` 在 npm 包内缺少运行时 JS：`tsc` 编译至 `dist/`，exports 指向 `dist/*.js`（不再引用 `src/*.ts`）
* 修复 CI 干净 `tsc -b`：`session-reference/types` 改依赖 `@xrkseek/protocol`，不拉 gitignore 的 stub `lib/`

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.1.1
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.1.1 web`
