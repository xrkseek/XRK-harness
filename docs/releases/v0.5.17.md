# v0.5.17

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.16](./v0.5.16.md)：减轻大会话把 Desktop Host 内存顶爆后自动重启、思考中途断流的情况；关 Host 时回收虚胖的 `sessions.db` 空页。

Relative to [v0.5.16](./v0.5.16.md): reduce Desktop Host auto-restarts mid-turn when a heavy session balloons RAM; reclaim freelist bloat in `sessions.db` when the Host shuts down cleanly.

### 修复

* 修复 agent 多步循环里 `request/header` 因 system 注入抖动反复落库：自动路径只在路由 / 工具表变化时追加；显式 `reason`（如溢出压缩）仍记录完整快照。降低 `sessions.db` 与 Host 驻留内存增速，减少 OOM 后壳自动拉起 Host、对话「思考着断掉」的概率。
* 修复概况 `contextHeaders` 投影无限堆积整段 system：最多保留最近 32 个 epoch。
* 修复独占 Host 关闭时不对过大 freelist 回收：空闲页 ≥ 64MB 且占比 ≥ 20% 时 best-effort `VACUUM`（失败不挡退出）。

### 其他变更

* 对话输入：超长粘贴折叠为可展开摘要块，避免 contenteditable 里堆整墙文本。
* 公开线目标 **`@xrkseek/harness-cli@0.5.17`**（接管 npm `@latest`）；npmjs 保留 **0.5.17** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.17**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.17
xrkh web
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.17-win-x64`（或签名）安装包，或从已装旧版经应用内更新。首次干净退出 Host 后，本机 `~/.xrk/sessions/sessions.db` 若虚胖可能自动收一次空页。

## 验证

* 长工具循环会话：`request/header` 不再几乎每步一条；Host 工作集不再在同会话内无故冲到数 GB 后闪断重连。
* 关掉 Desktop 再开：若库曾有大量 freelist，文件体积可明显下降（或关库日志无 VACUUM 报错）。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.17`。

---

### Fixed

* Agent tool loops no longer append a full `request/header` on every system-inject jitter: the auto path only logs when the route or standing tools change; an explicit `reason` (for example overflow compaction) still stores the full snapshot. That slows `sessions.db` / Host RSS growth and cuts the chance the shell respawns Host after an OOM and the turn dies mid-thinking.
* Overview `contextHeaders` keeps at most the newest 32 epochs instead of pinning every full system string.
* Exclusive Host shutdown best-effort `VACUUM`s when freelist is ≥ 64MB and ≥ 20% of pages (failures never block exit).

### Other changes

* Composer: over-long pastes fold into expandable summary chips so contenteditable never holds a wall of text.
* Public line target **`@xrkseek/harness-cli@0.5.17`** (owns npm `@latest`); npmjs keeps **0.5.17** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.17**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.17
xrkh web
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.17-win-x64` (or signed) package, or update in-app from an older install. After a clean Host exit, a bloated `~/.xrk/sessions/sessions.db` may reclaim freelist pages once.

## Verify

* Long tool-loop sessions: `request/header` is not nearly one row per step; Host working set no longer spikes to multi-GB and flash-reconnects for no reason in the same session.
* Quit and reopen Desktop: if the DB had a large freelist, file size may drop (or close logs show no VACUUM hard failure).
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.17`.
