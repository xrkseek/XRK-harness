# v0.5.6

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.4](./v0.5.4.md)：概况栏大会话切会话不再因 soft-face 快照撕裂炸槽；会话权限 **自动审查 / Auto review**（无沙箱 + 每调用评审）与分类器三档；大会话 fork 批量落库与侧栏加载态；Status / 权限条对齐「Approve for me / 代我审批」；中文壳文案与「自动展开工具」设置。

Relative to [v0.5.4](./v0.5.4.md): Overview soft-face publish-on-notify for large Sessions; session **Auto review** (no sandbox + per-call review) with classifier tiers; large-session fork bulk seed + sidebar loading chrome; Status / permission chrome “Approve for me”; Chinese shell copy + Settings auto-expand tools.

### 新增

* 新增会话权限 **Auto**（`/permission auto`）：仅 Guardian `registerAuto` 存活时出现在会话 catalog；Settings `defaultPreset` 永不提供 `auto`。
* 新增 Auto-review 分类器三档：**启发式**（默认）· **HTTP**（Settings URL / `XRK_AUTO_REVIEW_CLASSIFIER_URL`）· **会话 LLM**（Host 当前模型）；`xrkh doctor` 探活标明档位。
* 新增 Settings → 通用 **自动展开工具**（`ui-conversation.toolsDefaultExpanded`）：工具行默认展开，仍可逐条收起；默认关。

### 完善

* 完善概况 soft face：`presenceCues` / `changeTurnsFallback` 改为 **publish-on-notify**（只在 Session 通知时读库；`getSnapshot` 只返回已发布引用；内容未变不通知）。
* 完善表情球空闲时钟：忙时直接 `idleMs = 0`，不再用 `Date.now()` 刷 `setState`。
* 完善 web-runtime：`BootGate` / `ChunkFold` 同样在变更时发布快照，连续 `getSnapshot` 引用稳定。
* 完善 Status / 权限条：Auto 时显示 `Auto review (Approve for me)` / `自动审查（代我审批）`，并明示无沙箱 + 每调用评审。
* 完善 Host：`approval never` 时 classifier deny → 最终 `AUTO_REVIEW_DENIED`；默认 ask → Face 审批。
* 完善 ToolCallTree：`AUTO_REVIEW_DENIED` 强制 GenericToolCard，跳过 keyed bash/read 等 toolview。
* 完善 dispose：撤回 Auto catalog 前将仍为 `auto` 的会话迁到 `danger-full-access`。
* 完善中文 UI：权限下拉 / 确认框 / 拒绝卡使用「自动审查」等中文文案（英文仍保留 Auto review）；权限菜单为 Auto 补齐盾牌+星芒图标（与只读/写入/完全访问同套）。
* 完善轨迹工具栏：展开/收起回合与调用等 zh 文案。
* 完善大会话 fork：`SessionStore.seed` 一次事务写入前缀；Face 跳过逐条 mux，投影懒折叠；侧栏简约加载遮罩。

### 修复

* 修复大会话切入概况触发 React #185（`Maximum update depth`）后 `details` abdicate、随后小会话也像坏掉的问题（槽位已卸，非小会话逻辑）。
* 修复 soft-face / 轨迹折叠在 `getSnapshot` 内现场 `ensureFresh` 或反复分配导致的撕裂风险。
* 修复命令「+」打开菜单后立刻被空草稿 `track` 关掉（对齐 DSH：launcher 打开的菜单在聚焦回写时存活）。
* 修复把 Auto-review 写成假「Guardian fragment」的过时文案；工具预审与 context-fragments 分栏说明。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.6`**（接管 npm `@latest`）；npmjs 保留 **0.5.6** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.6**（`package:desktop` 产物名随版本）。

### Added

* Session permission **Auto** (`/permission auto`): only while Guardian `registerAuto` is live in the session catalog; Settings `defaultPreset` never offers `auto`.
* Auto-review classifier tiers: **heuristic** (default) · **HTTP** (Settings URL / `XRK_AUTO_REVIEW_CLASSIFIER_URL`) · **session LLM** (Host current model); `xrkh doctor` probes report the tier.
* Settings → General **auto-expand tools** (`ui-conversation.toolsDefaultExpanded`): tool rows expand by default and still collapse per row; off by default.

### Improved

* Overview soft faces (`presenceCues` / `changeTurnsFallback`) are **publish-on-notify**: read the Session only on notify; `getSnapshot` returns the published reference; unchanged content skips listeners.
* Presence ball idle clock: busy forces `idleMs = 0` without `Date.now()` `setState` thrash.
* web-runtime `BootGate` / `ChunkFold` publish snapshots on mutate so consecutive `getSnapshot` calls share one reference.
* Status / permission chrome: Auto shows `Auto review (Approve for me)` / `自动审查（代我审批）` and states no sandbox + per-call review.
* Host: with `approval never`, classifier deny ends as `AUTO_REVIEW_DENIED`; default ask still surfaces Face approval.
* ToolCallTree: `AUTO_REVIEW_DENIED` forces GenericToolCard (skips keyed bash/read toolviews).
* Dispose: sessions still on `auto` move to `danger-full-access` before Auto leaves the catalog.
* Chinese UI: permission menu / confirm / deny cards use 自动审查 copy (English keeps Auto review); Auto menu icon matches the read/write/full-access set.
* Trajectory toolbar: zh expand/collapse turn and call copy.
* Large-session fork: `SessionStore.seed` writes the prefix in one durable transaction; Face skips per-event mux and lazy-folds projections; sidebar shows a simple loading overlay.

### Fixed

* Switching into a large Session no longer trips React #185 in Overview and abdicates `details` (which previously made later small Sessions look broken).
* Soft-face / trajectory fold paths no longer tear by live `ensureFresh` or fresh allocations inside `getSnapshot`.
* Command “+” menus no longer close immediately from empty-draft `track` (launcher-opened menus survive focus rewrite).
* Stale “Guardian fragment” Auto-review copy replaced; tool pre-review vs context-fragments explained separately.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.6`** (owns npm `@latest`); npmjs keeps **0.5.6** and rollback pin **0.3.11**.
* Desktop private shell version aligned to **0.5.6** (`package:desktop` artifact names follow).
