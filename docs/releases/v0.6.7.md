# v0.6.7

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.6](./v0.6.6.md)：附件本地存储与 DSH 附件桥接线（`cordis-attachments-bridge` · `storedImagePath`）；token usage 协议统一四种供应商形状、上下文压力不再把 cacheWrite 计入窗口；命令面板按 frecency 排序；Alt+←/→ 循环切换子代理；模型面板提供方长按排序并同步到 composer 分组；gemini / openai-responses 开始上报 usage；`todo_write` 完成纪律改为未结项时动态注入。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.7`（发包后）。

Relative to [v0.6.6](./v0.6.6.md): local attachment storage and the DSH attachments bridge are wired (`cordis-attachments-bridge` · `storedImagePath`); the token-usage protocol unifies four vendor shapes and context pressure no longer counts cacheWrite toward the window; the command palette ranks by frecency; Alt+←/→ cycles subagents; Models providers reorder by long-press and the composer groups follow; gemini / openai-responses now report usage; `todo_write` completion discipline is injected dynamically only while items remain open. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.7` (after publish).

### 新增

* **DSH 附件桥**：新 `cordis-attachments-bridge` 提供 Cordis `attachments` 座位——OFM free-lane 图像 resolver 的 `imageHostPath` 同步路径、`readImage` / `saveImage` / `readImageRequest`（含 `imageLimits` 声明），字节一律落产品本地 content-addressed store（`{XRK_HOME}/attachments/v1`），不再各插件自存一份。`attachment-local` 导出 `storedImagePath`（`objects/<aa>/<sha>` 绝对路径），配 `stored-image-path` 测例。
* **命令 frecency**：命令面板空查询按「次数 × 近因衰减」排序，命中查询用 frecency 打破同分平局；每条命令执行即 `recordCommandUse`。存储是**设备本地** `localStorage`（diff-only），与快捷键同姿态，不进 Host `settings.yaml`。
* **子代理循环快捷键**：`layout.prevSubagent` / `layout.nextSubagent`（默认 `Alt+←` / `Alt+→`，可改键）沿 team root + 健康直系子会话排环切换；根节点走 `openSession`、子节点走目录地址 `openSubagent`。无兄弟时**不吞键**（`runShellAction` 返回 false，让给焦点控件）。箭头键在快捷键面板显示 `←` `→` `↑` `↓`，`comboFromEvent` 识别 `ArrowLeft/Right/Up/Down`。
* **模型提供方长按排序**：`ProviderReorderRow` 长按 420ms（移动 >10px 取消）后拖动，行上/下半画插入线，松手按 DOM-insertBefore 语义落位；顺序持久化到 `llm-pi-ai.providerOrder`（乐观本地 splice，失败 `load()` 回滚并报错）。只读页、行展开中、单提供方时不启用，列表顶部给「长按后拖动」提示。
* **提供方顺序全链同步**：Face `llm.providers` 与 composer `llm.models` 分组同读 `providerOrder`（`deepseek-official` → 目录分组 `deepseek` 映射），未知 id 忽略、缺省项按发现序补在末尾。

### 完善

* **token usage 协议统一四种形状**：`tryParseOpenAiUsage` 同时接受 OpenAI chat（`prompt_tokens`）、Responses（`input_tokens` + `input_tokens_details`）、Anthropic（`cache_read/creation_input_tokens`）、Gemini（`promptTokenCount` / `candidatesTokenCount` / `totalTokenCount` / `cachedContentTokenCount`）；「wire prompt 总数含 cache 命中 → 从 input 里减出 cacheRead」的减法对四家统一。`total_tokens` / `totalTokenCount` 等 provider 总数存在即采信为 `totalTokens`。
* **上下文压力口径修正**：`inputPressureTokens` 优先 `totalTokens`（Codex `tokens_in_context_window`），否则 `promptPressureTokens` = `input + cacheRead`；**不再加 `cacheWrite`**（Anthropic `cache_creation` 本就是 wire input 的计费子集，相加会把 Context 环吹爆）。新 `promptPressureTokens` 供 timeline 的 prompt 行使用；`xrk-token-meter` 的 `pressureFrom` 同步去掉 cacheWrite；meter 规则与 skill 补禁令。协议 README 与 `docs/protocol-events.md` 中英同步。
* **gemini / openai-responses 上报 usage**：两适配器的 chat 返回与 SSE 流都解析 usage 并 yield `{ type: "usage" }`（gemini `usageMetadata`、responses `usage`），测例钉住解析结果——meter 与上下文压力在这些路由上不再空白。
* **`todo_write` 纪律分层**：静态 description 保持短（standing task list + 状态枚举 `pending | in_progress | completed`）；「同轮标完成、别留 stale in_progress、继续时推进下一条」只在本注册表**仍有未结项**时经 `dynamicSchema` 注入，全部结清后撤下。standing plan 文案同步为「re-projected while open items remain; omitted when settled」，站立 `AGENTS.md` 指向同一纪律。
* **快捷键面板响应式多列**：宽度随视口取 `min(480/720/1040px, 100vw - 32px)`（≥800px / ≥1280px 断点），列表 1/2/3 栏、组内 `break-inside: avoid`，高度放宽到 `min(60vh, 480px)`——长键位表不再挤成一条窄柱。
* **干员导入更顺手**：导入按钮在**草稿态**也可见（原来只有未选成员时才出现）；导入 scope 跟随当前上下文，不再硬编 `workspace`；提示改中性「已导入（未带外形）」。
* **OFM 打通**：`root.provide('profileContext')`（`web` / `web-desktop`，Desktop Host `XRK_SURFACE=desktop` → `web-desktop`，对齐 OFM vault `detectSealedHost`）；`settings.configure()` 只给 channel-pack 的 `auto: false`（不提供 legacy `register`）；credentials 桥补 `describe`（值外视图，channel-pack 登录状态/池 UI，`source: "local"`）与 `unset`（登出，等价 delete）；社区模型同步改走 `listModelsForCommunitySync` 带 `lastBaseUrl` 缓存。
* **`@earendil-works/pi-ai` 0.85.1 → 1.3.0**：WorkBuddy peer 跟进，`docs/status.md` 中英与 `community-plugins` 记录同步。

### 修复

* **one-shot 外部运行时不再注册 Face 子会话**：`run_in_background` 默认已是 continuable（会建 Face child），外部 ACP 路径的测例显式钉 `false`，确保「一次性 = 不留常驻子会话」。
* **agent-loop 设置键断言收紧**：`settings-loop-wired` 由 `>= 14` 改为 `== 13` 且缺失必为空——键位增删都要显式过这条，不再被下限掩盖。
* **团队名册导入输入框复位**：hidden file input 提到成员操作区，选择后立即 `value = ''`，同一文件可重复导入。

### Added

* **DSH attachments bridge**: the new `cordis-attachments-bridge` provides the Cordis `attachments` seat — the sync `imageHostPath` OFM’s free-lane resolver stats, plus `readImage` / `saveImage` / `readImageRequest` (with `imageLimits`). Bytes always land in the product’s local content-addressed store (`{XRK_HOME}/attachments/v1`) instead of one copy per plugin. `attachment-local` exports `storedImagePath` (`objects/<aa>/<sha>` absolute path), covered by the `stored-image-path` test.
* **Command frecency**: an empty query in the command palette ranks by count × recency decay, and frecency breaks ties on matches; every execution calls `recordCommandUse`. Storage is **device-local** `localStorage` (diff-only), same posture as shell shortcuts — never Host `settings.yaml`.
* **Subagent cycle shortcut**: `layout.prevSubagent` / `layout.nextSubagent` (default `Alt+←` / `Alt+→`, rebindable) walk a ring of team root + healthy direct children; the root opens via `openSession`, children via their catalog address `openSubagent`. With no siblings the chord **is not swallowed** (`runShellAction` returns false so the focused control keeps the key). Arrows render as `←` `→` `↑` `↓` in the shortcuts panel, and `comboFromEvent` recognizes `ArrowLeft/Right/Up/Down`.
* **Long-press provider reorder in Models**: `ProviderReorderRow` arms after a 420ms hold (movement >10px cancels), paints an insert line by row half, and commits with DOM-insertBefore semantics; order persists to `llm-pi-ai.providerOrder` (optimistic local splice, `load()` rollback plus an error message on failure). Disabled on read-only pages, while a row editor is open, or with a single provider; the list header carries a “press and hold, then drag” hint.
* **One order for both surfaces**: Face `llm.providers` and the composer `llm.models` groups both read `providerOrder` (`deepseek-official` maps to catalog group `deepseek`); unknown ids are skipped and missing ids append in discovery order.

### Improved

* **Token usage unifies four vendor shapes**: `tryParseOpenAiUsage` accepts OpenAI chat (`prompt_tokens`), Responses (`input_tokens` + `input_tokens_details`), Anthropic (`cache_read/creation_input_tokens`), and Gemini (`promptTokenCount` / `candidatesTokenCount` / `totalTokenCount` / `cachedContentTokenCount`); the “wire prompt total includes cache hits → subtract cacheRead out of input” rule is shared across all four. A provider total (`total_tokens` / `totalTokenCount`) is trusted as `totalTokens` whenever present.
* **Context pressure corrected**: `inputPressureTokens` prefers `totalTokens` (Codex `tokens_in_context_window`), else `promptPressureTokens` = `input + cacheRead`; it **no longer adds `cacheWrite`** (Anthropic `cache_creation` is already a billing subset of wire input, so adding it blew up the Context ring). The new `promptPressureTokens` feeds the timeline prompt row; `xrk-token-meter`’s `pressureFrom` drops cacheWrite the same way; the meter rule and skill gain the matching prohibition. Protocol README and `docs/protocol-events.md` are synced in both languages.
* **gemini / openai-responses report usage**: both adapters parse usage on the chat return and on the SSE stream and yield `{ type: "usage" }` (gemini `usageMetadata`, responses `usage`), pinned by tests — the meter and context pressure are no longer blank on these routes.
* **`todo_write` discipline is layered**: the static description stays short (standing task list plus the `pending | in_progress | completed` enum); the “mark completed in the same turn / never leave stale in_progress / advance the next pending” tip is injected through `dynamicSchema` **only while this registry still holds open items**, and disappears once everything is settled. The standing plan copy reads “re-projected while open items remain; omitted when settled”, and standing `AGENTS.md` points at the same discipline.
* **Responsive shortcut panel**: width follows the viewport as `min(480/720/1040px, 100vw - 32px)` at the ≥800px / ≥1280px breakpoints, the list renders 1/2/3 columns with `break-inside: avoid` per group, and height relaxes to `min(60vh, 480px)` — a long key table no longer squeezes into one narrow column.
* **Smoother member import**: the import button is visible in the **draft state** (it used to appear only with nothing selected); import scope follows the current context instead of hard-coding `workspace`; the hint text is neutral — “Imported (no costume).”
* **OFM wiring**: `root.provide('profileContext')` (`web` / `web-desktop`; Desktop Host sets `XRK_SURFACE=desktop` → `web-desktop`, matching OFM vault `detectSealedHost`); `settings.configure()` serves channel-pack’s `auto: false` (no legacy `register`); the credentials bridge gains `describe` (a value-free view for channel-pack login status / pool UI, `source: "local"`) and `unset` (logout, an alias of delete); community model sync now goes through `listModelsForCommunitySync` with a `lastBaseUrl` cache.
* **`@earendil-works/pi-ai` 0.85.1 → 1.3.0**: the WorkBuddy peer follows, with `docs/status.md` (both languages) and the `community-plugins` record synced.

### Fixed

* **One-shot external runs register no Face child**: `run_in_background` now defaults to continuable (which creates a Face child), so the external ACP test pins `false` — “one-shot” must not leave a resident child behind.
* **Agent-loop settings key assertion tightened**: `settings-loop-wired` went from `>= 14` to `== 13` with an empty missing list — any key added or dropped has to be explicit, no longer masked by a floor.
* **Roster import input resets**: the hidden file input moved into the member actions and clears `value` right after selection, so the same file can be imported again.

## Verify

* Read an image through the DSH side: `imageHostPath` points at `{XRK_HOME}/attachments/v1/objects/…`, and re-reading the same attachment yields the same content-addressed path.
* Command palette: clear the query — frequent commands float up; run a few others and the order follows (it survives reopening the panel on the same machine).
* Parent with children: `Alt+←` / `Alt+→` cycles root ↔ children; with no children the chord stays with the focused control / browser.
* Settings → Models: long-press a provider, drop it on the upper/lower half of another row — the list and the composer model groups reorder together; a read-only page shows no hint and refuses the drag.
* Anthropic route, long session: ring occupancy ≈ `input + cacheRead` (+ surface delta), never inflated by cacheWrite; Codex routes use `totalTokens`.
* With every todo completed, `todo_write`’s description no longer carries the “mark completed in the same turn” paragraph.
* Shortcuts panel at 1280px wide: three columns, no group split across a column break.
