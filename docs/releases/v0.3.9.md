# v0.3.9

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.8](./v0.3.8.md)：本机「在应用中打开」与资源管理器定位在 Windows 上能真正弹出窗口。

Relative to [v0.3.8](./v0.3.8.md): native Open In and Explorer reveal actually map windows on Windows.

---

## 修复 / Fixed

* Windows 用资源管理器打开工作区目录：走 `cmd /c start`（ShellExecute），不再对已在跑的 Explorer 做无窗口的 CreateProcess
* 顶栏「在应用中打开」：Cursor / VS Code 优先真 `.exe`，不用 WindowsApps 别名路径；Windows Terminal 用 `wt -d` 且不隐藏窗口、不叠 `-w new`
* 打开路径去掉客户端拼接的尾部 `/.`，并保留 `/` 与盘符根 `C:\`，避免盘符根被当成相对路径拒绝
* 「在应用中打开」只接受已存在的绝对目录；失败时整个分裂按钮标错误态
