# v0.5.30

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.29](./v0.5.29.md)：桌面拖入的文件把**原始路径**带进会话，模型可以直接用附件 id 读内容而不是满盘找文件；对话统计口径对齐 DSH；WorkBuddy 国际版不再依赖注册表发现。

Relative to [v0.5.29](./v0.5.29.md): desktop drag/drop carries the original OS path into the session, so the model reads uploads by attachment id instead of hunting the disk; conversation stats align with DSH; the WorkBuddy international app is located without Windows registry discovery.

### 新增

* **拖放文件的源路径贯通**：`ImageAttachmentRef` / `FileAttachmentRef` 新增 `sourcePath`，从客户端拖放解析 → prompt 线 → durable 落盘 → Face 回读一路携带；`sanitizeAttachmentSourcePath` 只放行绝对路径（`/…`、`\\…`、`C:\…`），剪贴板粘贴与裸文件名一律丢弃。本地存储把它写进 `.source-path` sidecar，重开附件仍能还原。
* **`read_file` 支持附件 id**：`createFsTools` 接受可选 attachments 存储，`path` 给 `sha256:…` / `attachment:sha256:…` 即可直接读内容，尾部附 `path:` 行（优先原始拖放路径，其次 Host alias）；工具说明与 fs 路由提示同步写明这条用法。
* **附件句柄文案带源路径**：`fileHandleText` / `imageHandleBlock` / `fileUploadHandleBlock` 在有 `sourcePath` 时附「源路径 …」，模型不必再猜文件在哪。
* **WorkBuddy 国际版 Electron 定位**：`ensureWorkBuddyAiElectronBin` 在 win32 下按 `%LOCALAPPDATA%\Programs\WorkBuddyAI` 的安装版式（`WorkBuddyAI.exe` + `resources\app.asar` + `version` 三项齐全）写入 `WORKBUDDY_AI_ELECTRON_BIN` 提示，绕过非 ASCII 卸载路径上不完整的 PowerShell 回退。已显式设置该变量时永不覆盖，非 win32 直接返回。
* **上下文占用补测试**：`contextOccupancy` 覆盖投影优先、仅压力值、缺任一项、超 100% 封顶四类。

### 修复

* **修复附件句柄文案漏进气泡**：旧线路上 `modelOnly` 丢失时，`[文件附件 …]` / `[图1 …]` / `[File '…' …]` 会以用户气泡、排队预览、复制/编辑内容的形式露出来；现在按文本形态兜底隐藏，`inbox-wire` 也保留 `modelOnly` 标记。
* **修复按内容 id 读文件丢扩展名**：`readFileByAttachmentId` 从 alias 目录恢复原始文件名，`read_file` 的 DOCX / PDF 文本抽取不再退化成无扩展名的裸文件。
* **修复缓存命中率口径**：分母改回全部计费输入桶（uncached + cache read + cache write），与 DSH StatsPills 一致 —— 0.5.29 把 cache write 排除在外，本版按上游口径修正。
* **修复上下文环读数**：有 `projectedTokens` 时优先用它（DSH ContextMeter 口径），否则用 `pressureTokens`；`~` 前缀标明是估算值。
* **修复 token 数字本地化**：ContextMeter 的用量 / 窗口 / 分解行改走 `token-format` 的 `formatTokens(value, t)`，千分位与单位按当前语言呈现，不再硬编码英文缩写。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.30`**（接管 npm `@latest`）。
* Desktop 私有壳版本对齐 **0.5.30**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

---

### Added

* **Drag/drop source path end-to-end**: `ImageAttachmentRef` / `FileAttachmentRef` gain `sourcePath`, carried from client drop resolution → prompt wire → durable commit → Face read-back. `sanitizeAttachmentSourcePath` admits absolute paths only (`/…`, `\\…`, `C:\…`); clipboard paste and bare leaf names are dropped. The local store writes it to a `.source-path` sidecar so reopening the attachment restores it.
* **`read_file` accepts attachment ids**: `createFsTools` takes an optional attachments store, so `path` may be `sha256:…` / `attachment:sha256:…` and still returns content, with a trailing `path:` line (original drop path first, Host alias otherwise). The tool description and fs routing prompt document this.
* **Handle captions carry the source path**: `fileHandleText` / `imageHandleBlock` / `fileUploadHandleBlock` append 「源路径 …」 when `sourcePath` exists, so the model stops guessing where the file lives.
* **WorkBuddy international Electron location**: `ensureWorkBuddyAiElectronBin` writes a `WORKBUDDY_AI_ELECTRON_BIN` hint on win32 when the verified `%LOCALAPPDATA%\Programs\WorkBuddyAI` layout is present (`WorkBuddyAI.exe` + `resources/app.asar` + `version`), bypassing the PowerShell fallback that exits incomplete on non-ASCII uninstall trees. An explicit value is never overridden and non-win32 returns immediately.
* **`contextOccupancy` coverage**: projected-first, pressure-only, missing-either, and >100% clamping cases.

### Fixed

* **Attachment handle captions leaking into the bubble**: when an older wire dropped `modelOnly`, the `[文件附件 …]` / `[图1 …]` / `[File '…' …]` captions surfaced as user bubbles, queue previews and copy/edit content. They are now hidden by text shape as a fallback, and `inbox-wire` preserves the `modelOnly` marker.
* **Extension lost when reading by content id**: `readFileByAttachmentId` recovers the original name from the alias directory, so `read_file`'s DOCX / PDF extraction no longer degrades to an extensionless blob.
* **Cache-hit denominator**: back to all billed prompt buckets (uncached + cache read + cache write) per the DSH StatsPills definition — v0.5.29 excluded cache writes, this release realigns with upstream.
* **Context ring reading**: prefers `projectedTokens` when present (DSH ContextMeter parity), else `pressureTokens`, clamped at 100%; the `~` prefix marks the figure as projected.
* **Token figure localization**: ContextMeter usage / window / breakdown rows go through `token-format`'s `formatTokens(value, t)`, so separators and units follow the active locale instead of hardcoded English abbreviations.
