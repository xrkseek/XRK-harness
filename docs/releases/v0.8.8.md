# v0.8.8

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.7](./v0.8.7.md)：划词贴边跟滚与右键菜单位置；复制后轻扫不再甩顶/底；Desktop 更新状态与安装门闩。

### 完善

* **划词贴边跟滚**：只在拖动手柄 / 延长选区时跟滚；方向按指针最近行，不再按整段选区并集甩动。
* **右键 / 长按菜单**：手机贴按压行上方；滚轮武装短窗口，流式贴底不会误关菜单。
* **Desktop 设置脚更新**：独立状态 pill（检查中 / 下载中 / 可安装 / 失败），悬停不再换成「安装并重启」。

### 修复

* **复制后轻扫对话**：idle 选区不再把 transcript 抽到顶或底。
* **草稿滚轮 / 软键盘收起**：经滚动账本写入，不再被当成读者滑动打断贴底。
* **Desktop 更新**：下载完成前不可安装；失败可见可点重试；手动检查与自动轮询共享进行中的检查；安装中文案与下载进度分离。
* **折叠贴底**：折叠落到地板后，「回到底部」不再粘在中间跟着上移。

### 其他变更

* 公开线版本号对齐 **0.8.8**（npm / Desktop / 手机 / 官网下载同号）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.7](./v0.8.7.md): selection edge-scroll and context-menu placement; no whip after copy; Desktop update status and install gate.

### Improved

* **Selection edge-scroll**: follows only while dragging handles / extending the selection; direction uses the line nearest the pointer, not the full selection union.
* **Context / long-press menu**: on phone, prefer above the pressed line; short wheel/touch arm so streaming floor-follow does not dismiss the menu.
* **Desktop Settings update chip**: dedicated status pills (checking / downloading / ready / failed) — hover no longer swaps to “Install and restart”.

### Fixed

* **Light flick after copy**: an idle highlight no longer yanks the transcript to the top or floor.
* **Draft wheel / soft-keyboard dismiss**: writes through the conversation scroll ledger so stick-to-bottom is not treated as reader motion.
* **Desktop updates**: Install stays disabled until download is ready; failures stay visible and retryable; manual check shares an in-flight automatic check; installing copy is separate from download progress.
* **Fold at floor**: after an in-view fold lands on the floor, the sticky back-to-bottom control no longer rides mid-column upward.

### Other

* Public line version **0.8.8** (npm / Desktop / phone / site download share the same number).
