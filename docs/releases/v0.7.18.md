# v0.7.18

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.17](./v0.7.17.md)：语言可跟随系统；计算机使用默认关闭；向日葵添加干员不再卡死；插件清单双列；Desktop 通知与「命令行 xrkh」卡顿修复；手机更新开安装权限后可自动继续。

### 新增

* 设置 → 语言：增加「跟随系统」；旧安装里被产品默认写成 `en` 的偏好会迁成 `system`，界面与席位标题跟本机语言走。

### 完善

* 设置 → 插件清单：改为双列卡片布局，扫一眼就能对照启用状态。
* 席位标题 / 向日葵身份文案在「跟随系统」时按 Host / 本机 locale 解析（不再误锁英文）。
* Desktop（Windows）：`AppUserModelId` 与安装包 `appId` 对齐，系统通知不再挂到 Chrome 图标；设置 →「命令行 xrkh」读写用户 PATH 改为异步，不再冻住整窗。

### 修复

* 向日葵从目录「添加干员工作区」时真正 `mintHome`，测员等干员不再添加后卡住。
* 计算机使用默认改为关闭；未配置时设置卡不再误显示为 agent-desktop。
* 手机 App：打开「安装未知应用」并返回后自动继续安装；权限已开时点「去开启」不再反复进设置（不必大退）。
* 手机 App：Host 启动失败（如 code 1）时仍显示设置球，可进引擎状态 / 保活 / 更新，不只剩「重试」。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.18
xrkh web
```

桌面安装包见 GitHub Release `v0.7.18` 与站点下载页（AGT 上线后）。手机 APK 见 [XRK-harness-mobile `v0.7.18`](https://github.com/xrkseek/XRK-harness-mobile/releases/tag/v0.7.18)。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.17](./v0.7.17.md): language can follow the OS; computer-use defaults to off; adding roster agents from Sunflower no longer hangs; plugin inventory is two-column; Desktop toast and “CLI xrkh” freezes are fixed; mobile update continues after the install-permission toggle.

### Added

* Settings → Language: “Follow system”; installs that still have the old forced `en` preference migrate to `system` so UI and seat titles track the machine locale.

### Improved

* Settings → Plugin inventory: two-column card layout for quicker enablement scan.
* Seat titles / Sunflower identity copy resolve Host / machine locale when preference is “Follow system” (no longer stuck on English).
* Desktop (Windows): `AppUserModelId` matches the installer `appId` so toasts no longer attach to Chrome; Settings → “CLI xrkh” PATH get/set is async and no longer freezes the window.

### Fixed

* Sunflower “Add agent workspace” actually `mintHome`s catalog agents (e.g. Tester) instead of hanging after add.
* Computer-use defaults to off; a missing settings row no longer looks like agent-desktop.
* Mobile App: after enabling “install unknown apps” and returning, install continues; tapping “Enable” when already allowed no longer reopens Settings (no full quit needed).
* Mobile App: on Host start failure (e.g. code 1) the settings ball stays so engine status / keepalive / updates remain reachable — not only “Retry”.
