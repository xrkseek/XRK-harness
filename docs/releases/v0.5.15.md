# v0.5.15

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.14](./v0.5.14.md)：大会话切换与概况软轮询不再拖死壳；「加载更早」与轮次轨跳转在预算裁切后仍连续；装扮贴纸支持 SVG；Desktop 开屏与 `xrk-app://` 载波一次成型；侧栏可回看打包的变更公告。

Relative to [v0.5.14](./v0.5.14.md): switching a heavy session and soft-polling Overview no longer freeze the shell; “Load earlier” and the turn rail stay contiguous after budgeted history pages; dressing stickers accept SVG; Desktop splash and the `xrk-app://` carrier stay one document; the sidebar can reopen bundled release notes.

### 新增

* 侧栏脚区变更公告（未读红点；打开后记入 `ui-onboarding.releaseNotesReadVersion`），公告文本随构建打包、可回看历史版本。
* Desktop / Web 开屏可玩 Chromium 离线小恐龙（`BootDinoRunner`），Host 与插件就绪前占住等待感。
* Overview 概况 **SWR 加载缓存**：同会话重开立刻画上次 Status / plan / office，再后台刷新。

### 完善

* 完善 `session.history`：在 message 边界分页之外增加约 **1.5MiB** 字符预算，超限从更旧一侧收缩并置 `hasMore`；丢弃已固化 chunk / 裁切后仍保留**日志绝对 seq**（不得按页内下标重编号）；wire 只走页内事件，turn/step 编号在日志增长时只扫后缀。
* 完善 `session.status`：按事件数 · drain · jobs · presence · 委派子树 · 父 presence 做修订缓存，软轮询命中时不再重扫多 MB 日志与每个子会话整段。
* 完善 Overview / PresenceDock 软轮询：空闲 5s 起跳、忙时 1.2s；上一次 Face 慢则拉长间隔并合流在途请求，避免叠压 Host。
* 完善装扮：设置 / Agent Team 贴纸导入接受 **SVG**（与 PNG 等同槽）；Face / 壳归一 FileReader 的 `charset` / url-encoded 形态为规范 base64，避免导入后被 Host 拒写而闪没；眼镜贴纸按 **96×32 半幅**各跟一只眼缩放（不叠引擎黑鼻梁/镜腿，框画在 SVG 里）；贴纸手持略放大；内置眼镜仍为引擎矢量件；家目录 skill `xrk-presence-dressing` 写明半幅构图与 SVG 优先路径。
* 完善 Desktop：产品页全程留在 **`xrk-app://`**，Face / 侧栏经主进程 Host Fetch 桥；开屏到插件就绪不 remount 文档（见 [ADR-0008](../adr/0008-desktop-shell-private-host.md) · [host-face](../host-face.md)）。

### 修复

* 修复点开已结束的大会话时渲染进程长时间无响应：尾页按预算下发，Status 软轮询不再次次全量重建。
* 修复概况每次打开从空态 / 计数从 0 跳变：有缓存先画再刷新。
* 修复大会话「加载更早」与轮次轨跳转失效：预算裁切 / 丢弃 supersede chunk 后若重编 seq，客户端连续性检查会清掉 `hasMore`；现保持绝对序号，更早页尾 seq + 1 等于当前窗 `baseSeq`。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.15`**（接管 npm `@latest`）；npmjs 保留 **0.5.15** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.15**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

---

### Added

* Sidebar-foot release notes (unread red dot; open writes `ui-onboarding.releaseNotesReadVersion`); notes ship in the build and past versions stay readable.
* Playable Chromium offline dino on Desktop / Web splash (`BootDinoRunner`) while Host and plugins come up.
* Overview **SWR load cache**: reopening a session paints the last Status / plan / office immediately, then soft-refreshes.

### Improved

* `session.history`: ~**1.5MiB** char budget on top of message-boundary pages (shrink from the older side, keep `hasMore`); after dropping superseded chunks / trimming, keep **absolute log seq** (never renumber by in-page index); wire only the page; turn/step maps scan only the append suffix when the log grows.
* `session.status`: revision cache keyed by event count · drain · jobs · presence · delegated subtree · parent presence, so soft-polls skip rewalking multi‑MB logs and every child log.
* Overview / PresenceDock soft-poll: 5s idle / 1.2s busy base, stretch after a slow Face reply, coalesce in-flight loads.
* Dressing: Settings / Agent Team stickers accept **SVG** (same slots as PNG); Face and the shell normalize FileReader `charset` / url-encoded SVG to canonical base64 so Host does not reject and wipe the import; glasses stickers use a **96×32 dual-half** layout that tracks each eye (no engine black bridge/temples — draw the frame in the SVG); held stickers scale up slightly; built-in glasses stay engine vectors; home skill `xrk-presence-dressing` documents the half-canvas contract and SVG-first path.
* Desktop: product page stays on **`xrk-app://`** with the main-process Host Fetch bridge; splash → plugins without remounting the document ([ADR-0008](../adr/0008-desktop-shell-private-host.md) · [host-face](../host-face.md)).

### Fixed

* Opening a finished heavy session no longer freezes the renderer for many seconds: budgeted history tails and cached Status soft-polls.
* Overview no longer flashes empty / zero counters on reopen when a prior load is cached.
* “Load earlier” and turn-rail jumps no longer die on heavy sessions: renumbering seq after budget trim / delta drop cleared client `hasMore`; absolute seq keeps older-page tail + 1 equal to the window `baseSeq`.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.15`** (owns npm `@latest`); npmjs keeps **0.5.15** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.15**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
