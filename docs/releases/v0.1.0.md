# v0.1.0

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.11](./v0.0.11.md)：**首个 0.1 公开发版**。在成熟 CLI / Host / Face 主路径之上，本版把产品壳跟至 DSH `dsh-v0.1.1-rc.2` 的引用与附件栈，接上 Face 侧 `@` 发现 remotes，补齐 DSH 社区 Host bridge，并统一本地附件与 DeepSeek 视觉管线。npm 公开线仍为 **`@xrkseek/harness-cli`**；能力边界以 [status.md](../status.md) 为准。

---

## 这版解决什么

0.0.x 已能 `web` / `serve`、Settings 配模型与 MCP、工作区注入与双工具面。0.1.0 把**浏览器里怎么引用文件与会话、怎么挂图片、怎么装社区 DSH 面板**三条用户路径补齐到可依赖的主路径：

| 用户动作 | 0.1.0 行为 |
|----------|------------|
| 输入框打 `@` | `ui-reference` 统一 `@file` / `@session`；菜单分组、quoted token；候选来自 Face 发现 RPC |
| 拖图 / 选图发送 | `ui-attachment` slot 插件渲染 composer 附件栏与消息内图片；`attachment-local` 规范化与 request-image 上限 |
| `plugin add` 社区 client | `dsh-compat` Host + HTTP bridge 覆盖 wire 形状；未覆盖路径返回诚实 JSON，而非 SPA 404 |
| DeepSeek 视觉模型 | Files API 上传复用；`read_image` 带坐标缩放 |

**刻意未做**：不嵌入 Cordis Host 主进程；跨会话 `@session` **prepare**（把另一会话快照注入 prompt）仍依赖 Cordis `sessionQuery`，Face 主路径只做元数据发现。

## 产品壳（`apps/web` + `packages/client`）

对照真源见 [apps/web/UPSTREAM](../../apps/web/UPSTREAM)（tag `dsh-v0.1.1-rc.2`）。组装后 `boot.json` **37** 条插件（含 `client-ui-reference` · `client-session-log-export`；省略 HMR / Cordis UI / native picker）。

| 包 | 本版变化 |
|----|----------|
| `client-ui-attachment` | 从 platform seed 迁为 **slot 插件**：`conversation.input.attachments` · `message.images` |
| `client-ui-conversation` | InputBar 走 attachment slots；保留 `image-limits-projection` |
| `client-ui-subagent` | 会话头 **lineage** + 只读 composer；移除内嵌 `@` 源 |
| `client-ui-reference` | **新增**：统一 `@file` / `@session` input source |
| `client-ui-input-trigger` | rc.2 `@` 语法：quoted token、`showGroupTitle`、候选 `section` / `value` |

欢迎声明改为 XRK-Harness 产品口径（版本戳 `2026-08-23.1`），不再沿用上游营销文案。

维护者从 bar 再同步：

```text
node scripts/resync-client-from-bar.mjs ui-attachment ui-conversation ui-subagent ui-input-trigger
node scripts/resync-context-from-bar.mjs file-reference file-reference-local session-reference
node scripts/resync-context-from-bar.mjs --client ui-reference
```

`resync-context-from-bar.mjs` 会在拷贝后自动应用 harness 侧 tsconfig、package exports→`src`、以及 `search.ts` / `uri.ts` import 修补。

## 引用栈（`@file` / `@session`）

教科书：[modules/references.md](../modules/references.md)。

```text
ui-reference（Web）
  → xrk-api-remotes
  → Face fileReferences/list · sessionReferenceResolver/candidates
  → reference-discovery（工作区索引 + session list 投影）
```

| 层 | 包 / 入口 | 职责 |
|----|-----------|------|
| Web | `@xrkseek/client-ui-reference` | composer `@` 菜单与提交契约 |
| 契约 | `packages/context/*` | grammar · 本地 search · session URI codec |
| Face | `handlers/references.ts` | 发现 RPC；**不**扫 transcript |
| 未接 | `session-reference` prepare | 需 Cordis `sessionQuery`；见 status「未稳」 |

Face wire 已登记上述两个 remote；壳侧经 `@xrkseek/xrk-api-remotes` 绑定。

## 附件与视觉

| 组件 | 说明 |
|------|------|
| `@xrkseek/attachment-local` | 本地存储、编码、压缩上限、`request-image` 管线 |
| `@xrkseek/llm-deepseek` Files API | 视觉上传复用 file id；与 openai-compatible 双闸 |
| `read_image`（`exec-fs`） | 工具结果带坐标缩放，配合会话图片准入 |
| Face `session.attachment` | intake 默认 text+image；与 Registry modality 双闸 |

消息块数组、`MessageContent` 与 MCP 工具结果投影路径与 0.0.x 一致，本版补齐壳上展示与上传管线。

## DSH 社区兼容

不 vendor 整仓上游；经 `extensions/dsh-compat`（`kind: host`）+ `@xrkseek/server-http/dsh-compat` 接入。详见 [community-plugins.md](../community-plugins.md)。

0.1.0 bridge 覆盖四类常见 vendor 缺口（本地可测，非生产级云端长连接）：

| 能力 | bridge 要点 |
|------|-------------|
| Cordis fiber | 进程内 `host.mjs` 失败时 fork 子进程 RPC |
| IM | connector · provision · message.send/list · webhook ingress |
| TongFlow | TS 节点运行时 · `/tongflow/scan` |
| GenUI | React tree live preview |
| Vision | paste/analyze · OCR 启发式 |

社区 client 按 HTTP/RPC **形状**落入 A–J 适配层级，不按包名硬编码 adapter。

### 新增

* 新增产品壳 `@` 引用：`client-ui-reference` 统一 `@file` / `@session` 输入源；Face `fileReferences/list` 与 `sessionReferenceResolver/candidates` 提供工作区路径与会话 mention 候选（元数据发现）
* 新增附件 slot 插件 `client-ui-attachment`：composer 附件栏（`conversation.input.attachments`）与消息图片（`message.images`），经 `boot.json` 加载
* 新增 `packages/context/{file-reference,file-reference-local,session-reference}` 引用契约源码；教科书 [modules/references.md](../modules/references.md)
* 新增 `@xrkseek/attachment-local`：本地附件规范化、`request-image` 管线与压缩上限
* 新增 DSH 社区 Host 兼容器 `extensions/dsh-compat` 与 HTTP bridge（Cordis fiber 子进程、IM 消息/webhook、TongFlow TS 节点运行时、GenUI React tree、vision OCR 启发式）
* 新增 DeepSeek Files API 视觉上传复用；`read_image` 工具支持坐标缩放
* 新增 Face 引用发现实现（`reference-discovery.ts` · `handlers/references.ts`）及 Vitest 覆盖
* 新增 resync 脚本：`resync-client-from-bar.mjs` · `resync-context-from-bar.mjs`（含 harness 自动修补）

### 完善

* 完善产品壳 rc.2 定点 resync：`ui-conversation` InputBar 走 attachment slots；`ui-subagent` 展示 lineage + 只读 composer；`ui-input-trigger` 支持 rc.2 `@` 语法（quoted token、分组菜单）
* 完善 `web:build` + `client:bundle` + `web:assemble` 产物：**37** 条 boot 插件（含 `client-ui-reference` · `client-session-log-export`）
* 完善 `tsdown.client.ts`：context 包内联解析；`dsh-require-remap` 登记 `client-ui-reference`
* 完善欢迎声明为 XRK-Harness 产品口径（版本戳 `2026-08-23.1`）
* 完善 `scripts/check.mjs`：Node ≥26 门禁、`childEnv` 规避 Cursor helper Node 22
* 完善教科书：`host-face.md` · `learn.md` · `status.md` · `community-plugins.md` 与引用/附件边界对齐

### 删除

* 移除 `ui-subagent` 内冗余 `@` 子代理源（`SubagentCatalogAction`；迁至 `ui-reference`）

### 修复

* 修复 `product-shell.test` 与当前 welcome 文案、boot 清单（含 `client-ui-reference`）对齐
* 修复 context 包 resync 后 bar 残留 vendor tsconfig / 缺失 peer 导致 harness 树无法 typecheck 的问题（现由 resync 脚本自动修补）

### 其他变更

* 跨会话 reference **prepare**（快照注入 prompt）仍依赖 Cordis `sessionQuery`，Face 主路径未接
* context 包暂无独立 `lib` 构建；Face / vitest 经 `package.json` exports 指向 `src`
* 需要 Node **≥26**；见 [getting-started.md](../getting-started.md)
