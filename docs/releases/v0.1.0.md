# v0.1.0

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对预览线 [v0.0.11](./v0.0.11.md)：**正式公开线唯一版本**。成熟 CLI / Host / Face 之上，补齐产品壳 `@` 引用与附件主路径、社区插件 Host 兼容器、移动访问门禁，以及安装与壳稳定性修复。npm 公开包为 **`@xrkseek/harness-cli`**（主 bin **`xrkh`**，亦 `xrk-harness`）。能力边界以 [status.md](../status.md) 为准。

Relative to the preview line [v0.0.11](./v0.0.11.md): **the sole formal public release**. On a mature CLI / Host / Face base, this release completes product-shell `@` mentions and attachments, the community-plugin Host adapter, mobile-access gating, and install/shell stability fixes. Public npm package: **`@xrkseek/harness-cli`** (primary bin **`xrkh`**, also `xrk-harness`). Capability truth: [status.md](../status.md).

公开线仅保留本版与预览 [v0.0.11](./v0.0.11.md)；不再保留中间预览或中间正式修订号。

The public line keeps only this release and preview [v0.0.11](./v0.0.11.md); intermediate preview and formal patch numbers are not retained.

---

## 新增 / Added

* 产品壳 `@` 引用：`client-ui-reference` 统一 `@file` / `@session`；Face `fileReferences/list` · `sessionReferenceResolver/candidates`
* 附件 slot 插件 `client-ui-attachment`（composer 附件栏 · 消息图片）
* `packages/context/{file-reference,file-reference-local,session-reference}` 与 `@xrkseek/attachment-local`
* 社区 Host 兼容器 `extensions/dsh-compat` + `@xrkseek/server-http/dsh-compat`（fiber · IM · 任务流 · GenUI · vision · wallet 等）
* DeepSeek Files API 视觉上传复用；`read_image` 坐标缩放
* CLI bin **`xrkh`**；子命令 **`plugin reconcile`**
* 移动访问：LAN/WAN PIN；远程隧道 HTTP+WS；窄屏壳 CSS seam
* 工作区种子与插件开发配方（自 0.0.11 延续并纳入正式线）

## 完善 / Improved

* Hero 标语 **「向阳而生，驭光而行」**（en: *Grow toward the sun. Harness the light.*）；去掉「预览版」角标
* CLI / 文档 / serve 横幅以 **`xrkh`** 为主命令
* monorepo 下 `xrkh web` **优先** `apps/web/dist`；`boot.json` **37** 条插件
* 设置导航按 id 保底；slot 崩溃显示 `[data-slot-error]`；浏览器诊断 `?xrkLog=debug`
* `xrkh serve --verbose`：结构化日志与 pluginsDir / inventory 摘要
* 教科书正式中英双语体例（见 [audiences.md](../audiences.md) · [community-plugins.md](../community-plugins.md)）
* 兼容器底层可迁出边界：`PACKAGE.md` · 子路径 `@xrkseek/server-http/dsh-compat`

## 删除 / Removed

* 移除未接线的 `ui-settings-dsh-bridge`（硬编码分区表方案已否决）
* 移除 `ui-subagent` 内冗余 `@` 子代理源（迁至 `ui-reference`）
* 公开线不再保留 `0.0.1`–`0.0.10` 与 `0.1.1`–`0.1.3` 发行说明与包版本

## 修复 / Fixed

* npm 干净安装：context 包 exports 指向 `dist/`（不再引用未发布的 `src/*.ts`）
* `client:bundle` 门禁：阻止 inline-safe stub 泄漏为浏览器 `require()`（修复「Failed to load plugins」白屏）
* Hero 品牌回退与 `settling` 相位导致新会话中间全黑
* Windows `plugin remove` 无法删除 `@scope` 父目录；inventory 与 staging 不同步
* 社区设置页：cost-meter Typert 外壳、mnemon/memento/chat-import/tokenledger 形状、wallet 余额与刷新
* better-sidebar：ModuleLoader remap、Git/FS/upload/sidechat/browser/jobs 形状与 Face 桥接
* turn-rewind Apply；mobile LAN 配对；pocket 设置页桥接（代理 · 隧道 · version · update）

## 其他变更 / Other changes

* 跨会话 `@session` **prepare**（快照注入 prompt）Face 主路径未接 — 见 status「未稳 / Unstable」
* 需要 Node **≥26**；见 [getting-started.md](../getting-started.md)
* 不嵌入第三方 Host 内核；不对 deepseek-ai 提 PR — 见 [ADR-0002](../adr/0002-no-embed-upstream.md)
