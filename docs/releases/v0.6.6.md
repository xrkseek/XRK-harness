# v0.6.6

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.5](./v0.6.5.md)：会话工程身份与协作边界成文并接线（奇创/IM 编排 · 编码父 · 干员 · fork）；干员默认可续、跟父模型，去掉舰队级 `subagentModel`；子代理座位用锁定芯片展示模型与权限，一次性子会话只读；添加工作区先落位置磁贴（OS 真源路径 · Esc 回退）；新建工作区不跃置顶；策展记忆缺省写区与诚实边界写清。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.6`（发包后）。

Relative to [v0.6.5](./v0.6.5.md): session engineering identity and collab boundaries are documented and wired (Qichuang/IM orchestrator · coding parent · delegated child · fork); children default to continuable and inherit the parent model — the fleet `subagentModel` setting is gone; subagent seats show locked model/permission chips, and one-shot children are view-only; Add Workspace opens on place tiles (OS-resolved paths · Esc restore); new workspaces no longer leap pins; curated-memory default zones and honest limits are spelled out. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.6` (after publish).

### 新增

* **会话工程身份 `kind`**：从 badge / 工作区 / 子代理链路派生 `orchestrator` · `coding_parent` · `delegated_child` · `fork_clone`（契约见 [session-identity.md](../session-identity.md) · 场景走查 [session-identity-scenarios.md](../session-identity-scenarios.md)）。turn-start 板与工具 `dynamicSchema` 按身份重写动词，避免模型猜错 `subagent` / `workspace_session_prompt` / `thread_message`。
* **干员小队板**：委托子会话在 turn-start 看到同父队友与自身任务（不是全仓主线 / 名册板）；同父干员 attach 时自动 `peer` 互连（`label=sibling`，不覆盖手改）。`thread_message` 文案可附 live sibling ids。
* **`close_agent` 与可续默认**：子代理默认可续（`run_in_background` 省略即 continuable）；一次性须显式 `false`。结束走 `close_agent`（interrupt + 末轮助手快照），与只停不回快照的 `interrupt_agent` 分清。
* **应用内目录位置步**：`host.listDirectoryPlaces` + 浏览对话框磁贴（主目录 / 桌面 / 文档 / 下载 / 磁盘 · 最近）；分段、搜索、方向键、Enter；列浏览 Esc 先回磁贴。上次成功的磁贴写入本机，刷新后再开先画缓存再后台更新。远程 / SSH 只暴露工作区根。
* **位置路径 OS 真源**：Windows Known Folder / `shell:Downloads`；macOS `osascript` + `/Volumes`；Linux XDG `user-dirs`；英文 / 中文 / OneDrive 作回退。Desktop Host 与本地 Face 同路径。

### 完善

* **子代理模型跟父、去掉舰队覆写**：删除 Settings → Plugins → Agent loop 的 `subagentModel` 与 `resolveSubagentModelSetting`。子会话路线 = 调用参数钉选，否则继承父会话在 `session.create` 已拷的选择。子代理座位的模型选择器改为只读锁定芯片（向阳权限芯片同构）；权限档在锁定座位同样画静态芯片，不再灰下拉。
* **一次性子会话只读输入区**：`mode=one-shot` 时禁用 composer，占位说明只读；可续子会话仍可 steer / followup。
* **协作工具文案按身份动态生成**：`session-tool-copy.ts` 集中 `subagent` / `list_agents` / `send_message` / `followup_task` / `team_graph` / `thread_message` / `workspace_*` / `session_inspect` 等描述；静态 description 只留短契约。
* **策展记忆缺省写区与诚实文档**：主会话默认 `scope=session`，有干员 `memberId` 时默认 `agent`；会话结束 Phase1/2 写入该会话分层 store（不再误走单独 home-only global provider）。工具 / 策略段强调 `action` 或非空 `operations` 必填；[curated-memory.md](../curated-memory.md) 补分层完整性表（写盘成功 ≠ 本会话冻结段刷新）。
* **工作区选择器（对齐选模型菜单）**：弹出限高约 360px、列表内滚动；有工作区时始终显示搜索（名称 / 路径）；行下附路径；基线刷新时保留上次列表，避免空窗。Create upsert **追加**到未置顶段末尾。
* **菜单 / 壳细节**：Menu 限高时 `overflow` + viewport 滚动，页脚「添加」钉住；站立 `AGENTS.md` 与子代理 / 会话查询提示词跟身份矩阵对齐。
* **运行时 / 注入 / 概览 / 轨迹过渡**：目录、任务、画布、变更 diff、轨迹在刷新时先留上次画面，新结果到了再原地替换（不插「正在更新」把列表顶开）。无本会话缓存时运行时 / 注入可先画最近一次成功帧。搜索 / 展开不串会话。

### 修复

* **子代理锁定芯片显示已钉选模型**：只读座位仍读取 `session.models`，芯片画出路线名；切换仍拒绝。不再停在「选择模型」。
* **Agent Team 更易懂 + 导出导入**：名册空态写清「名称 / 职责 / Playbook」步骤；导出下载 `xrk-agent-member` JSON（不含外形）；导入文件或 `team_import` 只落能力面。子代理一律不能 `team_save` / `team_import`；人类决策走 `ask`（卡片出在父会话）。
* **子会话工具面按场景收紧**：委派子会话卸掉继承的父工具（`ask_user`、名册写入、settings、workspace、canvas、`propose_skill`）；角色禁令叠加。`<session_capability>` 是真源（`omitted` · `child_gap` · `human_face`）；站立 / spawn / 工具动态文案只指路不复述。
* **提示词工程 Codex 分层**：capability 报事实、posture 报派活动词、collab/squad 板报 ids、向阳 skills（revision 3）与站立 `AGENTS.md` / `xrk-delegate` 压成短 playbook，去掉跨层复诵。
* **无位置 RPC 时浏览不空白**：`listDirectoryPlaces` 失败或未注入时直接落主目录列浏览。
* **记忆空 `action` 报错可执行**：提示须传 `add|replace|remove|list` 或非空 `operations`，不再只报 `Unknown action ''`。

## 验证

* 向阳 / IM：turn-start 可见 `kind=orchestrator`；应用内无 nested `subagent` 实现路径。
* 编码父 spawn 干员：默认可续；子座位模型 / 权限为锁定芯片；小队板列出 sibling。
* Settings → Agent loop：**没有**「子代理模型」字段。
* 添加工作区：先磁贴（桌面 / 文档 / 下载 / 盘符），Esc 回退两级；新建未置顶项不插到钉前。
* 策展记忆：主会话写入默认进 `session` 区；空 `action` 报错含可执行示例口径。
* 运行时 / 注入：在会话 A 搜索后切到 B 再回 A，应立刻看到 A 的上次目录与搜索词，短暂「正在更新…」后数字若变才替换。

### Added

* **Session engineering identity `kind`**: derived as `orchestrator` · `coding_parent` · `delegated_child` · `fork_clone` ([session-identity.md](../session-identity.md) · [session-identity-scenarios.md](../session-identity-scenarios.md)). Turn-start boards and tool `dynamicSchema` rewrite verbs per identity so the model stops guessing among `subagent` / `workspace_session_prompt` / `thread_message`.
* **Delegated-child squad board**: children see same-parent teammates and their own task — not the full workspace 主线 / roster. Same-parent children auto-`peer` on attach (`label=sibling`, no overwrite of hand-edited labels). `thread_message` copy may include live sibling ids.
* **`close_agent` and continuable-by-default**: omit `run_in_background` → continuable; one-shot requires explicit `false`. Closing uses `close_agent` (interrupt + last-assistant snapshot), distinct from interrupt-only `interrupt_agent`.
* **In-app directory places step**: `host.listDirectoryPlaces` plus tile UI (home / Desktop / Documents / Downloads / drives · recent) with sections, search, arrows, Enter; Esc from columns restores tiles. The last successful tile set is stored locally and painted immediately on the next open, including after refresh. Remote / SSH exposes only the workspace root.
* **OS-resolved place paths**: Windows Known Folder / `shell:Downloads`; macOS `osascript` + `/Volumes`; Linux XDG `user-dirs`; English / Chinese / OneDrive fallbacks. Desktop Host shares the local Face path.

### Improved

* **Children inherit the parent model; fleet override removed**: Settings → Plugins → Agent loop no longer has `subagentModel`; `resolveSubagentModelSetting` is gone. Child route = per-call pin, else the parent selection copied at `session.create`. The subagent model seat is a read-only locked chip (same chrome as 向阳 permission); locked permission seats are static chips too.
* **One-shot children are view-only**: `mode=one-shot` disables the composer with a read-only placeholder; continuable children still steer / follow up.
* **Collab tool copy is identity-dynamic**: `session-tool-copy.ts` owns `subagent` / `list_agents` / `send_message` / `followup_task` / `team_graph` / `thread_message` / `workspace_*` / `session_inspect` descriptions; static descriptions stay short contracts.
* **Curated memory default zones + honest docs**: main session defaults to `scope=session`, roster children to `agent`; session-end Phase1/2 writes that session’s layered store (not a separate home-only global provider). Tool / policy text requires `action` or a non-empty `operations` batch; [curated-memory.md](../curated-memory.md) adds a completeness table (disk write ≠ refreshing this composition’s freeze).
* **Workspace picker (model-menu shape)**: ~360px capped card with internal scroll; search always on when any workspace exists (title / path); path under each row; last list kept across a pending baseline so the menu does not blank. Create upsert **appends** after pins.
* **Menu / standing copy**: Menu height cap scrolls the viewport (footer add stays pinned); standing `AGENTS.md` and subagent / session-query prompts align with the identity matrix.
* **Runtime / Inject / Overview / trajectory transitions**: catalogs, todos, canvas, change diffs, and the trajectory ledger keep the last frame while a refresh runs, then replace in place (no “Updating…” row that shifts the list). A session with no catalog row yet can paint the latest successful frame. Search and expand stay per session.

### Fixed

* **Locked child chip shows the pinned model**: the read-only seat still reads `session.models` and paints the route; switching stays refused. The chip no longer stays on “Select model”.
* **Agent Team clearer + export/import**: empty roster explains name / duty / playbook; Export downloads an `xrk-agent-member` JSON file (no costume); Import / `team_import` apply capability only. Children never get `team_save` / `team_import`; human decisions use `ask` (card on the parent session).
* **Child tool surface is scenario-scoped**: delegated children drop inherited parent tools; role denials stack. `<session_capability>` is the source of truth (`omitted` · `child_gap` · `human_face`); standing / spawn / tool dynamic copy only point there.
* **Codex-shaped prompt layers**: capability = facts; posture = dispatch verbs; collab/squad boards = ids; Xiangyang skills (revision 3) and standing `AGENTS.md` / `xrk-delegate` are short playbooks with no cross-layer re-lecture.
* **Browse without places stays usable**: missing or failed `listDirectoryPlaces` falls through to the home listing.
* **Empty memory `action` is actionable**: errors say to pass `add|replace|remove|list` or a non-empty `operations` array.

## Verify

* Qichuang / IM: turn-start shows `kind=orchestrator`; no nested `subagent` implementation path in-app.
* Coding parent spawns a child: continuable by default; model / permission seats are locked chips; squad board lists siblings.
* Settings → Agent loop: **no** “subagent model” field.
* Add Workspace: tiles first (Desktop / Documents / Downloads / drives), two-level Esc; a new unpinned workspace stays below pins.
* Curated memory: main-session writes default to the `session` zone; empty `action` errors are actionable.
* Runtime / Inject: search in session A, switch to B, return to A — A’s last catalog and query paint immediately; a brief “Updating…” soft-refresh may replace counts.
