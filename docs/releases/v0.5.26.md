# v0.5.26

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.25](./v0.5.25.md)：写文件 / 编辑类工具在流式参数阶段就能画出 diff；工具行、推理行、技能行的跑动辉光改为合成器动画；所有跑动光带都尊重「减少动态效果」偏好；附件句柄的 modelOnly 标记不再在 Face 适配层丢失。

Relative to [v0.5.25](./v0.5.25.md): write / edit tools paint their diff while arguments are still streaming; the running sweep on tool, reasoning, and skill rows becomes a compositor animation; every running band honors reduced-motion; the modelOnly flag on attachment handles no longer drops at the Face adapt layer.

### 修复

* 修复写文件 / 编辑类工具在流式阶段没有 diff 可看：Host 的 `tool/call` 尚未到达时（`callView` 为空），模型原先只能等，现在从已解析完整的 `argsRaw` 推出临时 diff，JSON 一闭合就能画。覆盖 `write_file` / `write` / `fx-write` 与 `apply_edit` / `edit`，并兼容 `file_path` / `old_string` / `new_string` 等旧字段别名。
* 修复 `write_file` / `apply_edit` / `read_file` 的 Host 线名没挂上专用行组件：工具视图注册键从简写名换成 exec-fs 的实际线名，fixture 简写名保留兼容。`apply_patch` 归入编辑族外观。
* 修复附件句柄的 modelOnly 标记在 Face 线适配时被剥掉：`user/message` 的文本块现在原样带出 `modelOnly`，客户端得以隐藏内部句柄文字，而持久日志与模型的 `flattenText` 仍能拿到它。

### 完善

* 完善跑动辉光的动画开销：工具行、推理行、通用命令卡、技能行、bash 示例行的扫光从动画 `left`（每帧触发布局）改为 `transform` + `will-change`（纯合成器），容器加 `container-type: inline-size`，扫光终点用 `100cqw` 跟随实际行宽。
* 完善 Overview 刷新扫光：同理由 `background-position` 改为 `transform`，视觉范围与原先一致。
* 完善「减少动态效果」支持：所有跑动光带在 `prefers-reduced-motion: reduce` 下真正隐藏（不再只是停在首帧），状态点改为静态低透明度，DisclosureRow 的图标过渡关闭。
* 完善 DisclosureRow / SkillRow 的展开提示：展开时箭头旋转 180°，并补上 `contain: style` 隔离样式重算。
* 完善动效时长口径：图标淡入淡出改用设计系统的 `--ds-motion-instant` / `--ds-ease-out`。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.26`**（接管 npm `@latest`）；npmjs 保留 **0.5.26** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.26**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

---

### Fixed

* Write / edit tools had no diff while arguments streamed: before Host emits `tool/call` (`callView` is null) the model had nothing to show. It now derives a provisional diff from a fully parsed `argsRaw`, so the diff paints as soon as the JSON closes. Covers `write_file` / `write` / `fx-write` and `apply_edit` / `edit`, accepting the `file_path` / `old_string` / `new_string` aliases.
* `write_file` / `apply_edit` / `read_file` wire names were not bound to their dedicated rows: toolview registration keys moved from fixture short names to the exec-fs wire names, with the short names kept for samples. `apply_patch` joins the edit-family chrome.
* The modelOnly flag on attachment handles was stripped at the Face wire adapt: `user/message` text blocks now carry `modelOnly` through, so the client can hide the internal handle caption while the durable log and the model’s `flattenText` still receive it.

### Improved

* Running-sweep cost: the tool row, reasoning row, generic command card, skill row, and bash sample row sweep moved from animating `left` (layout every frame) to `transform` + `will-change` (compositor only), with `container-type: inline-size` so the sweep end tracks the real row width via `100cqw`.
* The Overview refresh sweep likewise moved from `background-position` to `transform`, covering the same visual range.
* Reduced-motion support: every running band is now actually hidden under `prefers-reduced-motion: reduce` (it used to freeze on the first frame); the state dot becomes a static dim dot; DisclosureRow icon transitions are off.
* DisclosureRow / SkillRow open cue: the chevron rotates 180° when open, plus `contain: style` to isolate style recalculation.
* Motion tokens: icon fades use the design system’s `--ds-motion-instant` / `--ds-ease-out`.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.26`** (owns npm `@latest`); npmjs keeps **0.5.26** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.26**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
