# v0.7.0-rc.3

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.0-rc.2](./v0.7.0-rc.2.md)：第三过程号。收口 **席位展示底层**（内置干员多语正式名 · 正式名（昵称）· 向日葵经理席对位）、**概况 / 干员团队球标题**、**模型设置 Default Model 软刷新**、**对话轮次 / 插话标记**、**后台子代理父会话镜像延后**，以及 **席位信道前缀**、**策展记忆 live 片段**、**向日葵免费卡**、**移动端 / 特权连接面**。npm dist-tag **`@rc`** 指向本号（**不**接管 `@latest`；`@latest` 仍为 **0.6.23**）。

Relative to [v0.7.0-rc.2](./v0.7.0-rc.2.md): third process number. Lands **seat-label foundation** (locale formals for catalog agents · formal（nick） · sunflower as manager-counterpart), **Overview / TeamRoster captions**, **Models Default Model soft refresh**, **chat round / steer marks**, **deferred parent mirror for background subagents**, plus **seat-channel prefixes**, **curated-memory live fragment**, **Sunflower-free card**, and **mobile / privileged connection plane**. npm dist-tag **`@rc`** points here (**does not** take `@latest`; `@latest` stays **0.6.23**).

### 新增

* **内置干员多语正式名**：Host `catalog-seed-labels` 为 catalog 种子提供 zh / en / ja 正式名；存储可保留稳定 `name`，Chrome / Team / 概况统一解析。
* **向日葵命名契约**：正式名 `向日葵` / `Sunflower` / `ひまわり`；锁定昵称 **`xrkseek`**（不可改）。向阳 Overview 右球为 **经理 · 向日葵（xrkseek）**（经理席对位，不再把 `xrkseek` 当正式名）。
* **席位信道前缀**：委派子席入账可带 `[老板…]` / `[经理…]` 等标记；文案跟 Settings 席位称呼，不硬编码中文。
* **对话「插话」轮次标**：同 Host 轮内非开场用户行标「第 N 轮 插话」；开场仍为「第 N 轮」；自动「继续」不重复轮次标。
* **Team 席位 live 覆盖**：改昵称 / 外观时乐观写入本地 live，概况球即时跟上；纯外观补丁不再用 `nickname:null` 清掉 Face 昵称。
* **策展记忆 live 片段**：MEMORY / USER 经 last-wins `additional_context` 热推；turn 开头有文则注入，工具后仅在正文指纹变化时再推。
* **向日葵免费设置卡**：Plugins 面独立 egress 卡（OpenCode + Kilo）；Save 可 remount / 再探测，不必整机重启。

### 完善

* **概况双球标题**：右球 `正式名（昵称）`（如 `干员 · 创业作业（成经吴）`）；左球委派方跟 Face `parentLabel` / 席位 id；缺 `memberId` 的旧 spawn 可按正式名回查 roster。
* **干员团队席位卡**：卡片名只显示正式短签（昵称进编辑区）；席位行均分宽度 + `overflow` 省略，长名不再撑破卡片。
* **模型设置 Default Model**：`providerOrder` / `settings/document-updated` 走软刷新；选项集合未变时不卸载 Default Model 卡。
* **后台子代理父会话镜像**：父侧「User message to background subagent …」延到该 admit `prompt/promoted`（真正进 step）再写，避免排队阶段抢先入父 transcript。
* **`present` 多文件头**：交付物行可为每个路径单独可点开链。
* **移动端访问 / 特权面**：PIN 页跟产品主题；公网 / 非回环部署可声明 privileged / trusted 主机；回环与 PIN 遥控面分离更清晰。
* **连接 / 操作员抬权**：loopback · LAN · 抬权 RPC 口径加厚，非回环听口下的 Settings / 凭据面更稳。

### 修复

* **拖动提供方顺序后 Default Model 卡消失**：硬 `load` 把 status 打回 loading；现为软刷新并保留选项集合。
* **概况缺昵称**：live 仅改外观时曾下发 `nickname:null` 盖掉 Face 正式名（昵称）；现仅在显式改昵称时覆盖。
* **向日葵显示成 `xrkseek（向日葵）`**：正式名 / 昵称对调；Overview 前缀为经理席对位。
* **向日葵免费 remount**：`syncSunflowerFree` 正确挂到 Face runtime 选项，Settings Save 可热同步。
* **无头 Linux `host.openPath`**：CI / 无 GUI 环境接受 `not-implemented`，不再误判失败。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.7.0-rc.3`**（npm dist-tag **`rc`**；`@latest` 仍为 **0.6.23**）。
* Desktop 私有壳对齐 **0.7.0-rc.3**（与 `apps/cli` / `packages/sdk` 同号）。
* Host 冷启动在 `cron ticker started` 之后仍有 Face 组装 / WorkflowEngine 探测等静默段；**cron 本身不阻塞** listen；MCP reconcile 在 listen 之后继续。

# v0.7.0-rc.3

> **Audience**: End users · Integrators · Maintainers (release notes)

Relative to [v0.7.0-rc.2](./v0.7.0-rc.2.md): third process number. Lands **seat-label foundation** (locale formals for catalog agents · formal（nick） · sunflower as manager-counterpart), **Overview / TeamRoster captions**, **Models Default Model soft refresh**, **chat round / steer marks**, **deferred parent mirror for background subagents**, plus **seat-channel prefixes**, **curated-memory live fragment**, **Sunflower-free card**, and **mobile / privileged connection plane**. npm dist-tag **`@rc`** points here (**does not** take `@latest`; `@latest` stays **0.6.23**).

### Added

* **Locale formals for catalog agents**: Host `catalog-seed-labels` supplies zh / en / ja formals; disk may keep a stable `name`, while chrome / Team / Overview resolve through one path.
* **Sunflower naming contract**: formal `向日葵` / `Sunflower` / `ひまわり`; locked nick **`xrkseek`**. Xiangyang Overview right ball is **经理 · 向日葵（xrkseek）** (manager counterpart — `xrkseek` is no longer the formal).
* **Seat-channel prefixes**: delegated-child admits may carry `[老板…]` / `[经理…]` markers from live Settings seat titles (never hardcoded Chinese).
* **Chat “steer” round marks**: mid-turn human rows show 「第 N 轮 插话」; openers stay 「第 N 轮」; auto-continue does not repeat the mark.
* **Team live nick/look overlay**: optimistic local live for nick / appearance so Overview balls update immediately; look-only patches no longer clear Face nick via `nickname:null`.
* **Curated-memory live fragment**: MEMORY / USER ride a last-wins `additional_context` row; inject on turn start when non-empty, and after tools only when the body fingerprint moves.
* **Sunflower-free Settings card**: dedicated egress card (OpenCode + Kilo); Save can remount / re-probe without a full Host restart.

### Improved

* **Overview dual-ball captions**: right ball `formal（nick）` (e.g. `干员 · 创业作业（成经吴）`); left seat follows Face `parentLabel` / member id; older spawns without `memberId` can match roster by formal name.
* **TeamRoster seat tiles**: card label is formal short name only (nick lives in the editor); seats share width with contained ellipsis — long names no longer blow the card.
* **Models Default Model**: `providerOrder` / `settings/document-updated` use soft refresh; unchanged option sets keep the Default Model card mounted.
* **Background-subagent parent mirror**: parent 「User message to background subagent …」 waits until that admit is `prompt/promoted` (enters a step), so queued admits do not hit the parent transcript early.
* **`present` multi-file header**: each deliverable path can be its own openable link.
* **Mobile access / privileged plane**: PIN pages follow product theme; WAN / non-loopback deployments can declare privileged / trusted hosts; loopback vs PIN remote stay separate.
* **Connection / operator elevation**: thicker loopback · LAN · elevation RPC posture for Settings / credentials off loopback.

### Fixed

* **Default Model card vanishing after provider reorder**: hard `load` flipped status to loading; soft refresh keeps the option set.
* **Missing Overview nick**: look-only live patches used to push `nickname:null` over Face formal（nick）; nick overlays only when nick is explicitly edited.
* **Sunflower shown as `xrkseek（向日葵）`**: formal / nick swapped; Overview prefixes the manager seat.
* **Sunflower-free remount**: `syncSunflowerFree` wires through Face runtime options so Settings Save can hot-sync.
* **Headless Linux `host.openPath`**: CI / no-GUI accepts `not-implemented` instead of a false failure.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.7.0-rc.3`** (npm dist-tag **`rc`**; `@latest` stays **0.6.23**).
* Private Desktop shell aligns to **0.7.0-rc.3** (same number as `apps/cli` / `packages/sdk`).
* After `cron ticker started`, Host still runs a quiet Face / WorkflowEngine stretch; **cron itself does not block** listen; MCP reconcile continues after listen.
