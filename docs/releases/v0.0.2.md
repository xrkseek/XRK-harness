# v0.0.2

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.1](./v0.0.1.md)：修复全局 / `npx` 安装后缺 `zod` 无法启动。

### 修复

* 修复 `@xrkseek/harness-cli` 捆绑依赖：补入 MCP SDK 所需的 `zod`，避免 `npm install -g` / `npx` 报 `ERR_MODULE_NOT_FOUND`

### 其他变更

* 发版 stage 在打 tarball 前校验 `node_modules/zod` 已 hoist，缺则失败

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.2
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.2 web`
