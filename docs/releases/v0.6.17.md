# v0.6.17

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.16](./v0.6.16.md)：**提供方 / 模型双层 HTTP 代理**；**设置面板焦点与深链**；**输入与列表可触控可滚动手感**。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.17`（发包后）。

Relative to [v0.6.16](./v0.6.16.md): **provider / model HTTP proxy layers**; **Settings focus trap and deep links**; **touch / scroll polish on inputs and lists**. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.17` (after publish).

### 新增

* **出站 HTTP 代理（双层）**：Settings → 提供方可设默认代理；模型「能力」可单独覆盖。模型优先于提供方；两边都空则继承进程 `HTTP(S)_PROXY`（未设环境代理即直连）。填 `direct` / `none` 强制不走代理。

### 完善

* **设置面板**：打开时 `#root` 为 `inert`，Tab 不再逃到背景；多层确认框时 Escape 先关内层；`#/settings`、`#/models` 等 hash 可打开对应分区，关闭时清 hash。
* **详情列折叠**：折叠态整列 `inert`，焦点不会落到隐藏控件。
* **触控与滚动**：Switch / 字号行命中区加大；设置选项区 `scroll-padding` + 聚焦滚入视口；输入框与菜单列表焦点环更清晰；复制反馈更稳。
* **Markdown**：单波浪线不再误判为删除线；代码块复制按钮手感对齐。

### 修复

* **Apply 密钥探测**：仅认证形失败拦写入；网络 / 无 listing 仍可保存配置。
* **Modal Escape**：内层对话框先处理，避免误关整页设置。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.6.17
xrkh web
```

或 `npm i -g @xrkseek/harness-cli@latest`（发包后）。

## 验证

* 在提供方填 `http://127.0.0.1:7890`，该提供方下未单独配代理的模型走此代理；某模型填 `direct` 则该模型直连。
* 打开设置后连续 Tab：焦点留在面板内；关闭设置后焦点回到齿轮。
* 访问带 `#/models` 的 URL：打开设置并落在模型页。

---

### Added

* **Outbound HTTP proxy (two layers)**: Settings → provider default proxy; per-model override under Capacities. Model beats provider; both empty inherit process `HTTP(S)_PROXY` (direct when unset). `direct` / `none` force no proxy.

### Improved

* **Settings panel**: `#root` is `inert` while open so Tab stays inside; nested confirms own Escape first; `#/settings` / `#/models` hashes open the matching section and clear on close.
* **Collapsed details column**: whole column is `inert` so focus cannot land on hidden controls.
* **Touch and scroll**: larger Switch / font-size hit targets; options pane `scroll-padding` + focus scroll-into-view; clearer focus rings on inputs and menus; stabler copy feedback.
* **Markdown**: a lone tilde is no longer treated as strikethrough; code-block copy control matches other surfaces.

### Fixed

* **Apply key probe**: only auth-shaped failures block writes; network / missing listing still saves.
* **Modal Escape**: inner dialogs handle Escape before the Settings panel closes.
