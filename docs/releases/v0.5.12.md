# v0.5.12

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.11](./v0.5.11.md)：回合轨现在按**整段日志的无空隙轮次**编号，并把导航收进 10 格滑动镜头（读者不在尾部时额外钉一根「回到底部」的底格）；`turnOutline` 投影新增 `round`，没有人类开场的 Host 轮次不再占号；历史分页在接线任何一页之前先按全日志编号，首轮不会再显示成「第 5 轮」；对话流上每条用户开场消息上方直接标「第 N 轮」；Stop 只给真正被截断的那一步打「已停止」；插队改成在 `runTurn` 工具步边界认领，不必等整轮跑完；`team_save` 接受自然 id（自动补 `mem_` 前缀）并对非法 id 明确报错；设置与 Agent Team 的装扮拆成帽 / 眼镜 / 手持三槽，手持带内置小道具并跟球一起动。

Relative to [v0.5.11](./v0.5.11.md): the turn rail numbers by the whole-log gapless 轮次 and navigates through a 10-mark sliding camera (plus an 11th floor tick that jumps back to the bottom when the reader is not on the tail); `turnOutline` gains `round` and Host turns without a human opener no longer occupy a slot; history primes wire numbers from the full log before wiring a page, so the opening round no longer shows as “第 5 轮”; each human opener carries an on-flow “第 N 轮” label; Stop marks only the step it actually cut; a steer is claimed at the `runTurn` tool-step boundary instead of waiting for the whole turn; `team_save` accepts natural ids (prefixing `mem_`) and reports illegal ones instead of dropping them; Settings and Agent Team costumes split into hat / glasses / held slots, with held builtins that ride the ball.

### 新增

* 新增 `turnOutline.round`：已发布 opener 上的无空隙轮次（从 1 起），与 Host `turn`（跳转键）分开。视图丢弃 `prompt===''` 的 Host 轮次后再编号；`stateVersion` 2 → 3。
* 新增 `thread_message`：同一工作区里已挂主线的**主会话**互发消息；以 steer 插队进对方会话（不跟 Settings `busyEnter` 排队）；默认等待对方本轮助手回复并回传到发起方。不是子代理（子会话仍用 `send_message` / `followup_task`）。
* 新增全局名册种子：探网员 / 文书员 / 排障员 / 测员；Agent Team 全局栏也可「新建」。
* 新增 `FaceWireIdMaps.primeFromLog()`：`session.history` 在接线任何一页之前按**全日志**的 `turn/start` / `step/start` 预分配 wire 编号。
* 新增 `owningTurnStartIndex()`：历史分页的消息数切点回退到该事件所属的 `turn/start`，切点不再落在同一轮的后续 assistant 上。
* 新增轨上滑动镜头 `slideTurnRailWindow()`（`TURN_RAIL_WINDOW = 10`）：读者不在最新一轮时，把会话最新一轮作为第 11 格「回底部」刻度钉住，并留出 `FLOOR_SKIP_PX` 的视觉间隔。
* 新增对话流内的「第 N 轮」标签：`ChatNodeSeat` 按 `roundByTurn` 只在用户开场行右对齐渲染小号标签。
* 新增 `normalizeMemberId()` / `memberIdProblem()`：自然 id（如 `xrk-releaseer`）补 `mem_` 前缀而不是被丢弃；非法 id 返回可读错误。
* 新增 `promotePendingSteers()` 在 `runTurn` 工具步边界被调用：上一步工具 settle 后、下一次 `chat()` 之前认领全部 pending steer（不碰 queue），开篇第一步跳过，以免 `continueTurn({ text })` 抢走 inbox 里的插队。
* 新增手持内置装扮：小花 / 茶杯 / 小旗 / 火花（设置 → 通用设置，以及 Agent Team 成员外观）。
* 新增家目录 skill `xrk-presence-dressing`：用 `image_generate` 出透明贴图，再点该槽的 **+** 导入（不要把 data URL 塞进工具参数）。

### 完善

* 完善回合轨：刻度更贴近调宽条（`translateX(-100%)` 停在宽度手柄内侧），三档长度收敛为 rest 6px / 底格 12px / 阅读位 22px，悬停不再制造第四档；底格始终是「会话最新一轮」，中长，不分是否正在输出。
* 完善阅读位判定：`resolveActiveTurn` 新增 `loadedTurns`，底部与「没打中任何行」的回退只认**最新已加载轮**，不再认整段日志里最新的 offer tick。
* 完善轨数据源：`mergeTurnRailItems` 接受「已加载且有 `turn/start` 的 Host 轮」集合，纯 outline-only 的刻度不会挡住已加载行；`round` 缺省时才回退到 prompted 序号。
* 完善 assistant 节点：`stoppedAtThisStep()` 只有真正被 Stop 截断的那一步打「已停止」；turn 级 abort 原因不再盖到同轮已完成的前序步骤（回合尾部仍保留 turn 级标记）。
* 完善插队语义：等当前**工具步**结束就进同一 Host turn 的下一次模型请求（不再等整轮）；等待期壳文案由「插队中」改为「发送中」，认领后即普通发送。
* 完善插队徽章：用户气泡的「发送中」只认 inbox claim（`pendingAdmitId`），不再按当前回合形状推断；编辑 / 删除同样只跟 inbox。
* 完善名册 id 校验：`team_save` 与 `team/upsert` 两条入口都在落库前校验 id，错误文案写明 `mem_` 规则、长度上限与「省略即生成」。
* 完善内置名册：`mem_seed_*` 不可改、不可删、不可 overlay；定制走「以该预置为基底新建」。
* 完善站立 Skills 与 Agent Team：有子代理工具时名册命中则 spawn；**Frugal / 无子代理徽章**仍 Skill-load，不强迫 spawn。
* 完善装扮：帽 / 眼镜 / 手持分槽，导入只落当前点的那一槽；选择块缩小，导入加号改为虚线小格。
* 完善手持：内置道具画在球身上，跟着弹跳和转头，不再是舞台上的死贴图。
* 完善表情球颜色卡：当前选中项有底板和描边。

### 删除

* 删除 `TurnNavigator` 的 `.markPreview`（悬停加长）样式与对应过渡。

### 修复

* 修复尾页先到时开场轮显示成「第 5 轮」：wire 编号改为按全日志「首次出现」序预分配。
* 修复长会话（90 轮）从尾部打开时标成「第 87 轮」：轨上的「第 N 轮」不再随加载窗口重新编号。
* 修复分页切点落在同一轮的后续消息上，导致该轮开场消息不在本页、轨跳转落错位置。
* 修复在底部时轨标的是最新 offer tick 而不是最新已加载轮，尾页第一泡被当成整段日志的第 N 轮。
* 修复 turn 级 Stop 在同轮每一步都打「已停止」。
* 修复插队在工具跑完后仍等到整轮结束才进模型请求。
* 修复子代理 Overview 委派方球丢主会话 `presence_set` 文案、回落到「待机巡演」。
* 修复给另一条主线上的会话发 `thread_message` 前误调 `thread_switch`：发信不改本会话钉；switch 只在要共用那条钉时用。
* 修复侧栏 Agent Team 装扮库 `getSnapshot` 每次分配新数组，触发无限更新直至崩溃。
* 修复同时戴帽和眼镜时引擎缺 `layoutSpecsLens`，球停在加载。
* 修复设置里选手持内置立刻弹回「无」：Face 校验现在接受 `flower` / `tea` / `flag` / `spark`。
* 修复戴眼镜后一只眼暂时不可见时 `specSize` 打崩动画循环，球一直转圈。
* 修复帽子贴图出现在眼镜和手持三行。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.12`**（接管 npm `@latest`）；npmjs 保留 **0.5.12** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.12**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 验证

* 90 轮会话从尾部打开：对话流第一条用户消息上方标「第 1 轮」，轨最下一格也是「第 1 轮」，末轮标「第 90 轮」。
* 读者滚到中部：轨最多 10 格，末尾额外一根底格（会话最新一轮），点底格回到底部；回到底部后不重复出现底格。
* 只发过开场但被 Stop 的 Host 轮次不占轮次号：轨上不出现空刻度，下一条开场消息仍是下一个无空隙号。
* 长会话翻页：跨页跳转后轮次号与整段日志一致，不随窗口重编号。
* 一个回合跑多个工具步时点 Stop：只有最后一步显示「已停止」，前面完成的步骤不显示。
* 工具还在跑时插一条人话：当前工具 step 结束后立刻进入同一回合的下一次模型请求，等待期气泡标「发送中」且可撤回。
* `team_save` 用 `id: "xrk-releaseer"`：成功并返回 `mem_xrk-releaseer`；用 `id: "bad id!"`：返回可读错误而不是静默丢弃。
* 设置 → 通用设置选手持「小花」：选中态保持，球右下角花跟着弹跳；点眼镜后球能出来，不再一直转圈。
* 颜色卡当前项有描边；帽槽导入的贴图不出现在眼镜 / 手持行。

### Added

* `turnOutline.round`: gapless 轮次 among published openers (from 1), separate from the Host `turn` jump key. The view drops `prompt===''` Host turns before numbering; `stateVersion` 2 → 3.
* `thread_message`: parent sessions already on a 主线 in the same workspace can message each other as steer (not Settings `busyEnter` queue); wait (default) returns the peer’s next assistant reply. Not a subagent (`send_message` / `followup_task` stay for children).
* Global roster seeds: web scout, docs writer, debugger, tester; Agent Team global rail also has New.
* `FaceWireIdMaps.primeFromLog()`: `session.history` primes wire numbers for `turn/start` / `step/start` from the **whole log** before wiring any page.
* `owningTurnStartIndex()`: a history message-count cut falls back to the owning `turn/start` instead of a later assistant of the same turn.
* Rail camera `slideTurnRailWindow()` (`TURN_RAIL_WINDOW = 10`): when the reader is not on the newest 轮次, the session newest is pinned as an 11th floor tick (jump to bottom) with a `FLOOR_SKIP_PX` visual gap.
* An on-flow “第 N 轮” label: `ChatNodeSeat` renders a small right-aligned label on the human opener row via `roundByTurn`.
* `normalizeMemberId()` / `memberIdProblem()`: a natural id (e.g. `xrk-releaseer`) is prefixed with `mem_` instead of dropped; an illegal id returns a readable error.
* `promotePendingSteers()` is called at the `runTurn` tool-step boundary: after the previous tool settles and before the next `chat()`, every pending steer is claimed (queues untouched). The opening step is skipped so `continueTurn({ text })` cannot steal inbox steers.
* Held builtins: flower / tea / flag / spark in Settings → General and Agent Team appearance.
* Home skill `xrk-presence-dressing`: generate a transparent overlay with `image_generate`, then import via that slot’s **+** (do not paste data URLs into tool args).

### Improved

* The turn rail sits just inside the width-handle strip (`translateX(-100%)`), with three lengths (rest 6px / floor 12px / reading 22px); hover no longer adds a fourth width, and the floor tick is always the session newest.
* Reading-position resolution: `resolveActiveTurn` takes `loadedTurns`, so the floor and the no-hit fallback pin the newest **loaded** turn rather than the newest offered tick.
* Rail data: `mergeTurnRailItems` receives loaded turns that actually have a `turn/start`, so outline-only marks cannot mask loaded rows; `round` falls back to the prompted index only when the wire omits it.
* Assistant nodes: `stoppedAtThisStep()` marks 「已停止」 only on the step Stop actually cut; a turn-level abort reason no longer stamps every earlier finished step (the turn tail keeps the turn-level marker).
* Steer semantics: enter the same Host turn’s next model request after the current **tool step** settles instead of after the whole turn; the shell copy is “Sending…” and a claimed steer is an ordinary send.
* Steer badge: the user bubble’s “Sending…” state comes from the inbox claim (`pendingAdmitId`) only, no longer inferred from the running turn; edit / delete follow the same rule.
* Roster id validation: both `team_save` and `team/upsert` validate the id before persisting, and the error spells out the `mem_` rule, the length cap, and “omit to mint one”.
* Built-in catalog: `mem_seed_*` cannot be edited, deleted, or overlaid; customize by forking a new role from the template.
* Standing Skills vs Agent Team: spawn a fitting member when the badge has subagent tools; **Frugal** (and other no-subagent badges) Skill-load and do the job here.
* Costumes: hat / glasses / held are separate slots; an import stays on the row that was clicked; picker tiles are smaller and the plus is a dashed 28px cube.
* Held builtins are drawn on the ball body and bounce / yaw with it.
* Presence color cubes show a selected fill and border.

### Removed

* The `.markPreview` (hover-grow) style and its transition in `TurnNavigator`.

### Fixed

* A tail-first open showing the opening round as “第 5 轮”: wire numbers now follow whole-log first-seen order.
* A 90-turn session opened at the tail labelling the first bubble “第 87 轮”: rail 轮次 no longer re-index from the loaded window.
* A paging cut landing on a later message of the same turn, leaving that turn’s opener out of the page.
* At the flow floor the rail pinned the newest offered tick instead of the newest loaded turn, so a tail page’s first bubble read as a whole-log 轮次.
* turn-level Stop printing 「已停止」 on every step of the turn.
* A steer waiting for the entire turn instead of entering the model request after the running tool step settled.
* `thread_message` does not require `thread_switch`; switching to mail a sibling rebound this session’s sidebar pin.
* Stop left no 「已停止」 on the turn tail when the turn already had an assistant closer and later tool rows.
* Child Overview 委派方 seat dropped the parent’s `presence_set` caption and fell back to ambient 待机.
* Agent Team dressing library `getSnapshot` allocating a new array each read, crashing the sidebar in an update loop.
* Hat + glasses together hanging the engine (`layoutSpecsLens` missing).
* Settings held builtins snapping back to 「无」 because Face only accepted `none`.
* Glasses hanging the spinner when one eye was off-screen (`specSize` on a missing slot).
* A hat import appearing on the glasses and held rows.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.12`** (owns npm `@latest`); npmjs keeps **0.5.12** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.12**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
* Face → shell `turnOutline` entries gain `round` (apiproxy type and shell declare-merge in the same change); older shells ignore the unknown field.
