# v0.8.9

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.8](./v0.8.8.md)：对话顶栏几何收敛（概况不被表情球长卡片盖住）；手机划词菜单更贴选区；侧栏桌面开关进顶栏流式；去掉 Host 为绝对 FAB 硬垫。

### 完善

* **对话顶栏**：概况 / 作业在 `header.actions` 不收缩；`header.utilities` 从左排布；表情球芯片跟随座位宽度，不再独立撑出盖住概况。
* **手机划词菜单**：粗指针 + 有选区时只保留复制（与翻译）；菜单更贴按压行上方。
* **侧栏插件 xrkh-better-sidebar 0.20.31**：桌面底栏+侧栏开关进顶栏 utilities；手机仍仅侧栏浮动 FAB、无底栏。

### 删除

* **Host 顶栏 100px FAB 硬垫**：不再因 `layout-side` / 第一方 toggle-cluster 预留绝对定位空隙；浮动 FAB 由插件自管 clearance。

### 修复

* **概况按钮**：侧栏关闭、表情球为长卡片时，概况不再被盖住或裁没。
* **顶栏右缝空白**：侧栏打开时不再多出一段神秘垫距（与流式开关对齐）。

### 其他变更

* 公开线版本号对齐 **0.8.9**（npm / Desktop / 手机 / 官网下载同号）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.8](./v0.8.8.md): conversation header geometry (Overview no longer covered by the full Presence chip); tighter phone selection menu; sidebar desktop toggles in-flow; remove Host absolute-FAB hard pad.

### Improved

* **Conversation header**: Status / Jobs in `header.actions` never shrink; `header.utilities` packs start; Presence chip follows seat width instead of painting over Overview.
* **Phone selection menu**: coarse pointer + live selection keeps Copy (+ Translate); menu hugs above the pressed line.
* **Sidebar plugin xrkh-better-sidebar 0.20.31**: desktop bottom + side toggles on header utilities; phone stays side-only floating FAB (no bottom panel).

### Removed

* **Host header 100px FAB pad**: no longer reserves absolute-FAB clearance from `layout-side` / first-party toggle-cluster; floating FABs own their own clearance.

### Fixed

* **Overview control**: with the side closed and Presence as a full chip, Overview stays visible and hittable.
* **Header right gutter**: opening the side no longer leaves a mysterious pad once toggles are in-flow.

### Other

* Public line version **0.8.9** (npm / Desktop / phone / site download share the same number).
