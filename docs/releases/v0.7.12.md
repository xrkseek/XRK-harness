# v0.7.12

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

## 中文

相对 [v0.7.11](./v0.7.11.md)：computer_use 新增 `find`（按 role/name/text 语义定位，返回新索引）与 `clipboard_set`/`clipboard_get`；坐标点击必须显式 `headed=true`（会移动真实光标），headless AX 不抢焦点。browser_* 新增 `browser_find`（语义定位 + 动作）、`browser_frame`（iframe 切换）；`browser_get` 支持 `selector`；tab `label` 做 ASCII slug。modality 路由新增 `routeAllowsImage` 感知实时模型路由，text-only 时 `vision`/`som`/`browser_vision` 软降级（图进 gallery、不进 LLM wire）；`<session_capability>` 新增 `model:` 与 `modality:` 两行。提示词文案做了精简：去掉重复说明、统一 @eN 记法、修正若干不完整句子；同时清理了内部 lint 问题，行为不变。

### 主要变更

* **computer_use**：`find`、`clipboard_set`/`clipboard_get`；坐标点击需 `headed=true`。
* **browser_***：`browser_find`、`browser_frame`；`browser_get` 支持 `selector`；tab label ASCII slug。
* **modality 路由**：`routeAllowsImage`；text-only 软降级；`<session_capability>` 新增 `model:`/`modality:`。
* **文案与质量**：精简重复说明、统一 `@eN`、修正病句；清理 2 个 eslint error 与 1 个脆弱断言。

# Release Notes

> **Audience**: End users · Maintainers

## English

Relative to [v0.7.11](./v0.7.11.md): computer_use adds `find` (semantic locate by role/name/text returning fresh indices) and `clipboard_set`/`clipboard_get`; coordinate clicks require explicit `headed=true` (moves the real cursor), headless AX never steals focus. browser_* adds `browser_find` (semantic locate + action) and `browser_frame` (iframe switch); `browser_get` supports `selector`; tab labels become ASCII slugs. Modality routing adds `routeAllowsImage`-aware live model routing; text-only soft-degrades `vision`/`som`/`browser_vision` (images go to gallery, not the LLM wire); `<session_capability>` gains `model:` and `modality:` lines. Prompt copy is tighter: duplicate notes removed, @eN unified, fragments rewritten as sentences; internal lint issues cleared. No behaviour change.

### Highlights

* **computer_use**: `find`, `clipboard_set`/`clipboard_get`; coordinate clicks need `headed=true`.
* **browser_***: `browser_find`, `browser_frame`; `browser_get` supports `selector`; tab labels ASCII slugs.
* **Modality routing**: `routeAllowsImage`; text-only soft-degrade; `<session_capability>` gains `model:`/`modality:`.
* **Copy & quality**: trimmed duplicate notes, unified `@eN`, fixed fragments; cleared 2 eslint errors and 1 brittle assertion.
