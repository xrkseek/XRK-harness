# v0.8.3

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.2](./v0.8.2.md)：插件设置安装区与菜单选择；Git worktree 归运行时；Desktop 品牌图标（奶油底黑瓣）落窗 / 安装包。Desktop 对齐 **0.8.3**。

### 完善

* **插件安装区**：安装入口置于内置列表之上，窄卡可滚动。
* **设置菜单选择**：若干原原生 `<select>` 改产品 `Menu`，触控与键盘一致。
* **Git worktree**：以运行时/内置面呈现，不再当作可列表开关的普通插件行。
* **Desktop 品牌图标**：`logo-plate` 奶油底 + 黑瓣 + 黄尖 → **圆角** `icon.png` / 多尺寸 `icon.ico`（保留透明角，勿 flatten 成方块；进 asar `build/`，安装包 `win.icon` 同源）；窗口对齐 git-repository-manager（`BrowserWindow.icon` **字符串路径**，勿 `nativeImage.createFromPath`）；`app.setName`；Windows `AppUserModelId` 改为 `com.xrkseek.XRKHarness`（旧 `com.xrkseek.harness` 被本机 `electron.exe` 钉脏后任务栏会一直显示 Electron 原子标——Electron 默认 AUMID 为 `electron.app.$1`）。快捷方式须带同一 AUMID（勿用 WScript 重写 `.lnk`；必要时用 `apps/desktop/scripts/fix-win-aumid-shortcuts.py` + pywin32）。

### 修复

* **插件更新探测**：仅探测 managed 行；可选/未托管包不再误报本地可更新。
* **electron-builder Win 图标**：补齐 `iconIco` 路径，NSIS / exe 资源与 `prepare:icons` 同源。

### 其他变更

* 公开线版本号对齐 **0.8.3**（本轮可先装 Desktop 未签名测包；npm / 手机 / 官网下载页随完整发版流水线）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.2](./v0.8.2.md): plugin Settings install placement and Menu selects; Git worktree as runtime; Desktop brand icon (cream plate, black petals) for window / installer. Desktop aligns to **0.8.3**.

### Improved

* **Plugin install slot**: install UI sits above the builtin list; narrow cards scroll.
* **Settings Menu selects**: several native `<select>` controls use the product `Menu` for touch/keyboard parity.
* **Git worktree**: shown as runtime/builtin surface, not a list-togglable plugin row.
* **Desktop brand icon**: `logo-plate` cream + black petals + yellow tip → **rounded** `icon.png` / multi-size `icon.ico` (keep transparent corners; do not flatten to a square); window follows git-repository-manager (`BrowserWindow.icon` string path); `app.setName`; Windows `AppUserModelId` is now `com.xrkseek.XRKHarness` (the old `com.xrkseek.harness` id was poisoned by pinning monorepo `electron.exe` — Electron’s default AUMID is `electron.app.$1`). Shortcuts must share that AUMID (do not rewrite `.lnk` with WScript). Phone mist launcher mipmaps regenerated from the rounded `xrk-mark-tile` (see mobile `tool/sync_launcher_mist_from_tile.mjs`).

### Fixed

* **Plugin update probe**: probes managed rows only; optional/unmanaged packages no longer fake a local update.
* **electron-builder Win icon**: `iconIco` path defined so NSIS / exe resources match `prepare:icons`.

### Other

* Public line version **0.8.3** (Desktop unsigned test build may ship first; npm / Android / site download follow the full release pipeline).
