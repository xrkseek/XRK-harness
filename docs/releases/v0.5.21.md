# v0.5.21

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.20](./v0.5.20.md)：对话粘贴与回合交付物门控、右键菜单原语、插件列表推荐 Office 预览，以及仅模型可见的附件句柄文本。

Relative to [v0.5.20](./v0.5.20.md): paste fold and turn deliverable gating, context-menu primitive, Settings recommend for Office preview, and model-only attachment handle text.

### 新增

* 新增 UI 右键菜单原语（`ContextMenu`），与 Menu / Modal 同族手势。
* 新增 Settings 插件列表一键安装推荐：`xrkh-better-sidebar` 与独立包 `xrkh-better-sidebar-plugin-office`（高保真 `.docx` / `.xlsx` / `.pptx`）。
* 新增协议 `TextBlock.modelOnly`：附件句柄只进模型上下文，气泡与会话标题对人不可见。

### 完善

* 完善输入区大段粘贴折叠与展开交互。
* 完善回合交付物与 turn-tail 门控：历史回合与未结束回合展示更稳，侧栏产出文件列表更干净。
* 完善 Face / Host 会话工具绑定与 durable prompt 接线。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.21`**（接管 npm `@latest`）；npmjs 保留 **0.5.21** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.21**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。
* 侧栏插件 **`xrkh-better-sidebar@0.20.1`** 与 Office 预览 **`xrkh-better-sidebar-plugin-office@0.1.0`** 已单独发 npm（AGPL 预览包外置，不进本仓主包）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.21
xrkh web
```

可选高保真 Office 预览：

```bash
xrkh plugin add xrkh-better-sidebar@0.20.1
xrkh plugin add xrkh-better-sidebar-plugin-office@0.1.0
xrkh restart
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.21-win-x64`（或签名）安装包，或从已装旧版经应用内更新。

## 验证

* 大段粘贴可折叠；回合结束后交付物门控正常，历史会话尾栏不误伤。
* Settings → 插件列表可见两条推荐安装（侧栏与 Office）。
* 带附件句柄的回合：气泡不显示内部 id，模型仍能收到句柄。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.21`。

---

### Added

* Context-menu primitive (`ContextMenu`), same gesture family as Menu / Modal.
* Settings plugin list one-click recommends: `xrkh-better-sidebar` and separate `xrkh-better-sidebar-plugin-office` (hi-fi `.docx` / `.xlsx` / `.pptx`).
* Protocol `TextBlock.modelOnly`: attachment handles reach the model only; bubbles and session titles stay reader-facing.

### Improved

* Large pasted-text fold / expand in the composer.
* Turn deliverables and turn-tail gating: stabler history vs open turns; cleaner sidebar produced-files list.
* Face / Host session tool binding and durable-prompt wiring.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.21`** (owns npm `@latest`); npmjs keeps **0.5.21** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.21**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
* Sidebar plugin **`xrkh-better-sidebar@0.20.1`** and Office preview **`xrkh-better-sidebar-plugin-office@0.1.0`** ship separately on npm (AGPL preview package stays out of the main tarball).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.21
xrkh web
```

```bash
xrkh plugin add xrkh-better-sidebar@0.20.1
xrkh plugin add xrkh-better-sidebar-plugin-office@0.1.0
xrkh restart
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.21-win-x64` (or signed) package, or update in-app from an older install.

## Verify

* Settings → plugin list shows both recommend install chips (sidebar and Office).
* Turns with attachment handles: bubbles hide internal ids; the model still receives handles.
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.21`.
