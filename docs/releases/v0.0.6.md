# v0.0.6

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.5](./v0.0.5.md)：可用 CLI 安装用户插件到 `~/.xrk/plugins`，重启 `web` 后自动加载。

### 新增

* 新增 `xrk-harness plugin add|remove|list|path`：用 `npm pack` 安装社区 / 本地包，无需本机 pnpm
* 新增客户端叠加安装：识别 `xrk.client` / `dsh.client`，写入 `web/boot.json` 与 `/plugins/<id>/client.js`
* 新增进程插件安装：识别 `xrk.plugin.json` / `xrkseek.plugin` / `dsh.plugin`，落到可 discover 目录
* 新增 DSH → XRK inject 重映射（`@deepseek-ai/dsh-client-*` → `@xrkseek/client-*`）

### 完善

* 完善 Host 默认 `pluginsDir`：未设 `XRK_PLUGINS_DIR` 且 `~/.xrk/plugins` 已存在时自动拾取
* 完善插件规格与入门说明（`plugin-loader` · `configuration` · `getting-started`）

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.6
xrk-harness plugin add @huanlin/dsh-plugin-spur
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.6 web`

规格：[plugin-loader](../plugin-loader.md) · [configuration](../configuration.md)。
