# v0.8.0-rc.1

> **读者**：终端用户 · 维护者（发行说明）

相对 [v0.7.22](./v0.7.22.md)：开启 **`0.8.x`** 首个过程号（npm dist-tag **`@rc`**，**不**接管 `@latest`；`@latest` 仍为 **0.7.22** 直至正式 `0.8.0`）。协作回传收成一条纪律；干员家能改自己；每回合看得见主线/支线；时间线 Voice×Lane；长会话更省提供方缓存；手机 WebSocket 半开不再卡「思考中」。

### 新增

* **子代理回传单一通道**：工具结果只报状态；完成经 courier×handoff 进委派方 inbox；父停 / 子停 / 一次性子代理仍回传，并唤醒闲置父会话。
* **会话协作回传同纪律**：`thread_message` / `workspace_session_prompt` 与子代理对齐——`wait:true` 成功只走工具结果；`wait:false`、超时、对端 Stop 走异步 steer，同 stretch 不丢不重。
* **干员家 `team_self`**：身份席可改自己的 playbook / brief / inject / tools；不铸包、不删别人。
* **每回合 `<session_lanes>`**：本会话主线 / 支线 / open todos 与完成后的切换动词（含子会话）。
* **Voice×Lane 时间线**：消息行 / 工具行带 `data-voice` / `data-lane`（席位头像见下「待办」）。
* **概况委派方 N→1**：左栈收敛为单一被委派方球。
* **`session://memory`**：Inject 目录可见指针；正文靠 `memory` 工具发现。

### 完善

* **长会话更省缓存（用户可感）**：同一条 DeepSeek Flash 会话里，改人设 / 斜杠配方 / MCP 目录变动时，不再轻易把整段历史缓存打穿——多数回合继续复用前缀，账单与延迟更稳。活事实仍在回合板、工具结果与上下文注入里，不靠藏信息省钱。
* **斜杠配方仍生效、但不搅系统前缀**：`/…` 的 recipe 进「上下文注入」（同配方 id 后来的覆盖先前的）；普通续聊仍看得见最近一次配方。
* **MCP / deferred 展开更稳**：`tool_search` 可用 `list` 浏览目录；展开过的工具在 Host 重启、编辑重发截断后，会尽量从会话头恢复，不必反复手动搜。
* **名册 ↔ 干员家身份热同步**：playbook 与家目录 `AGENTS.md`（及高级 `playbook.md`）双向即时同步。
* **子会话主线与斜杠**：子会话可自钉主线；斜杠白名单可用（`/status` · `/compact` · `/export` · `/theme` · `/feedback` · `/skills` · `/model`）。
* **工作区发现**：活跃窗 / 条数 / 上限之上，加 sibling 范围、图深度、同仓优先。
* **干员团队面板**：软轮询刷新，改外形 / 昵称不必重开。
* **`present` / 工具路径**：内联出图；长路径可 wrap。
* **压缩 EMPTY×5**：失败不闸死会话；硬裁剪后备 + 可见诊断。
* **侧栏标题**：`干员 · 主线` 可读组合。

### 修复

* **手机截图进模型**：本机 Guest 与远程 `xrk-phone-bridge` 不再丢 `imageBase64`（需同号 App + bridge）。
* **会话导出 ZIP**：`attachments/sha256:…` 冒号叶名可抽出。
* **全屏 Modal**：`--ds-safe-*` 避让手机状态栏。
* **停回传不丢不重**：子代理中断 / 一次性停、会话互聊 Stop 都有 courier。
* **`team_save` 省略 playbook**：只改 brief 时不再盖掉磁盘上更新的 `playbook.md`。
* **安全模式提示**：手机安全模式可 toast；设置球离开可回正常（壳侧）。
* **手机 / Web「思考中」卡死**：mux/host WebSocket 半开时壳侧空闲看门狗会重连并清乐观 `running`（对齐 Desktop SSE）；Host 每 15s 发应用层 `: keepalive`。
* **根网页加载中误退后台**：手机根 WebView 仍在加载时系统返回不再 `SystemNavigator.pop`（壳侧）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.8.0-rc.1`**（npm dist-tag **`rc`**；`@latest` 仍为 **0.7.22**）。
* Desktop 私有壳对齐 **0.8.0-rc.1**（与 `apps/cli` / `packages/sdk` 同号）。

### 待办（本版刻意不做）

* **DressingAvatarSvg**：消息 / 工具 / bash 行挂席位头像（chrome 现仅 Voice×Lane）。
* **提供方 `toolUpdate` addition-only**：expand / 工具增减仍可能整表重发 tools 段（下一波成本大件；见 [session-optimize](../session-optimize.md) §5）。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.22](./v0.7.22.md): first process number on the **`0.8.x`** line (npm dist-tag **`@rc`**; **does not** take `@latest`; `@latest` stays **0.7.22** until formal `0.8.0`). One report-back discipline; agent-home can revise itself; live 主线/支线 each turn; Voice×Lane chrome; warmer provider cache on long sessions; Mobile/Web no longer sticks on 「思考中」 for half-open WebSockets.

### Added

* **Single-channel subagent report-back**: tools stay status-only; completion via courier×handoff; stop still reports; wakes idle parents.
* **Session-collab report-back (same discipline)**: `thread_message` / `workspace_session_prompt` — `wait:true` in the tool result; async steer otherwise — one channel per stretch.
* **Agent-home `team_self`**: revise own playbook / brief / inject / tools; mint/remove stay on managers.
* **Per-turn `<session_lanes>`**: 主线 / 支线 / open todos + switch verbs.
* **Voice×Lane transcript chrome**: `data-voice` / `data-lane` (seat avatars deferred).
* **Overview N→1 delegators**: one delegatee ball.
* **`session://memory`**: Inject catalog pointer; discover via `memory` tool.

### Improved

* **Longer sessions, warmer cache (user-visible)**: on DeepSeek Flash, mid-session persona / slash recipe / MCP catalog churn no longer casually busts the whole history prefix — most turns keep reusing it. Live facts still show on turn boards, tool results, and context injects.
* **Slash recipes still apply without rewriting the system head**: recipes land as context injects (same id last-wins); follow-up turns still see the latest recipe.
* **MCP / deferred expand survives better**: browse with `tool_search list`; expanded tools rehydrate after Host restart and after edit-resubmit truncate when the standing header remains.
* **Roster ↔ agent-home identity hot sync**.
* **Child mainline + slash whitelist**.
* **Workspace discovery extensions** (sibling scope, graph depth, same-workspace ranking).
* **Agent Team panel** soft-poll refresh.
* **`present` / tool paths**: inline images; wrap long paths.
* **EMPTY×5 compaction**: hard-trim fallback + visible diagnostic.
* **Sidebar titles**: readable `seat · 主线`.

### Fixed

* **Phone screenshots to the model** (guest + remote bridge).
* **Session export ZIP** `attachments/sha256:…` leaves.
* **Fullscreen Modal** safe-area insets on phones.
* **Stop handoff** without loss/dup for subagents and peer Stop.
* **`team_save` omit playbook** no longer overwrites a fresher on-disk playbook.
* **Safe-mode notice** on mobile + leave-to-normal from the settings ball.
* **Stuck 「思考中」 on Mobile / Web**: WebSocket half-open peers now idle-fail and reconnect (Desktop SSE parity); Host sends app-level `: keepalive` every 15s.
* **Root Web leave while loading**: system back no longer backgrounds the app during host-switch / first paint (mobile shell).

### Other

* Public line target **`@xrkseek/harness-cli@0.8.0-rc.1`** (npm dist-tag **`rc`**; `@latest` stays **0.7.22**).
* Desktop private shell aligned to **0.8.0-rc.1** (moves with `apps/cli` / `packages/sdk`).

### Deferred (intentional)

* **DressingAvatarSvg** seat avatars on message / tool / bash rows.
* **Provider `toolUpdate` addition-only**: expand / tool-set churn may still resend the full tools segment (next cost wave; see [session-optimize](../session-optimize.md) §5).
