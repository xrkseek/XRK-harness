# v0.6.0-rc.1

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.31](./v0.5.31.md)：开启 **`0.6.x` 预览线**（npm dist-tag **`@rc`**，**不**接管 `@latest`）。主轴：会话归档热库减负、向阳/IM 编排、侧栏与插件页重组、站立渐进披露、策展记忆分层、社区 Host 热卸、以及若干对话/工具面打磨。

Relative to [v0.5.31](./v0.5.31.md): opens the **`0.6.x` preview line** (npm dist-tag **`@rc`**; **does not** take `@latest`). Themes: archive hot-store offload, Xiangyang/IM orchestration, sidebar + Plugins page reshape, standing progressive disclosure, layered curated memory, live community Host dispose, and conversation/tool polish.

### 新增

* 新增会话 **归档热库减负**：`workspace.archiveSession` 把该会话日志从热库 `sessions.db` 迁到 `sessions-archive.db`（侧栏仍隐藏、工作区 membership 保留）；解档 / 置顶迁回热库；Host 启动时自动迁走已归档旧会话。
* 新增 Settings「已归档会话」**批量操作**：全选、批量解档、批量永久删除（确认后）；搜索过滤与单行操作仍可用。
* 新增产品默认工作区 **向阳空间**（id `ws_default`，路径 `~/.xrk/xiangyang-workspace`）：首次启动默认打开，**不可删除/改名**；会话锁工具面 **奇创**（`qichuang`）。
* 新增奇创 / IM **跨工作区编排工具**：`workspace_list` · `workspace_create` · `workspace_session_prompt`；IM 还可 `subagent(workspace_id)` 派进编码工作区；奇创**无嵌套子代理**。
* 新增 **IM 工作区**（`ws_im`）：网关连接 / 首次挂会话时生成，**可删**（下次连接再建）；入站 admit 带 `origin=im` 与会话映射。
* 新增 IM 出站工具 **`im_send` / `im_reply`**（text + 附件）；本地 ingress（webhook/poll/SSE 或本机 WS `/api/im/gateway/ws`）与 Desktop/Web 共享 Face 投影。
* 新增回合开头 **`<session_posture>`**：IM / 奇创父会话注入编排角色说明（编码徽章只靠 `<session_capability>`）。
* 新增回合开头 **`<session_capability>`** 强化：权限（path gate）× 工具面正交快照，含 Frugal / 浅层 / harness / IM / 奇创 briefs。
* 新增侧栏 **「插件」utility 入口**（新会话下方）：一键打开 Settings → 插件；齿轮导航不再是唯一入口。
* 新增跨插件 **`settingsNav.openSection`**（Cordis 服务）：插件首页 / 引导可打开指定 Settings 分区。
* 新增 Settings → 插件 **工具目录** / **技能文档**页签：`session.tools` 分组浏览；inject / skill 文档与 Host 真实站立同源（非静态猜列表）。
* 新增 Face RPC **`session.tools`** · **`skill.list` / `skill.read`**（及 inject 文档目录），供壳与模型侧加载。
* 新增站立种子技能 **`xrk-presence`** · **`xrk-attachment`** · **`xrk-craft`**（家目录 fingerprint 刷新）；站立 `AGENTS.md` 写明渐进披露硬规则与工程薄红线。
* 新增 **分层策展记忆**：global / workspace / session / agent 独立区，同一 `memory` 工具面；系统提示按区拼接。
* 新增 Voice **本地 SenseVoice STT** 缝（`{XRK_HOME}/voice/sensevoice` 或 `XRK_VOICE_SENSEVOICE_DIR`；有 `sherpa-onnx-node` 时转写，否则诚实失败）。
* 新增 Computer-use **`mode=background`** 投递（Credentials `XRK_COMPUTER_USE_BACKGROUND` helper；截屏/列窗仍可叠 UIA）。
* 新增社区插件 **live Host apply**：WB / OFM 等进程内半部可软禁用 / 重载时 dispose，不必整 Host 重启。
* 新增 UI fork **谱系持久化**（`fork-lineage.json`）：探索性 fork 在会话列表带 `origin: "fork"` + 父会话 id（≠ 子代理图）。
* 新增产品级右键 **划词翻译**（Bing Edge / 可选 Google gtx；无 API key；中英启发式目标语）。
* 新增通用 **`Switch`** 原语；插件卡 **主开关**（boolean / mode）统一接线。
* 新增权限预设 **自动审查**（id `auto`：无沙箱 + 每调用评审；`/permission auto` · Settings Permissions）。

### 完善

* 完善永久删除语义：仅已归档可删；`session.delete` 同时抹热库与归档库，并可 freelist VACUUM；文案标明归档=分离、删除=不可撤销。
* 完善版本公告座位：铃铛从侧栏脚挪到「插件」同区 utility 行，样式对齐安静工具行；插件区与工作区树之间有内缩细分割线。
* 完善向阳 `presence_set` 绑定（支线 tips；与表情球开关解耦）；IM 仍不绑表情球工具。
* 完善 Agent 预设本地化：缺目录条目时仍显示「奇创」等内置名，不再裸露 wire id。
* 完善 Identity / 站立分层：家目录 `AGENTS.md` · `SOUL.md` fingerprint 刷新；自定义人设写工作区 `.agents/`；「用户是谁」真源=策展 `memories/USER.md`。
* 完善插件页结构：配置卡 / 工具目录 / 技能目录分栏；去掉易混淆的 Advanced 堆叠；插件卡标题区主开关与 artwork。
* 完善插件清单与 Settings 通用：安装 UI、进程通道、Host 信息卡与侧栏 Agent 推送行继续加厚。
* 完善 Presence 装扮 / Overview 球：帽·眼镜·手持分槽与贴纸导入路径对齐；会话驱逐清行。
* 完善子代理 / Agent Team：编排徽章不误绑嵌套子代理；`subagent` 说明与 workspace 派发路径更清晰。
* 完善社区 LLM / WorkBuddy / OFM：Host 侧模型同步、Electron 二进制查找（含 intl 路径）、共享 registry 更稳。
* 完善 IM 会话绑定键与消息桥：chatKey / session map / Face admit 路径对齐 sidecar 契约。
* 完善对话壳：权限选择器、输入区、回合尾与消息图标动作等布局与可达性。
* 完善上下文菜单手势与模型；工具行默认展开偏好与 bash 样例卡。
* 完善 web_fetch / HTML 文本抽取与 computer-use 工具说明。
* 完善桌面 / Web 共用 Settings 导航与归档页 locale。

### 修复

* 修复权限越界确认与 path gate：ask / 自动审查路径下越权行为与确认流更一致。
* 修复编排工作区权限锁：IM / 向阳固定 full-access 路径闸，避免与编码徽章混淆。
* 修复向阳会话迁移与专用 skills 落盘路径，升级后不丢默认家。
* 修复插件软禁用后社区 Host 半部残留：live dispose 可卸路由。
* 修复侧栏公告与插件入口抢座位 / 样式不一致的问题。

### 删除

* 删除 Settings → 插件 **Advanced** 堆叠页（能力并入配置卡与目录页签，避免双入口）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.6.0-rc.1`**（npm dist-tag **`rc`**；`@latest` 仍为 **0.5.31**）。
* Desktop 私有壳版本对齐 **0.6.0-rc.1**；`apps/cli` / `apps/desktop` / `packages/sdk` 同步。
* 教科书同步：`docs/status` · `profiles` · `skills-layers` · `workspace-inject` · IM / community-plugins 等与上述能力对齐。

### Added

* **Archive hot-store offload**: `workspace.archiveSession` moves that session’s log from hot `sessions.db` into `sessions-archive.db` (sidebar hide + membership kept); unarchive / pin restore to hot; Host start migrates already-archived sessions.
* **Archived-sessions bulk actions**: Settings archived page supports select-all, bulk unarchive, and bulk permanent delete (after confirm); search + per-row actions remain.
* **Xiangyang space** (id `ws_default`, path `~/.xrk/xiangyang-workspace`): first-launch default, **undeletable / unrenamable**; sessions lock to tool surface **奇创** (`qichuang`).
* **Cross-workspace orchestration tools** for 奇创 / IM: `workspace_list` · `workspace_create` · `workspace_session_prompt`; IM may also `subagent(workspace_id)` into a coding workspace; 奇创 has **no nested subagents**.
* **IM workspace** (`ws_im`): created on gateway connect / first attach, **deletable** (recreated next connect); ingest admits with `origin=im` and session map.
* **IM outbound tools** `im_send` / `im_reply` (text + attachments); local ingress (webhook/poll/SSE or WS `/api/im/gateway/ws`) shares Face projection with Desktop/Web.
* Turn-start **`<session_posture>`** for IM / 奇创 parents (coding badges stay on `<session_capability>` only).
* Stronger turn-start **`<session_capability>`**: orthogonal permission (path gate) × tool_surface snapshot with Frugal / shallow / harness / IM / 奇创 briefs.
* Sidebar **Plugins utility** under New Session: opens Settings → Plugins; gear nav is no longer the only entry.
* Cross-plugin **`settingsNav.openSection`** (Cordis): Plugins home / onboarding can open a Settings section by id.
* Settings → Plugins **tools catalog** / **skills documents** tabs: live `session.tools` grouping; inject/skill docs match Host standing (not a static guess list).
* Face RPCs **`session.tools`** · **`skill.list` / `skill.read`** (plus inject document listing) for shell and model load paths.
* Standing seed skills **`xrk-presence`** · **`xrk-attachment`** · **`xrk-craft`** (home fingerprint refresh); standing `AGENTS.md` states progressive-disclosure hard rules and thin engineering invariants.
* **Layered curated memory**: independent global / workspace / session / agent zones on one `memory` tool surface; system prompt concatenates zones.
* Voice **local SenseVoice STT** seam (`{XRK_HOME}/voice/sensevoice` or `XRK_VOICE_SENSEVOICE_DIR`; transcribes when `sherpa-onnx-node` is present, otherwise fails honestly).
* Computer-use **`mode=background`** delivery (Credentials `XRK_COMPUTER_USE_BACKGROUND` helper; capture/listWindows can still stack UIA).
* Community **live Host apply**: WB / OFM in-process halves can dispose on soft-disable / reload without a full Host restart.
* UI fork **lineage persistence** (`fork-lineage.json`): exploratory forks show `origin: "fork"` + parent id on the session list (≠ subagent graph).
* Product-wide right-click **selection translate** (Bing Edge / optional Google gtx; no API key; CJK heuristic target).
* Shared **`Switch`** primitive; plugin-card **master switches** (boolean / mode) wired uniformly.
* Permission preset **Auto review** (id `auto`: no sandbox + per-call review; `/permission auto` · Settings Permissions).

### Improved

* Permanent delete stays archived-only: `session.delete` drops hot and cold rows and may VACUUM freelist; copy states archive = separate, delete = irreversible.
* Release-notes seat moves from the sidebar foot into the same utility list as Plugins (quiet list chrome); an inset hairline separates utilities from the workspace tree.
* Xiangyang binds `presence_set` (支线 tips; independent of the emotion-ball toggle); IM still does not bind the emotion-ball tool.
* Agent-preset localization: missing catalog rows still show built-in labels such as 「奇创」 instead of bare wire ids.
* Identity / standing layers: home `AGENTS.md` · `SOUL.md` fingerprint refresh; custom persona under workspace `.agents/`; factual “who the user is” = curated `memories/USER.md`.
* Plugins page structure: configuration / tools catalog / skills catalog columns; confusing Advanced stack removed; card title master switch + artwork.
* Plugin inventory and Settings general: install UI, process channels, Host info card, and sidebar Agent push rows keep thickening.
* Presence dressing / Overview ball: hat · glasses · held slots and sticker import paths align; rows clear on session eviction.
* Subagent / Agent Team: orchestration badges do not bind nested subagents by mistake; `subagent` copy and workspace dispatch paths are clearer.
* Community LLM / WorkBuddy / OFM: stabler Host-side model sync, Electron binary lookup (incl. intl paths), shared registry.
* IM session bind keys and messaging bridge: chatKey / session map / Face admit align with the sidecar contract.
* Conversation chrome: permission select, input bar, turn tail, and message icon actions for layout and reachability.
* Context-menu gestures/model; tool-row default-expanded preference and bash sample card.
* web_fetch / HTML text extraction and computer-use tool descriptions.
* Shared Settings navigation and archived-page locales for Desktop / Web.

### Fixed

* Overreach confirm and path gate: ask / auto-review paths agree more consistently on overreach.
* Orchestration workspace permission lock: IM / Xiangyang stay on full-access path gate and do not confuse with coding badges.
* Xiangyang session migrate and dedicated skills landing path so upgrades keep the default home.
* Soft-disabled community Host halves no longer linger: live dispose tears routes down.
* Sidebar release-notes vs Plugins seat/chrome inconsistency.

### Removed

* Settings → Plugins **Advanced** stacked tab (capabilities fold into configuration cards and catalog tabs).

### Other changes

* Public line target **`@xrkseek/harness-cli@0.6.0-rc.1`** (npm dist-tag **`rc`**; `@latest` stays **0.5.31**).
* Desktop private shell aligned to **0.6.0-rc.1**; `apps/cli` / `apps/desktop` / `packages/sdk` move together.
* Textbook sync: `docs/status` · `profiles` · `skills-layers` · `workspace-inject` · IM / community-plugins align with the above.
