# v0.8.11

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.10](./v0.8.10.md)：提供方前缀缓存再收一轮（工具序冻结、会话粘性、Messages `toolUpdate`），并向日葵免费车道与过程/思考折叠 chrome 对齐手感。

### 完善

* **工具列表前缀稳定**：同系列 expand / Direct 增工具只在 `tools[]` **尾部追加**；空 tools（max-steps）不再清锚；compaction / 换路由 / 删会话才重基线。
* **会话粘性路由**：OpenCode / Command Code / Custom / 官方 DeepSeek Chat 按文档挂会话头；Responses 会话级 `prompt_cache_key`；产品 `User-Agent` 一致。
* **Messages `toolUpdate`**：仅 `anthropic-messages`（含 DeepSeek Messages Flash）投影 `defer_loading` + `tool_addition`；Chat Completions 不发明该字段。
* **向日葵免费缓存**：Host `x-session-id` → sidecar 粘上游 `x-opencode-session`（压缩后不再靠正文哈希换会话）。
* **过程 / 思考折叠 chrome**：统一为图标 · 标题 · › · 摘要；› 与标题、圆点间距对齐。

### 修复

* **官方 DeepSeek**：Chat 路径补挂 `x-session-id`，不盖过 Pro 的 systemPromptUpdate withhold。
* **Anthropic 中段 system**：不再误折进顶层 system（保护 in-history 前缀）。

### 其他变更

* 公开线版本号对齐 **0.8.11**（npm / Desktop / 手机 / 官网下载同号）。

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.10](./v0.8.10.md): another pass on provider prefix cache (tools-order freeze, session affinity, Messages `toolUpdate`), plus sunflower-free stickiness and process/think fold chrome alignment.

### Improved

* **Stable tools[] prefix**: same-series expand / Direct adds **append at the tail only**; empty tools (max-steps) no longer wipe the anchor; compaction / route change / session delete re-baseline.
* **Session affinity routing**: OpenCode / Command Code / Custom / official DeepSeek Chat headers per docs; Responses session-level `prompt_cache_key`; consistent product `User-Agent`.
* **Messages `toolUpdate`**: only on `anthropic-messages` (incl. DeepSeek Messages Flash) with `defer_loading` + `tool_addition`; Chat Completions never invents the field.
* **Sunflower-free cache**: Host `x-session-id` → sidecar sticky upstream `x-opencode-session` (no more body-digest rotation after compaction).
* **Process / think fold chrome**: icon · title · › · summary; spacing between title, ›, and the sep dot aligned.

### Fixed

* **Official DeepSeek**: Chat path attaches `x-session-id` without overriding Pro systemPromptUpdate withhold.
* **Anthropic mid-convo system**: no longer folded into the top-level system (protects the in-history prefix).

* Public line version **0.8.11** (npm / Desktop / phone / site download share the same number).
