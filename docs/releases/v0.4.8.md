# v0.4.8

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.7](./v0.4.7.md)：修复长驻 Host 在会话驱逐后堆无限增长（OOM）；落地视频理解与交付物声明；`read_image` 支持原图像素 region 裁剪；图/视频生成结果进对话卡片。

Relative to [v0.4.7](./v0.4.7.md): fix unbounded Host heap growth after session eviction (OOM); ship video analysis and deliverable presentation; `read_image` optional original-pixel region crop; image/video gen results render as chat cards.

### 新增

* 新增 `video_analyze`：整段视频 URL/工作区路径 → 多模态 LLM 文本分析（Settings → Plugins → 视频理解；见 [video-analyze.md](../video-analyze.md)）。
* 新增 `present`：模型声明已存在文件为最终交付物，经 `deliverables/presented` 进会话事件与产物卡。
* 新增 `read_image` 可选 `region [x1,y1,x2,y2]`：在入场归一化前按原图像素裁剪（本地 attachment + sharp）。
* 新增对话内 `image_generate` / `video_generate` 结果卡片（attachmentId / file / jobId 文本信封解析）。

### 完善

* 完善 Settings / 配置模板与教科书：视频理解凭据槽、status 能力行、attachment / seams / configuration 同步。

### 修复

* 修复 Face 会话 LRU 驱逐时只清 tool-arg 内层 Map、未删除外层会话桶，且未清 `wireIds` / `inboxWire`，导致长驻 Host 堆随会话更替无限增长（OOM）。

### 其他变更

* 无。公开线版本号 `@xrkseek/harness-cli@0.4.8`（本说明写毕后执行 `pnpm release` 再接管 `@latest`）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.4.8
xrkh web
```

## 验证

* 多开会话再关闭/驱逐后，Host 进程堆不再随「已驱逐会话」持续上涨。
* Settings 开启视频理解后，`video_analyze` 对小视频返回 JSON 分析（或诚实失败文案）。
* `read_image` 带合法 `region` 时返回裁剪偏移说明。
* 图/视频生成工具结果在对话中显示卡片而非纯文本。

---

### Added

* `video_analyze`: whole-clip URL/workspace path → multimodal LLM text analysis (Settings → Plugins → Video analyze; see [video-analyze.md](../video-analyze.md)).
* `present`: model declares existing files as final deliverables via `deliverables/presented` into session events and the produced-files card.
* Optional `read_image` `region [x1,y1,x2,y2]`: crop in original-image pixels before admission normalize (local attachment store + sharp).
* In-chat `image_generate` / `video_generate` result cards (parse `attachmentId=` / `file=` / `jobId=` text envelopes).

### Improved

* Settings / config templates and textbook: video-analyze credential slot, status capability row, attachment / seams / configuration sync.

### Fixed

* Face session LRU eviction only cleared the inner tool-arg map and left outer session buckets, and never cleared `wireIds` / `inboxWire` — long-running Host heaps grew without bound across evictions (OOM).

### Other changes

* None. Public line `@xrkseek/harness-cli@0.4.8` (run `pnpm release` after this note to take `@latest`).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.4.8
xrkh web
```

## Verify

* After opening then closing/evicting many sessions, Host heap no longer climbs with already-evicted sessions.
* With Video analyze enabled in Settings, `video_analyze` returns JSON analysis (or an honest failure) on a small clip.
* `read_image` with a valid `region` returns crop-offset guidance.
* Image/video gen tool results show cards in chat instead of plain text only.
