# v0.8.10

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.9](./v0.8.9.md)：会话生命周期与前缀缓存上的严重缺陷修复——归档冷写、空白/孤儿子树胀库、Stop 假级联、以及一批会反复打断提供方 KV 前缀的注入路径。

### 完善

* **归档侧栏**：全部 / 仅已归档筛选给行加「已归档」标识；`⋯` 变为「取消归档」，不再二次归档。
* **Settings 已归档**：只列主会话（隐藏工具委派子行）；无摘要登记也可删。
* **成本命中率**：`costUsage.cacheHitRate` 进入 Status / 投影，便于看前缀缓存是否在爬。

### 修复

* **归档后无法继续写**：点开已归档行，或 prompt / fork / truncate / rename / cwd / 审批 / checkpoint restore，会先 restore 到热库再写（不再 `assertHotMutable` 炸）。
* **空白会话胀库**：Hero「新会话」在直播会话上跳过复用后，多余 blank 会立刻按工作区压到 ≤1；无 membership 的 blank 一并清掉；Host 启动再扫一遍历史脏数据。
* **孤儿子树幽灵**：父会话已不在时，工具委派子树（含孙代）启动时永久抹掉；不再只挂 link、也不再卡在「下一轮启动才清」。
* **Stop ≠ 生命周期**：`session.cancel` 不再假装 cascade；归档 / 永久删除 / 半成品 spawn 丢弃才真正级联工具委派子（fork 仍独立）。
* **create/fork 失败幽灵**：权限钉失败走完整 wipe，不再留下 membership / `sessionOrder` 槽。
* **删项目工作区会话悬空**：释放出的会话自动进归档集，便于 Settings 永久清理；删干员家仍解组到「未分组」（不归档）。
* **启动修复竞态**：孤儿修剪 → blank 修剪 → 归档 offload → 一次 reclaim 串行执行，避免 VACUUM 空转与 blank 修剪被吞。
* **热库回收**：delete / offload 后 freelist 门槛与 FTS optimize 对齐，归档分离后热库真正能瘦。
* **前缀缓存连环打断**：standing plan 改挂尾部并 peel 后再 lift；context-fragment / slash-recipe 按 digest 门控；fragment last-wins 不再搬家；system append 只挂 baseline 后缀 delta；Host 重启可从日志 hydrate series baseline；去掉开局无效 double image offload。

### 其他变更

* 公开线版本号对齐 **0.8.10**（npm / Desktop / 手机 / 官网下载同号）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.9](./v0.8.9.md): severe session-lifecycle and prefix-cache fixes — cold writes on archived chats, blank/orphan subtree bloat, fake Stop cascade, and inject paths that kept breaking provider KV prefixes.

### Improved

* **Archive sidebar**: all / archived-only filters badge rows; `⋯` becomes Unarchive (no second archive).
* **Settings archived**: lists human-facing sessions only (hides tool-delegated children); registry-only rows stay deletable.
* **Cache hit rate**: `costUsage.cacheHitRate` on Status / projections so prefix health is visible.

### Fixed

* **Writes on archived chats**: opening an archived row, or prompt / fork / truncate / rename / cwd / approval / checkpoint restore, restores hot before writing (no more `assertHotMutable` blow-ups).
* **Blank session bloat**: when Hero New Session skips reuse on a live chat, surplus blanks are capped at ≤1 per workspace immediately; membership-less blanks are wiped; Host boot re-heals historical dirt.
* **Orphan subtree ghosts**: tool-delegated subtrees (including grandchildren) whose parent is gone are permanently wiped on boot — not link-only, not deferred to the next restart.
* **Stop ≠ lifecycle**: `session.cancel` no longer pretends to cascade; archive / permanent delete / half-spawn discard truly cascade tool-delegated children (forks stay independent).
* **create/fork failure ghosts**: permission-pin failure uses a full wipe so membership / `sessionOrder` slots are not left behind.
* **Project workspace delete orphans**: released sessions park into the archive set for Settings purge; deleting an agent-home still ungroups identity sessions (not archive).
* **Boot repair races**: orphan prune → blank prune → archive offload → one reclaim run serially so VACUUM is not a no-op and blank prune is not swallowed.
* **Hot-store reclaim**: freelist gate + FTS optimize after delete / offload so archive separation actually shrinks the hot DB.
* **Prefix-cache thrash**: standing plan moves to the tail (peel then lift); context-fragment / slash-recipe gated by digest; fragment last-wins no longer relocates; system append is baseline-suffix delta only; Host restart hydrates series baseline from the log; drop the useless turn-start double image offload.
