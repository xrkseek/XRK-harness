# v0.7.17

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.16](./v0.7.16.md)：对话区模型菜单在窄屏 / 刘海机上不再被裁切；手机 App 覆盖更新保留 `/root` 数据。

### 完善

* 对话区模型选择菜单改为视口 portal：右对齐触发钮后钳入安全边距，活动会话 `overflow-x` 不再裁掉菜单。
* 手机 App（旁仓）：同 runtime 壳升级软愈合；runtime 指纹变化时重装 rootfs 并抬回 `/root`（会话 / 设置 / 凭据保留）。

### 修复

* 窄屏 / 刘海机上模型菜单贴左时不再画出视口或被会话层裁切。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.17
xrkh web
```

桌面安装包见 GitHub Release `v0.7.17` 与站点下载页（AGT 上线后）。手机 APK 见 [XRK-harness-mobile `v0.7.17`](https://github.com/xrkseek/XRK-harness-mobile/releases/tag/v0.7.17)。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.16](./v0.7.16.md): the chat model menu no longer clips on narrow / notched phones; the mobile App overlay upgrade keeps `/root` data.

### Improved

* Chat model picker uses a viewport portal: right-align to the trigger, then clamp into safe margins so active-session `overflow-x` cannot crop the menu.
* Mobile App (sibling repo): shell-only bumps soft-heal; runtime fingerprint changes reinstall rootfs and carry `/root` (sessions / settings / credentials kept).

### Fixed

* On narrow / notched phones the model menu no longer paints past the left edge or gets clipped by the conversation layer.
