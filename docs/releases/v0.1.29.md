# v0.1.29

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.28](./v0.1.28.md)：Settings 可调前台 bash yield（Codex 250–30s）；默认 yield 对齐 Codex **30s**；输入区 **后台任务** dock 在 composer 上方提供 **停止/后台**。

Relative to [v0.1.28](./v0.1.28.md): Settings-tunable foreground bash yield (Codex 250–30s); default yield aligned to Codex **30s**; input-zone **background jobs** dock exposes **Stop/Background** above the composer.

---

## 新增 / Added

* 新增 Settings → Plugins → **Shell · 前台 yield（ms）**（`bash.foregroundYieldMs`，250–30_000，默认 30_000）
* 新增输入区 **后台任务** 折叠条（有 live job 时出现，展开后与会话头共用停止/后台控件）

---

## 完善 / Improved

* 完善默认前台 bash yield：**60s → 30s**（与 Codex `MAX_YIELD_TIME_MS` 一致）
* 完善文档：明确 **后台** 仅在 yield 窗口内（`foreground: true`）；yield 后主要用 **停止**

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.29
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：长命令在 yield 前可在输入区 dock 点 **后台** 提前解除 turn 阻塞；yield 后请用 **停止** 结束进程。
