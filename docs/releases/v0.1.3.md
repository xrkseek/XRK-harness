# v0.1.3

## 设置（Face / CLI `web` · `serve`）

- **文件真源**：`{workspace}/.xrk/settings.yaml` + `.credentials.yaml`；`settings.update` / `credentials.set` 落盘并在 UI 即时反映。
- **模型 namespace**：`llm-deepseek`（官方 DeepSeek 字段）与 `llm-pi-ai`（OpenAI 兼容网关 / 多运营商）。
- **`llm-pi-ai` 预置 catalog**：OpenAI、OpenRouter、Groq、Fireworks、Together、GitHub Models、Ollama、Azure、New API、CherryIN、Custom 等（来自 Registry `OPENAI_CHAT_BRANDS`；DeepSeek 兼容面走 `llm-deepseek`）。
- **协议字段**：`openai-chat` · `openai-completions` · `openai-responses` · `anthropic-messages`。
- **Agent 预设**：`agent-presets.default` 持久化；卡片选择写入 yaml，`agentPreset.list` 反映 `isDefault`。
- **其它 namespace**：`permission` · `bash` · `agent-loop` · `ui-conversation` · `web-search-deepseek` · `mcp` · `locale` · `ui-theme` · `ui-onboarding`。
- **清理**：移除冗余 `FACE_LLM_SCHEMA` / 泛化 `llm` settings namespace mutate 路径。

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.1.3 --registry=https://npm.pkg.github.com
```

GitHub Release 资产 `xrkseek-harness-cli-0.1.3.tgz` 亦可离线安装（无需 Packages token）。

## 验证

```bash
xrk-harness doctor
xrk-harness web --workspace .
```

Settings → Models / Agent preset / Plugins 应可编辑并落盘。
