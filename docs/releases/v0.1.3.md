# v0.1.3

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.1.2](./v0.1.2.md)：修复产品壳「新会话」中间全黑（会话 slot 崩溃）；monorepo 开发优先使用 freshly assembled `apps/web/dist`；插件 staging 与删除更可靠。

### 新增

* CLI 子命令 **`plugin reconcile`**：以 `.xrk-plugins.json` 为真源，清理 `web/plugins` 孤儿目录

### 完善

* monorepo 下 `xrk-harness web` **优先** `apps/web/dist`，避免 `client:bundle` 后仍服务陈旧的 `product-web/`
* 设置导航用 `entriesOfSlot('settings.section')`，避免社区插件重复注册侧栏项
* slot 崩溃时显示可读告警（`data-slot-error`），不再无声空白

### 删除

* 移除未接线的 **`ui-settings-dsh-bridge`** 包（硬编码 DSH 分区表方案已否决）

### 修复

* 修复 Hero 品牌回退引用不存在的 `FishLogo`，导致 `conversation` slot React #130、中间列全黑
* 修复 `settling` 相位只藏 composer 不画 Hero，历史回放时整列黑屏
* 修复 Windows 上 `plugin remove` 无法删掉 `@scope` 父目录（`EISDIR`）
* 修复插件 inventory 与磁盘 staging 不同步（add/remove 后 reconcile）

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.1.3
xrk-harness web
# 或
xrkh web
```

或：`npx @xrkseek/harness-cli@0.1.3 web`
