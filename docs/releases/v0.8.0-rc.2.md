# v0.8.0-rc.2

> **读者**：终端用户 · 维护者（发行说明）

相对 [v0.8.0-rc.1](./v0.8.0-rc.1.md)：远程手机桥与本机 guest 共用同一份 `xrk-phone` playbook；手机操控浮层收球更稳；干员身份同步在同秒 mtime 下不再盖掉磁盘新稿。仍走 npm **`@rc`**，**不**接管 `@latest`（仍为 **0.7.22**）。

### 完善

* **远程 = 本机手机操控用法**：`xrk-phone-bridge` materialize 写入 `$XRK_HOME/skills/xrk-phone`（与 guest 种子同文）；在线时 prompt 只绑定「先 skill 再 phone_*」，去掉 Host「勿加载」类防御文案。
* **手机操控浮层**：收成小球改为交叉淡入，避免硬切闪动；按键反馈不再把首字挤出圆角轮廓（壳侧）。
* **读屏拒因可读**：本机拒绝读 XRK 自己界面 / 拒名单时，工具结果带上具体原因，不再只剩空泛一句。

### 修复

* **`team_save` 省略 playbook**：同秒 mtime 下 adopt 优先已相对 roster 发散的磁盘稿，避免 AGENTS.md 盖掉更新的 pack `playbook.md`。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.8.0-rc.2`**（npm dist-tag **`rc`**；`@latest` 仍为 **0.7.22**）。
* Desktop / 手机 APK / guest runtime 对齐 **0.8.0-rc.2**；远程桥建议 **`@xrkseek/xrk-phone-bridge@0.7.25+`**。

### 升级

```bash
npm i -g @xrkseek/harness-cli@0.8.0-rc.2
# 或
npm i -g @xrkseek/harness-cli@rc
```

也可 `npx @xrkseek/harness-cli@0.8.0-rc.2 web`。日常 `@latest` 仍指向 0.7.22。

Desktop：安装 `xrk-harness-0.8.0-rc.2-win-x64`。Android：`XRK-harness-mobile` Release `v0.8.0-rc.2`。
