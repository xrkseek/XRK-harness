# v0.1.27

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.26](./v0.1.26.md)：完善 Settings 与对话选模型体验；精简并对标 Cursor 的产品 skill 剧本。

Relative to [v0.1.26](./v0.1.26.md): smoother Settings and model-picker UX; leaner product skills aligned with Cursor authoring patterns.

---

## 新增 / Added

* 新增 Settings **Models** 教练 skill **`xrk-models-settings`**（手动模型 ID、获取列表、对话搜索）
* 新增斜杠配方 **`/models-config`**（`.agents/recipes/models-config.yaml`）
* 新增产品 skill **`xrk-create-skill`**（对标 Cursor create-skill / create-rule 的 XRK 落点）

---

## 完善 / Improved

* 完善 MCP 设置：粘贴 JSON 后按钮改为 **添加 / Add**（不再显示「从 JSON 添加」）
* 完善模型目录：**添加模型** 可直接填 ID；**获取可用模型** 默认全选，并支持 **全选 / 取消全选**
* 完善对话模型选择：模型超过 5 个时在输入栏芯片列表显示 **搜索**（`/model` 弹窗仍自带搜索）
* 完善 bundled skills：压缩 `xrk-capability-attach` · `xrk-adapt-workspace` · `xrk-create-skill`；维护者笔记 **`xrk-workspace-skills`** 增加 Cursor 对照表

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.27
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`
