# v0.7.9

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

## 中文

相对 [v0.7.8](./v0.7.8.md)：Voice 产品化主线——Edge TTS 成为默认 TTS 引擎（免费、约 300 神经音色、无需 key），`text_to_speech` 改为落盘为会话附件并返回 `file` block，客户端行内播放条播放；修复「TTS 音频播不出来」的六层 bug；修「过程 · 思考」永久闪动；记忆/技能清理；底层代码质量提升。

### Voice 产品化（主线）

* **Edge TTS 成为默认 TTS 引擎**：`local` 降为离线兜底，`openai` 付费可选。切引擎时清空 `voice`/`voiceEn`（Edge 音色名不能带给 SAPI/OpenAI）。Host 默认 TTS 引擎回退值与 schema 对齐（`local` → `edge`）。
* **`text_to_speech` 落盘为会话附件**：返回 `file` block（`attachmentId` + `mediaType`），客户端行内播放条播放；支持 `language` / `voice` / `format` 参数。`VOICE_MAX_TTS_TEXT = 8000` 共享上限；SAPI 音色不存在改为诚实报错。
* **修复「TTS 音频播不出来」六层 bug**：最终根因是 `session.attachment` 的 RPC 响应 zod 契约只接受 image 形状，file 行被判 `invalid_union`；已加 `fileAttachmentRefSchema` + union。
* **TTS 行不再被折进「过程」分组**：`isStandaloneTranscriptTool` 加 `text_to_speech`。
* **修「过程 · 思考」永久闪动**：`live` 判定加 `!settled`。
* **`tts-row` 资源泄漏修复**：autoPlayers 卸载清理 + autoPlayed 上限 + `<audio>` onError。

### 记忆 / 技能

* **`memory` 工具**：`target` 不再必填（唯一值是 `memory`），错误文案不再指向不可写的 `user`。
* **`USER.md` 归属写清**：用户手写，工具不暴露（`AGENTS.md` 种子 + `docs/curated-memory.md` + 工具描述三处同步）。
* **三合一 `xrk-plugin` 旧名残留全清**：9 个文件（`.agents/`、`.cursor/skills/`、三份 CLI seed skill）。

### 底层质量

* **`output-bound`**：含 file/image 的结果不再报 `originalBytes: 0`（按 text 块真实累加）。
* **`model-catalog`**：同一 provider 不再出现两个同名分组。
* **`durable-inject`**：截断提示抽常量（原本两份硬编码）+ 目录条目精确匹配（`xrk-plugin` 不再误匹配 `xrk-plugin-dev`）。
* **`standing-skill-dirs`**：`extraSkillDirs` 三处表达收敛为 `skillDirs` + `preferredSkillDirs`。
* **`layered`**：`isLayered` 单一判定，`preset` 不再重复推导。
* **Host 默认 TTS 引擎回退值与 schema 对齐**：`local` → `edge`。

### 文档

* `docs/voice.md`：`text_to_speech` 返回 file block、ns 是 `tts`/`asr` 而非 `voice`、Edge 默认、SenseVoice 默认 `auto`。
* `docs/settings-fields.md`：重跑 `node scripts/dump-settings-fields.mjs`（tts 段补 `voiceEn`/`language`、engine 含 edge）。
* `docs/status.md`：Voice 行补 Edge + 播放条；SenseVoice 默认改 `auto`。
* `docs/curated-memory.md`：USER.md 写入者归属。

# Release Notes

> **Audience**: End users · Maintainers

## English

Relative to [v0.7.8](./v0.7.8.md): Voice productization — Edge TTS becomes the default TTS engine (free, ~300 neural voices, no key), `text_to_speech` now lands as a session attachment and returns a `file` block played inline; fixed the six-layer "TTS audio won't play" bug; fixed the perpetual "process · thinking" flicker; memory/skill cleanup; underlying quality improvements.

### Voice productization (mainline)

* **Edge TTS is the default TTS engine**: `local` becomes the offline fallback, `openai` is the paid option. Clear `voice`/`voiceEn` when switching engines (Edge voice names must not leak into SAPI/OpenAI). Host default TTS engine fallback aligns with schema (`local` → `edge`).
* **`text_to_speech` lands as a session attachment**: returns a `file` block (`attachmentId` + `mediaType`), played by an inline player; supports `language` / `voice` / `format`. Shared `VOICE_MAX_TTS_TEXT = 8000` cap; SAPI missing voice now reports honestly.
* **Fixed the six-layer "TTS audio won't play" bug**: root cause was the `session.attachment` RPC response zod contract only accepting image shapes, so file rows were judged `invalid_union`; added `fileAttachmentRefSchema` + union.
* **TTS rows no longer fold into the "process" group**: `isStandaloneTranscriptTool` now includes `text_to_speech`.
* **Fixed perpetual "process · thinking" flicker**: `live` check now includes `!settled`.
* **`tts-row` resource leak fix**: autoPlayers cleanup on unmount + autoPlayed cap + `<audio>` onError.

### Memory / skills

* **`memory` tool**: `target` no longer required (the only value is `memory`); error text no longer points at the unwritable `user`.
* **`USER.md` ownership clarified**: user writes it by hand; the tool does not expose it (`AGENTS.md` seed + `docs/curated-memory.md` + tool description, three places in sync).
* **Cleared `xrk-plugin` old-name residue**: 9 files (`.agents/`, `.cursor/skills/`, three CLI seed skills).

### Underlying quality

* **`output-bound`**: results containing file/image no longer report `originalBytes: 0` (real per-text-block accumulation).
* **`model-catalog`**: no two groups with the same name under one provider.
* **`durable-inject`**: truncation hint extracted to a constant (was duplicated) + exact directory-entry match (`xrk-plugin` no longer matches `xrk-plugin-dev`).
* **`standing-skill-dirs`**: three `extraSkillDirs` expressions converged to `skillDirs` + `preferredSkillDirs`.
* **`layered`**: single `isLayered` predicate; `preset` no longer re-derived.
* **Host default TTS engine fallback aligned with schema**: `local` → `edge`.

### Docs

* `docs/voice.md`: `text_to_speech` returns file block; ns is `tts`/`asr` not `voice`; Edge default; SenseVoice default `auto`.
* `docs/settings-fields.md`: re-ran `node scripts/dump-settings-fields.mjs` (tts section adds `voiceEn`/`language`, engine includes edge).
* `docs/status.md`: Voice row adds Edge + player bar; SenseVoice default changed to `auto`.
* `docs/curated-memory.md`: USER.md authorship.
