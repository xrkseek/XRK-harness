# v0.4.7

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.6](./v0.4.6.md)：概况栏更干净（Status 精简、告警去重、默认密度）；侧栏归档筛选三态；Teams 合回/冷恢复失败可见。

Relative to [v0.4.6](./v0.4.6.md): cleaner Overview (slim Status, deduped alerts, denser defaults); sidebar archive filter tri-state; Teams merge/cold-resume failures surface inline.

### 新增

* 新增侧栏视图选项归档筛选三态：隐藏已归档 / 全部 / 仅已归档（`ArchiveViewMode`；Face 剥离 membership 时按 cwd 回挂）。

### 完善

* 完善概况 Status：时间线只保留 token 条形图与计数；完整 inject / compact / spill 事件与预览留在「上下文」页签。
* 完善 Spill 列表：Status 压缩卡与上下文页签共用同一 peek +「打开 spill」控件。
* 完善概况默认密度：舰队 / Teams / 任务 / 投递 / 精简时间线默认展开；会话 / 子代理 / 压缩 / 成本 / 账单 / 通道默认收起。
* 完善通道告警：明细只在通道卡展示；舰队卡保留 health 与 `channelAlerts` 计数，不再双份列表。
* 完善 Agent Teams 任务板：打开 / 暂停 / 恢复 / 合回失败时行内短错误；动作按钮独立样式；长 child id / retained 提示折叠到 `title`。

### 修复

* 修复概况「全部展开/收起」首帧覆盖各卡 `defaultOpen`，导致默认展开卡被一并收起。

### 其他变更

* 无。公开线版本号 `@xrkseek/harness-cli@0.4.7`（本说明写毕后执行 `pnpm release` 再接管 `@latest`）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.4.7
xrkh web
```

## 验证

* 打开概况 → Status 无长事件表；点「上下文」可见事件与 spill 打开。
* 通道告警只在通道卡出现一份。
* Teams 合回失败时行内出现错误文案。
* 侧栏视图选项可切换归档三态，刷新后仍保留（`xrk.workspace.view.v6`）。

---

### Added

* Sidebar view-options archive filter tri-state: hide archived / all / archived-only (`ArchiveViewMode`; cwd reattach when Face strips membership).

### Improved

* Status Overview timeline keeps token bar + counts only; full inject / compact / spill events and peek live on the Context tab.
* Spill lists share one peek + Open control across Compaction (Status) and Context.
* Overview default density: fleet / Teams / jobs / delivery / slim timeline open; session / subagents / compaction / cost / billing / channels collapsed.
* Channel alert detail only on the Channels card; fleet keeps health + `channelAlerts` count without a second list.
* Agent Teams board: inline short errors on open / pause / resume / merge failures; dedicated action button style; long child ids / retained hints fold into `title`.

### Fixed

* Overview expand/collapse-all no longer overrides per-card `defaultOpen` on first paint.

### Other changes

* None. Public line `@xrkseek/harness-cli@0.4.7` (run `pnpm release` after this note to take `@latest`).
