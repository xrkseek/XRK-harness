# v0.5.3

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.2](./v0.5.2.md)：概况栏落地 **XRK-harness** 会话表情球（完整情绪目录 · `presence_set` · 注视），全局 `SOUL.md` 一次写入；桌面与 Web 共用同一套 home seed 建立。

Relative to [v0.5.2](./v0.5.2.md): Overview ships the **XRK-harness** presence ball (full emotion catalog · `presence_set` · gaze); global `SOUL.md` create-once; Desktop and Web share one home-seed establish path.

### 新增

* 新增概况 Status **XRK-harness** 表情球：EmotionBall、窗口级鼠标注视、一会话一球；Face 工具 **`presence_set`** 粘性写入 + `session.status.presence`；无粘性时按回合 / 作业 / 舰队活动推断。
* 新增产品种子 **`~/.xrk/SOUL.md`**（**create-once**：已有文件不覆盖）与可刷新 **`AGENTS.md`**（含 Craft 阶梯与 presence 用法）。

### 完善

* 完善 home seed 建立：`establishProductHomeSeeds` 单入口；`xrkh web` / `serve` / `restart` 与 Desktop Host boot 同路径；CLI 导出 `@xrkseek/harness-cli/home-seeds`。
* 完善 standing / recipes 扁平种子策略（fingerprint vs create-once）与 doctor 同源探针。
* 完善表情区布局：去掉「AI 设定」来源标签，标题改为 **XRK-harness**，球区留白收紧。

### 修复

* 修复 Desktop 开包 / 更新后未建立 `~/.xrk` 产品种子的缺口（与 Web Host 对齐）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.3`**（接管 npm `@latest`）；npmjs 保留 **0.5.3** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.3**（`package:desktop` 产物名随版本）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.3
xrkh web
```

侧栏（可选）：

```bash
xrkh plugin add xrkh-better-sidebar@0.18.20
xrkh restart
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.3-*-unsigned`（或签名）安装包。

## 验证

* 概况 → XRK-harness：球可见；移动鼠标眼睛跟踪；`presence_set` 后标题旁情绪名更新。
* 新用户目录：出现 `~/.xrk/AGENTS.md` 与 `SOUL.md`；改过的 `SOUL.md` 不被二次覆盖。
* Desktop 首次打开后同上种子出现；`xrkh doctor` 的 `user-home-seeds` 有 standing 明细。

### Added

* Overview Status **XRK-harness** presence ball: EmotionBall, window gaze, one ball per session; Face **`presence_set`** sticky write + `session.status.presence`; activity-derived fallback without sticky.
* Product seeds **`~/.xrk/SOUL.md`** (**create-once**) and refreshable **`AGENTS.md`** (Craft ladder + presence usage).

### Improved

* Home-seed establish: single `establishProductHomeSeeds` entry for `xrkh web` / `serve` / `restart` and Desktop Host boot; CLI export `@xrkseek/harness-cli/home-seeds`.
* Flat standing / recipe seed policies (fingerprint vs create-once) shared with doctor.
* Presence chrome: drop “AI set” source chips; title **XRK-harness**; tighter ball layout.

### Fixed

* Desktop open/update now establishes `~/.xrk` product seeds (aligned with Web Host).

### Other changes

* Public line **`@xrkseek/harness-cli@0.5.3`** takes npm `@latest`; npmjs keeps **0.5.3** and rollback pin **0.3.11**.
* Private Desktop shell version aligned to **0.5.3**.
