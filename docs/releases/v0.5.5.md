# v0.5.5

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.4](./v0.5.4.md)：概况栏大会话切会话不再因 soft-face 快照撕裂炸槽；同类 uSES 可观察源改为变更时发布、读取稳定引用。

Relative to [v0.5.4](./v0.5.4.md): Overview no longer crashes the details slot when switching into large Sessions via soft-face snapshot tearing; matching uSES observables publish on mutate and return stable references.

### 完善

* 完善概况 soft face：`presenceCues` / `changeTurnsFallback` 改为 **publish-on-notify**（只在 Session 通知时读库；`getSnapshot` 只返回已发布引用；内容未变不通知）。
* 完善表情球空闲时钟：忙时直接 `idleMs = 0`，不再用 `Date.now()` 刷 `setState`。
* 完善 web-runtime：`BootGate` / `ChunkFold` 同样在变更时发布快照，连续 `getSnapshot` 引用稳定。

### 修复

* 修复大会话切入概况触发 React #185（`Maximum update depth`）后 `details` abdicate、随后小会话也像坏掉的问题（槽位已卸，非小会话逻辑）。
* 修复 soft-face / 轨迹折叠在 `getSnapshot` 内现场 `ensureFresh` 或反复分配导致的撕裂风险。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.5`**（接管 npm `@latest`）；npmjs 保留 **0.5.5** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.5**（`package:desktop` 产物名随版本）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.5
xrkh web
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.5-*-unsigned`（或签名）安装包。

## 验证

* 小会话开概况正常 → 切大会话（长历史）概况仍渲染，无「Slot details failed」→ 再切回小会话仍正常。
* 大会话 Ctrl+F5 与会话切换均可打开概况 Status / 表情球。
* 忙时表情球不掉进 idle sleep；工具失败 tip 仍可在窗口内显示并到期消退。

---

### Improved

* Overview soft faces (`presenceCues` / `changeTurnsFallback`) are **publish-on-notify**: read the Session only on notify; `getSnapshot` returns the published reference; unchanged content skips listeners.
* Presence ball idle clock: busy forces `idleMs = 0` without `Date.now()` `setState` thrash.
* web-runtime `BootGate` / `ChunkFold` publish snapshots on mutate so consecutive `getSnapshot` calls share one reference.

### Fixed

* Switching into a large Session no longer trips React #185 in Overview and abdicates `details` (which previously made later small Sessions look broken).
* Soft-face / trajectory fold paths no longer tear by live `ensureFresh` or fresh allocations inside `getSnapshot`.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.5`** (owns npm `@latest`); npmjs keeps **0.5.5** and rollback pin **0.3.11**.
* Desktop private shell version aligned to **0.5.5** (`package:desktop` artifact names follow).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.5
xrkh web
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.5-*-unsigned` (or signed) package.

## Verify

* Small Session Overview OK → switch to a large (long-history) Session: Overview still renders, no “Slot details failed” → switch back to a small Session: still OK.
* Large Session Overview works after Ctrl+F5 and after session switch (Status / presence ball).
* Presence ball stays out of idle sleep while busy; tool-error tips still show and expire in-window.
