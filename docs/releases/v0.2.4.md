# v0.2.4

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.2.3](./v0.2.3.md)：六档会话徽章；`xrkh web`/`serve` 向 `~/.xrk` 种子 skills、薄全局 `AGENTS.md` 与 slash recipes；Plan → Build / 委派 / 审查 playbook。

Relative to [v0.2.3](./v0.2.3.md): six session badges; seed `~/.xrk` skills, a thin global `AGENTS.md`, and slash recipes on `xrkh web`/`serve`; Plan → Build / delegate / review playbooks.

---

## 新增 / Added

* 会话徽章六档：**Minimal** · **Shell** · **Frugal** · **Plan** · **Shallow** · **XRK Harness**（`AgentPresetProfile`；工具面与子代理策略按档位组合）
* `xrkh web` / `serve` 启动时写入 **`~/.xrk`**：`skills/*`、Codex 风格薄 **`AGENTS.md`**、`recipes/*`（缺才装；用户改过的永不覆盖；不 mkdir 工作区）
* 家目录技能：`xrk-plan-build` · `xrk-code-review` · `xrk-delegate`（另有既有 attach / models / create-skill / adapt-workspace）
* 斜杠 recipes（home → 工作区合并）：`/plan-build` · `/code-review` · `/mcp-attach` · `/models-config`

## 完善 / Improved

* **Frugal** 关闭子代理；**Shallow** 限制子代理深度与并发；**Plan** 默认进入计划模式（`exit_plan_mode` 后再实现）
* 全局站立只种薄 `AGENTS.md`，不自动种 SOUL / IDENTITY / TOOLS 人格栈
* Face / harness：slash recipes 按 `~/.xrk/recipes` → `.agents/recipes` → `.xrk/recipes` 合并（后写覆盖同 id）
* 子代理系统提示改为短路由指引（细节以工具 schema 为准）

## 其他变更 / Other

* 公开基线 **v0.2.4**（npm **`@latest`**）；上一版 **v0.2.3**；正式留档仍为 **v0.1.31**
* CLI / SDK 包版本对齐 **0.2.4**
* 契约：[profiles.md](../profiles.md) · [skills-layers.md](../skills-layers.md) · [workspace-inject.md](../workspace-inject.md)

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.2.4
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后硬刷新浏览器（Ctrl+Shift+R）。首次 `web` 会在本机 `~/.xrk` 补齐种子（已有改动的文件不会被覆盖）。
