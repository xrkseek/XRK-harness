## 一、本线交付了什么 / What the line delivers

XRK 在 0.3.x 是「能写代码的终端 Agent」。到 0.4.0，它长出了**外围操作**（浏览器、桌面、图像/视频/语音）、**多代理编排**（子代理续跑、任务板、目标环、Ralph 环、受管 worktree）、**会话工程化**（格式迁移链、检索、导出、回退快照）、**可插拔执行世界**（本机 / HTTP sidecar / SSH / 多沙箱后端），以及一套**把这一切接进界面的契约层**（右侧工作台、侧栏真推送、31 张能力设置卡、草稿输入器）。

### 运行形态与接入

| 入口 | 交付 |
|------|------|
| `xrkh web` / `serve` / `run` | 产品主路径；`xrkh <preset>` ≡ `web --preset`（Host 徽章真源） |
| **`xrkh tui`**（新） | 薄 Face 终端：HTTP unary + mux stream、工具轨、`/status`；复用已跑起来的 Host（默认 `127.0.0.1:8787`，`--session-id` / `--workspace` 可指）；非 TTY 直接失败不假装有界面 |
| `xrkh acp` | 编辑器经 stdio 驱动本进程，stdout 只走 JSON-RPC，诊断进 stderr |
| `xrkh skill add/list/remove/path` | 本地目录或 git 仓（`#subdir` 取单个技能），装前 fail-closed 校验 |
| `xrkh mcp login` + **Face `mcp.oauth.*`**（新） | 设备码登录在 CLI 与 Settings MCP 卡两侧同一 token 布局；Web 里也能登录/查状态/登出 |
| 外部 Agent 委托 | `XRK_CLAUDE_CODE` / `XRK_CODEX_APP_SERVER` / `XRK_ACP_AGENT`，`subagent runtime=acp\|app-server\|claude-code` |
| 启动失败分类 | Failed vs Waiting 可辨，落盘 `~/.xrk/logs/startup-*.log` |

### 代理内核与工具面

* **工具结果溢出（spill）`@xrkseek/spill`**（新）：`SpillStore` / `LocalSpillStore` 落盘并返回不透明 `SpillLocator` + `retrievalHint`；`applySpillPolicy` / `formatSpillNotice` 决定何时溢出与模型可见提示；`parseSpillLocator` 让概况 Status 直接打开 spill 文件。默认根目录 `{XRK_HOME}/spill/tool-outputs`。存储与策略分离，`agent-loop` 侧经 `tool-result-bound` 转发同一实现
* **`apply_patch`**：Codex `*** Begin Patch` 格式解析 + 应用，与 `write_file` / `apply_edit` 同处 `@xrkseek/exec-fs`；`FsService.remove` 补上 Delete/Move 需要的单文件删除；共享会话 cwd（含受管 worktree）
* **执行世界 `@xrkseek/exec-environment`**（新）：`ExecEnvironmentProvider → ExecWorld`（`fs` + `subprocess`），provider `local`（默认）· `http`（serverless 样例：`GET /health`、`POST /v1/exec`、`POST /v1/fs`）。`XRK_EXEC_ENVIRONMENT=local|http` + `XRK_EXEC_ENVIRONMENT_URL` / `_TOKEN` 选择。**与 `createSandboxStack` 是两条缝**：后者管 confinement，前者管 world；SSH 仍是 Host `remoteExecution` 的 `createSshExecutionWorld`，同形状不同旋钮
* **出网白名单**：`XRK_WEB_FETCH_ALLOWLIST` 收紧 `web_fetch` 目标主机并留审计痕（默认从 env 取）
* **运行时不变量 `@xrkseek/runtime-invariants`**（新）：包自有 registry（不依赖 Cordis），`./invariant` 伴侣挂关键包，`wrapSessionStore` 包住 `SessionStore.append`；`XRK_INVARIANTS_FAIL_FAST=1` 时违规抛 `InvariantError`（`code: "INVARIANT"`，带 `packageName`）。社区 Cordis 叠层继续用 stubs `@xrkseek/xrk-invariants`
* **凭证 `@xrkseek/secrets`**（新）：`SecretStore`（service+account 的 load/save/delete）+ `createMemorySecretStore` / `createOsKeyringStore`（动态 `keytar` 探测，缺依赖只报 unavailable），`XRK_SECRETS_BACKEND` 选路；`/redact` 子路径供日志与工具输出脱敏
* **审批分类**（新）：`classifyApproval` 把人工确认分成网络 / 升级 / 工具三类以决定文案与配色，纯启发式、不当安全边界

### 多代理编排

* **子代理家族补齐**：`subagent` · `list_agents` · `send_message` · **`followup_task`**（新，唤醒可续跑的 child 并留 durable id）· **`wait_agent`**（新，等 child 变 idle）· **`analytics`**（新，配额/占用）· `interrupt_agent`（`takeover:true` 暂停待人工）。Settings → `agent-loop.maxSubagentDepth` / `maxActiveSubagents` 默认 2/2，硬上限深度 3；徽章可再收紧；系统提示按 `tool:subagent` 注入
* **受管 worktree `managed-worktree.ts`**（新）：`subagent worktree:true` 分配 / 回收独立 git worktree，写 owner 记录（`MANAGED_WORKTREE_OWNER_FILENAME`）绑定到 Agent Teams 任务；回收后经 `ManagedWorktreeManager.mergeIntoParent`（ff-only）把成果并进父工作区
* **Agent Teams**：`agent-team-roles`（spawn 角色模板，`delegator|worker|observer` 图标签之外真给 child prompt 加前缀）· `agent-team-tasks`（新，交付 / 结果 / 暂停接管任务板，内存态 + 可选 JSON sidecar，按根会话键）· `agent-team-output`（输出契约与 JSON 候选抽取）
* **目标环**：`get_goal` / `update_goal` 工具 + `/goal` 斜杠 + `goal-round-driver`（续跑提示渲染与 `decideGoalTurnEnd` 决定回合是否自动续），Face 侧 `GoalStore` 持态，不碰 Cordis
* **`ralph` 工具**（新）：前台一轮一个全新 one-shot child，跨轮只传有界结构化交接，工作区即 durable memory——DSH Ralph 语义的 Face 原生实现，无 WorkflowEngine/Cordis 依赖
* **代码模式**：`run_code` 以脚本批量驱动工具（见 [code-mode.md](../code-mode.md)）

### 会话与记忆

* **`@xrkseek/session-format`**（新）：相邻世代迁移链 + 制品探测。三条真源边——`xrk-interchange`（角色 JSONL ↔ 事件，`importSessionInterchange`）、`xrk-sqlite-schema`（`sessions.db` 物理 schema，0→1→2→3 相邻升）、`xrk-packed-jsonl`（导出 packed 行 / `.jsonl.zst`）。第三方 Session Format V3 **不采纳**，探测到即 `refused`（立场见 [ADR-0009](../adr/0009-session-format-v3-vs-sqlite-schema-v3.md)）
* **会话检索**：`session_search` · `session_read` · `session_trace` 三个模型面工具（SQLite 召回 + 导出旁路），配合 `@session` 引用与跨会话 prepare
* **回合回退与工作区快照**：`@xrkseek/checkpoint` 影子 git；Face RPC `session.checkpoint.list|planRestore|restore|snapshot`；`/rollback` 斜杠；`continueTurn` 前自动快照，回退到某回合时把该回合改过的文件一并还原（细节见 [turn-rewind.md](../turn-rewind.md)）
* **策展记忆**（rc.1 起）：`memory` 写 `{XRK_HOME}/memories/{MEMORY,USER}.md`，跨会话生效；策略段常驻系统提示——**会话内未完工作进 `todo_write`，不进 MEMORY**（rc.3 的这条修复一并覆盖新建会话不再把进度笔记当任务队列）
* **上下文片段 `@xrkseek/context-fragments`**（新）：按 phase 收集、可插拔的模型可见上下文（`pipeline.collect(phase, ctx, { budgetChars })`），与 durable workspace inject 分缝；详见 [context-fragments.md](../context-fragments.md)
* **技能学习环 `propose_skill`**（新）：复杂多工具回合结束后，下一 turn-start 可注入一条 fragment 提示；模型提交 class-level `SKILL.md` 草案（When to Use / Procedure / Pitfalls），Face 弹 `Write skill` / `Reject` 人确认，**只有批准后**才走 `installSkillFromLocalDir` 的 fail-closed 路径写 `{workspace}/.agents/skills/<name>/`。本切片不做 background review fork / curator
* **rollout-trace**（新）：本地离线 reducer，把会话事件 + 子代理链路压成 nodes/edges 供调试回放。**不是 OTLP、不上传**，只是导出旁的调试边车
* **会话遥测**（rc.1 起）：`XRK_TELEMETRY=1` + `XRK_TELEMETRY_OTLP_ENDPOINT` 导出 OTLP

# Release Notes (English summary)

**v0.4.0 closes the `0.4.x` preview line** and takes over npm `@latest`. rc.1–rc.4 are historical process numbers; this file is the single entry point for the line.

* **Periphery**: interactive browser (`browser_*`), desktop (`computer_use`), image/video generation, voice trio, scheduled `cronjob`, multi-sandbox backends (`docker` · `bwrap` · `windows`), editor access via `xrkh acp`, external-agent delegation, device-code MCP login in both CLI and Settings.
* **Kernel**: tool-result spill as a first-class contract (`@xrkseek/spill`, openable from the Status overview), Codex-style `apply_patch`, pluggable execution worlds (`@xrkseek/exec-environment`: `local` · `http` sidecar, separate from sandbox confinement and SSH), outbound allowlist, package-owned runtime invariants with fail-fast, credential store with OS keyring + redaction.
* **Orchestration**: subagents gain `followup_task` / `wait_agent` / `analytics` and managed worktrees that merge ff-only into the parent; Agent Teams spawn roles plus a task board; goal loop (`/goal`, `get_goal`/`update_goal`) with a round driver; native `ralph` tool.
* **Session engineering**: `@xrkseek/session-format` migration chain (interchange · SQLite schema · packed JSONL; third-party Session Format V3 detected and refused per ADR-0009), `session_search` / `session_read` / `session_trace`, shadow-git workspace checkpoints behind `/rollback`, curated memory with an explicit "in-session WIP belongs to `todo_write`" policy, context fragments, and a human-approved `propose_skill` learning loop.
* **UI**: first-party thin workbench shell that yields to the community sidebar, real `agent-opens` / `agent-terminals` push behind preferences, unified Status/`/status` data, draft editor with reference chips and suffix retention, file cards, and 31 capability settings cards that degrade honestly.
* **Quality**: 9 new packages, 3 new specs, 37 docs updated, 5 golden eval tracks, `tsc`/`eslint` clean, **421 files / 2 295 tests green**, kernel coverage 99.04% statements / 100% functions.
