# v0.4.12

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.11](./v0.4.11.md)：修正 Mux 发送队列超顶掐线导致「每用一次工具就重连」；心跳与文档对齐 DSH gateway 语义。`0.4.x` 预览线本号为 npm `@latest` 终态；下一档进 `0.5.x`。

Relative to [v0.4.11](./v0.4.11.md): stop over-budget Mux send-queue terminates that forced a reconnect after every tool burst; heartbeats and docs align with DSH gateway semantics. This closes the `0.4.x` line on npm `@latest`; next train is `0.5.x`.

### 修复

* 修复 Face Mux / host 发送队列：超软顶或单帧过大时**丢帧并 warn**，不再 `terminate` 对端（对齐 DSH：出站压力不掐物理套接字）。
* 修复写失败只停入队，避免工具突发与半开写错误竞态逼重连。
* 修复 Ping 看门狗漏 Pong 容忍由 2 次放宽为 **5** 次（Face mux 与工具/投影共事件循环；DSH gateway 仍为 2）。

### 完善

* 精简 `ws-send-queue` / `ws-heartbeat` 接口与注释；导出 `FACE_WS_HEARTBEAT_MAX_MISSED`。
* 同步 [host-face](../host-face.md) · [modules/server-face](../modules/server-face.md)。

### 其他变更

* 公开线 `@xrkseek/harness-cli@0.4.12`（接管 `@latest`）。
* npmjs 仅保留 **0.4.12** 与回退用 **0.3.11**；其余号撤回或弃用（GitHub Release 文稿保留）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.4.12
xrkh web
```

## 验证

* 连续多次工具调用不因队列超顶而周期性重连；Host stderr 最多出现一次 `send queue over budget` warn。
* 半开连接仍会在约 10s 无 Pong 后被掐掉。

---

### Fixed

* Face Mux / host send queue: over soft-cap or oversize single frames **drop with a warn** instead of `terminate` (DSH-aligned: outbound pressure must not kill the physical socket).
* Write failures only stop enqueue — no race that forced reconnects on tool bursts.
* Ping watchdog missed-Pong allowance raised from 2 to **5** (Face mux shares the Host event loop with tools/projections; DSH gateway remains at 2).

### Improved

* Slimmed `ws-send-queue` / `ws-heartbeat` surface and comments; export `FACE_WS_HEARTBEAT_MAX_MISSED`.
* Synced [host-face](../host-face.md) · [modules/server-face](../modules/server-face.md).

### Other changes

* Public line `@xrkseek/harness-cli@0.4.12` (takes `@latest`).
* npmjs keeps only **0.4.12** and rollback pin **0.3.11**; other numbers withdrawn or deprecated (GitHub Release notes remain).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.4.12
xrkh web
```

## Verify

* Repeated tool calls do not cycle reconnect from queue-budget terminates; Host stderr shows at most one `send queue over budget` warn.
* Half-open peers are still terminated after ~10s without Pong.
