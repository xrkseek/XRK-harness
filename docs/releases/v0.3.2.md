# v0.3.2

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.1](./v0.3.1.md)：补齐侧栏 Git worktree 清单与「本轮文件变动」事件增量，去掉多余扫盘。

Relative to [v0.3.1](./v0.3.1.md): wire sidebar `git.worktrees` and session `changes.ops`; drop redundant worktree status scans.

---

## 新增 / Added

* Host `/sidebar/api/git.worktrees`：列出当前仓库 linked checkout（`path` · `branch` · `current` · `changes`）
* Host `/sidebar/api/changes.ops`：按 `afterSeq` 增量返回 Face wire 形状的 `tool/call` · `tool/result`（文件变动「本轮」视角）

## 完善 / Improved

* `git.status` 补客户端字段 `isRepo` / `root`；Git RPC 尊重 `worktree` / `repoRoot` 选型
* `resolveGitWorktree` 只校验 membership，不再对每个 checkout 重复 `git status`

## 其他变更 / Other

* CLI / SDK 对齐 **0.3.2**（npm **`@latest`**）
* 公开双档：**v0.3.2** + **v0.2.7**；`xrkh-better-sidebar` 无需换版
* 仍未做：真实 `agent-opens` 推送（现为空闲 stub，避免重连风暴）
