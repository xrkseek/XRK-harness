# v0.1.28

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.27](./v0.1.27.md)：前台 Shell 有界 yield、作业与子代理完成 **steer** 投递、会话头作业 **停止/后台** RPC 与 UI；Skills YAML 块标量解析与种子指纹自动刷新。

Relative to [v0.1.27](./v0.1.27.md): bounded foreground shell yield, **steer** delivery for job and subagent completion, session-header **Stop/Background** job RPC and UI; YAML block-scalar parsing for skills and automatic seed fingerprint refresh.

---

## 新增 / Added

* 新增 Face RPC **`job.kill`** · **`job.background`**（会话头作业列表 **停止 / 后台** 按钮）
* 新增前台 bash **60s yield**：长命令变 job，可在 yield 窗口内停止或转后台而不阻塞 agent loop
* 新增 CLI 种子 **SHA-256 指纹**：bundle 升级后自动刷新 `~/.xrk/skills` 中对应 bundled skill

---

## 完善 / Improved

* 完善 **job / 子代理完成通知**：投递改为 **`steer`**，注入当前 turn（对标 Codex inject，不受用户 queue 偏好影响）
* 完善 **`JobView.foreground`**：壳与 wire 投影前台作业状态
* 完善 **subprocess 终止**：默认 `stdin: ignore`、延长 kill settle grace、Windows **`taskkill /T /F`** 树杀
* 完善 **skill frontmatter**：解析 YAML 折叠/字面块标量（`>` · `>-` · `|` · `|-`），bundled skill 可保留多行描述
* 完善 **`xrkh doctor` / `serve`**：报告 seeded 与 refreshed 的 home skills

---

## 产品面 / Product UI

v0.1.28 起网页壳里**终端用户能直接看到**的变化（细节见 [shell-jobs.md](./shell-jobs.md)「产品壳」）。

### 会话头 · 后台任务

| 表现 | 说明 |
|------|------|
| **何时出现** | 仅当**当前会话**有 job 时标题栏才出现控件；无 job 时完全隐藏 |
| **触发器** | 「N 个后台任务运行中」/「N 个后台任务」；运行中带状态点 |
| **列表** | kind · label · status/detail · 耗时；**停止**（运行中/停止中）；**后台**（仅前台 yield 的 running 行） |

### 对话与时间线

| 表现 | 说明 |
|------|------|
| **60s yield** | 长 `bash` 最多等 **30s**（Settings 可调）后 tool 返回 job id，**turn 继续**；命令仍在列表里 |
| **steer 完成通知** | Job / 后台子代理结束时**不进输入框排队**，在 tool-step 边界注入时间线（像上下文块，非手打消息） |
| **后台按钮** | 仅在前台 yield **窗口内**（`foreground: true`）；yield 后请用 **停止** |
| **输入区 dock** | 有 live job 时在 composer 上方显示，展开可 **停止/后台** |

### 无新网页控件

种子指纹刷新 · skill YAML 块标量 · subprocess 树杀——分别体现在 CLI 日志/doctor、skill  authoring、**停止**更可靠。

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.28
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：前台 shell 超过 yield 时间仍会继续运行，但 agent 可继续对话；yield 窗口内可 **后台**，之后用会话头或输入区 dock 的 **停止**。
