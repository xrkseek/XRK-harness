# v0.8.16

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.15](./v0.8.15.md)：后台任务完成回传按 job 分卡、deflate 干员包可 Host 导入、未就绪干员闸门与后台任务面板限高。

### 完善

* **后台任务面板**：列表与输出限高，并按触发器下方可视区域夹紧，收起不必再把会话滚回顶。
* **干员工作区**：未就绪干员在名册添加与侧栏行上可见「未就绪」；禁止开家 / 新建会话，并 toast 说明先「标记就绪」。

### 修复

* 多个 `job-completion` 插队不再合成一张「后台任务完成」卡（`jobId` 分族；客户端 cover key 与内核对齐）。
* 并发 `ask-user` 迟到答不再并卡（`questionRpcId` 分族）。
* 微信等重新打包的 deflate 干员 zip 不再误报「非产品 zip」——有 Host 时回落 `team.importPack`。
* 未就绪 advanced 干员不能再经「添加干员工作区」铸家（Face `mintHome` 拒绝）。

### 其他变更

* 公开线版本号对齐 **0.8.16**（npm / Desktop / 手机 / 官网下载同号）。
* 投递规格补充：带 per-item id 的插件 notice 一 id 一族（[session-delivery](../session-delivery.md)）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.15](./v0.8.15.md): per-job completion chips, Host import for deflated member zips, not-ready agent gates, and a shorter background-job sheet.

### Improved

* **Background job sheet**: caps list/output height to space below the header chip so collapse stays reachable without scrolling the chat to the top.
* **Agent workspace**: not-ready members show「未就绪」 on Add-agent and sidebar rows; mint-home / new session are blocked with a toast to Mark ready first.

### Fixed

* Multiple `job-completion` steers no longer smash into one「后台任务完成」chip (`jobId` families; client cover key matches the kernel).
* Concurrent `ask-user` late answers no longer coalesce (`questionRpcId` families).
* Deflated member zips (e.g. WeChat re-saves) no longer false「not a product zip」— Host `team.importPack` is used when available.
* Not-ready advanced members can no longer mint a home via「添加干员工作区」(Face `mintHome` refuses).

### Other

* Public line version **0.8.16** (npm / Desktop / phone / site download share the same number).
* Delivery docs note per-item plugin notice families ([session-delivery](../session-delivery.md)).
