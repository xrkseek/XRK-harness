# v0.5.2

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.1](./v0.5.1.md)：概况栏落地 **Canvas 工作区看板**，会话级记住开合 / 页签 / 滚动并软 hop 委派；Desktop 闪屏跟 Settings 主题；附件 id 可点开预览；产品 skill 种子与概况 chrome 收紧。

Relative to [v0.5.1](./v0.5.1.md): Overview ships **workspace Canvas boards**, per-session open/tab/scroll memory with soft-hop on delegation; Desktop splash follows Settings theme; attachment ids open a lightbox; product skill seeds and Overview chrome tighten.

### 新增

* 新增概况 **Canvas** 页签：Face `canvas_*` 工具写工作区看板（markdown / table / kpi / series），跨会话保留于 `{XRK_HOME}/canvases/…`；产品 skill **`xrk-canvas`**。
* 新增对话附件 **lightbox 预览**（`sha256:…` / `attachment:…`），不再只能当路径打开。
* 新增 Desktop **闪屏底色跟 Settings 主题**（`settings.yaml` / `host-settings.json`），暗色用户不再先闪浅灰地板。

### 完善

* 完善概况栏记忆：开合按会话；宽度仍共用；页签与**按页签**滚动位置按会话记住；父子 / 同父委派 **soft hop** 借上一跳内容，避免整栏闪白。
* 完善概况 chrome：pending 顶扫、空态、画布 chip 键盘、改动栏 diff 卡片与 focus 环；`prefers-reduced-motion` 关掉动画。
* 完善产品种子 skill / 工作区 `AGENTS.md` 与种子路由（含 Canvas 教练入口）。
* 完善 DiffBlock / 概况「改动」与插件清单安装 UI 的 quiet 视觉与可键盘操作。

### 删除

* 删除仓内 **`@xrkseek/client-ui-workbench`** 包：浮动文件树 / 终端改以社区 **`xrkh-better-sidebar`** + Host `/sidebar/*` 为默认（见 [sidebar-workbench](../sidebar-workbench.md)）。

### 修复

* 修复概况开合被做成全局习惯后，一切会话同开同宽的错觉：开合回按会话，委派 hop 仍保持开着。
* 修复 Desktop 协议 / 窗体生命周期与首屏外观在主题切换下的不一致。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.2`**（接管 npm `@latest`）；npmjs 保留 **0.5.2** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.2**（`package:desktop` 产物名随版本）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.2
xrkh web
```

侧栏（可选）：

```bash
xrkh plugin add xrkh-better-sidebar@0.18.20
xrkh restart
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.2-*-unsigned`（或签名）安装包。

## 验证

* 概况 → Canvas：工具写入看板后出现 chip，可切换播放；切会话再回来仍在。
* 会话 A 打开概况并滑到「改动」→ 切无关会话 B 概况应关；回 A 仍开、仍在「改动」与原滚动。
* 父子委派 hop：概况保持开着，内容 soft pending 后落稳。
* Desktop：暗色 Settings 下闪屏为深色地板，再进产品壳。
* 点工具卡 / 读图里的附件 id：弹出 lightbox，而非误走路径打开。

---

### Added

* Overview **Canvas** tab: Face `canvas_*` tools write workspace boards (markdown / table / kpi / series) under `{XRK_HOME}/canvases/…`; product skill **`xrk-canvas`**.
* Chat attachment **lightbox** for `sha256:…` / `attachment:…` ids.
* Desktop **splash floor follows Settings theme** (no light-gray flash for dark users).

### Improved

* Overview memory: open/closed per Session; shared width habit; per-tab scroll per Session; parent/child soft hop reuses prior paint.
* Overview chrome: pending sweep, empty states, Canvas chip keyboard, Changes diff card + focus rings; reduced-motion kills animations.
* Product skill seeds / workspace `AGENTS.md` routing (including Canvas coaching).
* DiffBlock / Overview Changes / plugin-inventory quiet chrome and keyboard affordances.

### Removed

* In-repo **`@xrkseek/client-ui-workbench`**: floating tree/terminal defaults to community **`xrkh-better-sidebar`** + Host `/sidebar/*` (see [sidebar-workbench](../sidebar-workbench.md)).

### Fixed

* Overview open bit no longer global (unrelated Sessions no longer share forced-open); soft hop still keeps the column open.
* Desktop protocol / window lifecycle vs first-paint appearance under theme preference.

### Other changes

* Public line **`@xrkseek/harness-cli@0.5.2`** takes npm `@latest`; npmjs keeps **0.5.2** and rollback pin **0.3.11**.
* Private Desktop shell version aligned to **0.5.2** (artifact names follow).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.2
xrkh web
```

Optional sidebar:

```bash

xrkh restart
```

Then hard-refresh the client half. Desktop: install this cut’s `xrk-harness-0.5.2-*-unsigned` (or signed) package.

## Verify

* Overview → Canvas: boards appear after tool writes; survive Session switches.
* Session A Overview open on Changes → unrelated B stays closed; return to A restores tab + scroll.
* Parent/child hop: Overview stays open; soft pending then settles.
* Desktop: dark Settings → dark splash floor before product shell.
* Attachment ids open lightbox instead of path-open.
