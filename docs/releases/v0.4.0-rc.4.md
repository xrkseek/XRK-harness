# v0.4.0-rc.4

> **读者 / Audience**：终端用户 · 插件与集成者（发行说明）

相对 [v0.4.0-rc.3](./v0.4.0-rc.3.md)：概况栏与侧栏工作台可同开；壳发布布局 insets；修复 rc.3 损坏的根 README 与漏 bump 的 SDK 版本。

Relative to [v0.4.0-rc.3](./v0.4.0-rc.3.md): overview and sidebar workbench may stay open together; the shell publishes layout insets; root README encoding and the missed SDK version bump from rc.3 are fixed.

---

## 完善 / Improved

* 壳发布公共 `LayoutInsets`（`--xrk-layout-inset-*` · `data-xrk-layout-*` · `ctx.layout.insets`），浮动工作台用 CSS 变量让位，不再与概况栏互斥收起
* 概况「打开」控件跟 insets 戳同步按下态，二次点击可关闭概况栏

## 修复 / Fixed

* 根 `README.md` 中文在 rc.3 发包时被错误编码写坏，本版恢复
* `@xrkseek/harness` 版本与 CLI 对齐到本号（rc.3 曾漏 bump，仍停在 rc.2）

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.4.0-rc.4
xrkh web
```

也可 `npx @xrkseek/harness-cli@0.4.0-rc.4 web`，或 `@rc`。预览线不覆盖 `@latest`：日常安装仍用 `npm install -g @xrkseek/harness-cli@latest`（v0.3.11）。

侧栏请升级：`xrkh plugin add xrkh-better-sidebar@0.18.7`，然后硬刷新 Web。

SDK：`pnpm add @xrkseek/harness@0.4.0-rc.4`

GitHub Release 资源：`xrkseek-harness-cli-0.4.0-rc.4.tgz` · `xrkseek-harness-0.4.0-rc.4.tgz`
