# v0.2.0

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.31](./v0.1.31.md)：Session / Face / PTY / 对话壳整层加固——统一日志读面、WebSocket 心跳、Linux 进程快照、历史分页与 Job / 等待时钟体验。本版为 **0.2 预览线**，仍以 npm **`@latest`** 安装。

Relative to [v0.1.31](./v0.1.31.md): a foundation pass across Session, Face, PTY, and the conversation shell — unified log reads, WebSocket heartbeat, Linux process snapshots, history pagination, and Job / wait-clock UX. This is the **0.2 preview line**, still installed via npm **`@latest`**.

---

## 新增 / Added

* Session 日志读面（`@xrkseek/core-session`）：位置类型 `SessionSeq` / `SessionLogOffset` / `SessionSeqCursor`；仓必选 `readEvents`；`readSessionEvents` · `sessionEventCount` · `sessionEventAt` · `lastSessionEvent` · `sessionEventsFrom` · `snapshotEvents` · `resolveHalfOpenEventRange`；列表元数据 `computeListHints` / `sessionListHints`（见 [session-log.md](../session-log.md)）
* Face mux 独立序号：`FaceMuxSeq` · `FaceSeqClock`（含 `ensureAtLeast`，history 回放一次跳齐水位，避免 O(maxSeq) 空转）
* Face WebSocket 心跳：`ws-heartbeat` 对 mux/host 升级口约 **2s** Ping；连续 **2** 次无 Pong 则 `terminate` 半开连接（见 [host-face.md](../host-face.md)）
* Linux PTY 进程快照：`ProcessSnapshot` 一次采样进程表，供 stdin-wait 与拆毁路径复用；tid fdinfo / 多 ABI syscall / TTY 过滤（见 [pty-tools.md](../pty-tools.md)）
* 历史分页：`paginateSessionHistory` 返回 `startIndex`；当页事件建 Face mux seq 映射；导出 `dropSupersededStreamDeltas`
* 含图会话门禁：Face runtime 维护 `sessionHasImage` / `sessionImageScanned`，`session.selectModel` 换无图模型时 O(1) 拒绝（冷会话首次 miss 扫一次）

## 完善 / Improved

* 生产读日志统一走 `readSessionEvents`：Face、agent-loop、agent、HTTP、Host sidebar、face-session-query、admit / dangling / prune、presets、CLI dump；`forkSession` 经读面取前缀再 append
* 内存仓与持久化仓：全量读复用驻留数组身份；`listHints` 缺会话统一抛错；SQLite / memory 的 `readEvents` 委托 `snapshotEvents`
* HTTP：会话存在性用 `store.has`；增量推送用 `sessionEventCount` / `sessionEventsFrom` / `lastSessionEvent`
* `session-added` blank 判定走 `sessionListHints`（优先仓 `listHints`，不必手扫 `turn/start`）
* 压缩写入：`runCompaction` → `priceCurrentSurfaceWindow` → `shadowedTokenCount`；`compactNow` 缺省 shadow 按 0；assemble 路径 `foldPlanMode` 只算一次
* protocol：`effectiveApprovalPolicy` / `foldPlanMode` 改为反向扫描最新事件
* 对话壳：进行中「等待」时钟改为**本段等待**时长（挂载起算），与结算后「Ran for」整轮时长区分；短间隙仍只显示文案
* Job 输入区 dock：仅对 **live** jobs 展开；去掉无用 CSS
* workspace inject：duck-typed store 优先 `readEvents`，否则 `get().events`
* 教科书：新增 [session-log.md](../session-log.md)；同步 session / compaction / host-face / pty / status / modules 地图

## 删除 / Removed

* workspace 未使用的 skill 目录别名导出（`PROJECT_SKILL_REL_DIRS` / `USER_SKILL_REL_DIRS` 一类）
* 未使用类型 `OptionalSessionSeq`
* 仓库内 `.artifacts/proposal-build` 提案构建残骸
* GitHub Release 公开页仅保留 **v0.1.31** 与 **v0.2.0**（其余历史 Release / 对应 tag 下线；`docs/releases/v*` 文稿仍可查阅）

## 修复 / Fixed

* 修复长会话 history 回放：mux 水位用 `ensureAtLeast` 跳齐，避免按序号逐个 `next` 卡顿
* 修复含图会话选模型：冷路径扫一次后缓存，避免每次 `selectModel` 全量扫日志
* 修复进行中等待时钟与「Ran for」混用同一锚点导致的观感不一致

## 其他变更 / Other

* 公开基线 **v0.2.0**（预览成熟度，npm **`@latest`**）；上一正式留档 **v0.1.31**
* `npm-prune-withdrawn` 保留集改为当前正式线 + **0.1.31**（不再以 0.0.11 为默认保留预览号）
* CLI / SDK 包版本对齐 **0.2.0**
