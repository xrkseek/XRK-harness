# v0.1.10

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.9](./v0.1.9.md)：工作区 inject 支持全局 `~/.agents` 养 AI；本仓 `.agents/` 取代模板 sync；注入工作区根锚点与 inject 预算设置。

Relative to [v0.1.9](./v0.1.9.md): workspace inject gains a global `~/.agents` persona layer; repo-native `.agents/` replaces template sync; workspace root anchor and inject budget settings.

---

## 新增 / Added

* 新增用户主目录 inject 层：`~/.agents/`（`AGENTS.md` · `rules/` · `context/`）与 `~/.xrk/` 站立文件，工作区层覆盖全局
* 新增仓库内 `.agents/` 产品 Agent 层（skills · context · recipes），Harness 源码仓作工作区即可写插件，无需 `syncSeeds`
* 新增工作区根锚点 inject（`workspace-root`），`session.list` 携带 `workspaceId` / `workspaceTitle`，`previewInject` 按会话 cwd 解析
* 新增 Settings `workspace-inject.injectMaxChars`（4000–128000，默认 32000）供 Host 调节 inject 预算

---

## 完善 / Improved

* 完善 inject 顺序：去除 `.agents/AGENTS.md` 重复注入
* 完善 skill catalog：inject 与 `skill.list` 一致扫描用户主目录 skill 根
* 完善 harness preset：recipes 自动加载 `.agents/recipes` 与 `.xrk/recipes`

---

## 删除 / Removed

* 删除 `templates/`（`office-agent` · `xrk-harness`）与 `workspace.syncSeeds` / `syncSeedsFrom` 整条同步链路
* 删除根目录 `examples/`（`hello-agent` · `sdk-quickstart`）
* 删除示例 channel 插件 `extensions/channels-onebot` · `extensions/channels-stdin`

---

## 修复 / Fixed

* 修复多工作区场景下 inject 缺少绝对路径锚点、模型在错误盘符乱搜的问题
* 修复 `modsearch` 与会话 cwd 不一致时使用 Host serve 根目录的问题

---

## 其他变更 / Other

* **破坏性**：Face 不再提供 `workspace.syncSeeds`；请改用仓库 `.agents/` 或 `~/.agents/` 全局层

---

npm install -g @xrkseek/harness-cli@0.1.10
xrkh web
