# v0.6.20

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.19](./v0.6.19.md)：**过程折叠手感对齐标准模式预期**——完成后自动收起、收起摘要点名工具、进行中行带扫光、输入区不再被折叠顶起。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.20`（发包后）。

Relative to [v0.6.19](./v0.6.19.md): **process-fold UX matches Standard-mode expectations** — auto-folds when a Turn completes, collapsed headers name tools, live runs shimmer, and the composer stays docked when content shrinks. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.20` (after publish).

### 完善

* **标准 / 精简完成后自动收起**：跟到底部或过程仍在视口内时也会折成摘要头（过渡动画）；仅视口上方的组走即时折叠 + 滚动补偿。
* **收起摘要更可读**：「过程」与详情之间留分隔点；标准 / 详细显示工具名（过长 `+N`）与思考次数；精简仍只报步数。
* **进行中特效**：Turn 未关闭时，过程行摘要带与状态行同款扫光；标准 / 详细优先显示当前工具名（或「思考」）。
* **整行可点**：过程头整行展开 / 收起，不必只点左侧图标。
* **四档语义写清**：精简 / 标准 / 详细 / 始终展开在设置说明里各自标明分组、收起与进行中详情。
* **折叠不抬输入框**：对话区在内容变短时仍铺满滚动视口减去 composer 高度，输入区留在底部。

### 修复

* **「标准」看起来从不收起**：原先在底部跟随或视口内阅读时把过程永久 latched 为展开；现与偏好一致。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.6.20
xrkh web
```

或 `npm i -g @xrkseek/harness-cli@latest`（发包后）。

## 验证

* Settings → 过程详情选「标准」：Turn 结束后过程自动折成一行；跟到底部时同样收起。
* 收起态：「过程」与工具名之间有分隔点；工具名可读。
* 进行中：过程行摘要扫光，并显示当前工具（或思考）。
* 短对话里手动收起过程后，输入框仍贴在视口底部。
* 「始终展开」：不分组、不自动收起。

## 完整变更范围

过程折叠策略、摘要投影、过程头交互与 composer 贴底几何；设置文案与侧栏公告同步。

---

### Improved

* **Standard / Compact auto-fold on completion**: folds even when following the floor or when the run is on screen (animated); above-viewport runs still use instant fold + scroll compensation.
* **Clearer collapsed summary**: separator between “Process” and the detail; Standard / Detailed name tools (`+N` when long) and reasoning counts; Compact stays step-only.
* **Live shimmer**: open Turns shimmer the process summary like the status band; Standard / Detailed prefer the in-flight tool name (or Think).
* **Whole-row toggle**: the process header expands / collapses on the full row.
* **Four modes spelled out**: Compact / Standard / Detailed / Always expanded each state grouping, fold, and live detail in Settings copy.
* **Composer stays docked**: the transcript column keeps a min-height so folding short content does not lift the input mid-screen.

### Fixed

* **“Standard never folds”**: floor-follow / in-viewport latch previously kept the run open forever; it now matches the preference.

* Live: process summary shimmers and shows the current tool (or Think).

* Always expanded: no grouping and no auto-fold.

## Full change scope

Process-fold policy, summary projection, header interaction, and composer dock geometry; Settings copy and side-panel release notes stay in sync.
