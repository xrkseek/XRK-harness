# v0.7.20

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.19](./v0.7.19.md)：会话写锁可识别假活进程并支持手机单写者回收；官网下载区与产品壳样式对齐，文案改为产品介绍口吻。

### 完善

* 会话目录写锁：锁文件带 `xrkh-host` 身份；POSIX 读 `/proc` cmdline、Windows 读 `tasklist` 映像名；非 Host 形态可回收一次；手机 guest 可设 `XRK_SESSIONS_LOCK_RECLAIM=1` 短等后强制清一次残留锁（Desktop / 多 Host 勿开）。
* 官网下载页：安装列表收入与工作台同风格的面板；版本 pill；macOS 合并为一条 `xrkh web` 提示；CLI 安装与打开工作台分步展示；首页摘要改为产品介绍文案。

### 修复

* 更新 / 硬杀后残留的 `sessions.write.lock` 不再把手机 guest 误推进「会话目录占用」失败路径（配合壳侧清锁与 reclaim）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.20
xrkh web
```

桌面安装包见 GitHub Release `v0.7.20` 与站点下载页（AGT 上线后）。手机 APK 见对应 `XRK-harness-mobile` Release（若同发）。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.19](./v0.7.19.md): session write locks recognize false-alive holders and support a phone single-writer reclaim; the site download block matches the product shell, and marketing copy reads as a product intro.

### Improved

* Session-dir write lock: lockfiles carry an `xrkh-host` marker; POSIX reads `/proc` cmdline and Windows uses `tasklist` image names; non-Host shapes reclaim once; phone guests may set `XRK_SESSIONS_LOCK_RECLAIM=1` for one short-wait force clear (omit on Desktop / multi-Host).
* Site download page: install rows sit in a shell-styled panel with version pills; macOS collapses to one `xrkh web` tip; CLI install and open-workbench steps are separated; the homepage description is product copy.

### Fixed

* Leftover `sessions.write.lock` after update / hard-kill no longer pushes the phone guest into a sessions-dir-in-use failure path (with shell clear + reclaim).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.7.20
xrkh web
```

Desktop installer: GitHub Release `v0.7.20` and the site download page (after AGT publish). Mobile APK: matching `XRK-harness-mobile` Release when shipped together.
