# v0.5.20

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.19](./v0.5.19.md)：权限路径边界与越权确认、工具渐进披露、计划模式 Canvas+Build，以及对话里工具卡壳与等待提示落点。

Relative to [v0.5.19](./v0.5.19.md): path permission boundaries and overreach confirm, progressive tool disclosure, Plan mode Canvas+Build, plus tool-card shells and waiting-tip placement in chat.

### 新增

* 新增工具渐进披露：`tool_search` + Exposure；MCP 默认 Deferred；目录有字节预算；模型侧无 search 时全量回退。
* 新增每轮 `session_capability`：权限轴与工具面短快照，委派前可自检；子代理 preamble 写明继承的权限与削弱后的 caps。
* 新增 workspace-write 路径越权确认（对象路径白名单；短窗确认后放行）。
* 新增计划模式 Overview 画布 **Build**：退出 Plan 并催实现（可选快捷出口，不挡回合）。
* 新增长工具参数流式时先出工具卡壳再填内容（复用既有 ToolRow running 动效）。

### 完善

* 完善四档权限路径边界；子代理继承父会话 `pathAccessMode` 与对象白名单视图。
* 完善 `web_fetch`：图片/二进制探测与代理支持；web 族工具文案正交去重。
* 完善插队后新 turn 的等待提示：落到开该 turn 的消息下方，不再拖在旧气泡尾。
* 完善计划模式：轮级姿态 + 工作区 Canvas 交付；Plan 芯片 / 种子与徽章正交。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.20`**（接管 npm `@latest`）；npmjs 保留 **0.5.20** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.20**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.20
xrkh web
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.20-win-x64`（或签名）安装包，或从已装旧版经应用内更新。

## 验证

* 工具面较大时首轮目录不再一次性塞满；可用 `tool_search` 展开 Deferred（含默认 Deferred 的 MCP）。
* `/permission` 为 workspace-write 时，盘外路径触发短窗确认；子代理路径闸与父会话一致。
* Plan 开启后概况 Canvas 可见 **Build**；一点后退出 Plan 并 steer 实现。
* 长工具参数流式时先见工具卡壳；插队开新 turn 后等待行在该用户消息下方。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.20`。

---

### Added

* Progressive tool disclosure: `tool_search` + Exposure; MCP defaults to Deferred; catalog byte budget; full list fallback when the model has no search.
* Per-turn `session_capability`: short permission × tool-surface snapshot for delegation checks; child preamble states inherited permission and weakened caps.
* workspace-write path overreach confirm (object path allowlist; short confirm window).
* Plan mode Overview Canvas **Build**: exit plan and steer implement (optional shortcut; does not gate turns).
* Streaming long tool args paint a tool-card shell first, then fill (reuses ToolRow running chrome).

### Improved

* Four-tier path permission boundaries; subagents inherit the parent `pathAccessMode` and object allowlist view.
* `web_fetch`: image/binary probe and proxy support; orthogonal web-tool guidance (no cross-tool echo).
* Waiting tip after interrupt opens a new turn lands under that opener message, not trailing the old bubble.
* Plan mode: turn stance + workspace Canvas delivery; Plan chip / seeds stay orthogonal to badges.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.20`** (owns npm `@latest`); npmjs keeps **0.5.20** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.20**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.20
xrkh web
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.20-win-x64` (or signed) package, or update in-app from an older install.

## Verify

* Large tool surfaces no longer dump the full catalog every turn; `tool_search` expands Deferred tools (including default-Deferred MCP).
* With `/permission` workspace-write, out-of-allowlist paths prompt a short confirm; child path gates match the parent.
* With Plan on, Overview Canvas shows **Build**; one click exits plan and steers implement.
* Streaming long tool args show a shell first; after interrupt opens a new turn, the waiting tip sits under that user message.
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.20`.
