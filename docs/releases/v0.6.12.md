# v0.6.12

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.11](./v0.6.11.md)：**子智能体会话可贴图 / 拖文件**；子会话锁定模型芯片显示思考强度的**目录显示名**（如「极高」），不再露出原始 id（如 `xhigh`）。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.12`（发包后）。

Relative to [v0.6.11](./v0.6.11.md): **subagent sessions accept image and file intake**; the locked child model chip paints the catalog **display name** for thinking intensity (e.g. 「极高」) instead of the raw id (e.g. `xhigh`). npm **`@latest`** points at `@xrkseek/harness-cli@0.6.12` (after publish).

### 完善

* **子会话附件与主会话同轨**：子智能体输入栏可贴图、拖图、选文件、拖文件夹；Host `prompt` 本就可收 image/file 部件，去掉壳上 intake 门禁。
* **锁定芯片思考强度可读**：子代理模型座位只读芯片从目录 `effort.name` 解析标签，与可点触发器一致。

### 修复

* **子会话误报「暂不支持图片」**：Composer 在 `subagent !== null` 时整批拒附件；视觉模型其实可用。
* **子会话露出 `xhigh` 等 id**：锁定芯片未走目录显示名，与主会话「极高」等文案不一致。

## 用户侧复杂情况

| 用户行为 | 风险 | 本工作树 | 覆盖 |
| --- | --- | --- | --- |
| 在子会话贴截图 | toast 拒收，以为模型不支持视觉 | intake 与主会话同轨 | InputBar · input-bar 测 |
| 看子会话模型条 | 显示 `xhigh` 而非「极高」 | locked chip 解析 `effort.name` | ModelSelect · model-select 测 |

## 验证

* 子会话粘贴 PNG：进入附件轨，**不**出现「暂不支持图片」。
* 子会话锁定芯片：`reasoningEffort: xhigh` 且目录 `name: 极高` → 可见「极高」、不可见 `xhigh`。
* `pnpm test:client` 相关 InputBar / ModelSelect 测例绿。

---

### Improved

* **Subagent attachments match the parent**: paste / drop / pick images and files in the child composer; Face `prompt` already accepted image/file parts — the shell intake gate is removed.
* **Readable locked-chip effort**: the read-only child model chip resolves the catalog `effort.name`, same as the interactive trigger.

### Fixed

* **False “images unsupported” on subagents**: the composer rejected attachments whenever `subagent !== null` even though vision models work.
* **Raw effort ids on child chips**: locked chips painted `xhigh` instead of the localized catalog name shown on the parent.
