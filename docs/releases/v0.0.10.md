# v0.0.10

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.9](./v0.0.9.md)：修复 `web`/`serve` 关停时反复打印 `shutting down...` 与 Server `close` 监听器堆积。

### 修复

* 修复 Ctrl+C 关停非幂等：首次信号开始 teardown，再次信号强制退出，避免挂起时刷屏与 `MaxListenersExceededWarning`
* 修复 `http.close` / Face WS upgrade / Host `stop` 可重入：同一次关停复用同一 Promise，并 `closeAllConnections` + terminate 未关 WebSocket，避免浏览器 SSE/WS 拖死 `server.close`

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.10
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.10 web`
