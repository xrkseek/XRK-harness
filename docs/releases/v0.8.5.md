# v0.8.5

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.4](./v0.8.4.md)：浮动工作台让位改为 Host 公开 API；宽屏不再被 Visual Viewport 键盘噪声顶出空白缝；开放平台总览与金样可玩。

### 新增

* **开放平台总览**：`docs/open-platform.md` 汇总进程 / client / layout / HTTP·Face 可玩面；金样 `example-workbench-push` 演示 `reserveSide` / `reserveBottom`。
* **`ctx.layout.reserveSide`**：侧栏宽度预约真源；壳整框 `margin-right` 让位，对话与概况不再被固定侧栏盖住。

### 完善

* **`reserveBottom`**：列宽重发不再冲掉底栏预约；与 `--xrkh-workbench-*` 兼容戳同号。
* **`@xrkseek/plug`**：作者面补地板 / 侧栏拟合 helpers（`xrkPlugPushFloor` · `xrkPlugFitWorkbenchWidth` 等），与第一方工作台同政策。

### 修复

* **宽屏 / 桌面键盘 inset**：Visual Viewport 噪声不再把 sticky 输入抬起，底栏上方不再留空白缝；Flutter 薄壳自管键盘时 binder 强制为 0。
* **手机壳**：底 / 侧 push 强制为 0，避免遗留 workbench CSS 挤占对话列。

### 其他变更

* 公开线版本号对齐 **0.8.5**（npm / Desktop / 手机 / 官网下载同号）。
* 第一方侧栏 **`xrkh-better-sidebar@0.20.23`** 走 `reserveSide` / `reserveBottom`（另发 npm；Settings → 插件更新即可）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.4](./v0.8.4.md): floating workbench yield uses public Host APIs; wide / desktop no longer lifts sticky composers on Visual Viewport noise; open-platform map + playable gold sample.

### Added

* **Open-platform map**: `docs/open-platform.md` covers process / client / layout / HTTP·Face play surfaces; gold sample `example-workbench-push` demos `reserveSide` / `reserveBottom`.
* **`ctx.layout.reserveSide`**: canonical side-width reservation; shell frame yields via `margin-right` so chat / Overview are not covered.

### Improved

* **`reserveBottom`**: column republish no longer wipes the bottom reservation; stays in lockstep with `--xrkh-workbench-*` compat stamps.
* **`@xrkseek/plug`**: author helpers for push floors / side fit (`xrkPlugPushFloor` · `xrkPlugFitWorkbenchWidth`, same policy as the first-party workbench).

### Fixed

* **Wide / desktop keyboard inset**: Visual Viewport noise no longer lifts sticky composers or leaves a blank band above the bottom strip; Flutter shells that own the keyboard force the binder to 0.
* **Phone chrome**: bottom / side push forced to 0 so stale workbench CSS cannot squeeze the chat column.

### Other

* Public line version **0.8.5** (npm / Desktop / phone / site download share the same number).
* First-party sidebar **`xrkh-better-sidebar@0.20.23`** uses `reserveSide` / `reserveBottom` (separate npm publish; update from Settings → Plugins).
