# v0.2.6

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.2.5](./v0.2.5.md)：修复左侧工作区崩溃；插件库存打开目录 / 停用 / 删除 / 更新可用。

Relative to [v0.2.5](./v0.2.5.md): fix left workspace crash; make plugin inventory open / disable / delete / update work.

---

## 修复 / Fixed

* **`sidebar.workspaces`**：`SessionTree` 未接收 `home` 导致 `ReferenceError`，左侧只显示 “Slot … failed to render”
* **插件库存「打开目录」**：解析 `~/.xrk/plugins/web/plugins/<id>`（客户端插件真实路径），不再只找 `plugins/<id>`
* **停用**：写入 disabled 列表后重写 `web/boot.json`；Host 合并 overlay 时再过滤一次，重启后真正不加载
* **删除**：清理 disabled 标记并刷新 boot；CLI mutate 优先走 `xrkh`
* **更新**：新增 Settings「更新」→ `pluginInventory/update`（按 inventory `source` 或 `name@latest` 重装）

## 其他变更 / Other

* 公开基线 **v0.2.6**（npm **`@latest`**）；上一版 **v0.2.5**；正式留档仍为 **v0.1.31**
* CLI / SDK 包版本对齐 **0.2.6**

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.2.6
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后硬刷新浏览器（Ctrl+Shift+R）。已停用的侧栏插件需 **重启 Host** 后才会从 boot 消失。
