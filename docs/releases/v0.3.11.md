# v0.3.11

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.10](./v0.3.10.md)：长工具结果与 MCP 运行时垃圾不再落进工作区；全文在 `~/.xrk/spill/`，模型可用 `read_file` 按路径取回。

Relative to [v0.3.10](./v0.3.10.md): long tool bodies and MCP runtime dumps stay out of the workspace; full text lives under `~/.xrk/spill/`, and the model can `read_file` those absolute paths.

---

## 完善 / Improved

* 过大工具结果完整正文改存 `~/.xrk/spill/`（含 pipeline `tool-outputs` 与 agent-loop / `@session` spill），不再写入工作区 `.xrk/tool-outputs`
* stdio MCP 未配置 `cwd` 时默认 `~/.xrk/mcp-cwd/<serverName>`，避免 `@playwright/mcp` 等在工作区生成 `.playwright-mcp`
* 产品 home 回退统一认 `XRK_HOME` / `XRK_DSH_HOME` / `DSH_HOME`（spill、附件、cost-meter、mnemon、插件目录等）

## 修复 / Fixed

* mnemon 状态不再自动创建 `{workspace}/.xrk/mnemon`（仅当目录已存在才报告 workspace 作用域）

## 其他变更 / Other

* 工具截断 marker 现为产品 home 下的**绝对路径**；Host 已将 `~/.xrk/spill` 列入 `hostReadableRoots`，`read_file` / `grep` 可取回全文

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.3.11
xrkh web
```

或：`npx @xrkseek/harness-cli@0.3.11 web`

SDK：`pnpm add @xrkseek/harness@0.3.11`
