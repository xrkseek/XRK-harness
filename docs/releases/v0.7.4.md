# v0.7.4

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.3](./v0.7.3.md)：修好 OFM channel-pack 路由展开（登录后模型数为 0 / Zod `invalid_union`）；向日葵免费模糊挂满目录并带思考档位。

Relative to [v0.7.3](./v0.7.3.md): fix OFM channel-pack router expand (0 models after login / Zod `invalid_union`); Sunflower free fuzzy-mounts the full catalog with thinking efforts.

### 修复

* **OFM Cordis `ctx.llm` 目录 RPC**：loopback 桥补齐 `listModels` / `listProviders` / `resolveModel`（及 `resolveModelInfo`），channel-pack `model.list` / 网关目录不再读空适配器。
* **社区 RPC 错误信封**：`wireRpcResultSchema` 接受插件侧非严格 error 形态，避免 Settings/路由 toast 因 Zod `invalid_union` 误伤。
* **Host Face 插件清单**：`ensureDshCompatHostPlugin` 后立刻 `refreshFacePlugins`，不再等向日葵 warmup 才看见 `dsh-compat-host`。

### 改进

* **向日葵免费模糊目录**：OpenCode 车道探针至少 1 个 `available` 时挂满 `FREE_MODELS`（不再只挂探针命中子集）。
* **向日葵思考档位**：`BrandModelEntry.reasoning` → Face ModelSelect → openai-compat `reasoning_effort`（含 `off`/`disabled`→`none`）。

npm i -g @xrkseek/harness-cli@0.7.4
