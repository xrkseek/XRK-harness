# v0.0.4

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.3](./v0.0.3.md)：Settings 成为产品配置主路径——自定义模型提供方可选可用；Web 搜索与 MCP 可在 Plugins 里配通；`web`/`serve` 默认带上 harness 工具面。

### 新增

* 新增 Settings → Plugins → **Web search** 卡：可选提供方 / 区域，Tavily·Brave 密钥经 Credentials 落盘，保存后重建 Agent 生效
* 新增 Settings 手写 LLM 路由（Custom provider）：写入 `llm-pi-ai.providers.<id>` 后出现在模型列表，可选中并走合成 binding（不必是 Registry brand）
* 新增 MCP **Allow connect**：与 Host 热挂载对齐；policy deny 时 **park**（保留 desired、不 spawn），不再只靠 env 默许

### 完善

* 完善 `web` / `serve` 默认 preset 为 **harness**（含 `web_*` 等）；`run` 仍默认 minimal
* 完善 MCP 设置保存：有服务器条目时默认允许连接并尝试挂载；粘贴 Cursor `mcpServers` / 逐条添加会打开 Allow
* 完善 Host 联网搜索接线：结构化 `SearchAccessConfig`（Settings + 可选 env 覆盖），不再克隆整袋环境变量
* 完善 Face 设置 mutate：产品 schema 校验失败会打日志；壳侧 schema 解码失败时隐藏卡片并告警，避免静默空白
* 完善会话 `agentPreset` 与 Host 工具工厂对齐（preset 切换影响 standing 工具表）

### 修复

* 修复自定义提供方创建成功但模型列表不出现、选中报 `unknown provider` 的问题
* 修复 MCP 已连接时设置卡因 `toolCount` 类型不匹配而整卡消失的问题
* 修复 Plugins 表单下拉框样式（CSS Modules `composes` 被打包丢弃导致像坏了的控件）

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.4
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.4 web`
