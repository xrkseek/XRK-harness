# v0.5.10

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.9](./v0.5.9.md)：子代理跟父会话同一工作区、同一模型，并带身份前缀与用户原话证据；侧栏新会话可继承当前模型；同轮插队合并一次卸回显，「插队中」只在本轮未完时出现；点停止后列表、输入区、概况立刻空闲；运行中作业只在输入区；思考计时每次从 0；模型挂起、只出思考、`web_fetch` 超时共用重试条；概况底栏让位对话列。

Relative to [v0.5.9](./v0.5.9.md): child agents share the parent workspace and model, with an identity preamble and bounded user-ask evidence; New Session can inherit the current model; same-turn steers merge and retire together; “Steering…” only while this turn is open; Stop idles the list, composer, and Overview immediately; live jobs stay in the composer dock; the thinking clock restarts each appearance; LLM hangs, reasoning-only stops, and `web_fetch` timeouts share the retry strip; the community bottom strip yields the conversation column.

### 新增

* 新增 Face `session.create({ inheritFrom })`：侧栏「新会话」拷源会话已 pin 的 provider / model / reasoning effort（只写内存，不进 `session-models.json`）。
* 新增设置 → 插件 → Agent loop **子代理模型**（`agent-loop.subagentModel`，`provider/model`，可带 `(effort)`；留空跟父）。`subagents.list` 条目可带 `model`。
* 新增产品 skill **`xrk-delegate`**（工作区 `.agents/skills` 与种子 `apps/cli/seeds/skills`）：何时委派、形状表、与 Face 注入字段对齐。
* 新增协议字段 `user/message.rpcIds`：同轮合并插队时，首条 echo 为 `rpcId`、其余进 `rpcIds`，壳与队列一次卸掉。
* 新增壳 LayoutInsets **`--xrk-layout-inset-bottom`** 与 `ctx.layout.reserveBottom`；社区插件写在 `documentElement` 上的 `--xrkh-workbench-height` 会镜像过来，对话列让出底栏高度。

### 完善

* 完善子代理委派：子会话继承父工作区（membership + cwd；`worktree: true` 除外）与父模型（可被单次 `subagent` 覆盖）。Face 在子 prompt 前注入 parent/child session id、mode、role、cwd、是否继承上下文；另附最多 4 条父会话真人原话（每条截到 600 字）作授权证据，任务正文冲突时仍以 `prompt` 为准。`role: worker` 提醒不得回滚其他代理或用户的改动。
* 完善插队：同一 turn 的多条 steer 合并成一条 `user/message`。已有插队未落地时 Enter 继续插队（Cmd/Ctrl+Enter 才改排队）；跨 turn 的排队仍 FIFO 一条对人。本轮仍开着时，已发出的人话与子代理回标「插队中」；该轮结束后按普通用户消息（无额外徽章），同批发送叠在一条气泡里。
* 完善后台任务壳：运行中作业只在输入区 dock（停止 / 后台）；会话头芯片只列已结束作业。
* 完善 Status / 概况：舰队 depth 达顶只在有活跃子会话、排队或本会话在跑时标 critical，闲置血缘达顶为 warn；概况健康点下内联首条告警原因；子代理行与协作图展示实际 `provider/model`。
* 完善回合尾耗时：不足 1 秒显示「&lt;1秒」。思考中计时按每次出现单独从 0 计，不把整轮工具间隙累加进去。
* 完善步内重试：同一步共用一条 `retryId`，壳按 1/N → 2/N → 3/N 画进度；`web_fetch` 超时与「只出思考、没有正文/工具」走与 LLM 挂起相同的 settle 重试次数。
* 完善 `apply_edit` 工具说明：须从刚读到的文件原文抄 `old_content`（含缩进），缺字段时错误文案写明。
* 完善 diff 卡滚轮：卡片滚到边后继续滚对话，不再把滚轮锁死在卡内。
* 完善 `session.cancel` 与 Status：`delivery.turnActive` 跟列表 / Stop；drain join 期间 `/compact` 仍看 `compactBlockedByTurn`。杀会话作业后立刻推 `session/jobs`。

### 修复

* 修复子代理落到 Host 默认工作区、与父会话树不一致；从子会话点「新会话」跟父工作区，不跟 Host 列表里排在前面的子 membership。
* 修复同轮合并插队后第二条本地气泡卸不掉；修复下一轮 running 或 drain 未清时，已结束插队 / 子代理回传仍永远标「插队中」。
* 修复模型挂起重试条停在 1/N：每次尝试换新 `retryId` 时壳只认第一次。
* 修复 `web_fetch` 超时被当成一次工具失败、吃不到与 LLM 挂起相同的重试次数。
* 修复流式只出 reasoning 后断流仍当成功结束回合：现记 `EMPTY_RESPONSE` 并进入步内重试。
* 修复 turn 未结束时会话头与输入区各出一条「后台任务运行中」。
* 修复点暂停后列表已空闲、Composer 仍停、概况仍「回合进行中」：Stop 只跟 `running`；`delivery.turnActive` 随 cancel 立刻 false。
* 修复概况拖宽时清空 LayoutInsets，底栏要等侧栏拖一下才重测。
* 修复 Host 绑子代理工具时把深度/并发上限冻死：现与 Settings ∩ 徽章 live 解析一致，`analytics` 与 spawn 同一套数。
* 修复 Teams `task_id` 已被另一子会话占用时静默改绑；spawn 失败后清掉该子会话留下的进行中任务卡。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.10`**（接管 npm `@latest`）；npmjs 保留 **0.5.10** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.10**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 验证

* 父会话开子代理：子会话工作区与父相同、默认同一模型；子 prompt 可见 parent/child id、cwd，以及父会话里最近的真人原话。设置钉死后 Status / 谱系显示该线路。
* 侧栏「新会话」保留当前 Composer 模型；从子会话开新会话跟父工作区。
* 忙碌时连发两条插队：本轮内两条都标「插队中」；本轮结束后合成一条普通发送（无额外徽章）。
* 思考中出现 → 工具卡片 → 再出现思考中：第二次从 0 计，不会累成十几分钟。
* 父会话看起来已结束、子代理回传不再永远「插队中」。
* 有运行中 bash：仅 composer 上方 dock 显示「运行中」；会话头不叠第二条。作业结束后会话头出现「N 个后台任务」。
* 极短回合尾标「&lt;1秒」。
* 模型挂起、只出思考、或 `web_fetch` 超时：重试条走到 2/N、3/N，而不是停在 1/N。
* 回合中点停止：列表、输入区、概况「回合」立刻空闲；bash 卡可稍后再落定。
* 打开社区底栏：对话被顶起而不是盖住；拖概况宽度时底栏跟着对话列走。
* 舰队 depth 达顶且本会话空闲：概况为 warn，不是 critical；有活子或本轮在跑时才 critical。

### Added

* Face `session.create({ inheritFrom })`: sidebar New Session copies the source session’s pinned provider / model / reasoning effort (in-memory only, not `session-models.json`).
* Settings → Plugins → Agent loop **Subagent model** (`agent-loop.subagentModel`, `provider/model`, optional `(effort)`; empty inherits the parent). `subagents.list` entries may include `model`.
* Product skill **`xrk-delegate`** (workspace `.agents/skills` and seed `apps/cli/seeds/skills`): when to spawn, shape table, Face preamble fields.
* Protocol field `user/message.rpcIds`: when same-turn steers coalesce, the first echo is `rpcId` and the rest are `rpcIds` so the shell and queue retire together.
* Shell LayoutInsets **`--xrk-layout-inset-bottom`** and `ctx.layout.reserveBottom`. A community `--xrkh-workbench-height` on `documentElement` is mirrored so the conversation column yields the bottom strip.

### Improved

* Child spawn inherits the parent workspace (membership + cwd; except `worktree: true`) and the parent model (overridable per `subagent` call). Face prepends parent/child session id, mode, role, cwd, and inherit-context; plus up to four recent human asks from the parent (600 characters each) as authorization evidence — the task `prompt` still wins on conflict. `role: worker` tells the child not to revert another agent’s or the user’s edits.
* Same-turn steers merge into one `user/message`. While a steer is already pending, Enter stays in that batch (Cmd/Ctrl+Enter queues). Queue items on later turns stay one-to-one FIFO. A human line or subagent notice sent while this turn is still open shows “Steering…”; when it opens the next turn it is an ordinary user message (no extra badge), with consecutive sends stacked in one bubble.
* Live background jobs render only in the composer dock (Stop / Background); the session-header chip lists settled jobs only.
* Status / Overview: depth-at-cap is `critical` only with a live child, queued inbox, or this session’s own turn; idle lineage at cap is `warn`. The summary health dot inlines the leading alert reason. Subagent rows and the collab graph show the live `provider/model`.
* Turn-tail duration under one second shows “&lt;1s”. The thinking-line clock starts at 0 each time that line appears; it does not sum every tool-gap in the turn.
* In-step retries share one `retryId` so the shell paints 1/N → 2/N → 3/N. `web_fetch` timeouts and reasoning-only stops use the same settle retry budget as an LLM hang.
* `apply_edit` tells the model to copy `old_content` verbatim from a file just read (including indentation); missing `old_content` says so in the error.
* Diff cards chain wheel events into the transcript at the card edge instead of trapping scroll.
* `session.cancel` and Status: `delivery.turnActive` follows the list / Stop; `/compact` still keys off `compactBlockedByTurn` during drain join. Killing session jobs publishes `session/jobs` immediately.

### Fixed

* Child agents no longer land on the Host default workspace instead of the parent tree. New Session from a child follows the parent workspace, not a child membership that Host listed first.
* Coalesced same-turn steers no longer leave a second local bubble. A stuck drain latch or later running bit no longer keeps finished steers / subagent notices badged “Steering…”.
* Model hang retries no longer stick at 1/N when each attempt minted a new `retryId`.
* `web_fetch` timeouts no longer fail the tool body once instead of using the LLM hang retry budget.
* A stream that only emitted reasoning and then stopped no longer closes the turn as success; it is `EMPTY_RESPONSE` and enters in-step retry.
* An open turn no longer shows two “background jobs running” strips (header + composer).
* Pause no longer leaves composer Stop / Overview “turn active” after the session list is idle: Stop follows `running` only; `delivery.turnActive` goes false on cancel.
* Dragging Overview width no longer clears LayoutInsets (the bottom strip waited on a sidebar drag to remeasure).
* Host no longer freezes subagent depth/concurrency at tool-bind time; spawn and `analytics` use the live Settings ∩ badge ceilings.
* Teams no longer silently rebind a `task_id` already owned by another child; a failed spawn forgets that child’s in-progress task card.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.10`** (owns npm `@latest`); npmjs keeps **0.5.10** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.10**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Verify

* Spawn a child from a parent session: same workspace and, by default, the same model; child prompt includes parent/child ids, cwd, and recent human asks from the parent. A Settings pin shows that route on Status / lineage.
* Sidebar New Session keeps the current Composer model; New Session from a child follows the parent workspace.
* Steer twice while busy: both show “Steering…” during this turn; after it ends they merge into one ordinary send (no extra badge).
* Thinking line → tools → thinking line again: the second appearance starts at 0, not a 10-minute sum.
* After the parent turn looks finished, subagent notices are ordinary messages, not stuck “Steering…”.
* With a live bash job, only the composer dock shows “running”; the header does not duplicate it. After settle, the header shows “N background jobs”.
* A very short turn tail shows “&lt;1s”.
* An LLM hang, reasoning-only stop, or `web_fetch` timeout advances the retry strip to 2/N and 3/N instead of staying at 1/N.
* Stop during a turn: list, composer, and Overview “turn” go idle immediately; bash cards may settle a moment later.
* Opening the community bottom strip lifts the conversation instead of covering it; dragging Overview width keeps the strip aligned with the conversation column.
* Depth-at-cap on an idle session is warn, not critical; critical only with a live child or this session’s own turn.
