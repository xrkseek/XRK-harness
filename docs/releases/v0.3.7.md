# v0.3.7

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.5](./v0.3.5.md)：修复斜杠命令组、输入框 `@` 引用渲染与回焦，并完善手机端作曲器安全区。侧栏建议 **`xrkh-better-sidebar@0.18.4`**。

Relative to [v0.3.5](./v0.3.5.md): fix slash Commands group, composer `@` reference paint/refocus, and mobile composer safe-area. Prefer sidebar **`xrkh-better-sidebar@0.18.4`**.

---

## 修复 / Fixed

* 斜杠菜单只剩「技能」：`/model` 改为 **decorate** Host 命令；贡献与 Host 撞名时 **跳过并记日志**，不再整组 `source-failed`
* 侧栏点 `@` 后输入框失焦、后续按键黏在引用上继续染蓝：作曲器提供 **`SessionInput.focus()`**；侧栏注入 **尾空格 + 回焦**；`@` 按钮 **mousedown 不抢焦**
* 工作区根文件 `@README.md` 与带扩展名路径可正确蓝色高亮；目录须 `@path/`（侧栏目录自动补 `/`）
* 作曲器光标条误用业务蓝：改为正文色，避免「回焦后仍像在引用里」
* `/model` 等弹层 Esc 后无回焦：InputBar 接线 **`commandUi.bindComposerFocus`**
* Windows「在资源管理器中打开」目录像无反应：目录 reveal 改为直接打开文件夹（不再对目录用 `/select`）

## 完善 / Improved

* 手机端作曲器根节点尊重 **safe-area-inset**（底/左右），减少被 Home 条挡住
* 侧栏建议版本 **0.18.4**（`@` 语法与回焦）

## 其他变更 / Other

* CLI / SDK **0.3.7**（npm **`@latest`**）；公开双档 **v0.3.7** + **v0.2.7**
* 本机用全局 `npm i -g @xrkseek/harness-cli` 时，发版后需重装或同步 `product-web`，否则仍可能吃到旧壳

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.3.7
xrkh web
# 侧栏（若已装旧版）
xrkh plugin add xrkh-better-sidebar@0.18.4
xrkh restart
```

或：`npx @xrkseek/harness-cli@0.3.7 web`

SDK：`pnpm add @xrkseek/harness@0.3.7`

GitHub Release 资源：`xrkseek-harness-cli-0.3.7.tgz` · `xrkseek-harness-0.3.7.tgz`
