# v0.6.21

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.20](./v0.6.20.md)：**过程折叠收口**——标准模式结束后必折、折后停扫光、贴底即时收起不抬输入框；队列缩略图与工具卡图片不再闪占位。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.21`（发包后）。

Relative to [v0.6.20](./v0.6.20.md): **process-fold close-out** — Standard always folds when a Turn settles, shimmer stops once tools settle, floor-follow folds instantly without lifting the composer; queue thumbs and tool-card images stop flashing placeholders. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.21` (after publish).

### 完善

* **贴底即时收起**：跟到底部时过程组跳过高度动画，避免短内容过渡帧把粘性输入框顶到中部。
* **视口高度加固**：对话区 `min-height` 优先用像素视口变量，减少 `%` 偶发未解析导致输入框上提。
* **图片预览更稳**：队列缩略图与工具卡支持同步 `peek`；展开工具卡长边约 520px，消息气泡仍 240px。
* **转向提示可看**：队列「转向」在禁用态仍能看到悬停说明（需正在运行的 Turn）。

### 修复

* **「标准」结束后不自动折**：`toolsDefaultExpanded` 不再否决过程组收起；Turn 关闭后不再被 latched 为永久展开。
* **折后仍蓝光扫到 Stop**：扫光只跟组内未 settle 的工具；会话已空闲且工具已齐时亦可收起（Desktop 丢 turn/end 时）。
* **Turn 关闭竞态**：过程组优先读时间线 `turnClosed`，不必等每个成员 Location 先标 closed。


## 验证

* Settings → 过程详情「标准」：Turn 结束后过程自动折成一行；跟到底部同样收起，输入框不中部上提。
* 工具全部 settle 后过程行停扫光（不必等 Stop）。
* 「始终展开」：不分组、不自动收起。
* 队列里已加载过的图再渲染不闪占位；展开含图工具卡预览大于气泡。

## 完整变更范围

过程折叠闸控与贴底几何、过程扫光、队列/工具图片 peek；设置侧栏公告与官网 win-x64 下载元数据同步。

---

### Improved

* **Instant floor fold**: when following the floor, process groups skip the height transition so short-content frames cannot lift the sticky composer.
* **Hardened viewport min-height**: the transcript column prefers the pixel viewport CSS variable so `%` resolve failures no longer leave the input mid-column.
* **Stable image previews**: queue thumbs and tool cards support synchronous `peek`; expanded tool cards use ~520px long edge (message bubbles stay 240px).
* **Steer hint when disabled**: the queue Steer control still shows its hover tip while disabled (needs a running Turn).

### Fixed

* **Standard never auto-folded**: `toolsDefaultExpanded` no longer vetoes process-group collapse; a closed Turn is no longer latched permanently open.
* **Shimmer until Stop**: shimmer tracks in-flight tools only; idle session + settled tools can fold even if Desktop lost turn/end.
* **Turn-close race**: process groups prefer timeline `turnClosed` instead of waiting for every member Location to close.
