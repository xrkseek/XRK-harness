## 修复 / Fixed

* 空白会话（Hero）发送 `/mcp`、`/status` 等斜杠命令后无结果：`command/run` 退出 blank，命令卡进入对话流
* 斜杠结果行长得像工具调用：命令卡标题改为 `/name`，前导为 `/`，多行结果默认展开
* 对话内 `settings_mutate` 安装 MCP 时返回 `Error: tool call aborted`：MCP 重挂载不再 abort 正在跑的 turn，idle 后再刷新 agent
* Agent/`settings.mutate` 写入 MCP 后设置页仍空列表并标「未保存」：无本地草稿时从 scope 重新灌入
* 后台任务 / Todo / 队列等高出输入区时对话跟底丢失：增高量等于触底缺口时仍 re-pin，ResizeObserver 多跟一帧
* 后台任务条：单任务直接出 Stop 行；多任务折叠条也能 Stop，并收紧贴合输入区
* `ask_user` 问题卡贴边：统一内边距，markdown 表格单元格恢复左右留白

## 完善 / Improved

* `/mcp` 文案改为引导 **设置 → 插件**；菜单说明写清 `/mcp verbose`
