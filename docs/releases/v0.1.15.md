# v0.1.15

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.14](./v0.1.14.md)：堵住长会话 Host 堆内存暴涨路径——工具结果进日志前 spill、软上下文预算 fail-closed，并把 DSH 对齐的 bash / 软预算 / spill 旋钮接到 Settings。

Relative to [v0.1.14](./v0.1.14.md): close the long-session Host heap blow-up path—spill tool bodies before they enter the log, fail-closed soft context budget, and wire DSH-aligned bash / soft-budget / spill knobs into Settings.

---

## 新增 / Added

* 新增工具结果 **spill**：纯文本超 **64KiB** 落盘到 `~/.xrk/spill/`，模型只见 head/tail 预览与路径（`read_file` / `read` / `read_image` 不 spill，避免读→spill→再读）
* 新增 Face Settings → Plugins 旋钮：`agent-loop.maxRequestTokens` · `keepTokens` · `bufferTokens` · `toolResultMaxInlineBytes`；`bash.maxOutputBytes` 默认 **64_000**

---

## 完善 / Improved

* 完善软上下文预算：估价改为 **消息面 + 站立 tool schemas**（`estimateRequestTokens`）；超限先 prune → compact，**仍超则 fail-closed**（不再带着超大请求出站）
* 完善 harness / server：`bash` 捕获默认上限 **64KiB**（对齐 DSH bash-local）

---

## 修复 / Fixed

* 修复工作区过大或递归 shell / MCP 输出时，完整工具正文写入 session 导致 Host **JS heap OOM**（约数 GB）的路径

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.15
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.1.15 web` · `npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：若曾在 Desktop 根等超大工作区遇到 Host OOM，请升级到本版后 **新开会话**；工作区仍应用具体项目目录，不要指到 Desktop 根。
