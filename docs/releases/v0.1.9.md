# v0.1.9

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.8](./v0.1.8.md)：修复长会话载入黑屏、用量账本 Token/余额为空、停止键响应滞后；完善 workspace 注入标题与 DSH 社区插件 Host 接线。

Relative to [v0.1.8](./v0.1.8.md): fixes long-session history black screen, empty token-ledger usage/balance, and sluggish stop control; improves workspace inject headings and DSH community Host wiring.

---

## 完善 / Improved

* 完善 workspace 注入块标题：standing 文件以路径标注（如 `## .xrk/assistant.md`），便于在对话中区分来源
* 完善 cost-meter 聚合：`/api/tokenledger/usage` 返回 DSH 插件所需的 `totals`、`windows` 与余额状态字段
* 完善 DSH Host 接线：预热 registry 时 flatten `tokenLedger` bridge，避免用量 API 命中无 bridge 的缓存

---

## 修复 / Fixed

* 修复长会话 `session.history` 一次返回数千条流式 chunk、客户端 `installWindow` 阻塞导致载入历史黑屏的问题
* 修复 `sessionRecallLabels` 未从 client-runtime 导出、界面卡在「载入历史…」的问题
* 修复用量账本（dsh-tokenledger）Token 显示 0、余额读取失败：Host 未接 cost-meter ledger 与 DeepSeek 余额缓存
* 修复停止键：`session.cancel` 先 abort agent 再 drain，客户端 cancel 成功后立即 idle，减少工具继续跑的情况

---
