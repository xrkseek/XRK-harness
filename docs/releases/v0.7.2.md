# v0.7.2

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.1](./v0.7.1.md)：全局 CLI 随包向日葵免费；社区 loopback 模型（OFM / WorkBuddy）统一 Cordis 桥与 host 底座；等待态状态文案在不支持 `background-clip: text` 时仍可见。

Relative to [v0.7.1](./v0.7.1.md): global CLI ships Sunflower free; community loopback models (OFM / WorkBuddy) share one Cordis bridge and host session; turn waiting label stays visible when `background-clip: text` is unsupported.

### 新增

* **CLI 内置向日葵免费**：`@xrkseek/harness-cli` 随包 `extensions/xrk-sunflower-free`（与 Desktop 同发现链）；无 Bun 时仍可走 Kilo。可选覆盖目录：`XRK_SUNFLOWER_FREE_ROOT`。

### 完善

* **社区 loopback → Face**：OFM / WorkBuddy 共用 `createCommunityLoopbackLlmBridge`（指纹 · 重试 · GET nudge · ephemeral `actualPort`）；Host 半包共用 `createCommunityCordisHostSession`（Context · connection/credentials · fiber await · live dispose）。
* **OFM**：`port:0` 盘面不再当成可用 baseUrl；优先 live `/summary.actualPort`；Magpie 工作台仍仅 win32。

### 修复

* **回合等待文案**：TurnStatus 先落实体色，仅在引擎支持 `background-clip: text` 时升级扫光，避免等待标签空白。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.2
xrkh web
```

亦可 `npm i -g @xrkseek/harness-cli@latest`（发包后指向本版）。
