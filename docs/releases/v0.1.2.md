# v0.1.2

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.1.1](./v0.1.1.md)：修复 `npx` 安装后产品壳「Failed to load plugins」（`@xrkseek/client-connection` 误将 `@xrkseek/xrk-llm/message` 打成运行时 external）；CLI 增加 `xrkh` 简写。

### 新增

* 支持 CLI bin 简写 **`xrkh`**（与 `xrk-harness` 同入口）；`restart` 指纹识别 `xrkh`

### 修复

* 修复 npm `product-web` 中 `client-connection` 等插件在 stub `lib/types` 未生成时把 `@xrkseek/xrk-llm/message` 等 inline-safe 依赖打成 `require()` external，浏览器模块表无法解析而白屏
* 修复 `client:bundle` 对外部泄漏无门禁：构建后检测 inline-safe stub 是否仍留在 bundle 的 `require()` 中

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.1.2
xrk-harness web
# 或
xrkh web
```

或：`npx @xrkseek/harness-cli@0.1.2 web`
