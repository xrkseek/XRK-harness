# v0.8.2

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.1](./v0.8.1.md)：XRK Plug 与插件表面地图；MCP 总/单台热启停；主会话 Git worktree；安全闸（DNS 私网、非回环绑定、IM ingress）；对话/概况/排队/选区翻译手感；**手机壳**系统返回、打开方式进输入框、Office MIME。Desktop / 手机 APK / guest 对齐 **0.8.2**。

### 新增

* **XRK Plug（`@xrkseek/plug`）**：作者面插件运行时门面（kinds · 槽位 · LayoutInsets / workbench 地板 · `xrkPlugPushFloor`）；门禁 `pnpm verify:first-party-plug`。
* **插件表面地图**：教科书 [plugin-surface-map](../plugin-surface-map.md)（P0–P3 · 槽位 · Settings 卡 chrome · 热更失败分提示）。
* **进程插件金样**：`example-prompt` · `example-commands` · `example-policy` · `example-hooks` · `example-llm`（可选 `trust` 披露）。
* **壳叠层金样**：`example-shell-wallpaper`（`shell.overlay`）· `example-shell-pet`（会话头工具钮）。
* **主会话 Git worktree 卡**：设置 → 插件；默认关；打开后热重挂 `create_worktree`（无需重启桌面）。
* **MCP 总开关 + 单台列表**：插件 → MCP 卡片头 `allowConnect` 热挂载/卸载全部工具；插件列表 `mcp:*` 行单台启停。
* **通义 Token Plan Individual CN**：Registry 增国内个人档；团队/个人端点与 env 对齐 pi-ai 1.6（旧 env 名仍回退）。
* **选区翻译多源竞速**：Bing / 有道 / MyMemory / Google 匿名链；自动路径分波并行，无意义回声可翻向。
* **非回环绑定闸**：Host spawn 经 `assertSecureHostBind`——非 loopback 须非空 `XRK_API_KEY` 且拒绝默认 CORS `*`（旁路 `XRK_ALLOW_INSECURE_BIND=1`）。
* **IM / connector 公网 ingress 闸**：loopback 或 `XRK_IM_GATEWAY_TOKEN` / `XRK_IM_WEBHOOK_TOKEN` / `XRK_API_KEY`（常量时间；不信 `Host`）。
* **手机 · 产品主页系统返回**：LocalHostShell 与 WebViewPage 同契约——先关 Face 浮层 / better-sidebar / 概况，再 WebView history，最后才退应用。
* **手机 · 打开方式 / 分享进对话**：`XrkAppCompose` 通道 + `__xrkAppCompose`/`__dshAppCompose` 别名同步；失败带 `reason`（无输入框时文本可进剪贴板）。

### 完善

* **手机壳键盘与浮层**：Flutter 占键盘时 Modal / 灯箱 / 引导面共用 `shell-frame`，全屏叠层不再盖住输入法；模型菜单不再清掉壳侧 inset。
* **桌面工作台推挤**：手机 chrome 跟**窗口宽**，不因 `#root` 被推挤误切手机布局；列宽跟帧宽同步，避免推挤首帧输入区溢出。
* **概况委派方栈**：按最近气泡重排时 FLIP 滑入首位；老板球/委派方排序跟会话气泡。
* **概况球轨**：中宽窗口或会话头偏窄时球可收成图标；Presence / Preview 触控与折叠更稳。
* **排队改稿**：Ctrl+Enter 冲刷前先提交 QueueDock 行内编辑；镜像与 echo 对齐 Host 改写正文。
* **过程折叠保锚**：展开过程组时按组根保锚，避免贴底跟随把刚展开的过程卷走；思考行流式中段仍保持 live chrome。
* **插件列表 / 软热更**：内置项不可在此停用；软卸载 vs 软重挂失败分提示；进程插件可展示 trust 说明。
* **对话 / 设置壳**：对话列与输入条跟 layout inset；Settings / 通用 / 引导面窄视口与安全区更贴；通用文案收紧。
* **出站 URL / 侧栏探链**：`web` 与 sidebar `browser.probe` 解析到环回/私网则拒绝（DNS 后再拦）；探链拒 URL 内凭据。
* **侧栏路径 / 打开**：绝对写须落在会话 cwd；仓外绝对读仅 TCP loopback；`open.external` 仅 http(s)。
* **手机 gate Host**：非回环 TCP 不因伪造 `Host: 127.0.0.1` 放行。
* **手机 · 返回层序**：`xrk_web_back.js` 先 better-sidebar 抽屉，再 Face 左栏 / 概况 sheet，再历史 DSH 抽屉。
* **手机 · 分享/打开方式**：VIEW→SHARE 可从 `intent.data` 取 `file:`；下载桥补 Office MIME（ppt/doc/xls）便于系统打开。
* **phone-bridge 白名单**：原子写盘，避免崩溃留下截断白名单。
* **Desktop 启动 splash**：默认底色改深色，减轻无边框窗口首帧白边。

### 修复

* **MCP `allowConnect` 默认**：未写入时按产品默认**开**；不再因 `settings.describe` 循环读空槽误盖成关。
* **手机打开方式空输入框**：仅升级 `__dshAppCompose`、漏同步 `__xrkAppCompose` 时，打开方式看似成功但草稿未进 Lexical——现两别名同写。
* **满载测例超时**：doctor / bash foreground yield / job journal 在全量套件下补足 timeout。

### 其他变更

* 公开线 **`@xrkseek/harness-cli@0.8.2`** 接管 npm **`@latest`**（本轮先 Desktop / 手机 / GitHub Release，npm 后发）。
* Desktop / 手机 APK / guest runtime 对齐 **0.8.2**。
* 社区 Host remap 对齐 **`@earendil-works/pi-ai@1.6.0`**（及 schema / telemetry 同号）。
* `agent-desktop` **1.3.1** · `agent-browser` **0.43.0**（workspace `minimumReleaseAgeExclude`）。
* 安全清单 / 插件教科书同步上述闸门与 XRK Plug 表面。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.8.1](./v0.8.1.md): XRK Plug + plugin surface map; MCP master/per-server hot toggles; main-session Git worktree; security gates (DNS private, off-loopback bind, IM ingress); conversation/Overview/queue/selection-translate polish; **mobile shell** system back, open-with into composer, Office MIME. Desktop / Android APK / guest align to **0.8.2**.

### Added

* **XRK Plug (`@xrkseek/plug`)**: author-facing plugin runtime facade (kinds · slots · LayoutInsets / workbench floors · `xrkPlugPushFloor`); gate `pnpm verify:first-party-plug`.
* **Plugin surface map**: textbook [plugin-surface-map](../plugin-surface-map.md) (P0–P3 · slots · Settings card chrome · hot-update failure hints).
* **Process gold samples**: `example-prompt` · `example-commands` · `example-policy` · `example-hooks` · `example-llm` (optional `trust` disclosure).
* **Shell overlay samples**: `example-shell-wallpaper` (`shell.overlay`) · `example-shell-pet` (session header utility).
* **Main-session Git worktree card**: Settings → Plugins; off by default; toggles remount `create_worktree` live.
* **MCP master + per-server list**: Plugins → MCP header `allowConnect` hot-mounts/unloads all tools; Plugins list `mcp:*` rows toggle one server.
* **Qwen Token Plan Individual CN**: Registry brand; team/individual endpoints and env align with pi-ai 1.6 (legacy env names remain fallbacks).
* **Selection translate multi-provider race**: Bing / Youdao / MyMemory / Google anonymous chain; auto path waves in parallel; no-op echoes can flip direction.
* **Off-loopback bind gate**: Host spawn via `assertSecureHostBind` — non-loopback needs non-empty `XRK_API_KEY` and rejects default CORS `*` (escape `XRK_ALLOW_INSECURE_BIND=1`).
* **IM / connector public ingress gate**: loopback or `XRK_IM_GATEWAY_TOKEN` / `XRK_IM_WEBHOOK_TOKEN` / `XRK_API_KEY` (constant-time; never trusts `Host`).
* **Mobile · product-home system back**: LocalHostShell matches WebViewPage — dismiss Face overlays / better-sidebar / Overview first, then WebView history, then leave the app.
* **Mobile · open-with / share into chat**: `XrkAppCompose` channel + synced `__xrkAppCompose`/`__dshAppCompose` aliases; failures carry `reason` (text may copy to clipboard when composer is inert).

### Improved

* **Phone shell keyboard + overlays**: Modal / lightbox / onboarding share `shell-frame` so portals do not cover the IME; model menu never clears shell-owned inset.
* **Desktop workbench push**: phone chrome keys off **window** width (not a squeezed `#root`); column solve tracks frame width so the first push frame does not overflow the composer.
* **Overview delegate stack**: FLIP slides the latest-speaking seat into the lead; boss/delegate order follows recent bubbles.
* **Overview ball rail**: mid-width window or narrow session header can collapse chips to the ball; stabler Presence / Preview touch and fold.
* **Queue edit flush**: Ctrl+Enter commits an open QueueDock inline edit before steer; mirror/echo align with Host rewrite text.
* **Process-fold anchor**: expanding a process group preserves on the group root; mid-stream reasoning keeps live chrome.
* **Plugin list / soft hot-update**: built-ins not disable-here; distinct soft-unload vs soft-remount failure hints; process plugins can show trust notes.
* **Conversation / Settings chrome**: conversation column and input follow layout insets; Settings / general / onboarding hug safe areas; tighter general copy.
* **Outbound URL / sidebar probe**: `web` and sidebar `browser.probe` refuse loopback/private after DNS; probe rejects credentialed URLs.
* **Sidebar paths / open**: absolute writes must stay under session cwd; off-workspace absolute reads only for TCP loopback; `open.external` is http(s) only.
* **Mobile gate Host**: non-loopback TCP peers do not pass via spoofed `Host: 127.0.0.1`.
* **Mobile · back layer order**: `xrk_web_back.js` closes better-sidebar drawer, then Face left rail / Overview sheet, then legacy DSH drawers.
* **Mobile · share / open-with**: VIEW→SHARE can take `file:` from `intent.data`; download bridge adds Office MIME for system openers.
* **phone-bridge whitelist**: atomic replace so a crash cannot leave a truncated file.
* **Desktop splash**: darker default background reduces frameless first-paint hairline.

### Fixed

* **MCP `allowConnect` default**: missing key follows product default **on**; `settings.describe` no longer stamps deny via an empty-slot circular read.
* **Mobile open-with empty composer**: upgrading only `__dshAppCompose` left `__xrkAppCompose` stale so open-with looked successful with an empty Lexical draft — both aliases now stay in sync.
* **Full-suite timeouts**: doctor / bash foreground yield / job journal get headroom under full-suite load.

### Other

* Public line **`@xrkseek/harness-cli@0.8.2`** owns npm **`@latest`** (this cut ships Desktop / Android / GitHub Release first; npm last).
* Desktop / Android APK / guest runtime align to **0.8.2**.
* Community Host remap aligns to **`@earendil-works/pi-ai@1.6.0`** (schema / telemetry same train).
* `agent-desktop` **1.3.1** · `agent-browser` **0.43.0** via workspace `minimumReleaseAgeExclude`.
* Security checklist / plugin textbooks sync the gates and XRK Plug surface map.
