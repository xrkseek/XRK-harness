# v0.4.9

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.8](./v0.4.8.md)：多厂商图/视频生成矩阵与参考图编辑；策展记忆 consolidate 与 `list`；压缩策略族；协作图 `team_graph`；Host 默认 Isolating WorkflowEngine；工作台入口与 MCP 设备码 OAuth 打磨；Desktop 打包/更新流水线进度（仍未稳）。

Relative to [v0.4.8](./v0.4.8.md): multi-provider image/video gen matrix with reference-image edit; curated-memory consolidate + `list`; compaction strategy family; collab-graph `team_graph`; Host default Isolating WorkflowEngine; workbench entry + MCP device-code OAuth polish; Desktop packaging/update pipeline progress (still Unstable).

### 新增

* 新增图像/视频生成多 Provider 矩阵：FAL · xAI · OpenRouter · DeepInfra · Krea · Meta Muse（图）与对应视频路径；Settings 凭据槽与 catalog/`action=catalog`。
* 新增 `image_generate` 参考图编辑与 `video_generate` 首帧 i2v / edit / extend（按 Provider `capabilities()` 暴露 schema）。
* 新增策展记忆会话结束 **leased Phase1** + 可选 **Phase2 LLM** 单飞 consolidate；工具 `memory` 支持 **`list`**；Status 投影 `curatedMemory`。
* 新增压缩策略族 `compactionStrategy`：`prune-summary` · `prune-only` · `summary-only` · `off`（软压与 overflow 共用；阶段进 Status/`/status`）。
* 新增模型面 **`team_graph`**（view/link/unlink/role/announce）与协作图深度/邻居查询。
* 新增首方浮动工作台会话头「文件」入口（`@xrkseek/client-ui-workbench`；有社区 `betterSidebar` 时让位）与对话开文件路由。

### 完善

* 完善 Host 默认挂载 **IsolatingWorkflowEngine**（`await tools.name(args)` 经 Face 回桥；禁嵌套 `run_code`/`workflow`/`ralph`）；Face `ralph` 可调 `maxResultChars`。
* 完善 MCP HTTP 设备码 OAuth：RFC 8628 续等/立即失败、令牌 refresh 徽标、Settings 卡取消/复制码/自动打开验证页。
* 完善子代理配额解析（Face + 徽章顶）、Teams 合回与 Status 任务板反馈路径。
* 完善 Desktop 打包底层（签名闸门 · unsigned 路径 · 更新检测/定时 · `clean:desktop` / `upload:desktop`）；产品入口仍 CLI/Web，安装包 **未稳**。

### 修复

* 修复 Composer / 提交 echo / QueueDock 在本地回显与 durable 消息同帧去重时的可见性边角。
* 修复侧栏计划/Office 预览加载与开文件路由在无社区侧栏时回落本机 openPath 的路径。

### 其他变更

* 公开线版本号 `@xrkseek/harness-cli@0.4.9`（本说明写毕后执行 `pnpm release` 再接管 `@latest`）。
* Desktop 仍为私有包进度，不随本号发公共安装包。

### Added

* Multi-provider image/video generation matrix: FAL · xAI · OpenRouter · DeepInfra · Krea · Meta Muse (image) and matching video paths; Settings credential slots and catalog / `action=catalog`.
* `image_generate` reference-image edit and `video_generate` first-frame i2v / edit / extend (schema from Provider `capabilities()`).
* Curated-memory session-end **leased Phase1** + optional **Phase2 LLM** single-flight consolidate; `memory` tool **`list`**; Status `curatedMemory`.
* Compaction strategy family `compactionStrategy`: `prune-summary` · `prune-only` · `summary-only` · `off` (shared by soft budget and overflow; stages in Status/`/status`).
* Model-facing **`team_graph`** (view/link/unlink/role/announce) plus depth/neighbor queries on the collab graph.
* First-party floating workbench session-header **Files** entry (`@xrkseek/client-ui-workbench`; yields to community `betterSidebar`) and chat open-file routing.

### Improved

* Host mounts **IsolatingWorkflowEngine** by default (`await tools.name(args)` via Face bridge; blocks nested `run_code`/`workflow`/`ralph`); Face `ralph` exposes `maxResultChars`.
* MCP HTTP device-code OAuth: RFC 8628 wait/fail semantics, refresh badge, Settings cancel/copy/auto-open verify URI.
* Subagent quota resolution (Face + badge ceiling), Teams merge feedback, Status task-board paths.
* Desktop packaging foundation (signing gates · unsigned path · update check/schedule · `clean:desktop` / `upload:desktop`); product entry stays CLI/Web — installer still **Unstable**.

### Fixed

* Composer / submission-echo / QueueDock same-render dedupe visibility edges between local echo and durable messages.
* Sidebar plan/Office preview load and open-file routing fallback to host openPath when no community sidebar is present.

### Other changes

* Public line `@xrkseek/harness-cli@0.4.9` (run `pnpm release` after this note to take `@latest`).
* Desktop remains a private-package progress track; this release does not ship a public installer.

## Verify

* With FAL/xAI (etc.) configured in Settings, `image_generate` / `video_generate` produce an image or job (or an honest failure).
* After a long session ends, Status shows curated-memory consolidate; `memory` `list` returns on-disk entries.
* With `compactionStrategy=prune-only`, soft-budget compaction does not call the summary LLM.
* Without a community sidebar, the session-header **Files** control toggles the first-party workbench; chat file-card Open routes to the workbench or system open.
