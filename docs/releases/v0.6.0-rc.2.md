# v0.6.0-rc.2

> **读者 / Audience**：终端用户 · 维护者（发行说明）

相对 [v0.6.0-rc.1](./v0.6.0-rc.1.md)：Desktop 热修。**本号未发 npm**；npm `@rc` 仍为 **0.6.0-rc.1**。桌面更新源与安装包为 **0.6.0-rc.2**。

Relative to [v0.6.0-rc.1](./v0.6.0-rc.1.md): Desktop hotfix. **Not published to npm**; npm `@rc` stays **0.6.0-rc.1**. Desktop update feed and installer are **0.6.0-rc.2**.

### 修复

* 修复 Settings → 插件「技能文档」预览：`skill:` 前缀切片错位导致读错名，并被 Face 误报为 `session-not-found`。
* 修复 Face `not-found` 一律映射为 `session-not-found`：仅带 `sessionId` 的会话缺失走该码；技能 / 路径 / 插件目录 / 附件缺失改为 `bad-request` 或 `attachment-error`。

### Fixed

* Settings → Plugins skills catalog peek: wrong `skill:` key slice truncated the name and Face remapped `not-found` to `session-not-found`.
* Face `not-found` no longer always becomes wire `session-not-found`: only session-shaped misses (with `sessionId`) keep that code; skill / path / plugin / attachment misses map to `bad-request` or `attachment-error`.
