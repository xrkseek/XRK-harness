# v0.3.4

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.3](./v0.3.3.md)：产品壳补齐文件上传、侧栏、可继续子代理排队/Steer/Stop、Open in、feedback、长会话与 Windows 加固；私有 Desktop 源码入仓（整包仍未做）；Playwright **21/21**。

Relative to [v0.3.3](./v0.3.3.md): product shell lands file upload, sidebar, continuable subagent queue/Steer/Stop, Open in, feedback, long-session and Windows hardening; private Desktop sources land in-tree (full package still Not done); Playwright **21/21**.

XRK-Harness 为自研栈；设计吸收 Codex 与业界 agent harness 长处，契约以本仓为准。

XRK-Harness is independently developed; it absorbs strengths from Codex and peer agent harnesses — this repo’s contracts are authoritative.

---

## 新增 / Added

* **任意类型文件上传**（与图片混排）：composer 预览 · 进度/取消 · 跨会话草稿 · Face file 零件 + `fileHostPath`/`read_file`；`product-shell-file-upload-sidebar`
* **侧栏 Host `/sidebar/*`**：多标签/分栏/全屏与 md·code·html·pdf·image 预览（建议 `xrkh-better-sidebar`）
* **模型产物文件菜单**：预览 / 默认应用 / 资源管理器（`host.openPath`）
* **顶栏「在应用中打开」**：`host.listOpenInApps` / `host.openInApp` + `@xrkseek/client-ui-open-in-app`
* **可继续子代理**：排队 · 编辑 · 删除 · Steer · Stop；one-shot 只读 / `subagent-not-resumable`；`product-shell-subagent-queue`
* **`/feedback` 明细**：独立提交 · category · 会话片段 sidecar · 壳弹窗
* **DeepSeek-V41-Flash** 默认策略；动态 system 不破 KV Cache（出站 wire only；ADR-0009）
* **`@session` spill** · StatsLine 双摘要 · 目标 pause 立即 abort
* 私有 **`apps/desktop`** · **`apps/desktop-host`** + ADR-0008 / ADR-0009（不进 npm；整包 **未做**）
* Playwright：`product-shell-file-upload-sidebar` · `product-shell-subagent-queue` · `product-shell-reconnect` · `product-shell-scroll`

## 完善 / Improved

* 出站代理 · Skill 模糊匹配 · `read_image` 顶层图文 · POSIX `~` 缩写 · `@` 目录 drill
* `llm.discoverModels` 自定义/`anthropic` 列表回填；长会话尾页分页 · 繁忙发送统一 · 断线恢复 · 滚到底
* Windows 盘符根 Workspace · 非终端子进程隐藏控制台 + 树杀
* 工具筛选后路由提示不指导不可用工具；MCP 重复游标拒绝
* `pnpm test:web` **21/21**；桌面单测 **77**；**`pnpm build:desktop` 已过**

## 删除 / Removed

* 本机发版暂存残骸（`.release-dead-*` / `.release-park-*`）；`.gitignore` 忽略同类路径
* 产品壳旧右列 Detail 面板降级

## 修复 / Fixed

* 子代理队列 E2E：开 turn 禁止第二份 SQLite store；经 Face `session.history` 取 `itemId` 再 steer
* 父会话繁忙 draft 与 Stop 竞态：排队走 Face，Steer/Stop 走壳
* Desktop 编译：file 附件类型 · openai-compatible 跳过 file 块 · `resolveFilePath`/`hostReadableRoots` · feedback `slicesDir` · `spill.ts` 入 tsconfig

## 其他变更 / Other

* CLI / SDK **0.3.4**（npm **`@latest`**）；公开双档 **v0.3.4** + **v0.2.7**
* Desktop 仍 **未做** 产品入口（差本机 Electron + 安装包）；社区兼容器包 id `dsh-compat` 仅为技术标识
