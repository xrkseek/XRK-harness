# v0.2.5

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.2.4](./v0.2.4.md)：MCP / Settings 代理工具面、斜杠补齐、Plan 与设置页打磨；Host 出站代理与路径 `~` 缩写；`read_image` 与 `@` 目录 drill。

Relative to [v0.2.4](./v0.2.4.md): agent MCP/Settings tools, slash polish, Plan/settings UX; Host outbound HTTP proxy and POSIX `~` paths; `read_image` cards and `@` folder drill.

---

## 新增 / Added

* Agent 工具 **`settings_get` / `settings_mutate`**（全局 `~/.xrk`；MCP 增删改走确认路径）与 **`/mcp`** 清单
* 斜杠 **`/theme`** · **`/model`**（查看与切换，与 Settings / 模型芯片同路径）
* Host **出站 HTTP 代理**（`undici`；配置热切）
* **`read_image`** 结果投影 + Web 工具卡；Host **`home`** + 工具行 / Workspace hover **POSIX `~`** 缩写
* `@` 引用：**Tab / chevron drill** 进入目录，Enter 插入 folder chip

## 完善 / Improved

* Plan 芯片与 pending 态；通用设置页导语（指向模型 / 插件与斜杠）
* Skill `/` 模糊搜索；插件库存与 MCP 文档对照 Codex 补齐
* Face coaching recipe 不再被吞；Settings 真源统一走 **`settings.mutate`** 落盘

## 其他变更 / Other

* 公开基线 **v0.2.5**（npm **`@latest`**）；上一版 **v0.2.4**；正式留档仍为 **v0.1.31**
* CLI / SDK 包版本对齐 **0.2.5**
* 侧栏插件建议：`xrkh-better-sidebar@0.18.2`（默认 Files 页签随 locale）

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.2.5
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后硬刷新浏览器（Ctrl+Shift+R）。侧栏若仍见英文「Files」，升级 `xrkh-better-sidebar` 至 **0.18.2** 后重载。
