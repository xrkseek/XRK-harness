# v0.7.14

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.13](./v0.7.13.md)：设置 → 通用新增 Git 共同作者开关；computer_use 按 Provider 收窄动作并软开启；Desktop 命令行 `xrkh` 默认不进用户 PATH；社区 Host 的 `@earendil-works/pi-ai` 升到 1.5.0。

### 新增

* 设置 → 通用：**Git 共同作者**（默认开）。开 = agent 提交说明末尾追加固定 `Co-authored-by: xrkseek`；关 = 不注入该段。不改 `git config` / commit Author。
* computer_use：动作枚举与工具说明按 delivery（agent-desktop / UIA / background）收窄，避免模型点到当前 Provider 没有的动作。

### 完善

* computer_use：裸 `XRK_COMPUTER_USE=1|true|on` 只软开启，优先跟 Settings 模式（不再静默钉死 UIA）；显式 `uia` 仍强制 UIA。
* agent-desktop：Host 解析可执行文件，不往 PATH 塞 shim；Desktop「命令行 xrkh」默认关、可热开关（内置 browser / agent-desktop 不依赖此项）。
* SSH 远程卡：host / workspace 成对校验；workspace 须绝对 POSIX（`/…`）。
* 插件卡：`switchOnly`（仅头开关）与 `readOnly`（可展开信息卡）分开，Host 信息 / 进程通道仍可展开。

### 修复

* background computer_use 的 act 在需要时正确落到 UIA 执行路径。

### 其他变更

* 社区 Host remap：`@earendil-works/pi-ai` **1.3.0 → 1.5.0**（WorkBuddy peer）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.14
xrkh web
```

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.13](./v0.7.13.md): Settings → General adds a Git co-author switch; computer_use scopes actions by delivery and soft-enables; Desktop command-line `xrkh` stays off the user PATH by default; community Host `@earendil-works/pi-ai` moves to 1.5.0.

### Added

* Settings → General: **Git co-author** (default on). On = agent commit messages append a fixed `Co-authored-by: xrkseek` trailer; off = no such guidance. Never changes `git config` or commit Author.
* computer_use: action enum and tool copy are scoped by delivery (agent-desktop / UIA / background) so the model cannot pick actions the Provider lacks.

### Improved

* computer_use: bare `XRK_COMPUTER_USE=1|true|on` only soft-enables and prefers the Settings mode (no silent UIA pin); explicit `uia` still forces UIA.
* agent-desktop: Host resolves the binary without PATH injection; Desktop “command-line xrkh” is off by default and toggles live (built-in browser / agent-desktop do not depend on it).
* SSH remote card: host / workspace must be set as a pair; workspace must be absolute POSIX (`/…`).
* Plugin cards: `switchOnly` (header switch only) vs `readOnly` (expandable info); Host info / process channels still expand.

### Fixed

* Background computer_use acts route onto the UIA execution path when required.

### Other changes

* Community Host remap: `@earendil-works/pi-ai` **1.3.0 → 1.5.0** (WorkBuddy peer).
