# v0.5.18

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.17](./v0.5.17.md)：同轮并行子代理真正一起跑；顶栏 / 概况委派图 / 侧栏预览共用同一套运行·终态指示；继续压低大会话 Host 内存与输入卡顿。

Relative to [v0.5.17](./v0.5.17.md): sibling `subagent` calls in one turn actually run together; top-bar / Overview graph / sidebar preview share one live+terminal state map; further cut Host RAM and composer jank on heavy sessions.

### 完善

* 完善子代理状态展示：运行中（蓝 chase）与终态（完成绿 / 异常红）拆成两轴；顶栏目录、概况委派图、Host `subagents.preview` / `subagents.graph` 读同一套 `activity` + `outcome`（含二三层 `depth` / `parentSessionId`），中止不再画成「已完成」。
* 完善 Presence 陪伴球：工作忙时走轻量绘制，会话空闲仍可完整动效；流式噪声不再误触发会话 cue。
* 完善超长粘贴折叠：更多行数阈值与装饰器挂载时序，减少「粘了看不见」与忙时吞键。

### 修复

* 修复模型同轮连开两个 `subagent` 却串行只跑一个：工具标明可并发，并在配额门上用同步 pending 槽挡住 TOCTOU，前台等待期间不双计名额。
* 修复 `request/header` 追加路径在大会话上反复扫整段历史：会话级上一快照缓存 + 自尾 last-wins 折叠；会话删除时丢掉缓存，避免泄漏。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.18`**（接管 npm `@latest`）；npmjs 保留 **0.5.18** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.18**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。
* 侧栏插件 `xrkh-better-sidebar`：请升级到能消费 `subagents.preview` 的 `outcome` / `depth` 字段的版本，否则仍只靠旧 live 线。

---

### Improved

* Subagent status: live (`running` chase) and terminal verdict (done green / abnormal red) are two axes; top-bar catalog, Overview graph, and Host `subagents.preview` / `subagents.graph` share `activity` + `outcome` (with nested `depth` / `parentSessionId`). Aborts no longer paint as completed.
* Presence companion ball: lite draw while work-busy; full motion when idle; stream noise no longer fires session cues.
* Over-long paste fold: higher line threshold and decorator mount timing so pastes are not invisible and busy keystrokes are not swallowed.

### Fixed

* Two `subagent` tool calls in one turn no longer serialize as exclusive barriers: the tool is concurrency-safe, and a sync pending slot closes the quota TOCTOU without double-counting during a foreground wait.
* `request/header` append on huge sessions no longer rescans the whole log every time: session-scoped previous-snapshot cache + reverse last-wins fold; cache is dropped when the session is deleted.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.18`** (owns npm `@latest`); npmjs keeps **0.5.18** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.18**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
* Sidebar plugin `xrkh-better-sidebar`: upgrade to a build that reads `outcome` / `depth` on `subagents.preview`, or it still only sees the old live line.
