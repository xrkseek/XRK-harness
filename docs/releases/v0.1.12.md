# v0.1.12

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.11](./v0.1.11.md)：修复长会话（百万 token · 多步 agent loop）Host OOM；会话内存 LRU 与投影白名单对齐 DSH / Codex。

Relative to [v0.1.11](./v0.1.11.md): fixes Host OOM on long sessions (1M+ tokens · multi-step loops); session memory LRU and projection allowlists aligned with DSH / Codex.

---

## 完善 / Improved

* 完善 SQLite 会话驻留：内存最多保留 8 个会话日志，淘汰时同步清除投影缓存（Codex 式不把全历史常驻堆）
* 完善 `session.history` / `session.list`：仅 fold 轻量投影 key（stats · meter · title），**不**在每次 history 构建 `contextTimeline` / `contextHeaders`
* 完善 `@session` 补全：不再对每个会话全量 `snapshot()`，改用 `listHints` + 已加载会话的 `stateOf`
* 完善 workspace 模块：`skill-dirs.ts` 单源 `resolveSkillDirs` + fingerprint；`inject()` 一次磁盘指纹；catalog 扫描只解析 frontmatter

---

## 修复 / Fixed

* 修复 30+ 步 · ~1.8M token 长会话在 UI 轮询 history 时 Host 堆内存涨至 OOM 崩溃的问题
* 修复 `session.history` 对整段日志 `collectToolCallArgs` 与全量投影的重复开销
* 修复 skill 目录解析与指纹在三处重复实现导致的冗余 I/O 与循环依赖风险

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.12
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.1.12 web` · `npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：OOM 过的旧会话建议新建；长任务注意 compaction；工作区用项目目录而非 Desktop 根。
