# v0.5.28

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.27](./v0.5.27.md)：社区 Cordis LLM 宿主（Our Free Model · WorkBuddy）底层共用 connection / credentials / 路由与 Face sync 辅助；可选产品包 `git-worktrees` 不再误标「待重启」。

Relative to [v0.5.27](./v0.5.27.md): community Cordis LLM hosts (Our Free Model · WorkBuddy) share one connection / credentials / route + Face sync bottom layer; the optional `git-worktrees` product bundle no longer sticky-flags “Restart pending”.

### 新增

* **共享 Cordis `connection` 桥**：`admit` / `requestRejection` + `fetch.register`（含 compose seal 后的 late-bind），OFM trust fence 与 channel-pack 不再因缺 admit 503。
* **共享 Cordis `credentials` 桥**：OAuth / 密钥池落到 `~/.xrk/community-credentials/<package>/`；OFM · WorkBuddy · `host.mjs` apply 同源。
* **共享社区 LLM sync 辅助**：`asCommunityLlmModelRows` · `baseUrlFromCommunityModels` · `scheduleCommunityLlmSyncRetries`；`matchWebServerRoute` / `pushCordisWebServerRoute` 统一 webServer 路由登记。

### 修复

* **修复 `git-worktrees` 一直「待重启」**：Host 门控的可选产品包在未 live 时不再标 `needsRestart`；启用后开关即生效（`create_worktree` 仍按 soft-disable），设置页刷新提示不再被该行反复挂起。
* **修复可选包 live 半部无法 soft-disable**：`OPTIONAL_OFF_BY_DEFAULT` 在 `runtime.plugins` 中也记为 managed，禁用后仍可标卸载待重启。

### 完善

* **完善 OFM / WorkBuddy Host 半部**：forward 默认开 · Face `syncCommunityLlmProvider` → `llm-pi-ai`；home 统一 `resolveCompatHome`（含 `DSH_HOME`）；装后重启 Host 即可进模型列表。
* **完善 Host module remap**：`dsh-*` → `xrk-*` / stubs；WorkBuddy stage `lib/`、OFM stage `index.js` 可加载。
* **完善文档**：community-plugins 清单标注 OFM / WorkBuddy full 适配行。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.28`**（接管 npm `@latest`）；npmjs 保留 **0.5.28** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.28**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

---

### Added

* Shared Cordis **`connection` bridge**: `admit` / `requestRejection` + `fetch.register` (with late-bind after compose seal) so OFM trust fence and channel-pack no longer 503 for missing admit.
* Shared Cordis **`credentials` bridge**: OAuth / key pools under `~/.xrk/community-credentials/<package>/` for OFM · WorkBuddy · `host.mjs` apply.
* Shared community LLM sync helpers: `asCommunityLlmModelRows` · `baseUrlFromCommunityModels` · `scheduleCommunityLlmSyncRetries`; `matchWebServerRoute` / `pushCordisWebServerRoute` for webServer registration.

### Fixed

* **`git-worktrees` stuck on “Restart pending”**: Host-gated optional product bundles no longer set `needsRestart` when not live; the toggle applies immediately (`create_worktree` still follows soft-disable) and the Settings refresh banner is no longer re-armed by that row.
* Optional bundles that are still live can soft-disable: `OPTIONAL_OFF_BY_DEFAULT` ids count as managed when present in `runtime.plugins`.

### Improved

* OFM / WorkBuddy host halves: forward on by default · Face `syncCommunityLlmProvider` → `llm-pi-ai`; home via `resolveCompatHome` (including `DSH_HOME`); restart Host after install to populate the model list.
* Host module remap: `dsh-*` → `xrk-*` / stubs; WorkBuddy staged `lib/` and OFM staged `index.js` load.
* Docs: community-plugins lists OFM / WorkBuddy as full adaptations.
