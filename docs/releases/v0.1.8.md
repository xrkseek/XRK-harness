# v0.1.8

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.7](./v0.1.7.md)：归档会话在 Host 重启后仍保持隐藏，不再回到「未分组」。

Relative to [v0.1.7](./v0.1.7.md): archived sessions stay hidden after a Host restart instead of reappearing under Ungrouped.

---

## 修复 / Fixed

* 修复会话归档仅保存在内存、重启后归档集合丢失、已归档会话重新出现在侧栏「未分组」的问题
