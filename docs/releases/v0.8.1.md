# v0.8.1

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.0](./v0.8.0.md)：`present` 图片进对话画廊；后台任务「停止全部」与人壳停后模型仍能收到结果；手机展开过程不再把标题顶出屏幕；排队改稿可稳定复用 admitId。

### 完善

* **`present` 内联图**：PNG/JPEG/WebP/GIF 交付物进持久附件，对话行先路径再画廊（与 `read_image` / `image_generate` 同槽）。
* **后台任务停法**：展开后每行可停；折叠多任务时输入区为 **停止全部**（不再误停最早一个）；人壳停用 `report:false`，settle 仍向模型 steer `[status: killed]`。
* **工具 / 披露行**：展开中段过程时保住阅读锚点，避免贴底跟随把标题卷出短视口。
* **工作区浏览器 / 概况球**：触屏与折叠轨样式更稳，干员列表与添加面板文案对齐。

### 修复

* **排队改稿 / steer 改写**：同一 admitId 撤回后再 admit 仍算 pending，不再被迫换新 id 并重映 RPC 表。
* **会话停与 job 完成通知**：会话 Stop 与模型 `job_kill` 不再和人壳停抢同一套 `reported` 语义。

### 其他变更

* 公开线 **`@xrkseek/harness-cli@0.8.1`** 接管 npm **`@latest`**。
* Desktop / 手机 APK / guest runtime 对齐 **0.8.1**。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.8.1
# 或
npm i -g @xrkseek/harness-cli@latest
xrkh web
```

也可 `npx @xrkseek/harness-cli@0.8.1 web`。

Desktop：安装 `xrk-harness-0.8.1-win-x64`（未签名测试包），或从已装旧版经应用内更新。Android：`XRK-harness-mobile` Release `v0.8.1`。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.8.0](./v0.8.0.md): `present` images gallery in chat; Stop-all for background jobs with human-stop model notice; mid-column expands keep the header on screen; queue edit/steer can reuse admitIds.

### Improved

* **`present` inline images**: PNG/JPEG/WebP/GIF deliverables become durable attachments; the chat row shows paths then a gallery (same slot as `read_image` / `image_generate`).
* **Background job stop**: per-row when expanded; collapsed multi-job chrome is **Stop all** (not oldest-only); human Face kill uses `report:false` so settle still steers `[status: killed]`.
* **Tool / disclosure rows**: mid-column expands preserve the reading anchor so floor-follow does not lift the header off a short viewport.
* **Workspace browser / Overview balls**: stabler touch and fold-rail styles; roster / add-agent copy aligned.

### Fixed

* **Queue edit / steer rewrite**: re-admitting the same admitId after withdraw is pending again (no forced new ids + RPC remap).
* **Session Stop vs job notices**: session cancel and model `job_kill` no longer share human-stop `reported` semantics.

### Other

* Public line **`@xrkseek/harness-cli@0.8.1`** owns npm **`@latest`**.
* Desktop / Android APK / guest runtime align to **0.8.1**.
