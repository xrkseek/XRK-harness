# v0.8.6

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.5](./v0.8.5.md)：概况委派球预览等比平分；拖窄概况两侧一起缩小；定时任务删除走产品 Modal；列宽与侧栏 FAB 让位更稳。

### 完善

* **概况委派球**：仅两球时左右 seat 平分容器；委派方与被委派方共用同一 stage（等比）；委派箭头两端到卡片间距对称。左侧出现第二 / 第三个球时再在左轨内叠 peek，箭头随之靠右，不预留空槽。
* **拖窄概况 / 手机全宽**：`--xrk-delegate-stage` 随容器宽度重算，两侧球同步缩小，不再只压右边。
* **列宽链**：缩窄视口时概况与侧栏不再反弹变宽；关闭概况时仍尽量保留有标签的左侧栏。
* **对话顶栏**：有侧栏 FAB / 工作台时为右侧 seam 留出空隙，概况折叠钮与 PresenceDock 不再与 FAB 叠在一起。

### 修复

* **定时任务删除**：改用产品 Modal（inset），不再弹出系统原生 confirm。
* **手机概况**：solo 委派方不再被手机 CSS 重新加上 peek 左 pad，左边不再空一截。

### 其他变更

* 公开线版本号对齐 **0.8.6**（npm / Desktop / 手机 / 官网下载同号）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.5](./v0.8.5.md): Overview delegate-pair stages stay equal; narrowing Overview shrinks both seats; schedule delete uses the product Modal; column / FAB clearance is steadier.

### Improved

* **Overview delegate pair**: with two seats the row splits evenly; both stages share one size; arrow↔card gaps stay symmetric. Extra left parents fan as peeks inside the left track (arrow shifts right) — no pre-reserved empty slot.
* **Narrow Overview / phone full-bleed**: `--xrk-delegate-stage` remeasures with the container so both balls shrink together instead of crushing only the right seat.
* **Column chain**: shrinking the viewport no longer widens Overview or the sidebar; dismissing Overview keeps a labeled left rail when it still fits.
* **Chat header**: when a side FAB / workbench is present, right-seam padding keeps the Overview collapse control and PresenceDock clear of the FAB cluster.

### Fixed

* **Schedule delete**: uses the product Modal (inset) instead of the native confirm dialog.
* **Phone Overview**: a solo left seat no longer re-acquires peek left padding from phone CSS.

### Other

* Public line version **0.8.6** (npm / Desktop / phone / site download share the same number).
