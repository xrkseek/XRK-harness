# v0.5.22

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.21](./v0.5.21.md)：桌面更新安装态不再闪回、粘贴折叠块的按钮与查看弹窗改用原生控件、右键菜单让位给输入框与模态、侧栏社区包版本识别向后兼容。

Relative to [v0.5.21](./v0.5.21.md): Desktop stays in the installing phase instead of flashing back to ready, the paste fold uses native controls, the context menu yields to text fields and modals, and sidebar community packages with the legacy manifest key still load.

### 修复

* 修复 Desktop 点「安装并重启」后阶段回闪：下载完成后保持 `installing` 直到退出，不再闪回「可安装」把按钮点亮又熄灭（旧壳无效，需换新壳）。
* 修复输入框与模态弹窗内的右键手势：被原生菜单接管，`textarea` 内的 `Ctrl+A` / 全选与粘贴弹窗编辑恢复正常。
* 修复右侧栏「产出文件」里文件夹名的字号：显式 12px，不再继承回合正文大小而显得过大。
* 修复 `xrkh-better-sidebar-plugin-office` 这类社区包在清单用旧键 `xrkh.client` 时无法被识别加载的问题。
* 修复 Overview 状态球在子代理仍在跑、父会话已停靠（`wait_agent`）时误显示「回合进行中」：子代理活跃优先于回合进行中（含 Preview 预览摘要）。

### 完善

* 完善大段粘贴折叠块：查看 / 编辑弹窗页脚改用统一 `Button`，图标操作常显，折叠块正文可整块选中复制。
* 完善右键菜单键盘导航：方向键聚焦加 `preventScroll`，菜单在对话框或输入区上方弹出时不再把背后的页面拽动。
* 完善桌面叠层注释：chrome 的 z-index 说明与侧栏面板 / 自由窗实际取值对齐（仅注释）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.22`**（接管 npm `@latest`）；npmjs 保留 **0.5.22** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.22**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。
* 侧栏社区包 **`xrkh-better-sidebar@0.20.3`** 与 Office 预览 **`xrkh-better-sidebar-plugin-office@0.1.1`** 已在 npm 上是当前 `@latest`（各自独立发布，不在本仓主包内，本轮未重发）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.22
xrkh web
```

可选高保真 Office 预览与侧栏增强：

```bash
xrkh plugin add xrkh-better-sidebar@0.20.3
xrkh plugin add xrkh-better-sidebar-plugin-office@0.1.1
xrkh restart
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.22-win-x64`（未签名测试包）安装包，或从已装旧版经应用内更新。

## 验证

* 大段粘贴折叠块可展开查看 / 编辑，页脚按钮可用，正文可整块复制。
* 输入框内右键保留原生菜单，`Ctrl+A` 正常。
* 右侧栏产出文件的文件夹名恢复到 12px。
* 「有更新」对话框下载完成后仍显示安装中，按钮不闪。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.22`。

---

### Fixed

* Desktop no longer flashes back to `ready` after “Install and restart”: the phase stays `installing` until quit (an older shell cannot carry this; install the new shell).
* Right-click inside text fields and modal dialogs goes to the native menu again, restoring `Ctrl+A` / select-all in `textarea` edit surfaces such as the paste modal.
* The produced-files folder caption in the sidebar no longer inherits the turn-body font size and renders oversized (explicit 12px).
* Community packages that declare the legacy manifest key `xrkh.client` (e.g. the Office preview) are classified and loaded again.
* The Overview presence ball no longer shows "turn in progress" while a subagent still drains and the parent is parked (`wait_agent`): live children now beat the home turn latch (including the Preview summary).

### Improved

* The paste fold’s view / edit modal now uses the shared `Button` primitive in its footer; the icon actions stay visible; the folded body is selectable for copying.
* Context-menu keyboard navigation focuses rows with `preventScroll`, so opening a menu over a dialog or the composer no longer scrolls the page behind it.
* Desktop chrome stacking comments match the sidebar panel / free-window z-index values actually in use (comment-only).

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.22`** (owns npm `@latest`); npmjs keeps **0.5.22** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.22**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
* Sidebar community packages **`xrkh-better-sidebar@0.20.3`** and **`xrkh-better-sidebar-plugin-office@0.1.1`** are already npm `@latest` (published separately, not inside this tarball; not re-published this round).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.22

```

Optional sidebar and hi-fi Office preview:

```bash

xrkh plugin add xrkh-better-sidebar-plugin-office@0.1.1

```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.22-win-x64` unsigned test package, or update in-app from an older install.

## Verify

* A folded paste opens the view / edit modal, footer buttons work, body copies as a whole.
* Right-click in a text field keeps the native menu; `Ctrl+A` works.
* The sidebar produced-files folder caption is back to 12px.
* After download the update dialog still reads installing; the button does not flash.
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.22`.
