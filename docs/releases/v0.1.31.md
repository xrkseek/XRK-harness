# v0.1.31

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.30](./v0.1.30.md)：修复输入框 `@` 文件路径高亮被截成目录前缀的问题；含 `/` 的文件路径整段按文件引用着色。

Relative to [v0.1.30](./v0.1.30.md): fix composer `@` path highlighting that stopped at a directory prefix; nested file paths paint as one file reference.

---

## 修复 / Fixed

* 修复输入框：`@dir/file.ext`（含中文路径）不再只把 `@dir/` 涂成目录蓝，文件名留白
* 修复输入框：以 `/` 结尾的 `@` 路径仍识别为目录；含 `/` 但不以 `/` 结尾的路径整段识别为文件并显示文件图标

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.31
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后执行 `xrkh restart`，浏览器硬刷新。
