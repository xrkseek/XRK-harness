# v0.1.24

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.1.23](./v0.1.23.md)：产品壳会话导航与手机体验完善；连接态、字号与代码高亮细节收口；Face 增加整段日志轮次投影供轨跳转。

### 新增

* 新增聊天 **轮次轨**（TurnNavigator）：右侧阶梯展示整段会话轮次预览，点击跳转到对应轮次
* 新增 Face **`turnOutline` 投影**：整段日志的 `turn` / `seq` / `prompt` / `response`；未加载进窗口的轮次经 **`loadThrough`** 分页拉齐后再滚动定位
* 新增轮次 **用量面板**：在助手消息侧查看该轮 token 与耗时摘要
* 新增设置 **字号** 行（外观）：调整壳正文字号并持久化
* 新增 **连接指示器**：紧凑展示连接 / 重连态（承接原横幅职责）

### 完善

* 完善 **手机窄屏** 壳：侧栏抽屉、遮罩、触控热区、safe-area 与会话区 / Settings / 菜单间距
* 完善 Settings 根面板与权限预设等设置卡的窄屏布局与文案
* 完善 Markdown **代码块**：进入视口再高亮；流式代码块高亮更稳、少闪烁
* 完善会话投影契约：`turnOutline` 进入 `session.history` 尾页基线与 mux 推送；`assistant/message` draft **不**刷 outline 变更帧，`turn/end` 才提交回复预览
* 完善连接层 fixture：与 Face 对齐的 turnOutline 基线 / 变更帧，便于本地联调

### 删除

* 删除 `ConnectionBanner`、`ConnectionOverlay` 旧连接横幅路径（由连接指示器承接）

### 修复

* 修复 fixture 事件链：`turn/start` 同时推进 `todos` 与 `turnOutline`，避免早退丢掉 todos 帧
* 修复取消回放路径上 context 窗口容量断言与模型真实窗口不一致的问题

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.1.24
xrkh web
```

或：`npm i -g @xrkseek/harness-cli@latest`
