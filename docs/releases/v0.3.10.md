# v0.3.10

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.9](./v0.3.9.md)：长 Think / 工具流不再把 Face 心跳挤死；轮次导航轨贴在消息列右侧，且只画一根。

Relative to [v0.3.9](./v0.3.9.md): long Think / tool streams no longer starve Face heartbeats; the turn rail sits on the message-column gutter as a single ladder.

---

## 完善 / Improved

* 流式 Think 与工具参数：同一 run 的首片立刻落库并画出来，后续片段约每 16ms 合并成一条 `assistant/chunk`，mux 序号仍连续
* Face mux / host WebSocket 写出串行排队，等上一帧 `send` 完成再发下一帧，Ping 能插空

## 修复 / Fixed

* 宽屏下轮次导航轨贴在消息列右侧沟，不再漂在窗口最右的空白带中间
* 轮次导航轨只画一根：底下那串点不了的重复刻度去掉；刻度多时在轨内滚动

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.3.10
xrkh web
```

或：`npx @xrkseek/harness-cli@0.3.10 web`

SDK：`pnpm add @xrkseek/harness@0.3.10`
