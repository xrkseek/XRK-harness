# v0.1.6

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.5](./v0.1.5.md)：**Linux / macOS / Windows 全局安装**可正常 `xrkh web`；CLI 发行包捆绑全平台 `sharp` 原生模块；图片附件改为延迟加载 native 绑定。npm 公开包 **`@xrkseek/harness-cli`**（主 bin **`xrkh`**，亦 `xrk-harness`）。能力边界以 [status.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/status.md) 为准。

Relative to [v0.1.5](./v0.1.5.md): **global install on Linux / macOS / Windows** can run `xrkh web`; the CLI release bundles all `sharp` platform runtimes; image attachments lazy-load native bindings. Public npm package **`@xrkseek/harness-cli`** (primary bin **`xrkh`**, also `xrk-harness`). Capability truth: [status.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/status.md).

公开线：**正式 0.1.6** + 预览 [v0.0.11](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md)。`latest` 指向本版；中间号见 [publishing.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/publishing.md) 弃用策略。

Public line: formal **0.1.6** + preview [v0.0.11](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md). `latest` points here; intermediate numbers follow [publishing.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/publishing.md) withdrawal policy.

## 修复 / Fixed

* 修复 **Linux 服务器** `npm i -g @xrkseek/harness-cli` 后 `xrkh web` 因缺少 `linux-x64` 版 `sharp` 立即崩溃的问题
* 修复 Windows 发版 stage 仅捆绑 `win32-x64` 原生模块、其他平台全局安装不可用的问题

## 完善 / Improved

* 完善 **`pnpm release:stage`**：在任意宿主 OS 上对缺失的 `@img/sharp-*` 执行 `npm pack` + `tar` 解包，打进 CLI tarball（不依赖 `npm install` 跨平台可选依赖）
* 完善 **`@xrkseek/attachment-local`**：`sharp` 改为用时加载；Web Host 启动不再因图片 native 模块缺失而在 import 阶段失败

## 其他变更 / Other changes

* 需要 Node **≥26** — [getting-started.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/getting-started.md)
* 发版 stage 要求宿主具备 **`tar`**（Windows 10+、Linux、macOS 自带）；发版机可为 Windows / Linux / macOS 任一
