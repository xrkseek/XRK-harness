# v0.6.16

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.15](./v0.6.15.md)：**OpenCode Zen / Go 出站带会话头**；**地区 / 免费档 / 拒答类失败显示真因**；**会话写锁可回收已死进程**；**Desktop Host OOM / 中途死亡手感**；变更文件列表去掉悬停预览。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.16`（发包后）。

Relative to [v0.6.15](./v0.6.15.md): **OpenCode Zen / Go send `x-opencode-session`**; **region / free-tier / refusal failures show the real cause**; **session write lock reclaims dead holders**; **Desktop Host OOM / mid-session death UX**; changed-files drops hover peek. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.16` (after publish).

### 完善

* **OpenCode Zen / Go**：聊天请求自动带 `x-opencode-session`（会话 id）。
* **失败文案**：`REGION` / `PROVIDER_DENIED` / `FORBIDDEN` / 配额与限流等按真因展示，并去掉 `openai-compatible HTTP …` 前缀；仅密钥类仍脱敏为「API key is invalid」。
* **会话目录写锁**：持锁进程已退出时清一次过期锁再抢。
* **Desktop Host**：OOM 不自动重启；中途死亡不叠系统错误框（冷启动仍提示）；关窗即中止自动重启。
* **变更文件卡**：去掉悬停 diff 预览，点击进入审阅。

### 修复

* **OpenCode 外接缺会话头**：上游拒路由或效率下降；本版按会话补齐 Zen 与 Go。
* **地区不可用 / 仅客户端免费档**：失败不再伪装成密钥无效。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.6.16
xrkh web
```

或 `npm i -g @xrkseek/harness-cli@latest`（发包后）。

## 验证

* 配置 OpenCode 密钥后选 Zen 或 Go 模型可完成一轮对话。
* 选地区不可用或仅客户端免费档模型：文案含地区 / 客户端限制语义，不是「API key is invalid」。
* 强杀 Host 后立刻重开：会话目录可再取得写锁。
* Desktop：Host OOM / 中途退出时壳可重连，不弹阻塞系统框。

---

### Improved

* **OpenCode Zen / Go**: chat requests send `x-opencode-session` (session id).
* **Failure copy**: `REGION` / `PROVIDER_DENIED` / `FORBIDDEN` / quota / rate-limit show the real cause and drop the `openai-compatible HTTP …` prefix; only credential failures stay scrubbed as “API key is invalid”.
* **Sessions dir write lock**: a dead holder’s stale lock is cleared once, then acquire retries.
* **Desktop Host**: no auto-restart on OOM; mid-session death skips the blocking OS error box (cold start still shows it); closing the window aborts restart.
* **Changed-files card**: hover diff peek removed; click opens review.

### Fixed

* **OpenCode missing session header**: routing refused or degraded; this release attaches it for Zen and Go.
* **Geo-blocked / client-only free models**: failures no longer masquerade as a bad API key.
