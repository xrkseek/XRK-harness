# v0.0.11

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

**预览线唯一保留版本** / **Sole retained preview release**。成熟 `restart`、XRK Harness 工作区种子与插件开发配方，以及壳上双工具面文案对齐。正式线见 [v0.1.0](./v0.1.0.md)。

Mature `restart`, XRK Harness workspace seeds and plugin-dev recipes, plus dual tool-surface copy on the shell. Formal line: [v0.1.0](./v0.1.0.md).

## 新增 / Added

* 工作区种子 `templates/xrk-harness`（人格 / rules / `recipes/plugin-scaffold`）
* 插件开发说明：[plugin-development.md](../plugin-development.md)

## 完善 / Improved

* `restart`：按端口 PID 锁识别本机 XRK Host 后优雅停再起；`--force` 只杀已识别的 XRK 监听
* 预设说明三层分离（见 [profiles.md](../profiles.md)）
* 壳文案：Agent 工具面仅展示 **Minimal** 与 **XRK Harness**
* 空草稿 + 队列运行中时回车可转向整队

## 其他变更 / Other changes

* Host `server` 工厂名不变；Face 内置工具表仍只有上述两面（`server` 工具面等同 harness）

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.0.11
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.0.11 web`
