# v0.0.11

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

**预览线唯一保留版本** / **Sole retained preview release**。在成熟 CLI / Host / Face 之上，提供稳定的 `restart`、XRK Harness 工作区种子与插件开发配方，以及壳上 **Minimal / XRK Harness** 双工具面文案对齐。**不含**正式线 [v0.1.6](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.1.6.md) 的 `@` 引用、附件主路径、社区插件 Host 兼容器与移动访问门禁。

On a mature CLI / Host / Face base, this preview adds reliable `restart`, XRK Harness workspace seeds, plugin-dev recipes, and aligned **Minimal / XRK Harness** tool-surface copy. It does **not** include formal-line [v0.1.6](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.1.6.md) features: `@` mentions, attachment primary path, the community-plugin Host adapter, or mobile-access gating.

公开线只保留本版（预览）与正式 **0.1.6**；中间号已在 npm / GitHub / 文档按 [publishing.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/publishing.md) 弃用。

The public line keeps only this preview and formal **0.1.6**; intermediate numbers are deprecated per [publishing.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/publishing.md).

* 预设说明三层分离 — 见 [profiles.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/profiles.md)
* 壳文案：Agent 工具面仅展示 **Minimal** 与 **XRK Harness**
* 空草稿 + 队列运行中时回车可转向整队

## 安装 / Install

**预览 tag**（npm `preview` → `0.0.11`）：

```bash
npm install -g @xrkseek/harness-cli@preview
# 或钉版本 / or pin:
npm install -g @xrkseek/harness-cli@0.0.11
xrk-harness web   # 预览包主命令当时为 xrk-harness / preview CLI primary bin was xrk-harness
```

一次性 / One-shot：`npx @xrkseek/harness-cli@0.0.11 web`

离线 / Offline：[GitHub Release v0.0.11](https://github.com/xrkseek/XRK-harness/releases/tag/v0.0.11) 资产 `xrkseek-harness-cli-0.0.11.tgz`。

## 升级到正式线 / Upgrade to formal

```bash
npm install -g @xrkseek/harness-cli@0.1.6
xrkh web
```

说明与契约变化见 [v0.1.6 发行说明](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.1.6.md)。
