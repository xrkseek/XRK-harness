# v0.0.11

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.10](./v0.0.10.md)：成熟 `restart`、XRK Harness 工作区种子与插件开发配方，以及壳上双工具面文案对齐。

### 新增

* 新增工作区种子 `templates/xrk-harness`（人格 / rules / `recipes/plugin-scaffold`），同步进 `{workspace}/.xrk` 后可按会话注入
* 新增插件开发说明：[plugin-development.md](../plugin-development.md)（与种子配方、Host 插件目录对齐）

### 完善

* 完善 `restart`：按端口 PID 锁识别本机 XRK Host 后优雅停再起；`--force` 只杀已识别的 XRK 监听进程，拒绝误杀外来占用
* 完善预设说明：会话徽章（Minimal / XRK Harness）、Host `--preset`、工作区种子三层分离（见 [profiles.md](../profiles.md)）
* 完善壳文案：Agent 工具面仅展示 **Minimal** 与 **XRK Harness**；上下文注入行更易辨认 skill 目录与指令摘要
* 完善空草稿 + 队列运行中时的回车：可转向整队（含 deep diving 提示）

### 其他变更

* Host `server` 工厂名不变；Face 内置工具表仍只有上述两面（`server` 工具面等同 harness）

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.11
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.11 web`
