# v0.0.9

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.8](./v0.0.8.md)：修复同 turn 持久注入挤掉对话行；对齐 DSH「每条 user 消息独立 MessageId」。

### 修复

* 修复开新对话后聊天记录整页空白：同 turn 的 skill-catalog / agent-instructions 注入与人类消息共用 `turnId` 时，Face 曾把 wire `data.id` 设成裸 `turnId`，客户端 conversation assembler 对重复 start Match 抛错
* 修复路径：每条 `user/message` 写入唯一 `messageId`（loop / workspace inject / Face append 兜底）；wire `data.id` = `messageId`，缺省时回退 `` `${turnId}:${seq}` ``

### 完善

* 完善测例：Face wire 同 turn 唯一 id；ui-conversation 同 turn inject+人话双行，以及重复 id 必抛
* 完善教科书：`protocol-events` · `workspace-inject` · `skills-layers` · `session` · `status` 写明 messageId 契约
