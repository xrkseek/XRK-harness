# v0.1.16

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.15](./v0.1.15.md)：把产品壳 Settings 补全到日常可调旋钮（含工作区注入），权限文案更诚实，并把入门 / 配置教科书改成「先 Settings、后 env」与整篇中英对半。

Relative to [v0.1.15](./v0.1.15.md): complete day-to-day Settings knobs in the product shell (including workspace inject), clarify permission copy, and reframe getting-started / configuration as Settings-first with whole-document CN then EN halves.

---

## 新增 / Added

* 新增 Settings → Plugins → **工作区注入**（`workspace-inject.injectMaxChars`）卡：rules/skills 注入字符预算可在壳内调节（默认 32000）

---

## 完善 / Improved

* 完善 Settings → Plugins → **Agent 循环** 卡：软请求预算 · keep/buffer · 工具结果 spill 在壳内可见可改（不再依赖手改 yaml / env）
* 完善 Access / 权限预设文案：三档中文标签（只读 / 工作区写入 / 完全访问）；完全访问确认说明 **fs 仍 path-jail**
* 完善教科书：`getting-started` · `configuration` · `audiences` 双语标准改为**整篇先中后英**；配置页开篇以 Settings 地图为主、env 为 Host/CI 旁路

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.16
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.1.16 web` · `npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后打开 **设置 → 插件 → 插件配置**，确认 **Agent 循环** · **终端** · **工作区注入** 均在列表中；日常调参不必再 export 环境变量。
