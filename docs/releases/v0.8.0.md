# v0.8.0

> **读者**：终端用户 · 维护者（发行说明）

相对 [v0.7.22](./v0.7.22.md)：`0.8.x` **正式线首发**，接管 npm **`@latest`**。本说明并入过程号 [rc.1](./v0.8.0-rc.1.md) · [rc.2](./v0.8.0-rc.2.md) 的全部用户可见结果，并补上正式版相对 rc 的增量（策展记忆 live / 区划普查、软预算 CJK、席位门禁、Settings soft remount、Desktop 更新镜像、概况与注入/运行时、原生 client 插件面）。

### 新增

* **子代理回传单一通道**：工具结果只报状态；完成经 courier×handoff 进委派方 inbox；父停 / 子停 / 一次性子代理仍回传，并唤醒闲置父会话。时间线打 `data-voice=courier` · `data-lane=handoff`。
* **会话协作回传同纪律**：`thread_message` / `workspace_session_prompt` 与子代理对齐——`wait:true` 成功只走工具结果；`wait:false`、超时、对端 Stop 走异步 steer，同 stretch 不丢不重。
* **干员家 `team_self`**：身份席可改自己的 playbook / brief / inject / tools；不铸包、不删别人。
* **每回合 `<session_lanes>`**：本会话主线 / 支线 / open todos 与完成后的切换动词（含子会话）。
* **Voice×Lane 时间线**：用户 / 助手 / 注入 / 压缩 / **工具调用与结果行**打 `data-voice` / `data-lane`（工具行固定 `seat`×`act`；席位头像仍见「待办」）。
* **概况委派方 N→1**：左栈收敛为单一被委派方球。
* **策展记忆可观测**：Inject `session://memory` 显示本席区划普查（treeRoot / 各 zone 条数 / 缺省写区）；正文靠 system 冻结段 + 磁盘变更后的 live `<external_curated_memory>` + `memory` 工具；概况 Status 有巩固卡（Phase1 / Phase2 色标 · 时间）。
* **同会话干预记忆**：`memory` 写盘后本会话经 live fragment 刷新（不改写 system 冻结段）。
* **原生 client 插件教科书与金样**：`docs/client-plugin-development.md`；`extensions/example-composer-action` · `example-theme-tokens`；会话标准工具包与 `settings.plugin.item` 配置卡写法。

### 完善

* **长会话更省缓存（用户可感）**：同一条 DeepSeek Flash 会话里，改人设 / 斜杠配方 / MCP 目录变动时，多数回合继续复用前缀。
* **斜杠配方进上下文注入**：同配方 id 后来的覆盖先前的；普通续聊仍看得见最近一次配方。
* **MCP / deferred 展开更稳**：`tool_search` 可 `list`；展开过的工具在 Host 重启、编辑重发截断后尽量从会话头恢复。
* **名册 ↔ 干员家身份热同步**：playbook 与家目录 `AGENTS.md`（及高级 `playbook.md`）双向即时同步。
* **子会话主线与斜杠**：子会话可自钉主线；斜杠白名单可用（`/status` · `/compact` · `/export` · `/theme` · `/feedback` · `/skills` · `/model`）。
* **工作区发现**：活跃窗 / 条数 / 上限之上，加 sibling 范围、图深度、同仓优先。
* **干员团队面板**：软轮询刷新，改外形 / 昵称不必重开。
* **`present` / 工具路径**：内联出图；长路径可 wrap。
* **压缩 EMPTY×5**：失败不闸死会话；硬裁剪后备 + 可见诊断。
* **侧栏标题**：`干员 · 主线` 可读组合。
* **Context meter 系统段估价**：站立 / 策展等 CJK 重 system 用软预算密度，减轻首包 usage 前圆环/分项偏低。
* **三级身份动态 titles**：席位词跟 Settings；共用 seed 不写死老板/经理/干员。
* **创建者 vs 委派方**：TTS/ASR 只挂老板创建席；子代理无 `workspace_*`；工具门禁图 `xrk-tool-surfaces`（MCP≠badge）。
* **向阳技能减负**：主线/记忆/清理/插件深文改指针到全局 seed，向阳只留编排差量。
* **Settings 客户端叠加层 soft remount / soft unload**：安装 / 启用 / 更新 / 重载软重挂；停用 / 删除经 `Loader.remove` 软卸载；失败才提示硬刷新（产品仍省略完整 HMR）。
* **远程 = 本机手机操控用法**：`xrk-phone-bridge` materialize 写入 `$XRK_HOME/skills/xrk-phone`；在线时 prompt 绑定「先 skill 再 phone_*」。
* **Desktop 应用内更新镜像**：GitHub Release 资产同源；国内可走 ghfast / gh-proxy 梯子；**按本机时区优先选源**（CN/SEA 先加速器，其它地区先 GitHub），并记住上次成功的源。
* **手机操控浮层**：收成小球交叉淡入；按键反馈不再挤出圆角轮廓（壳侧）。
* **概况 / 顶栏注入·运行时**：概况策展记忆卡；Inject 本回合片段按 Host 优先级排序并突出记忆区划；Runtime 按 surface 分组色轨。
* **概况球并联与热切**：同一会话概况可并排主球与支线球；点球改心情/文案即时落盘，支线 caption 跟随。
* **编辑并重新发送可改媒体**：进入编辑态会 hydrate 原消息附件；回形针可加图片/文件，草稿芯片可逐个移除后再发。
* **席位 chip 跟 Settings 热更新**：对话气泡头衔订阅 `ui-presence` titles，不再卡在开场硬编码「老板」。

### 修复

* **手机截图进模型**：本机 Guest 与远程 `xrk-phone-bridge` 不再丢 `imageBase64`（需同号 App + bridge）。
* **会话导出 ZIP**：`attachments/sha256:…` 冒号叶名可抽出。
* **全屏 Modal**：`--ds-safe-*` 避让手机状态栏。
* **停回传不丢不重**：子代理中断 / 一次性停、会话互聊 Stop 都有 courier。
* **`team_save` 省略 playbook**：只改 brief 或同秒 mtime 时，adopt 优先已相对 roster 发散的磁盘稿，不再盖掉更新的 `playbook.md`。
* **安全模式提示**：手机安全模式可 toast；设置球离开可回正常（壳侧）。
* **手机 / Web「思考中」卡死**：mux/host WebSocket 半开时壳侧空闲看门狗会重连并清乐观 `running`；Host 每 15s 应用层 `: keepalive`。
* **根网页加载中误退后台**：手机根 WebView 仍在加载时系统返回不再 `SystemNavigator.pop`（壳侧）。
* **读屏拒因可读**：本机拒绝读 XRK 自己界面 / 拒名单时，工具结果带上具体原因。

### 其他变更

* 公开线 **`@xrkseek/harness-cli@0.8.0`** 接管 npm **`@latest`**（过程号 `@rc` 仍可指向 `0.8.0-rc.2` 直至策略调整）。
* Desktop / 手机 APK / guest runtime 对齐 **0.8.0**；远程桥建议 **`@xrkseek/xrk-phone-bridge@0.7.25+`**。
* 建议侧栏 **`xrkh-better-sidebar@0.20.12`**（手机薄壳 `XrkShell` 下载 → Downloads / 分享；保存失败可见 Host 围栏原因）。

### 待办（本版刻意不做）

* **DressingAvatarSvg**：消息 / 工具 / bash 行挂席位头像（chrome 现仅 Voice×Lane 属性）。
* **提供方 `toolUpdate` addition-only**：expand / 工具增减仍可能整表重发 tools 段。

# v0.8.0 (EN)

> **Audience**: End users · Maintainers

Relative to [v0.7.22](./v0.7.22.md): **opens the `0.8.x` formal line** and takes npm **`@latest`**. Folds all user-visible results from [rc.1](./v0.8.0-rc.1.md) · [rc.2](./v0.8.0-rc.2.md), plus formal-only deltas (curated-memory live / zone census, CJK soft-budget, seat gates, Settings soft remount, Desktop update mirrors, Overview Inject/Runtime, native client-plugin surface).

### Added

* **Single-channel subagent report-back**: tools stay status-only; completion via courier×handoff; stop still reports; wakes idle parents. Timeline stamps `courier`×`handoff`.
* **Session-collab report-back (same discipline)**: `thread_message` / `workspace_session_prompt` — `wait:true` in the tool result; async steer otherwise.
* **Agent-home `team_self`**: revise own playbook / brief / inject / tools.
* **Per-turn `<session_lanes>`**: 主线 / 支线 / open todos + switch verbs.
* **Voice×Lane transcript chrome**: user / assistant / inject / compaction / **tool call+result rows** stamp `data-voice` / `data-lane` (tools = `seat`×`act`; seat avatars deferred).
* **Overview N→1 delegators**: one delegatee ball.
* **Observable curated memory**: Inject `session://memory` zone census; bodies via system freeze + live `<external_curated_memory>` + `memory` tool; Overview Status consolidate card.
* **Same-session intervention memory**: disk writes refresh via live fragment without rewriting the system freeze.
* **Native client-plugin textbook + gold samples**: `docs/client-plugin-development.md`; `example-composer-action` · `example-theme-tokens`; session standard kit and `settings.plugin.item` cards.

### Improvements

* **Warmer provider cache** on persona / slash / MCP churn within a DeepSeek Flash session.
* **Slash recipes as context injects**; later same-id recipes replace earlier ones.
* **MCP / deferred expand** recovers across Host restart and edit-resend truncates when possible.
* **Roster ↔ agent-home identity** live sync.
* **Child-session 主线 + slash** whitelist.
* **Workspace discovery** sibling / graph / same-repo preference.
* **Team panel** soft-poll refresh.
* **`present` / tool paths**: inline images; wrap long paths.
* **EMPTY×5 compaction**: hard-trim fallback + visible diagnostic.
* **Sidebar titles**: readable `seat · 主线`.
* **Context meter system pricing**: CJK-dense standing / curated system prompts use soft-budget density.
* **Dynamic three-tier seat titles**; creator vs delegator TTS/ASR and tool gates (`xrk-tool-surfaces`; MCP ≠ badge).
* **Xiangyang skills thinned** to orch deltas over global seeds.
* **Settings client overlay soft remount / soft unload**.
* **Remote phone UX matches guest** (`xrk-phone` playbook).
* **Desktop in-app update mirrors** (GitHub SoT; ghfast/gh-proxy; **timezone-ordered ladder** + last-success preference).
* **Phone control overlay** crossfade + press feedback clipping fix (shell).
* **Overview / header Inject·Runtime** polish (curated-memory card · Host-priority inject order · surface rails).
* **Overview parallel balls + hot status**: parent and sideline balls share the rail; mood/caption edits apply live.
* **Edit-and-resend media**: hydrate original attachments; paperclip add / chip remove before resend.
* **Seat chips follow Settings live** (no stuck opening 「老板」 hardcode).

### Fixes

* Phone screenshots reach the model (Guest + bridge).
* Session export ZIP extracts `sha256:` attachment leaves.
* Full-screen Modal respects `--ds-safe-*`.
* Stop / interrupt report-back stays single-channel.
* `team_save` omit-playbook prefers a diverged on-disk playbook on equal mtime.
* Safe-mode notice on mobile + leave-to-normal (shell).
* Mobile/Web half-open WebSocket no longer sticks on thinking chrome; Host app keepalive.
* Root Web leave-while-loading no longer backgrounds the app (shell).
* Screen-read refusals include a concrete reason.

### Other

### Deferred
