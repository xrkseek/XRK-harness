# v0.5.19

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.18](./v0.5.18.md)：Desktop Host 启动/崩溃门闩与重连一次生效；预算耗尽或 OOM 后可点重试，不再卡在「正在启动 Host」或要点两下。

Relative to [v0.5.18](./v0.5.18.md): Desktop Host bring-up / crash gate and reconnect take effect in one click; after budget exhaust or OOM you can retry instead of sticking on “Starting host” or needing a double tap.

### 完善

* 完善 Desktop Host 启动相位：`starting` → `attaching` → `ready` 驱动启动页提示；意外退出按预算自动重启，稳定运行后清零计数。
* 完善连接态文案：握手中显示阶段标签；Host 硬失败进入停等态，底栏为断开芯片（可一点重连），不是永久转圈。
* 完善检查更新：一点版本芯片即进入「正在检查」，不再先闪「已是最新」。

### 修复

* 修复 Host Fetch 门闩竞态：先听后问，避免 `whenHostReady` 永久挂起；失败文案 sticky，后续等待仍能拒绝或在清 sticky 后恢复。
* 修复重连「要点两次」：先等主进程 `rebring` 清 sticky，再重跑 `waitUntil`；`hostReady` 脉冲只在退避/停等时踢 Face，不打断首轮握手。
* 修复启动失败死胡同：预算耗尽后启动页提供「重试 Host」；产品就绪等待若遇停等同样可重试。
* 修复 Host 死后法医信号：保留 `lastDeath` / stderr 尾与 OOM 指纹，写入失败文案（含 `[OOM]` 前缀）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.19`**（接管 npm `@latest`）；npmjs 保留 **0.5.19** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.19**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.19
xrkh web
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.19-win-x64`（或签名）安装包，或从已装旧版经应用内更新。

## 验证

* Host 冷启动失败或中途崩溃：启动页或底栏可重试；一次点击后能重新连上（不必连点两次）。
* Host 预算耗尽：底栏为断开态，文案可含 OOM 指纹；点击重连会重新拉起 Host。
* 正常冷启动：启动页提示随相位推进，不永久停在「正在启动 Host」。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.19`。

---

### Improved

* Desktop Host bring-up phases (`starting` → `attaching` → `ready`) drive splash tips; unexpected exits auto-restart within a budget and reset after a stable window.
* Connection chrome: handshake stages stay labeled; a Host hard-fail parks on outage chrome (one-click reconnect), not a forever spinner.
* Update check: the first chip click paints “Checking…” instead of flashing “up to date” first.

### Fixed

* Host Fetch gate race: listen-before-poll so `whenHostReady` cannot hang forever; sticky failure text still rejects later waits until cleared.
* Double-click reconnect: await main-process `rebring` (clears sticky) before retrying `waitUntil`; `hostReady` kicks Face only from backoff/halted, not mid first handshake.
* Cold-start dead end: splash “Retry Host” after budget exhaust; product-ready wait arms the same retry when halted.
* Post-death forensics: `lastDeath` / stderr tail / OOM fingerprint feed failure copy (including an `[OOM]` prefix).

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.19`** (owns npm `@latest`); npmjs keeps **0.5.19** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.19**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.19
xrkh web
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.19-win-x64` (or signed) package, or update in-app from an older install.

## Verify

* Cold Host failure or mid-session crash: splash or footer retry reconnects in one click (no double tap).
* Budget exhausted: footer shows disconnected chrome (may include an OOM fingerprint); reconnect rebrings Host.
* Healthy cold start: splash tips advance with phase, not stuck on “Starting host”.
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.19`.
