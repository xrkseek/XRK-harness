# v0.6.18

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.17](./v0.6.17.md)：**模型探测补齐与思考档上线**；**子代理计数与父会话可见性**。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.18`（发包后）。

Relative to [v0.6.17](./v0.6.17.md): **richer model probe and thinking levels on the wire**; **subagent count and parent visibility**. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.18` (after publish).

### 新增

* **models.dev 二次补齐**：`GET /models` 列表缺 context / 输出上限 / 思考档 / 输入模态时，按提供方 id → 品牌别名 → 同域名族 → 未知名整库多数票从公共目录只填空、不覆盖手填值。Anthropic / Gemini 只补容量，不造 `reasoning_effort` 菜单。
* **Gemini 列表探测**：`gemini-generate` 可列模型。
* **思考档上线**：目录行已声明思考档时，OpenAI 兼容路由把所选档位写成 `reasoning_effort`（`off` → `none`）；未声明档位的路由不发该字段，避免网关 400。

### 完善

* **模型探测走提供方代理**：与聊天同一条出站代理偏好，避免「设置里配了代理、探测却报不可达」。
* **模型候选列表**：探测结果旁显示 ctx / out / 思考档摘要；采纳时同步空白的输入模态。
* **子代理用户跟进**：在子会话里发的指令会 steer 进父会话，主会话能看见用户对子代理说了什么（工具侧 follow-up 不重复镜像）。

### 修复

* **半成品子代理幽灵**：spawn 失败丢弃时发布 `host/session-removed`（`purged`），客户端从 catalog / 列表摘掉，不再把空壳算进「N 个子代理」。
* **头部计数**：catalog 已就绪时扣掉 summary 里不在 catalog 的直系幽灵，避免 7 个真子代理显示成 11。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.6.18
xrkh web
```

或 `npm i -g @xrkseek/harness-cli@latest`（发包后）。

## 验证

* OpenCode Zen 等只回 `{id}` 的列表：探测后候选行带 ctx / 思考档；采纳后模型行填上容量；聊天请求可带所选 `reasoning_effort`。
* 提供方配了 `http://127.0.0.1:7897` 时，模型探测与聊天同走该代理。
* 父会话派出 7 个子代理后，若中间有失败 spawn，头部计数与下拉与真实 catalog 一致。
* 打开子会话发一句跟进：切回父会话可见对应通知。

---

### Added

* **models.dev enrichment**: when `GET /models` omits context / output cap / thinking levels / intake modes, fill blanks from the public catalog by provider id → brand alias → same-host family → whole-catalog majority vote for unknown providers — never overwrite hand-set values. Anthropic / Gemini get capacities only (no fake `reasoning_effort` menu).
* **Gemini listing probe**: `gemini-generate` can list models.
* **Thinking levels on the wire**: when a catalog row advertises levels, OpenAI-compatible routes send the chosen one as `reasoning_effort` (`off` → `none`); routes without a menu never send the field (avoids gateway 400s).

### Improved

* **Model probe uses the provider proxy**: same outbound preference as chat, so a proxied route is not reported “unreachable” from Settings.
* **Model candidate list**: shows ctx / out / thinking-level facts beside each id; adoption also fills blank intake modes.
* **Subagent human follow-up**: messages typed in a child session steer into the parent so the orchestrator transcript shows what the user told the worker (tool-originated follow-ups are not double-mirrored).

### Fixed

* **Half-made subagent ghosts**: failed spawn discard publishes `host/session-removed` with `purged`, and the client drops catalog / list rows so empty shells no longer inflate “N subagents”.
* **Header count**: when the catalog is ready, subtract direct summary orphans missing from the catalog so seven real children are not shown as eleven.
