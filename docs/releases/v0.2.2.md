# v0.2.2

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.2.1](./v0.2.1.md)：发模型前增加 tool 邻接硬闸；崩溃水合折叠出 `toolCalls` 后同批结算；加固 LRU 淘汰与 Face checkpoint 交互。

Relative to [v0.2.1](./v0.2.1.md): fail-closed tool-call adjacency before each LLM call; settle toolCalls folded during crash repair in the same batch; harden resident LRU eviction around Face checkpoints.

---

## 完善 / Improved

* 发模型前：`assertToolCallsSettled` + `assertAssistantToolCallAdjacency`（拒双 assistant 夹断、orphan `tool`、错 `toolCallId`）；outbound `createToolPairStep` 复用同一断言
* `repairOpenTurnEvents`：折叠 stream 前缀若带出 `toolCalls`，同批再 settle 一轮后再关 step/turn
* Session 驻留 LRU：`onEvict` 结束后再摘除 LRU 项，避免 checkpoint `get` 留下幽灵驻留

## 修复 / Fixed

* 堵住崩溃水合后「assistant 已点名 toolCalls、尚无 result」的邻接洞，以及坏日志仍按 id 结算通过却打到供应商 **HTTP 400** 的静默路径

## 其他变更 / Other

* 公开基线 **v0.2.2**（npm **`@latest`**）；上一版 **v0.2.1**；正式留档仍为 **v0.1.31**
* CLI / SDK 包版本对齐 **0.2.2**
* 契约：[session.md](../session.md) · [session-log.md](../session-log.md) · [tool-settlement.md](../tool-settlement.md)

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.2.2
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后执行 `xrkh restart`，浏览器硬刷新。若旧会话已损坏，删除该会话后新建即可。
