# v0.7.15

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.14](./v0.7.14.md)：计算机使用封装层（packages/exec/computer-use）的坐标系与光标保持一并加固；agent-desktop 状态根迁到用户可写目录并自愈提权污染；配套单测与文档同步更新。

### 新增

* computer-use：`ComputerUseFrame` / `ComputerUseScreenshotGeometry` 两个类型（`src/types.ts`），并从包入口导出（`src/index.ts`）。
* computer-use 工具 schema 新增 `coordinateSpace`（默认 `"window"`）与 `preserveCursor`（默认 `true`）两个参数（`src/tools.ts`）。
* agent-desktop：`capture` 返回窗口 `frame`（逻辑屏幕像素）与截图几何（`offsetX/offsetY` 由 frame 与截图尺寸推导）。
* agent-desktop：headed 坐标点击后把用户真光标复位（PowerShell 读/写同一 DPI 虚拟化空间，往返自洽）。
* resolve-cli：状态根迁到 `%LOCALAPPDATA%/xrk-harness-agent-desktop`（非 Windows 走 `$XDG_DATA_HOME/…`），并新增 `clearWindowsAgentDesktopLease` / `isWindowsProcessElevated` / `isElevatedOwnedWindowsPath` / `ensureWritableAgentDesktopHome`，启动时尽力清 `ProgramData/agent-desktop` 交互租约。
* 测试：新增 `tests/agent-desktop-geometry.test.ts`（9 个用例）。

### 完善

* agent-desktop：`click` / `hover` / `mouse_move` / `mouse_wheel` / `drag` 统一经 `resolveCoordinate`：截图像素 → 屏幕 DIP 自动换算，模型不再做 DPI 加法。
* agent-desktop：冷启动无 frame 时自动补一次 snapshot 取 frame，不再直接报错。
* agent-desktop：`focus_window` 中文/含空格标签走 `--title`，失败回退 `--app`（此前把中文名塞给 `--app` 导致聚焦失败并连锁废掉后续 headed 动作）。
* agent-desktop：hollow AX 树提示改为键盘优先。
* format：快照文本输出 `frame` / `screenshot` 坐标系；guidance 改为键盘优先 + 坐标自动换算；0 元素时 `next` 提示修正。
* tools：修正 `som` 的虚假描述（agent-desktop 上 `som` 是 `vision` 别名，不绘制元素编号）。
* 文档：`docs/computer-use.md`、`docs/troubleshooting.md` 配套更新。

### 修复

* agent-desktop：headed 坐标点击后用户真光标不再被留在点击点（光标保持）。
* agent-desktop：归档 / dispose 时先 `close()` 关掉 cursor-overlay 再结束 CLI session，避免残留纯白光标层窗口。

### 其他变更

* 测试：`tests/agent-desktop.test.ts` 一个旧用例补 `coordinateSpace: "screen"` 语义；`tests/computer-use.test.ts` 配套 +37 行。

## 默认值语义与推荐路径

* `coordinateSpace` 默认 `"window"`：传入的坐标就是你在 capture 截图上量到的像素（客户端区），封装层自动加上窗口 frame 原点与客户区 inset，换算成屏幕逻辑像素；`"screen"` 则是直接传绝对桌面逻辑像素，不做任何换算。
* `preserveCursor` 默认 `true`：headed 动作完成后把用户真光标复位，避免抢走用户鼠标；仅在需要把光标留在目标点时设 `false`。
* 推荐路径：优先键盘（`key` / `type` / `set_value`），坐标点击作为兜底；截图坐标由封装层自动换算，模型无需 DPI 加法。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.14](./v0.7.14.md): the computer-use encapsulation layer (packages/exec/computer-use) hardens its coordinate spaces and cursor preservation; agent-desktop state root moves to a user-writable directory with self-healing for elevated pollution; tests and docs follow.

### Added

* computer-use: `ComputerUseFrame` and `ComputerUseScreenshotGeometry` types, exported from the package entry.
* computer-use tools: `coordinateSpace` (default `"window"`) and `preserveCursor` (default `true`) parameters.
* agent-desktop: `capture` returns the window `frame` (logical screen pixels) plus screenshot geometry (`offsetX/offsetY` derived from frame vs. screenshot size).
* agent-desktop: after a headed coordinate click, the user's real cursor is restored (PowerShell reads/writes the same DPI-virtualized space, round-trip consistent).
* resolve-cli: state root pins to `%LOCALAPPDATA%/xrk-harness-agent-desktop` (non-Windows: `$XDG_DATA_HOME/…`), with `clearWindowsAgentDesktopLease` / `isWindowsProcessElevated` / `isElevatedOwnedWindowsPath` / `ensureWritableAgentDesktopHome` to best-effort clear the `ProgramData/agent-desktop` interaction lease.
* Tests: new `tests/agent-desktop-geometry.test.ts` (9 cases).

### Improved

* agent-desktop: `click` / `hover` / `mouse_move` / `mouse_wheel` / `drag` all route through `resolveCoordinate` (screenshot pixels → screen DIPs automatically; no DPI math for the model).
* agent-desktop: cold start with no frame auto-snapshots once to obtain a frame instead of failing.
* agent-desktop: `focus_window` routes Chinese / spaced labels through `--title`, falling back to `--app`.
* agent-desktop: hollow AX-tree hint is now keyboard-first.
* format: snapshot text emits `frame` / `screenshot` coordinate systems; guidance is keyboard-first with automatic coordinate conversion; the zero-element `next` hint is corrected.
* tools: corrects the misleading `som` description (`som` is a `vision` alias on agent-desktop and does not draw element numbers).
* Docs: `docs/computer-use.md` and `docs/troubleshooting.md` updated.

### Fixed

* agent-desktop: the user's real cursor is no longer left at the click point after a headed coordinate action (cursor preservation).
* agent-desktop: on archive / dispose, `close()` shuts the cursor overlay before ending the CLI session, so no orphan white cursor window lingers.

### Other changes

* Tests: `tests/agent-desktop.test.ts` gains a `coordinateSpace: "screen"` semantic case; `tests/computer-use.test.ts` +37 lines.

## Defaults and recommended path

* `coordinateSpace` defaults to `"window"`: the coordinate is the pixel you measured on the capture screenshot (client area); the provider adds the window frame origin and the client inset to get logical screen pixels. `"screen"` passes absolute desktop logical pixels with no conversion.
* `preserveCursor` defaults to `true`: headed actions restore the user's real cursor afterwards so the mouse is not stolen; set `false` only when the cursor should stay on the target.
* Recommended path: prefer keyboard (`key` / `type` / `set_value`), coordinates as a fallback; screenshot coordinates are converted by the encapsulation layer, no DPI math needed from the model.
