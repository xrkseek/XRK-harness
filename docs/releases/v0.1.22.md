# v0.1.22

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.21](./v0.1.21.md)：对话流真空期反馈对齐 DSH drain 语义；Sidebar 中文文件名下载不再打爆 Host。

Relative to [v0.1.21](./v0.1.21.md): conversation flow vacuum feedback aligned with DSH drain semantics; Sidebar download with non-ASCII filenames no longer crashes Host.

---

## 完善 / Improved

* 完善 **flow waiting**（DSH `agent/status` + live surface）：`turnStatus.*` 在发话后首 token 前、step/turn 切换间隙、插话排队与 promote 后至 Think 前保持可见；工具行或 open-step 流式 Think/正文出现时让位
* 完善 partial 判定：仅 **当前 open step** 的可见 streaming partial 视为活跃面；已 closed step 的残留 partial 不再挡住 waiting 行

---

## 修复 / Fixed

* 修复长 turn **插话**后 Stop 仍亮但 flow 无反馈、易被误判卡死的问题
* 修复重连 generation 丢失时 **running** 乐观位不清、Stop 长时间不回落
* 修复 Sidebar **`/sidebar/file?download=1`** 中文等非 ASCII 文件名导致 `content-disposition` 抛错、Host 进程退出

---
