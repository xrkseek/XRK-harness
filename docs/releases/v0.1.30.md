# v0.1.30

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.29](./v0.1.29.md)：修复侧栏终端 WebSocket 断线后无限「重连中」；Host PTY 按会话+标签保活并支持短暂重连；补齐 `agent-opens` 升级口。

Relative to [v0.1.29](./v0.1.29.md): fix sidebar terminal WebSocket soft-reconnect loops; Host PTY keyed by session+tab with reconnect grace; accept `/sidebar/ws/agent-opens`.

---

## 完善 / Improved

* 完善侧栏终端 Host：按 `sessionId` + `tab` 复用 PTY，裸断线保留约 30s 重连宽限（对齐插件侧契约）
* 完善侧栏终端：cwd 生成失败时回退到 Host 工作区 / 用户主目录（缓解 Windows 非 ASCII 路径）
* 完善 dsh-compat：接受 `/sidebar/ws/agent-opens`（空闲保活，避免客户端无谓重试）

---

## 修复 / Fixed

* 修复侧栏终端：PTY 退出时不再用 WebSocket `1000` 空原因关闭（客户端会当成瞬断并一直显示「终端连接断开，重连中…」）
* 修复侧栏终端：进程退出后在已打开的 socket 上输出 `[process exited]`，保持连接可读

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.30
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后执行 `xrkh restart`，浏览器硬刷新；侧栏插件建议 `xrkh-better-sidebar@0.17.7` 及以上。
