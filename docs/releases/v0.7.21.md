# v0.7.21

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.20](./v0.7.20.md)：工作区 MCP 可叠加进本席挂载；回合注入一事一处并压短；席位称呼跟 Settings；子代理可向父席提问；Inject 目录与 Host 实发片段对齐。

### 新增

* 工作区 MCP：`{cwd}/.xrk/mcp.json` 可增补服务器并可选 `denyGlobal`；本席 `mcp_mount` 合并全局 + 会话工作区 + 干员家（同名会话赢）。
* 子代理 `ask` 通道：干员可经父席提问（capability `ask:` / `answer_ask`），不再只靠老板 `ask_user`。

### 完善

* 回合开头注入瘦身：capability / posture / seat / board / Delivery / 工具动态句一事一处；Frugal / Shell 仍无 posture。
* Settings → 插件 → Inject：`session://*` 与 Host 实发对齐（authority · capability · posture · boss · seat · board）。
* 席位称呼：老板 / 经理 / 干员正式名取自 Settings，注入与频道前缀跟活配置。
* 手机 guest AGENTS / 诊断 / `xrk-mobile-prompt` 压短；清单与禁项集中在 `xrk-phone`。

### 删除

* Settings 插件页 SSH Remote 卡（远端日常走 MCP；无头仍可用 `XRK_SSH_HOST`）。

### 修复

* 注入目录只列 capability / posture / board 时与模型实见片段不一致的问题。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.21
xrkh web
```

桌面安装包见 GitHub Release `v0.7.21` 与站点下载页（AGT 上线后）。手机 APK 见对应 `XRK-harness-mobile` Release。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.20](./v0.7.20.md): workspace MCP overlays into the seat mount; turn-start inject is leaner and one-fact-one-place; seat titles follow Settings; children can ask the parent seat; the Inject catalog matches what Host actually sends.

### Added

* Workspace MCP: `{cwd}/.xrk/mcp.json` can add servers and optionally `denyGlobal`; this seat’s `mcp_mount` merges global + session workspace + agent-home (session wins on name clash).
* Child `ask` lane: delegated agents can ask via the parent seat (`ask:` / `answer_ask`), not only boss `ask_user`.

### Improved

* Leaner turn-start inject: capability / posture / seat / board / Delivery / tool dynamic copy stay one-fact-one-place; Frugal / Shell still have no posture.
* Settings → Plugins → Inject: `session://*` mirrors Host fragments (authority · capability · posture · boss · seat · board).
* Seat titles: boss / manager / agent formals come from Settings; inject and channel prefixes follow live config.
* Phone guest AGENTS / diagnostics / `xrk-mobile-prompt` trimmed; lists and denials live in `xrk-phone`.

### Removed

* Settings Plugins SSH Remote card (day-to-day remote via MCP; headless still uses `XRK_SSH_HOST`).

### Fixed

* Inject catalog listing only capability / posture / board while the model saw a fuller fragment set.
