# v0.1.14

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.13](./v0.1.13.md)：修 OpenAI 兼容流式工具名被空白 delta 冲掉；压缩与 Context meter 对齐；站立 inject digest 与 skill-catalog 渐进披露；取消/失败态与可重建请求契约收紧；社区 dsh-context 趋势明细可用。

Relative to [v0.1.13](./v0.1.13.md): keep streamed tool-call identity across blank deltas; align compaction and Context meter; standing inject digest + progressive skill-catalog; tighter cancel/failure UX and reconstructable requests; dsh-context trend breakdown works.

---

## 完善 / Improved

* 完善 **上下文压缩**：provider overflow 与软预算均 **先 prune 超大 tool 结果再摘要**；摘要失败不再掩盖原始 overflow
* 完善 **Context meter**：`shadowedTokenCount` 与 `priceCurrentSurfaceWindow` 同价；todos 与 `/compact` 窗口正交（压缩不清站立计划）
* 完善 **工作区 inject**：盘未变且已有 instructions 或 skill-catalog 时整段跳过重扫；站立 **skill-catalog 默认只含工作区 skills**（`~/…/skills` 仍走 `skill` / `skill.list`，可开 `includeUserHomeSkills`）
* 完善 **长任务 UX**：TodoDock 在 `todo_write` 后显示、`turn/end` 保留、下一轮 `turn/start` 清空；入门文档补 `todo_write` + `/compact` 一句

---

## 修复 / Fixed

* 修复社区 **dsh-context** 趋势明细：`contextTimeline.requests` 补齐启发式 `total`/分项；`prompt`/`output` 由 provider usage 盖章；`events` 记录注入 · 压缩 · 剪枝 · 模型切换 · plan 模式
* 修复 OpenAI 兼容适配器：后续 SSE 空白 `id`/`name` 覆盖已流式拼好的工具身份，导致整轮 `Unknown tool:` / 空名工具循环
* 修复取消流式产品壳验收与协议语义：live Stop → `turn/end` **`aborted`** + 消息 `interrupted` + UI「Stopped」；崩溃修复开洞 turn 才是 **`interrupted`**
* 修复 AUTH 等终端失败在壳上的展示：`This turn failed` 经 `displayFailureMessage` 脱敏，不把密钥片段投到 UI

---

## 其他变更 / Other

* 非 assemble 路径：每步 LLM request 的 durable history 须等于派发时日志前缀的 `deriveMessages`；Host drain idle / stop 调用 `store.flush()` 作为耐久观察屏障（见 [session.md](../session.md) · [protocol-events.md](../protocol-events.md)）

```bash

xrkh web
```
