# v0.5.11

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.10](./v0.5.10.md)：子代理角色真正卸掉禁用工具；前台等待超时会抢救已写出的答案，并标成父代理中止而不是「用户停止」；谱系能区分完成 / 超时砍掉 / 出错；子会话不再吃家里站立人格；徽章区分「只显式委派 / 可主动开子代理」；插队未进下一模型请求前标「发送中」且可撤回；插话不占一轮，轨上「第 N 轮」按用户轮次而不是 Host turn；单回合也会出现回合轨；最小化桌面窗不再冻住流式回复；半开 SSE 会重连而不是一直假在线；策展记忆按最久未触碰条目腾位；发话后到首 token 前、以及工具跑完到下一轮 Think 之间会再出现「再想一层…」；概况球可叠装扮，子会话沿用干员外形，侧栏支线字幕可见。

Relative to [v0.5.10](./v0.5.10.md): spawn roles hard-deny tools; a foreground wait timeout salvages the child’s answer and records a parent abort (not a user Stop); the roster tells finished vs cut-off vs error; children skip the home persona layer; badges choose explicit vs proactive delegation; a steer shows “Sending…” and can be withdrawn before it becomes the next model request; a steer is not a 轮次 — the rail’s “turn N” is the user round, not Host `turn`; the turn rail appears even on a one-turn session; minimized Desktop no longer freezes streaming paint; a silent SSE downlink reconnects instead of staying fake-online; curated memory prunes by longest-untouched entry; the waiting line returns after send until the first token, and after a tool until the next Think; presence costume kits, roster looks on child sessions, and sidebar sideline captions.

### 新增

* 新增徽章委派姿态 `delegation`：`explicit`（Minimal / Shell / Frugal）只在用户、AGENTS.md 或任务正文要求时开子代理；`proactive`（Shallow / Harness）允许在深度与并发上限内主动并行。系统提示按徽章分别写明。
* 新增前台子代理等待超时抢救：默认 10 分钟内子会话若已写出答案，父工具结果带回该答案与 `wait_agent` / `session_read` / `followup_task` 续聊提示；无产出才 `session.cancel`（`cause: parent`）。若超时发生在模型重试中，结果另附 attempt / 状态码 / backoff。长任务请用 `run_in_background`。
* 新增 `subagents.list` / `list_agents` 末轮 **`outcome`**：完成、被父代理中止、用户停止、出错、打断、max-tokens、阻塞、尚未结束；侧栏谱系 idle 行显示该结论，不再一律「当前未运行」。
* 新增策展记忆触碰旁路 `.usage.json`：`list` 可带 `stale_entries`；字数顶满时错误带 `prune_candidates`（最久未触碰条目）；Phase1 软删按触碰年龄而非文件顺序，并记入 `.trim-log.jsonl`。
* 新增 Desktop SSE 下行空闲看门狗：Host `: keepalive` 每 15s；连续约 45s 无字节则判定半开连接并重连（活跃流式会清计时，不会误掐）。Web 仍走 WebSocket，不受这条影响。
* 新增未 promote 插队撤回：气泡标「发送中」，与排队一样可删（`session.updateQueue` remove）；操作「撤回插队」。已认领进日志的插队不再走这条。
* 新增会话主线：工作区级目录；AI 自定协作钉（`thread_upsert` / `thread_switch` / `thread_delete`），`thread_list` 只见本工作区已挂条目及挂上的主会话。标题由模型拟定，不会自动抄用户原话。会话之间没有实时对讲；发现后用 `session_search` / `session_read`。未挂前侧栏名称仍是用户第一条消息；挂上后侧栏与页头立刻换成主线标题。`presence_set` 的 `tips` 作支线字幕显示在会话名下方。
* 新增 Agent Team：侧栏把子会话的工具、注入、playbook 摆成名册（全局预置调研/施工/审稿/调度，可自建或主会话 `team_save`）；`team/dispatch` 或 `subagent(member_id)` 派发；派发后的子会话沿用该干员外形 / 颜色 / 装扮。

### 完善

* 完善 spawn `role`：`worker` / `researcher` / `reviewer` 在 Host 建 Agent 时卸掉禁止工具；角色写入子代理链路，重启后仍生效。`lead` / `default` 不额外收工具。
* 完善主线：`thread_*` 由模型维护；有持续任务时主动 `thread_upsert`，不从打招呼/插话自动建。`thread_list` 只列已挂会话。子会话继承已有父主线。Agent Team 配置面不编主线。未挂时侧栏名保持用户第一条消息；支线字幕来自 `presence_set` 的 `tips`。
* 完善插队：等当前回合结束后再进入下一模型请求；排队仍等轮次结束。等待期间标「发送中」可撤回；进入下一请求后是普通发送。
* 完善归档：侧栏归档会话会停掉该会话（及级联子会话）的进行中回合；编辑截断后的原会话归档即停。永久删除仍只接受已归档会话，删除时同样停回合。
* 完善 Agent Team：子会话的工具 / 注入 / playbook 与主会话的徽章、`.xrk`、发出的话同一套三面，只是公开成名册；全局预置调研/施工/审稿/调度；可自建或主会话 `team_save`；已有 `global.json` 会补上缺失种子 id、刷新仍标 `seed` 的条目（用户改过的不再被覆盖）；`team_list` 与 `subagent` 描述带短目录；主会话 / 调度员才绑 `team_list`·`team_save`；站立 `AGENTS.md` 与 `xrk-delegate` 按 `member_id` 委派；子会话表情球吃干员外形而不是全局 Presence 默认。
* 完善子会话 inject：`audience: subagent` 跳过家目录 SOUL.md / USER.md / IDENTITY.md / 家 AGENTS.md，身份只来自 Face spawn 前缀；工作区项目文档与 skills catalog 仍注入。节首增加 `> source: <path>` 溯源行。
* 完善 `subagent` 工具说明：写明前台等待有界、超时可抢救；后台回复统一带续聊动词；委派路由提示要求先规划关键路径、子任务互不重叠写同一文件。
* 完善回合轨：贴在对话列右缘内侧、更贴近调宽条，可点跳转。刻度上旧下新；当前所在轮最长、正在输出的最新轮（轨底）中等、其余最短；滚到对话底部时当前与最新重合为最长。单回合也显示轨；回合号与悬停预览同一簇。「第 N 轮」按用户轮次计，插话不占刻度。
* 完善概况表情球：概况列始终给球留台，展开不把 Status 撑开；标题栏球退场后再加载引擎。加载转圈与球姿交叉淡出；Status 未返回也可挂 Presence 轨。
* 完善权限「额外可写目录」：与 Settings 其它字段同层，已加路径为可删标签，输入框加「添加」立即写入。
* 完善 Session SQLite：仅用户消息与 turn/command/prompt 边界立即落盘；模型内部事件微批（上限 64）再刷，崩溃最多丢一批模型输出，不丢人话。
* 完善 CLI：`--version` / `--help` / 解析错误不再预加载全部 command 模块（及 `@xrkseek/server-*` 树）；真正跑 `serve` / `run` / `acp` 时仍按需加载。
* 完善概况协作图：`session.status` live 行带末轮 `outcome`（与 `list_agents` 同源）；`/status` 闲置行写出该结论。
* 完善并行工具：同一步里先结束的调用立刻写 `tool/result`（对话卡马上落下），下一轮模型请求仍等整批跑完。
* 完善 Agent Team 配置面：左右分栏编辑、预置徽标、工作区身份与「选择工作区」；预置角色不再提供删除（仍可覆盖）。名册球与会话表情球同一套引擎；外形/颜色目录加大（含心形、星、六边等与蜂蜜、海青等色）；害羞等表情红晕不跟球身色。
* 完善概况表情球装扮：Settings 外形/颜色旁可叠薄装扮（蝴蝶结 / 鸭舌帽 / 毛线帽 / 帽檐 / 圆框·方框·猫眼·墨镜 / 光环），贴图仍单独导入，不是商店。
* 完善 Web 启动：插件脚本与首屏模块同时下载；静态 JS/CSS 在浏览器支持时走 gzip。
* 完善本仓作工作区时的 inject：`.agents/AGENTS.md` / skills / recipes 不再复写 CLI seeds；全局站立与产品默认 skill 只走 `~/.xrk`。

### 删除

* 全局名册不再预置「发版干员」；已有 `global.json` 里仍标 `seed` 的该条目在合并时丢掉，用户自建角色保留。

### 修复

* 修复工具还在跑时插队「发送中」闪一下就没：徽章跟当前开着的回合。
* 修复插队进入下一模型请求后「发送中」徽章消失或残留：壳能认出落地的用户消息；已成为下一请求的按普通发送。
* 修复 Desktop / 后台标签页流式回复停画：最小化或被遮挡时回复仍刷新。
* 修复生产壳每次写入整树冻结：仅开发 / 测试环境冻结。
* 修复前台等待超时把子会话记成「用户停止」：无产出时记为父代理中止。
* 修复概况协作图把所有闲置子节点画成完成：父代理中止 / 出错 / 打断走 `outcome`，画错误点。
* 修复从当前会话点「新会话」Composer 停在「选择模型」：继承当前有效模型；有进行中会话时不复用工作区旧空白会话。
* 修复回合轨编号与对话时间线错位；流式草稿不串到下一会话。
* 修复等待条跟画面错位：发话后空着、或工具跑完还没下一层时出现；工具还在跑或 Think 正在出字时不叠一条。
* 修复编辑已发送消息再回车变成新排队、原文不变：走截断重发。
* 修复编辑仍在跑的会话时跳过回退确认、或 fork 后报 `scope … is disposed`：进行中回合也弹确认；先 fork 再停仍在跑的原会话（空闲原会话不停）；UI fork 子会话用独立 agent scope。
* 修复编辑第一条消息后新会话头顶出现无用户消息的「已停止」：`beforeSeq` 不再把当前回合的 `turn/start` 或仅有中止结尾的回合拷进种子。
* 修复会话模型芯片跳到没用过的目录默认值：未 `selectModel` 的会话跟日志里最后一次 `request/header`，不跟 Settings / 目录第一项。
* 修复编辑态下删光正文会退出编辑：清空草稿仍保持编辑；用 Escape 或「取消编辑」退出。
* 修复插话被当成新一轮：只有带开场用户消息的回合进轨。

## 验证

* Shallow / Harness：系统提示可见「Delegation: proactive」；未要求时也可开子代理（仍受 depth/active 上限）。Frugal：无子代理工具。
* `role: reviewer` 或 `researcher` 的子会话：工具列表无 `apply_edit` / `bash` / `web_*`（reviewer）等；`worker` 无 `subagent`。
* 前台 `subagent` 跑超过等待预算但仍写出答案：父结果含抢救正文与续聊提示，子会话仍可读；谱系与概况协作图标「被父代理中止」而不是「已完成」或「已停止」。
* 子会话系统侧：无家目录 SOUL/家 AGENTS 人格段；仍有工作区 AGENTS / rules；节上有 `> source:`。
* 忙碌时插一条人话：未 promote 前标「发送中」可撤回；promote 成下一模型请求后是普通发送。
* 只有一轮的会话右侧仍有回合轨，贴在内容右缘内侧、更贴近调宽条（可点）、不贴输入框；悬停刻度时预览篮与「第 N 轮」贴在一起。最长是当前所在轮，中等是正在输出的最新轮（未滚到底时在轨底），其余最短。滚到会话最底，轨标最后一轮（最长）。插话不增加刻度；Host turn 与「第 N 轮」可以不一致。
* Desktop：回合流式中最小化再恢复，回复继续刷新，无需硬刷新。
* `memory` `list` 在多次写入后可见 `stale_entries`；字数顶满时错误含 `prune_candidates`。
* `xrkh --version` 在冷启动下明显快于 `xrkh serve` 冷启动（未拉全量 Host 树）。
* 在已选 DeepSeek 的会话点「新会话」：Composer 触发器显示同一模型，而不是「选择模型」。
* 工具结果落地、模型尚未出下一 token：底部再出现「再想一层…」（或同类 `turnStatus.*`）与计时；下一轮 Think 开始或工具仍在跑时条消失。
* 上一轮已结束再发一条：底部立刻出现等待条（不必等 `turn/start` / 首 token）；Think 开始后条消失。工具还在跑时插队：只有工具，没有叠一条等待条。
* 忙碌时插队：气泡标「发送中」且有「撤回插队」，点后队列里这条消失；刷新后未进轮的插队仍在对话流（不是排队坞）。
* 编辑一条已发送用户消息再回车：有后续或仍在跑时确认是否回退文件；先 fork 新会话再发；仅当原会话仍在跑时才停下。子会话不会带上没有用户消息的「已停止」回合尾。侧栏归档原会话同样停回合。
* Settings 概况球可选装扮叠层；用 Agent Team 干员派发的子会话球跟干员外形/颜色/装扮。
* 侧栏会话行在名称下方显示 `presence_set` tips 支线字幕（未挂主线时标题仍为首条人话）。
* `thread_upsert` 立好主线后：侧栏与页头立刻换成主线标题，不必刷新。

### Added

* Badge `delegation` posture: `explicit` (Minimal / Shell / Frugal) spawns only when the user, AGENTS.md, or the task asks; `proactive` (Shallow / Harness) may fan out within depth/active caps. The `tool:subagent` system section injects the matching mode line.
* Foreground subagent wait salvage (default 10 min): if the child already wrote an answer, the parent tool result returns that text plus `wait_agent` / `session_read` / `followup_task` resume verbs; only an empty child is cancelled (`cause: parent`). A timeout mid model-retry also reports attempt / status / backoff. Prefer `run_in_background` for long work.
* `subagents.list` / `list_agents` last-turn **`outcome`**: completed, aborted by parent/user, error, interrupted, max-tokens, blocked, or still open. Sidebar lineage idle rows show that verdict instead of a uniform “not running”.
* Curated-memory usage sidecar `.usage.json`: `list` may include `stale_entries`; a char-cap error carries `prune_candidates` (longest-untouched); Phase1 soft-trim ranks by touch age and appends `.trim-log.jsonl`.
* Desktop SSE downlink idle watchdog: Host `: keepalive` every 15s; ~45s with no bytes treats the channel as half-open and reconnects (an active stream clears the timer). Web still uses WebSocket and is unaffected.
* Mid-turn **withdraw**: a still-pending “Sending…” row can be removed the same way as a queued row (`session.updateQueue` remove) via **Withdraw steer**. Already-claimed log rows are not this path.
* Session **mainline**: workspace catalog. The model owns the pin (`thread_upsert` / `thread_switch` / `thread_delete`); `thread_list` returns this workspace’s catalog and attached parent sessions only. Titles are model-chosen, not copied from the user. Sessions have no live chat bus — follow with `session_search` / `session_read`. Until bound, the sidebar name stays the first user message; once bound, sidebar and header switch to the 主线 title. `presence_set` `tips` show as a sideline caption under the title.
* **Agent Team**: sidebar roster for the child's tools, inject, and playbook (global research / implement / review / lead; add your own or `team_save` from the parent chat). Dispatch via `team/dispatch` or `subagent(member_id)`; the child session’s presence ball keeps that member’s shape / color / costume.

### Improved

* Spawn `role` hard-denies tools at Host Agent build (`worker` / `researcher` / `reviewer`); the role persists on the subagent-link sidecar across restarts. `lead` / `default` do not strip tools.
* The model owns 主线 (`thread_*`). `thread_list` omits unbound sessions. Children inherit a parent 主线 when the parent already has one. A steer does not create a 主线. Agent Team does not edit 主线. Until bound, the sidebar name stays the first user message; the 支线 caption is `presence_set` `tips`.
* Steer waits for this turn to end before becoming the next model request; queue still waits for the user 轮次. “Sending…” only while waiting.
* Archive stops the session (and cascaded children). After an edit-truncate fork, archiving the original stops its leftover turn. Permanent delete still requires archive first and also stops the turn.
* Agent Team is the child's tools / inject / playbook on the table (the same three surfaces the parent already edits via badge, `.xrk`, and the sent message). Base roles ship globally; users add roles or `team_save` from the parent chat; an existing `global.json` picks up missing seed ids and refreshes rows still marked `seed` (user edits stay); `team_list` and the `subagent` catalog show the short roster; parent / lead sessions bind `team_list`·`team_save`; standing `AGENTS.md` and `xrk-delegate` spawn by `member_id`; the child ball follows the member look, not the global Presence default.
* Child inject uses `audience: subagent`: skips home SOUL.md / USER.md / IDENTITY.md / home AGENTS.md; identity comes from the Face spawn preamble; workspace project docs and the skills catalog stay on. Each section carries a `> source: <path>` provenance line.
* `subagent` tool copy documents the bounded foreground wait and salvage path; background replies share the same resume verbs; routing text asks for a critical-path plan and disjoint child scopes.
* The turn rail sits just inside the content’s right edge, closer to the resize strip, and is clickable. Oldest ticks at the top, newest (live output) at the bottom. Reading is longest, the live tip is medium when you are elsewhere, everything else is short. A one-turn session still shows the rail. Rail labels are user 轮次; a steer does not add a tick.
* Overview presence rail keeps a reserved stage (including while the column is width 0) so expand does not grow Status around the ball; EmotionBall starts after the header dock exits. Spinner cross-fades to pose; the rail mounts before Status returns.
* Permission extra writable roots match other Settings fields (layer-1 hairline). Saved paths are removable chips; Add / Enter persists immediately instead of hiding “press Enter” in the label.
* Session SQLite flushes immediately only on user / turn / command / prompt boundaries; model-interior events micro-batch (cap 64). A crash may lose one model-output window, never a user message.
* CLI answers `--version` / `--help` / parse errors without loading every command module (and the `@xrkseek/server-*` tree); `serve` / `run` / `acp` still load on demand.
* Overview graph: `session.status` live rows carry last-turn `outcome` (same source as `list_agents`); `/status` idle lines print that verdict.
* Parallel tools append `tool/result` as soon as that call finishes (the card paints immediately); the next model request still waits for the whole step.
* Agent Team editor is a two-pane sheet: built-in badge, current workspace identity, and **Choose workspace**; catalog seeds are not deletable (overlay still works). Roster balls use the same EmotionBall engine as the session companion, with a larger shape/color catalog; shy blush is not recolored by the body palette.
* Overview presence costume kits: Settings shape/color gains thin overlays (`bow` / `cap` / `beanie` / `visor` / round·rect·cat-eye·sun glasses / `halo`); face stickers stay separate (not a shop).
* Web boot fetches every plugin script in parallel with the `immediately` factory barrier (large later bundles no longer wait for that tier); static JS/CSS is gzipped when the browser asks.
* This repo as a workspace no longer mirrors CLI seeds into `.agents/` (`AGENTS.md` / skills / recipes). Standing persona and default product skills stay in `~/.xrk` only.

### Removed

* The global roster no longer ships a “release” seed. An existing `global.json` row still marked `seed` for that id is dropped on merge; user-owned leftover roles stay.

### Fixed

* A steer while tools are live keeps a stable “Sending…” badge for the open turn.
* After a steer becomes the next model request it is an ordinary send (badge gone).
* Streaming paint continues when Desktop is minimized or a tab is hidden.
* Production shells freeze the store only in explicit dev/test.
* A foreground wait timeout records an empty child as aborted by the parent.
* Overview graph uses `outcome` for parent abort / error / interrupt (error dot).
* New Session from a live chat inherits the effective model.
* Turn-rail numbers stay aligned with the transcript; a streaming draft does not leak across sessions.
* The waiting line appears after send or after a finished tool, and hides while a tool or Think is live.
* Editing a sent message then pressing Enter truncate-resubmits (confirm if there is a tail or a live turn).
* Editing a still-running session no longer skips the revert confirm or fails with `scope … is disposed`: confirm on live turns, fork first, then stop the original only if it is still running; UI forks get their own agent scope.
* Editing the first message no longer copies a headless Stopped footer into the child: `beforeSeq` drops the current turn's `turn/start` and abort-only turns with no human message.
* Sessions that never called `selectModel` keep the last `request/header` route on the composer chip instead of jumping to the Settings / catalog default.
* Clearing the composer while editing a message no longer exits edit mode; use Escape or Cancel edit.
* A steer does not count as a new 轮次.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.11`** (owns npm `@latest`); npmjs keeps **0.5.11** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.11**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.
* Face → shell `subagents.list` adds optional `outcome` (apiproxy Zod in the same change); older shells ignore the unknown field.
