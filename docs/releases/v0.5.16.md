# v0.5.16

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.15](./v0.5.15.md)：Desktop 应用内更新在预下载未完成前不可点「安装并重启」；下载成功后才进入可安装态。

Relative to [v0.5.15](./v0.5.15.md): the in-app Desktop update dialog keeps **Install and restart** disabled until the prefetch finishes; only then does the build enter the installable state.

### 修复

* 修复 Desktop 更新对话框：检查到新版本后仍会自动预下载并显示进度，但「安装并重启」仅在下载完成（`ready`）后可点；避免中途安装或进度走完却因竞态报错。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.16`**（接管 npm `@latest`）；npmjs 保留 **0.5.16** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.16**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.16
xrkh web
```

然后硬刷新客户端半部。Desktop：安装本版 `xrk-harness-0.5.16-win-x64`（或签名）安装包，或从已装旧版经应用内更新。

## 验证

* Desktop：底栏出现「有更新」→ 打开对话框见进度条；进度未满时「安装并重启」禁用；到 100% / 文案变为已下载完成后按钮可点，安装并重启成功。
* `xrkh -v` / `npm view @xrkseek/harness-cli version` 为 `0.5.16`。

---

### Fixed

* Desktop update dialog: prefetch and the progress meter still start when a newer build is found, but **Install and restart** stays disabled until the download reaches `ready`, so mid-download install and finish-race errors no longer happen.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.16`** (owns npm `@latest`); npmjs keeps **0.5.16** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.16**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Install

```bash
npm i -g @xrkseek/harness-cli@0.5.16
xrkh web
```

Then hard-refresh the client half. Desktop: install this release’s `xrk-harness-0.5.16-win-x64` (or signed) package, or update in-app from an older install.

## Verify

* Desktop: the foot chip shows “update available” → open the dialog and watch the meter; **Install and restart** stays disabled until 100% / “download finished”; then install and restart succeeds.
* `xrkh -v` / `npm view @xrkseek/harness-cli version` is `0.5.16`.
