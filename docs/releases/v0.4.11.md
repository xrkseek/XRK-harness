# v0.4.11

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.10](./v0.4.10.md)：压住长驻 Host 在 Mux 重连与帧扇出路径上再次顶满堆（约 4GB OOM）。

Relative to [v0.4.10](./v0.4.10.md): stop long-running Host heaps from climbing to ~4GB again on Mux reconnect and frame fan-out paths.

### 修复

* 修复 Face Mux WebSocket 发送队列：待发帧数 / UTF-8 字节设软顶（默认 2048 帧 · 32MiB）；超限断开对端，避免重连风暴下 JSON 帧在 Host 侧无限堆积。
* 修复 Mux 连接握手不再对冷会话全量 `readSessionEvents` / projection snapshot（仅驻留会话补队列与投影）；冷会话仍发 `session/subscribed`。
* 修复会话 LRU 驱逐时同步清理 `costMeterRoutes` · `sessionAgentPresets` · `sessionCwds` · `sessionHasImage` · `sessionImageScanned`（补齐 0.4.8 未清的小桶）。

### 其他变更

* 公开线 `@xrkseek/harness-cli@0.4.11`（热修；接管 `@latest`）。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.4.11
xrkh web
```

## 验证

* 多会话 + 断线重连后，Host 进程堆不再随重连次数持续爬升至 ~4GB。
* 工具/思考突发仍可推流；对端过慢时连接被干净断开并可重连。

---

### Fixed

* Face Mux WebSocket send queue: soft caps on pending frames / UTF-8 bytes (default 2048 frames · 32MiB); over budget terminates the peer so reconnect storms no longer retain unbounded JSON frames on the Host.
* Mux connect no longer fully hydrates cold sessions via `readSessionEvents` / projection snapshot (queue + projections only for resident sessions); cold sessions still receive `session/subscribed`.
* Session LRU eviction also clears `costMeterRoutes` · `sessionAgentPresets` · `sessionCwds` · `sessionHasImage` · `sessionImageScanned` (small buckets left after 0.4.8).

### Other changes

* Public line `@xrkseek/harness-cli@0.4.11` (hotfix; takes `@latest`).

## Install

```bash
npm i -g @xrkseek/harness-cli@0.4.11
xrkh web
```

## Verify

* With many sessions and disconnect/reconnect, Host heap no longer climbs toward ~4GB with reconnect count.
* Tool/think bursts still stream; a slow peer is cleanly disconnected and can reconnect.
