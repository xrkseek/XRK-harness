# v0.0.3

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.2](./v0.0.2.md)：默认联网搜索与 AGT 对齐；设置里的 bash / agent-loop 真正进 Agent；会话工作区绑定在重启后仍有效；去掉未接线的 Web Search 设置卡。

### 新增

* 新增默认联网搜索链路：无密钥时优先 Parallel Free MCP，失败回退 DuckDuckGo（可用 `XRK_WEB_SEARCH_PROVIDER` 钉死单一源）

### 完善

* 完善 Plugins 设置端到端：`bash` 的超时 / 输出上限与 `agent-loop` 的并行工具上限写入 Agent 运行时，改设置后使缓存 Agent 失效重绑
* 完善会话与工作区绑定：`workspaces.json` 持久化 membership，Host 重启后 `session.list` / Agent cwd 仍落在对应工程目录

### 删除

* 删除未接线的 Web Search Plugins 设置卡（`web-search-deepseek`）；搜索改由环境变量与默认级联配置，见 [web-tools](../web-tools.md)

### 修复

* 修复 Host / `restart` 后会话 cwd 漂回 serve 根目录、侧栏像绑在 XRK-harness 本仓的问题

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.3
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.3 web`
