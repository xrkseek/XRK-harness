# v0.7.22

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.21](./v0.7.21.md)：社区壁纸 / 表情包 Host 半可装可挂且立绘不再花屏；干员团队编辑与概况球联动；工作区发现可调；插件更新探测跟装包同源；自定义模型草稿关 Settings 不丢；Desktop 安装包自带 npm 可装社区包。

### 新增

* 社区 `dsh-plugin-wallpaper-engine` / `dsh-nekowhale-stickers`：装包 stage `lib/` 与运行时 deps，Cordis Host 半 live apply（工具 / skills / settings / HTTP / 桌宠）。
* Settings → 插件：**工作区发现**卡（`workspace-discovery`：活跃窗小时 · 活跃条数 · 列表上限）；`workspace_list` 默认只回活跃画布，休眠用 `query` / `includeInactive`。
* Settings → 模型：自定义提供方表单草稿跨关闭 Settings 保留（未保存前不丢填写）。

### 完善

* 干员团队：昵称 / 外形 / 位置 / 注入与工具面改完即存；外形预览跟概况球；职责与委派收进下方；工作区覆盖与升全局提示更清楚。
* 席位工具面：奇创 / IM / 干员家锁定为只读说明（干员家跟名册，不跟徽章选择器）。
* 干员家 posture / 工具文案：编排链与 `thread_message` / `workspace_session_prompt` 车道写清（不误派进项目编码仓）。
* 插件清单：更新探测走与 `plugin add` 相同的 registry / proxy；已装版本追上 latest 时徽标清除；结算经 `host/remote-event` 推壳。
* 社区 Cordis：`applyEntry` 先跑 schemastery `Config` 默认；`dshHomePath` 经 `@xrkseek/xrk-home-paths` 别名；tools/skills/settings/webServer 共享面可挂。
* Wallpaper baseline：`/rope-art/<name>.png` · `/about-qr/<file>` 直出 staged 真资源；缺 mascot/avatar 回诚实 404 JSON。
* Desktop afterPack：把 vendored npm 拷进 `resources/runtime/node`，安装包内 Settings 装社区插件可用 `npm pack`。

### 修复

* 修复 wallpaper 产品立绘被 1×1 假像素拉伸成红块 / 花屏（仅 scene 缺帧仍用透明 stub）。
* 修复 nekowhale 缺 `lib/` 或 Config 未解析时 Host 半挂不上却仍冒充 ready 的路径（无假 GIF stub）。
* 修复 Desktop FileSet 剥掉 `node_modules` 后安装包内无 npm、社区插件装不上的问题。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.22
xrkh web
```

桌面安装包见 GitHub Release `v0.7.22` 与站点下载页（AGT 上线后）。手机 APK 见对应 `XRK-harness-mobile` Release。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.21](./v0.7.21.md): community wallpaper / stickers host halves install and apply without fake-pixel art; Agent Team edits sync to Overview balls; workspace discovery is tunable; plugin update probes share install registry/proxy; custom-provider drafts survive closing Settings; Desktop ships vendored npm for community installs.

### Added

* Community `dsh-plugin-wallpaper-engine` / `dsh-nekowhale-stickers`: install stages `lib/` + runtime deps; Cordis host half live-applies (tools / skills / settings / HTTP / pet).
* Settings → Plugins: **Workspace discovery** card (`workspace-discovery`: active window hours · max active · list cap); `workspace_list` defaults to active canvases; use `query` / `includeInactive` for dormant.
* Settings → Models: custom-provider form drafts survive closing Settings (unsaved fields kept).

### Improved

* Agent Team: nickname / look / where / inject / tool surface save live; look preview matches Overview balls; duty & dispatch sit below; clearer workspace-override vs promote-to-global copy.
* Seat tool surface: 奇创 / IM / agent-home locks are read-only chips (agent-home follows the roster, not the badge picker).
* Agent-home posture / tool copy: dispatch lane and `thread_message` / `workspace_session_prompt` rules stay off project coding canvases.
* Plugin inventory: update probes use the same registry / proxy as `plugin add`; badges clear when installed catches latest; settle pushes `host/remote-event` to the shell.
* Community Cordis: `applyEntry` runs schemastery `Config` defaults first; `dshHomePath` aliased via `@xrkseek/xrk-home-paths`; shared tools/skills/settings/webServer surfaces.
* Wallpaper baseline serves staged `/rope-art/<name>.png` · `/about-qr/<file>`; missing mascot/avatar returns honest 404 JSON.
* Desktop afterPack copies vendored npm into `resources/runtime/node` so Settings can `npm pack` community plugins.

### Fixed

* Wallpaper product art no longer stretches a 1×1 fake pixel into a red/glitch blob (transparent stub only for missing scene frames).
* Nekowhale without staged `lib/` / unresolved Config no longer pretends ready (no fake GIF stub).
* Desktop FileSet no longer strips npm out of the packaged runtime (community plugin install works in the installed app).
