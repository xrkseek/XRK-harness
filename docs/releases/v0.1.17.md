# v0.1.17

## 新增 / Added

### 社区 Host（dsh-compat）

* 新增 **IM 长连接网关**（ADR-0006）：`im-vendor-ws-client` 进程内 WebSocket；`im-gateway-sidecar` HTTP relay；默认 `connection.gateway.*` → `state: bridge`（webhook · poll/SSE 并存）；`XRK_IM_GATEWAY_WS_URL` / `XRK_IM_GATEWAY_URL` + `XRK_IM_GATEWAY_TOKEN`
* 新增 **Vision 云端 inference**（`cloud-vision-inference` · `cloud-vision-routing`）：OpenAI-compatible `chat/completions` · **Anthropic Messages** · **Gemini generateContent**；analyze 路径全 async
* 新增 **embedded 向量库**（`embedded-vector-store`）：`~/.xrk/memory-embeddings/store.json`；noema 增删同步；`embedding.search` 顺序 sidecar → embedded → local hash
* 新增 **GenUI npm bridge**（`genui-npm-bridge`）：`/_dsh/genui/components/registry` · `resolve`；schema `type: npm` → React tree `NpmComponent`；`XRK_GENUI_NPM_ALLOWLIST` · `~/.xrk/genui/npm-components.json`
* 新增 **TongFlow Python bridge**（`tongflow-python-bridge`，ADR-0007）：`kind: python` / `node.python.*`；`XRK_TONGFLOW_PYTHON*` · `~/.xrk/tongflow/python.json`；`/tongflow/scan` 合并 Python inventory
* 新增 **Host boot**（`dsh-compat-boot`）：`prewarmDshCompatAdapters` 后重建向量索引 · 按 env 启动 IM WS · 探测 sidecar；`shutdownDshCompatServices` 于 Host 关闭
* 新增 **进程插件接线**：`kind: channel` · `policy` · `llm` 经 `wireComposition*`；Face **`processChannels/list`** 暴露 IM `bridge` / `sidecar` / `ws-client`

### CLI · 诊断

* 新增 `xrkh doctor` 项：`xrk-home` · `community-plugins`（staging client 数量）· `community-env`（IM / memory / genui / tongflow 摘要）· 开发树 `dsh-compat-host`

### 测例

* 新增 `dsh-compat-boot.test.ts` · `genui-tongflow-bridge.test.ts`；扩展 `im-long-lived-gateway` · `cloud-vision-routing` · `process-channels` · `doctor`

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.17
xrkh web
```

或 / or：`npx @xrkseek/harness-cli@0.1.17 web` · `npm i -g @xrkseek/harness-cli@latest`

### 社区 client 速查

```bash
xrkh plugin add dsh-wallet          # 示例；以 npm 实际包名为准
xrkh restart                        # 必须：重载 Host + boot 服务
xrkh doctor                         # xrk-home · 已装 client · 可选 env
```

可选 env（Host/CI）：见 [configuration.md](../configuration.md)「社区插件 Host」— `XRK_IM_GATEWAY_*` · `XRK_MEMORY_EMBED_*` · `XRK_GENUI_NPM_ALLOWLIST` · `XRK_TONGFLOW_PYTHON*`。

### 源码维护者

```bash
pnpm install && pnpm build
pnpm web:build && pnpm client:bundle && pnpm web:assemble   # 产品壳 dist
pnpm check                                                  # 门禁
pnpm test:web                                               # Playwright 17/17
pnpm release                                                # 需 NPM_TOKEN + gh auth
```
