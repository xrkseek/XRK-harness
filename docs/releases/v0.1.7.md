# v0.1.7

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.6](./v0.1.6.md)：侧栏**任意工作区**（含首次启动自动登记的 Desktop / 默认工作区）均可删除；删除后其会话进入「未分组」，文件夹与会话日志保留。

Relative to [v0.1.6](./v0.1.6.md): **any workspace** in the sidebar (including the auto-registered Desktop / default workspace on first launch) can be deleted; its sessions move to **Ungrouped** while folders and session logs stay intact.

公开线：**正式 0.1.7** + 预览 [v0.0.11](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md)。`latest` 指向本版。

Public line: formal **0.1.7** + preview [v0.0.11](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md). `latest` points here.

---

## 修复 / Fixed

* 修复删除工作区时误报 `cannot delete default workspace`、导致 Desktop 等工作区无法移除的问题
* 修复删除非默认工作区时会话被塞进默认工作区而非「未分组」、与侧栏文案不一致的问题

## 完善 / Improved

* 完善工作区删除语义：仅移除侧栏登记，目录与会话日志保留；会话 cwd 不变
* 完善持久化：已从侧栏删除的默认工作区在重启后不再自动复活
