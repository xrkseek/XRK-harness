# v0.0.1

> **读者**：终端用户 · 维护者（发行说明）。

首个公开发行版。版本线从 **0.0.1** 起算；此前试验性 `0.1.x` GitHub Release / npm 版本已撤下。

### 新增

* 对外 CLI **`@xrkseek/harness-cli`**（bin `xrk-harness`）：`run` / `serve` / `web` / `doctor` / `dump-config`
* 产品网页壳随包附带（`product-web/`）：会话、Settings、MCP、模型与凭据
* Session 事件为对话真源；SQLite 持久化（默认 `~/.xrk/sessions`）；可选压缩与上下文用量展示
* Host Face：HTTP · Unary RPC · 双 WebSocket；preset `minimal` / `harness` / `server`
* LLM Registry：多厂商协议包（含 DeepSeek / OpenAI 兼容 / Anthropic / Gemini 等接线）
* MCP：stdio / streamable-http；设置卡可配置并热挂载（默认 deny）
* 发行三通道：npmjs · GitHub Packages · GitHub Release 离线 tarball

### 其他变更

* 包注册表改为 **registry.npmjs.org**（不再以 GitHub Packages 为用户默认安装源）
* 工具链要求 Node ≥26；pnpm 钉根 `packageManager`（当前 11.22.0），本机用 `npm install -g` 对齐

## 安装

```bash
npx @xrkseek/harness-cli@0.0.1 web
```

或全局：

```bash
npm install -g @xrkseek/harness-cli@0.0.1
xrk-harness web
```

离线：GitHub Release 资产 `xrkseek-harness-cli-0.0.1.tgz`。
