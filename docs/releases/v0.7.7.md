# v0.7.7

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

## 中文

相对 [v0.7.6](./v0.7.6.md)：语音输入/听写与朗读产品化落地——本地 SenseVoice 资产下载与就绪检测、ASR/TTS 设置卡片、对话框内麦克风按钮与系统 TTS；子代理与模型路由可固定/可追踪；启动卡住检测；图片自动降采样；Our Free Model 路由与凭据同步更稳；装扮/对话/附件一批体验修正。

### 新增

* **本地语音 (ASR) 产品化**：SenseVoice 资产下载/校验/就绪检测、ASR 设置卡片与「试一句」入口；麦克风按钮未就绪时打开准备对话框而非报错。
* **TTS 产品化**：系统 TTS 与 TTS 设置卡片，朗读工具接入。
* **对话内语音输入按钮** (`VoiceInputButton`) 接入组装式 composer。
* **启动卡住检测** (`boot-stall`)：启动超时可识别并提示。
* **图片自动降采样** (`downscale-image`)：大图进入请求前自动缩放。
* **子代理路由固定** (`subagent-route-pin`) 与模型目录守卫 (`session-model-catalog-guard`)：子代理模型路由可固定、可追踪。
* **装扮配色一致性守卫** (`presence-dressing-parity`)：三处装扮列表保持一致。

### 完善

* **Our Free Model Host**：路由与凭据同步、模型目录刷新更稳。
* **子代理工具面** (`subagent-tools`) 扩展：路由/固定/通知链路更完整。
* **对话体验**：ChatView、ProcessGroupSeat、presentation-policy、InputBar 一批交互修正；组装式 composer 测试覆盖。
* **模型选择** (`select-session-model`、`model-catalog`)：路由解析与展示更稳。
* **附件**：MessageImage 与降采样协同。

### 修复

* **语音资产**：下载中断不残留半截文件；就绪状态准确反映。
* **装扮**：三处列表缺项导致「能选但概况球读回 none」的问题有守卫覆盖。
* **启动**：Host 启动阻塞场景可识别。

# Release Notes

> **Audience**: End users · Maintainers

## English

Relative to [v0.7.6](./v0.7.6.md): voice input/dictation and text-to-speech productization — local SenseVoice asset download and readiness checks, ASR/TTS settings cards, in-composer microphone button and system TTS; pinnable/traceable subagent model routing; boot-stall detection; automatic image downscaling; steadier Our Free Model routing and credential sync; plus dressing/conversation/attachment polish.

### Added

* **Local speech (ASR) productization**: SenseVoice asset download/verification/readiness, ASR settings card and “try a phrase” entry; the mic button opens a setup dialog instead of erroring when not ready.
* **TTS productization**: system TTS and TTS settings card, read-aloud tool wiring.
* **In-conversation voice input button** (`VoiceInputButton`) in the assembled composer.
* **Boot-stall detection** (`boot-stall`): recognizes and reports a stalled startup.
* **Automatic image downscaling** (`downscale-image`): large images shrink before entering requests.
* **Subagent route pinning** (`subagent-route-pin`) and model-catalog guard (`session-model-catalog-guard`): pinnable, traceable subagent model routing.
* **Dressing parity guard** (`presence-dressing-parity`): keeps the three dressing lists in sync.

### Improved

* **Our Free Model Host**: steadier routing/credential sync and model-catalog refresh.
* **Subagent tool surface** (`subagent-tools`): more complete routing/pin/notice flow.
* **Conversation UX**: ChatView, ProcessGroupSeat, presentation-policy, InputBar fixes; assembled-composer test coverage.
* **Model selection** (`select-session-model`, `model-catalog`): steadier resolution and display.
* **Attachments**: MessageImage cooperates with downscaling.

### Fixed

* **Voice assets**: interrupted downloads leave no partial files; readiness reflects reality.
* **Dressing**: missing entries across the three lists (selectable but read back as `none` on the overview ball) now guarded.
* **Startup**: Host boot-block scenarios are now detectable.
