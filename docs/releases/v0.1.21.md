# v0.1.21

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.20](./v0.1.20.md)：工作区 inject 策略收口——单真源、去冗余路径；home `~/.cursor/**` 不再 standing 注入；skill 目录按 `.xrk` → `.agents` → `.cursor` 优先级合并。

Relative to [v0.1.20](./v0.1.20.md): workspace inject policy consolidation — single source of truth, redundant paths removed; home `~/.cursor/**` no longer standing-injected; skill dirs merge with `.xrk` → `.agents` → `.cursor` priority.

---

## 完善 / Improved

* 完善 inject 真源：`packages/workspace/src/inject-sources.ts`（`HOME_CONVENTION_INJECT` · `WORKSPACE_CONVENTION_INJECT` · skill 根列表）
* 完善 standing instructions：全局层不扫 `~/.cursor/rules`；工作区 `{root}/.cursor/rules/**` 仍注入（单文件 `xrk-inject: false` 可跳过）
* 完善 skill catalog：同名按 vendor 优先级合并（`.xrk/skills` 优先）；home skills 默认不进 standing catalog，仍经 `skill` 工具按需加载
* 完善 fingerprint：分层 marker 与 inject 策略对齐，减少无效重扫

---

## 修复 / Fixed

* 修复 Host 将 Cursor 维护者 home 树（`~/.cursor/**`）误注入产品 Agent 上下文的问题
