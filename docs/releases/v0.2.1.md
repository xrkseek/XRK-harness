# v0.2.1

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.2.0](./v0.2.0.md)：加固 Session 持久化驻留 LRU——进行中的 turn 不再被挤出内存，避免多 subagent 场景下偶发的 OpenAI `tool_calls` 配对 400。

Relative to [v0.2.0](./v0.2.0.md): harden Session persistent-store resident LRU so in-flight turns are not evicted, preventing intermittent OpenAI `tool_calls` pairing HTTP 400s when many subagents run together.

---

## 完善 / Improved

* Session SQLite 仓：驻留 LRU 跳过**未闭合 turn**；必要时允许临时超过 `maxResidentSessions`；淘汰前先 `flush` chunk 批再通知 Face checkpoint（见 [session.md](../session.md) · [session-log.md](../session-log.md)）
* 导出 `sessionHasOpenTurn`，供仓与测试判定开洞 turn

## 修复 / Fixed

* 修复多会话并行时：进行中 session 被 LRU 挤出 → 重水合 `repairOpenTurnEvents` 插入带 `toolCalls` 的 interrupted assistant，活 turn 继续写出第二条 assistant → 模型请求 `tool_calls` 未紧跟 tool 消息导致 **HTTP 400**

## 删除 / Removed

* 移除仓内 Cursor co-author 防护 hook / rule / 维护笔记扩写（不作为产品能力保留）

## 其他变更 / Other

* 公开基线 **v0.2.1**（npm **`@latest`**）；上一版 **v0.2.0**；正式留档仍为 **v0.1.31**
* CLI / SDK 包版本对齐 **0.2.1**

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.2.1
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后执行 `xrkh restart`，浏览器硬刷新。若旧会话已写入损坏的双 assistant(tool_calls) 日志，删除该会话后新建即可。
