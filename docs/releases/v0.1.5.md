## 完善 / Improved

* 完善 Face **`contextTimeline`** / **`contextHeaders`** 投影：`dsh-context` 可显示 system / tools / 消息类 **项数**与 toolList，不再仅有 token 数字
* 完善 **`costUsage`** 投影：接入 bundled 计价，`dsh-cost-meter` 会话 cost 字段可为非零估算
* 完善 Sidebar **`subagents.live`**：返回 `{ live: { [childId]: … } }`，running 子代理显示最新 chunk / tool 行
* 完善兼容器能力矩阵 **`DSH_COMPAT_KNOWN_GAPS`**，与 [community-plugins.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/community-plugins.md) 待补项一致
* 完善 `pnpm release`：转发 `NPM_CONFIG_OTP` / `NPM_OTP`；stage 不再全局 `CI=true` 卸掉 typescript，不再批量改写 workspace `package.json`

## 修复 / Fixed

* 修复 **`dsh-context`「有 token、0 项」**：兼容器曾下发空 nodes / headers stub
* 修复 CI 干净树 **`@xrkseek/client-ui-slots`** 入口解析失败（Vitest alias 至源码）
* 修复发版 stage 误跑 `ensurePrivateSurface` 类副作用导致工作区 package 被改乱的问题

## 其他变更 / Other changes

* 需要 Node **≥26** — [getting-started.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/getting-started.md)
* 记忆 embedding、云端 Vision 路由、IM 长连接网关等仍为诚实 stub / 待补 — 见 [status.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/status.md) 与矩阵 gaps
