# v0.1.5

相对 [v0.1.4](./v0.1.4.md)：MCP 设置卡 UX、插件输入框边框、Windows 目录浏览、CI pnpm。

## Face / 壳

- **MCP 设置卡**：与 Agent/Bash 同构的竖排字段（名称 / 传输 / 命令 / 参数 / 工作目录）；软边框；去掉框套框。
- **插件表单输入**：与 Models 一致的 `layer-1` + 软边框；中和浏览器 autofill 浅色底。
- **目录浏览**：Windows 用户目录隐藏「开始」菜单 / Application Data 等受保护 junction，避免点进 EPERM。
- **serve 日志**：启动时打印 `workspace=`（项目根）与 `sessions=`（默认 `~/.xrk/sessions`）。
- **MCP JSON**：Settings 粘贴框接受 Cursor `{ "mcpServers": { "name": { "command", "args" } } }`。

## CI

- `pnpm/action-setup` 不再写死 `version: 9`（与 `packageManager: pnpm@9.15.0` 冲突）。

## 安装

```bash
mkdir my-workspace && cd my-workspace
npm install -g @xrkseek/harness-cli@0.1.5 --registry=https://npm.pkg.github.com
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.1.5 web`。Release：`xrkseek-harness-cli-0.1.5.tgz`。
