# v0.5.8

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.5.7](./v0.5.7.md)：空闲首发不再闪排队栏；用户 Stop 不再误开模型重试条；重试 UI 取消后不再冻住后续对话；后台子代理完成通知与前台同走 12KB bound/spill；会话顶栏 Agent 徽章改为更大药丸形。

Relative to [v0.5.7](./v0.5.7.md): idle first-send no longer flashes the queue dock; user Stop no longer schedules a model-retry banner; cancelling a painted retry no longer freezes later turns; background subagent completion notices share the 12KB bound/spill path with foreground tools; session-header Agent badge is a larger pill.

### 完善

* 完善会话顶栏 Agent 预设徽章：灰色底略加大，圆角改为**药丸形**。
* 完善后台子代理完成通知：答案经 `boundChildAnswer`（≤12KB 内联，超限 spill），去掉旧的 **2000 字硬截**；`wait_agent` 工具描述改为短交叉引用，避免与 `subagent` 重复占上下文。
* 完善工具输出文档：标明短答案内联、空 `tool-outputs` 为常态，以及后台通知已与前台 bound 对齐。

### 修复

* 修复**空闲会话首发**消息在排队栏闪一下再进正文：Host 短暂入队不再把本地 `transcript` 回显降成 `queued`。
* 修复用户 **Stop** 后出现「正在重试模型请求 (1/5)」：`AbortSignal.reason`（`{ kind: "user" }`）被适配层误标成可重试 TRANSPORT；现归为 **ABORTED**，且 signal 已中止时不再写 `llm/retry`。
* 修复 Stop / 截断后重试条导致**后续消息被吞、刷新才见**：已可见的 model-retry 改为 `visibility: hidden`，不再撤回物化节点以免 Assembler 抛错冻住快照。
* 修复父会话自然结束误杀子代理、用户 Stop 父级联子且不发完成通知、子异常截断应回传等父子中止口径（与会话 latch / suppress 契约一致）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.8`**（接管 npm `@latest`）；npmjs 保留 **0.5.8** 与回退钉 **0.3.11**。
* Desktop 私有壳版本对齐 **0.5.8**；`apps/cli` / `apps/desktop` / `packages/sdk` 版本同步。

## 验证

* 空会话发一条消息 → 直接出现在对话流，排队栏不闪。
* 回合中点 Stop → 不出现「正在重试 (1/5)」；失败原因不再是 `openai-compatible: {"kind":"user"}`。
* 曾出现重试条后继续发消息 → 无需刷新即可看见新消息。
* 后台子代理写完较长正文 → 父会话 steer 通知含全文或 spill 路径，不是 2k 截断。
* 顶栏「XRK Harness」徽章为药丸形、略宽于上一版。

---

### Improved

* Session-header Agent preset badge: slightly larger gray plate, **pill** corners.
* Background subagent completion notices run through `boundChildAnswer` (inline ≤12KB, spill above) instead of a **2000-char hard clip**; `wait_agent` description is a short cross-ref to `subagent`.
* Tool-output docs: short answers stay inline; empty `tool-outputs` is normal; background notices match the foreground bound.

### Fixed

* Idle first-send no longer flashes the queue dock: a brief Host queue frame does not demote a local `transcript` echo to `queued`.
* User **Stop** no longer opens 「retrying model request (1/5)」: typed `AbortSignal.reason` (`{ kind: "user" }`) maps to **ABORTED**, not retryable TRANSPORT; an aborted signal never appends `llm/retry`.
* A painted model-retry cancelled by Stop no longer **swallows later messages** until refresh: hide the node instead of withdrawing a materialized target (Assembler freeze).
* Parent natural end vs user Stop cascade vs abnormal child report-back match the session latch / suppress contract.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.5.8`** (owns npm `@latest`); npmjs keeps **0.5.8** and rollback pin **0.3.11**.
* Desktop private shell aligned to **0.5.8**; `apps/cli` / `apps/desktop` / `packages/sdk` versions move together.

## Verify

* Empty session, one send → lands in the transcript; queue dock does not flash.
* Stop mid-turn → no 「retrying (1/5)」; failure text is not `openai-compatible: {"kind":"user"}`.
* After a retry row appeared, further sends paint without a refresh.
* Background child with a long body → parent steer notice has the full answer or a spill path, not a 2k clip.
* Header 「XRK Harness」 badge reads as a larger pill.
