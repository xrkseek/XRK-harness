# v0.7.1

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.0](./v0.7.0.md)：向日葵免费车道对齐 OFM（OpenCode / Kilo 分流）；默认菜单卡片恢复不透明；社区 Settings 在无真实 Host API 时不再因缺数组崩溃。

Relative to [v0.7.0](./v0.7.0.md): Sunflower free lane aligned with OFM (OpenCode / Kilo split); default menu cards opaque again; community Settings no longer crash on missing arrays when no real Host API claimed the route.

### 完善

* **向日葵免费 · OpenCode**：指纹对齐 OFM v2（UA `2.0.26`、官方 `read`/`shell`、`<env>` + placeholder；不粘贴 OC persona）；`working_directory` 线别名。
* **向日葵免费 · Kilo**：Host 直连 `api.kilo.ai`，**不依赖 Bun**（与 OFM `egressFetch` 一致）；有 OpenCode 时单独 brand `sunflower-kilo`。
* **Bun**：Desktop / CLI **不再随包**；用户自装后才启用 OpenCode；未安装则静默省略。

### 修复

* **默认菜单 / 弹出卡片**：恢复不透明表面（`--dsw-menu-surface-fill` 回 `bg-layer-3`）；社区主题仍可重绑半透明。
* **社区 Settings 兜底形状**：未登记 / 未 apply 的 Cordis Host API 被 catch-all 命中时，OFM `/stats` 等路径补齐面板硬依赖的空数组（`days` / `models` / `samples`），避免整页 Slot 崩。**这不是插件可用替代实现**——正常用 OFM 仍须装包并 apply Host 半；其它包同理应走真实适配器，而不是靠兜底假数据。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.1
xrkh web
```

亦可 `npm i -g @xrkseek/harness-cli@latest`（发包后指向本版）。
