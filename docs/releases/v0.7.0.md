# v0.7.0

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.23](./v0.6.23.md)：`0.7.x` **正式线首发**，接管 npm **`@latest`**。并入过程号 [rc.1](./v0.7.0-rc.1.md) · [rc.2](./v0.7.0-rc.2.md) · [rc.3](./v0.7.0-rc.3.md)：上下文工程重排、大会话读写、席位 / 向日葵命名、DeepSeek 搜索与交付物过程折叠、以及聊天主路径键盘焦点与「插队」术语收口。

Relative to [v0.6.23](./v0.6.23.md): **opens the `0.7.x` formal line** and takes npm **`@latest`**. Folds process numbers [rc.1](./v0.7.0-rc.1.md) · [rc.2](./v0.7.0-rc.2.md) · [rc.3](./v0.7.0-rc.3.md): context-engineering re-lay, large-session I/O, seat / sunflower naming, DeepSeek search and deliverable process-fold rules, plus chat keyboard focus and steer terminology close-out.

### 新增

* **经理专属 ledger `XRK.md`**：仅 `audience=user`（编码主会话）注入；干员 / 委派子席不注。产品站立与家约定不随 Audience 省略。
* **指令权威车道 `<instruction_authority>`**：order（站立 · 家约定 · 盘上规则 · 本回合口述）与 data（工具/网页/他会话）分车道；插件可扩展。
* **席位碎片 `<seat_identity>` / `<boss_status>`**：员工席 turn-start 身份与老板状态；Overview 老板球可开心情 / 状态 / 昵称。
* **Skill 渐进披露（无 `skill_search`）**：catalog 短 blurb → `skill` 精确名拉正文；优先序干员公文包 → 工作区 + 家 `xrk-*` → 全局可截。
* **Claude Code mods 运行时** + 输入区 Mods 带：观察 / 拒绝 / 改写工具调用；AbovePrompt 声明式控件回传。
* **添加干员工作区面板**、协作板 peer 字段、`session.eventWindow` / `session_trace`、影子 git `reclaim()`。
* **DeepSeek Search 提供方**：仅钉选时走网页搜索（不进 Auto）；`web_search` 可选 `proxy`。
* **过程折叠独立工具**：`present` · `ask_user_question` · `todo_write` · 图/视频生成 · `propose_skill` 始终平铺；`present` 行强制展开。
* **内置干员多语正式名** + **向日葵命名契约**：正式名 `向日葵` / `Sunflower` / `ひまわり`，锁定昵称 `xrkseek`；概况右球 `经理 · 向日葵（xrkseek）`。
* **对话「插话」轮次标**、席位信道前缀、Team live 昵称 / 外观覆盖、策展记忆 live 片段、向日葵免费 Settings 卡。
* **会话缓存回收**、Host `canOpenPath`、公网 `--host 0.0.0.0`（非回环武装 PIN；不保证公网安全）。

### 完善

* **大会话 I/O**：编辑重发 / truncate 物理尾删；fork SQL 前缀拷；冷开 history 尾读；history 投影盘缓存；写前语义 `flush`。
* **Audience 闸口收窄**：只闸经理 ledger；`subagent` / `minimal` 保留站立并同注家约定。
* **经理 vs 向阳工具面**：经理默认 coding-light；设置 / 管理面挂向阳。
* **概况 / 干员团队**：`正式名（昵称）`；席位卡短签 + 省略；改昵称即时上球，改装扮不清昵称。
* **模型设置 Default Model**：提供方顺序变更走软刷新，卡不再卸载。
* **后台子代理父会话镜像**：延到 `prompt/promoted` 再写进父 transcript。
* **软预算对齐 Codex**：留空按窗×90% 仍主动压；有圆环取更紧；压缩后保留提供方压力。
* **模型选择菜单**：冷开无伪 hover；长目录可滚。
* **聊天键盘一等**：复制 / 编辑 / 加载更早 / 回底 / 工具披露 / 压缩行对齐 Composer `:focus-visible` 环；Disclosure 行 `:focus-within` 可见 chevron。
* **轮次轨**：去掉 frame `height` 过渡，折叠瞬时落地。
* **「插队」术语**：忙时徽章与撤回 / 占位同词根（中「插队中」· 英 Steering… · 日 ステア中…）。
* **turn-cut 分支**：已关闭回合上的分支不因同轮后续 steering / 工具节点禁用（Host 锚定 ≥seq 的首个 `turn/end`）；再生成 / 恢复仍 tip-gate。
* **社区 Host 装包 / OFM**：根 Cordis `index.js` 按磁盘布局 staging；channel-pack 经 `connection.fetch` 晚绑定；wallet 根路径与 POST-only 路由诚实 405。
* **鲸女 live meter**：`/dsh-whale-girl/api/state` 走 Face cost-meter + 活跃会话投影（不扫全库）。

### 删除

* **产品 plan 模式**：`/plan` 仅退役提示；目录去掉 `exit_plan_mode`。大活同会话 outline → ask → `todo_write`。
* **仓库内产品人格副本当站立真源**：站立走 `~/.xrk` 种子；工作区不再依赖 `.agents/AGENTS.md` / `SOUL.md` 充当产品站立。

### 修复

* 编辑重发 / 再生成误读 `.ok` 假失败；截断后投影残留导致轮次虚增。
* 拖动提供方顺序后 Default Model 卡消失；live 仅改外观时 `nickname:null` 盖掉昵称。
* 向日葵显示成 `xrkseek（向日葵）`；向日葵免费 remount 热同步。
* 无头 Linux `host.openPath` 接受 `not-implemented`。
* 软压过晚 / 压完假撑满（压缩后清空提供方压力）。
* 社区 ModuleLoader 裸名 / scoped 双注册竞态（并行 prefetch 误报「未 register」）。
* Settings 在 Host 半缺失时对 OFM summary 等路径的 `.filter` 崩溃（incomplete 形状补数组）。
* 向日葵免费 OpenCode 车道：对齐 OFM `/inference/v1`（旧 `/inference/openai/v1` 已 404）；补 `x-opencode-project`、去掉 `tool_choice: none`、额度拒绝时不轮换 session。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.7.0`**（接管 npm **`@latest`**）。过程号 `0.7.0-rc.*` 仍可精确安装；`@rc` 可继续指向最近 rc 或随发包策略更新。
* Desktop 私有壳对齐 **0.7.0**（与 `apps/cli` / `packages/sdk` 同号）。
* `0.6.x` 预览线以 **v0.6.23** 收官；回退钉仍为 **0.3.11**。

* `@latest` 解析为 `0.7.0`；`xrkh web` 可起。
* 向阳概况：右球 `经理 · 向日葵（xrkseek）`；干员球 `正式名（昵称）`。
* Settings → Models：拖动提供方顺序后 Default Model 仍在。
* 同轮插话标「第 N 轮 插话」；忙时徽章为「插队中」。
* Tab：聊天列图标动作 / 加载更早 / 回底 / 工具披露 / 压缩行可见焦点环。

# v0.7.0

> **Audience**: End users · Integrators · Maintainers (release notes)

Relative to [v0.6.23](./v0.6.23.md): **opens the `0.7.x` formal line** and takes npm **`@latest`**. Folds process numbers [rc.1](./v0.7.0-rc.1.md) · [rc.2](./v0.7.0-rc.2.md) · [rc.3](./v0.7.0-rc.3.md): context-engineering re-lay, large-session I/O, seat / sunflower naming, DeepSeek search and deliverable process-fold rules, plus chat keyboard focus and steer terminology close-out.

### Added

* **Manager-only ledger `XRK.md`**: inject only for `audience=user`; delegated children omit it. Product standing and home convention stay.
* **Instruction-authority lane `<instruction_authority>`**: order vs data; plugins may extend.
* **Seat fragments `<seat_identity>` / `<boss_status>`**: turn-start identity plus Boss mood sheet on Overview.
* **Progressive skills (no `skill_search`)**: short catalog blurbs → exact-name `skill` body; briefcase → workspace + home `xrk-*` → global truncatable.
* **Claude Code mods runtime** + Mod band: observe / deny / rewrite tool calls; declarative AbovePrompt controls.
* **Add-agent workspace panel**, collaboration peer fields, `session.eventWindow` / `session_trace`, shadow-git `reclaim()`.
* **DeepSeek Search provider**: pin-only web search (not Auto); optional `web_search` `proxy`.
* **Process-fold independents**: `present` · ask · todo · image/video gen · `propose_skill` stay flat; `present` rows force-expanded.
* **Locale catalog formals** + **Sunflower naming contract**: formal 向日葵 / Sunflower / ひまわり with locked nick `xrkseek`; Overview right ball `经理 · 向日葵（xrkseek）`.
* **Steer round marks**, seat-channel prefixes, Team live nick/look overlay, curated-memory live fragment, Sunflower-free Settings card.
* **Session-cache reclaim**, Host `canOpenPath`, public bind `--host 0.0.0.0` (PIN off loopback; no public-security guarantee).

### Improved

* **Large-session I/O**: edit-resubmit / truncate tail-delete; fork SQL prefix copy; cold history tail read; history projection disk cache; semantic pre-write `flush`.
* **Audience gate narrowed**: manager ledger only; `subagent` / `minimal` keep standing and home convention.
* **Manager vs 向阳 tool surface**: manager coding-light; admin tools on 向阳.
* **Overview / Team**: `formal（nick）`; short contained seat tiles; nick live, look-only keeps nick.
* **Models Default Model**: soft refresh on provider reorder — card stays mounted.
* **Background-subagent parent mirror**: waits for `prompt/promoted`.
* **Codex-aligned soft budget**: blank = window×90% still proactive; tighter with provider ring; keep pressure across compact.
* **Model menu**: no cold-open pseudo-hover; long lists scroll.
* **Chat keyboard first-class**: copy / edit / load-earlier / to-bottom / tool disclosure / compaction match Composer `:focus-visible`; Disclosure `:focus-within` shows chevron.
* **Turn rail**: drop frame `height` transition — folds land instantly.
* **Steer terminology**: busy badge shares the steer word family (zh 插队中 · en Steering… · ja ステア中…).
* **Turn-cut branch**: closed-turn fork stays enabled with later same-turn steering / tools (Host anchors first `turn/end` ≥ seq); regenerate / restore stay tip-gated.
* **Community Host install / OFM**: root Cordis `index.js` staged by on-disk layout; channel-pack late-binds via `connection.fetch`; wallet roots and POST-only routes return honest 405.
* **Whale-girl live meter**: `/dsh-whale-girl/api/state` from Face cost-meter + active-session projection (no full-store fold).

### Removed

* **Product plan mode**: `/plan` is a retire notice only; `exit_plan_mode` dropped. Large work uses outline → ask → `todo_write` in-session.
* **In-repo persona copies as standing source**: standing comes from `~/.xrk` seeds; workspace no longer treats `.agents/AGENTS.md` / `SOUL.md` as product standing.

### Fixed

* Edit-resubmit / regenerate false `.ok` failures; truncate leftover projection inflating turn counts.
* Default Model card vanishing after provider reorder; look-only live `nickname:null` wiping nick.
* Sunflower shown as `xrkseek（向日葵）`; Sunflower-free remount hot-sync.
* Headless Linux `host.openPath` accepts `not-implemented`.
* Soft-budget too late / fake-full after compact cleared provider pressure.
* Community ModuleLoader bare/scoped dual-register race (parallel prefetch false “without registering”).
* Settings `.filter` crash on OFM summary-shaped paths when Host half missing (incomplete bodies supply arrays).
* Sunflower-free OpenCode lane: align to OFM `/inference/v1` (legacy `/inference/openai/v1` 404s); send `x-opencode-project`, strip `tool_choice: none`, keep session on quota refusal.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.7.0`** (takes npm **`@latest`**). Process numbers `0.7.0-rc.*` remain installable by exact pin; `@rc` may keep pointing at the newest rc per publish policy.
* Private Desktop shell aligns to **0.7.0** (same number as `apps/cli` / `packages/sdk`).
* The `0.6.x` preview line closed at **v0.6.23**; rollback pin remains **0.3.11**.
