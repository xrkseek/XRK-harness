# v0.8.12

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.11](./v0.8.11.md)：站立工具声明在同系列内字节冻结，折叠行间距在手机与桌面拉齐。

### 完善

* **工具声明字节冻结**：同系列仍在的工具复用上次 `description` / `parameters`；`dynamicSchema` 文案抖动不再整段打掉提供方前缀缓存；新工具仍只在 `tools[]` 尾部追加。
* **折叠行间距**：过程 / 终端 / 思考 / 工具统一为标题 — › — · — 摘要等距（6px），手机与桌面一致。
* **工具结果写入时剪枝**：过大 `tool/result` 落盘即截断，避免软压晚改早期结果砸掉提供方前缀缓存。
* **system 变更瘦身 header**：仅 system 抖动时写不含 `tools[]` 的 `request/header`，排障可见且不重写整段工具声明。

### 其他变更

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.11](./v0.8.11.md): freeze standing tool declaration bytes within a series, equalize fold-row spacing, and keep prefix cache stable under prune / system deltas.

### Improved

* **Standing tool schema freeze**: survivors reuse the prior wire `description` / `parameters`; `dynamicSchema` copy jitter no longer busts the provider prefix cache; new tools still append at the `tools[]` tail only.
* **Fold-row spacing**: process / terminal / think / tools share equal title — › — · — summary gaps (6px) on phone and desktop.
* **Write-time tool-result prune**: oversized `tool/result` bodies are truncated when written, so soft-budget no longer rewrites early callIds and cliffs the provider prefix cache.
* **Slim system-only headers**: system-only deltas log a `request/header` without rewriting `tools[]`, for auditability without re-emitting the full tool schema.
