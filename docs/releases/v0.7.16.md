# v0.7.16

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.15](./v0.7.15.md)：手机触屏会话/模型拖拽重排可用；工作区文件下载走壳通道；Linux guest / 手机 Host 首次站立不再误挂 `/root` 工作区。

### 完善

* 侧栏会话与设置→模型：触屏长按约 0.4 秒后拖拽重排；按下即 `touch-action: none`，避免列表滚动抢走手势。
* 桌面鼠标仍走 HTML5 拖放；带触屏的混合设备优先长按路径。
* 工作区打开 / 会话日志导出：手机壳经原生下载通道落盘，不再依赖失败的 `blob:` 地址。

### 修复

* 首次启动只登记向阳空间：Linux guest（cwd=/root）不再把 `/root` 当成编码工作区。
* 手机 `xrkh serve` 可显式钉向阳路径，避免默认 cwd 再挂出一个 root 工作区。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.16
xrkh web
```

桌面安装包见 GitHub Release `v0.7.16` 与站点下载页（AGT 上线后）。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.15](./v0.7.15.md): phone touch can reorder sessions and model providers; workspace file downloads use the shell channel; Linux guest / mobile Host first boot no longer mint a `/root` coding workspace.

### Improved

* Sidebar sessions and Settings → Models: hold ~0.4s then drag to reorder on touch; `touch-action: none` from press so the scroller cannot steal the gesture.
* Desktop mouse keeps HTML5 DnD; hybrid devices with a coarse pointer prefer the long-press path.
* Workspace open / session-log export: the mobile shell saves through the native download channel instead of failing `blob:` URLs.

### Fixed

* First boot keeps only Xiangyang: Linux guest (cwd=/root) no longer registers `/root` as a coding workspace.
* Mobile `xrkh serve` can pin the Xiangyang path so default cwd cannot mint a root project workspace.

## Install

```bash
npm i -g @xrkseek/harness-cli@0.7.16
xrkh web
```

Desktop installer: GitHub Release `v0.7.16` and the site download page (after AGT publish).
