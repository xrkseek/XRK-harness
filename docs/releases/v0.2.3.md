# v0.2.3

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.2.2](./v0.2.2.md)：侧栏 `/sidebar/*` 升为 Host 原生公共路由；子代理 live 活动线改为嵌套 `tool` wire；去掉 Side Chat；会话 catalog 空值加固。

Relative to [v0.2.2](./v0.2.2.md): mount `/sidebar/*` as a first-class Host public handler; nest `tool` on subagent live lines; remove Side Chat; harden empty session catalog entries.

---

## 完善 / Improved

* Host 经 `createSidebarPublicHandler` 挂载 `/sidebar/*`（`@xrkseek/server-http/sidebar`），不再经 dsh-compat 能力表；社区客户端共用同一契约
* `subagents.live` wire：`{ text?; tool?: { name; args } }`（`sidebar-live-line`）
* `SessionManager`：catalog `entries` 缺省按 `[]` 处理，避免 UI 读 `length` 崩溃

## 删除 / Removed

* Side Chat（beta）及 Host `sidechat.*` 桥接；子代理 / 后台任务走 Face + `subagents.live` / `jobs.*`

## 修复 / Fixed

* 子代理活动预览在旧扁平 `tool` 形状下对 `args` 误读导致的崩溃路径（配合侧栏插件 **0.18.1** 双形状兼容）

## 其他变更 / Other

* 公开基线 **v0.2.3**（npm **`@latest`**）；上一版 **v0.2.2**；正式留档仍为 **v0.1.31**
* CLI / SDK 包版本对齐 **0.2.3**
* 建议侧栏：`xrkh plugin add xrkh-better-sidebar@0.18.1`
* 契约：[community-plugins.md](../community-plugins.md)

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.2.3
xrkh web
xrkh plugin add xrkh-better-sidebar@0.18.1
xrkh restart
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

**建议 / Tip**：升级后硬刷新浏览器（Ctrl+Shift+R）。
