# v0.3.1

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.0](./v0.3.0.md)：修正用量面板误显示 `xrk/unknown`、MCP Settings 对象式 mutate、以及任务列表亚秒时长显示。

Relative to [v0.3.0](./v0.3.0.md): fix usage panel `xrk/unknown`, MCP Settings object-map mutate, and sub-second job duration display.

---

## 完善 / Improved

* 任务列表时长：不足 10 秒显示一位小数；极短任务不再整片显示 **0秒**
* 任务状态文案带 exit code 明细（如 `已完成 · exit code: 0`）
* 用量浮层隐藏遗留占位路由，避免把假模型名当成真实选型

## 修复 / Fixed

* Face 把助手消息 `source` 从会话 `request/header` / 当前选型灌入，用量 UI 不再固定成 **`xrk/unknown`**
* 历史回放同样按最近一次 `request/header` 标注 provider/model
* MCP `settings_mutate`：Cursor 风格 `servers` 对象 map / `{ mcpServers }` 先规范成数组再校验落盘（不再 `expected array`）

## 其他变更 / Other

* CLI / SDK（`@xrkseek/harness-cli` · `@xrkseek/harness`）对齐 **0.3.1**（npm **`@latest`**）
* 公开双档：**v0.3.1**（正式当前）+ **v0.2.7**（预览末号）；侧栏社区包 `xrkh-better-sidebar` 本版无改动、无需升级

---

## 升级 / Upgrade

```bash
npm i -g @xrkseek/harness-cli@0.3.1
xrkh restart
```

浏览器硬刷新（Ctrl+Shift+R）。侧栏插件无需换版。

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.3.1
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

离线：GitHub Release `xrkseek-harness-cli-0.3.1.tgz` · `xrkseek-harness-0.3.1.tgz`  
SDK：`pnpm add @xrkseek/harness@0.3.1`
