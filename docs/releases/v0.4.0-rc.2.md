# v0.4.0-rc.2

> **读者 / Audience**：终端用户 · 插件与集成者（发行说明）

相对 [v0.4.0-rc.1](./v0.4.0-rc.1.md)：站立计划与子代理打断按会话语义收敛；概况栏可读；侧栏任务焦点与系统浏览器打开可用。

Relative to [v0.4.0-rc.1](./v0.4.0-rc.1.md): standing plan and subagent interrupt follow session semantics; the overview column is readable; sidebar job focus and system-browser open work.

---

## 完善 / Improved

* 站立计划（`todos` 投影 / TodoDock）跨回合保留，直到下一次 `todo_write` 覆盖；与模型侧 `standingPlanMessage` 重投影一致
* 子代理 `interrupt`：在 cancel→idle 之前抑制父会话的「finished a turn」steer；子代理再次 running 后恢复正常完成通知
* 作曲器「概况」打开右侧概况栏：站立任务、计划模式与 Office 状态
* Host `openNativePath` 正确打开 http(s) URL（侧栏 client 经 Face bridge 唤起系统浏览器）
* 概况栏计划行读 live `plan` 投影，任务页读 live `todos` 投影

## 修复 / Fixed

* 打断后台子代理后父会话不再被完成通知自动续上
* TodoDock 不再在下一轮 `turn/start` 被清空
* Windows 上侧栏「在浏览器中打开」不再把 `https://` 改写成 `https:\\`

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.4.0-rc.2
xrkh web
```

也可 `npx @xrkseek/harness-cli@0.4.0-rc.2 web`，或 `@rc`。预览线不覆盖 `@latest`：日常安装仍用 `npm install -g @xrkseek/harness-cli@latest`（v0.3.11）。

侧栏请升级：`xrkh plugin add xrkh-better-sidebar@0.18.5`，然后硬刷新 Web。

SDK：`pnpm add @xrkseek/harness@0.4.0-rc.2`
