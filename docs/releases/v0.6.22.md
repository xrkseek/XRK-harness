# v0.6.22

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.21](./v0.6.21.md)：**过程折叠对齐 Cursor**——收起后一行活动摘要（查看了 N 个文件…），四档过程详情各有明确收起时机；标准模式在工具跑完就收，不必等整轮 Turn 结束。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.22`（发包后）。

Relative to [v0.6.21](./v0.6.21.md): **process fold matches Cursor** — a collapsed run shows one activity line (Explored N files…); the four Process detail modes each have a clear fold timing; Standard folds when the tool burst finishes, without waiting for Turn end. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.22` (after publish).

### 完善

* **折叠摘要**：收起后标题为「查看了 N 个文件，M 次搜索…」类活动行，不再是「过程 · N 步」。
* **四档收起时机**：精简一上来就收；标准工具跑完就收；详细保留动效、整轮 Turn 结束后再收；始终展开不分组、不自动收。
* **标准更早收起**：工具 burst settle 后即可折（最终答案仍可流式输出），不必等 turn/end。

### 修复

* **「标准」仍展开到答完**：过程组在工具全部 settle 后闩上收起，不再只靠 Turn 关闭。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.6.22
xrkh web
```

或 `npm i -g @xrkseek/harness-cli@latest`（发包后）。

## 验证

* Settings → 过程详情「标准」：工具跑完过程折成「查看了… / Explored…」一行；最终答案仍可在下方继续流出。
* 「精简」：过程出现即收成摘要行。
* 「详细」：进行中保持展开与动效，Turn 结束后再收。
* 「始终展开」：不分组、不自动收起。

## 完整变更范围

过程活动摘要（tool 名分桶）、四档 `foldWhen`、过程组折叠时机与侧栏公告 / 官网 win-x64 下载元数据同步。

---

### Improved

* **Collapsed activity line**: folded headers read like “Explored N files, M searches…” instead of “Process · N steps”.
* **Four-point fold timing**: Compact folds immediately; Standard when the tool burst finishes; Detailed keeps the live animation and folds at Turn end; Always expanded skips grouping and auto-fold.
* **Earlier Standard fold**: latch closed once tools settle (final answer may still stream) — no wait for turn/end.

### Fixed

* **Standard stayed open through the answer**: process groups now fold when the tool burst settles, not only when the Turn closes.
