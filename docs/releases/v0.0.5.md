# v0.0.5

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.0.4](./v0.0.4.md)：对齐 DSH 的 prompt 前缀稳定，多步工具循环里 DeepSeek 等前缀缓存更易命中。

### 完善

* 完善出站 tools **按 name 字典序**，MCP / 注册顺序不再打乱 tools JSON 前缀
* 完善同 turn 后续 step：不再插入 `[current message]`、不再刷新 volatile `time:`，对话中段可 append-only 复用
* 完善 Prompt cache 规格说明（`llm-provider-registry` · `learn`）与 StatsLine「缓存命中」对应关系

## 安装

```bash
npm install -g @xrkseek/harness-cli@0.0.5
xrk-harness web
```

或：`npx @xrkseek/harness-cli@0.0.5 web`

规格：[llm-provider-registry](../llm-provider-registry.md) · [learn](../learn.md)。
