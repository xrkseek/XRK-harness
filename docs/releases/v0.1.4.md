# v0.1.4

相对 [v0.1.3](./v0.1.3.md)：Session SQLite 真源、Registry R1 协议包、取消固化、导出压缩、Face `sessionStats`。

## Session / 持久化

- **`sessions.db`（schema v3）**：`node:sqlite` · WAL · FTS5 trigram；去掉 JSONL 仓。
- **lazy load** · **chunk 写批** · 物理 **`text-chunks`**（≥3）· **`flush()`**（drain idle / close）。
- **open-turn 崩溃修复**：load 时补 `interrupted` turn/end。
- **ZIP 导出**：`toPackedJSONL` + **`.jsonl.zst` sidecar**；明文 `.jsonl` 仍保留。
- Host `stop` 时 `store.close()`（Windows 删库不 EBUSY）。

## LLM / Registry

- **R1 协议包**：`anthropic-messages` · `openai-responses` · `gemini-generate`（+ `openai-completions` 为 chat 工厂别名）。
- Face `llm-pi-ai.providers.*.api` → `resolve({ protocol })` 选工厂。
- **DeepSeek V4** 默认；官方 API text-only，自定义 gateway 可 `text+image`。
- HTTP **413** 体过大 → `UnsupportedContentError`（overflow 仍 `ContextOverflowError`）。
- Settings → Agent 真实 LLM（`createSessionRoutingLlm` · `request/header`）——延续 0.1.4 接线。

## Face / 壳

- **`session.history`**：按 message 边界分页（默认 50）。
- **取消流式**：中止时固化 `assistant/message`（`interrupted`）+ `turn/end aborted`；硬刷 `product-shell-cancel.e2e.ts`。
- **`sessionStats` 投影**：全日志 turn/step + llm/ttft/tool 墙钟（StatsLine）。
- 产品壳 UPSTREAM：`dsh-v0.1.0-rc.8`。

## 安装

```bash
mkdir my-workspace && cd my-workspace
npm install -g @xrkseek/harness-cli@0.1.4 --registry=https://npm.pkg.github.com
xrk-harness web
```

或零安装：`npx @xrkseek/harness-cli web`。GitHub Release 资产：`xrkseek-harness-cli-0.1.4.tgz`（可离线解压）。

**密钥**：首次 `web` 后在 Settings → Credentials 填写；或 `cp .xrk/.credentials.yaml.example .xrk/.credentials.yaml`。勿提交真实 key。见 [getting-started.md](../getting-started.md)。

## 本地验证（本仓）

```bash
pnpm install
pnpm build
pnpm web:build && pnpm client:bundle && pnpm web:assemble
node apps/cli/dist/bin.js web --workspace .
```

| 项 | 怎么验 |
|----|--------|
| SQLite | `{workspace}/.xrk/sessions/sessions.db`；`session.search` 命中 |
| R1 | Settings → Models：anthropic / gemini / openai-responses |
| Cancel | 流式中点 Stop → 日志含 `interrupted` + `aborted` |
| 导出 | Session log → ZIP 含 `.jsonl` 与 `.jsonl.zst` |
| Stats | 对话统计条数字不随分页漂移（有 `sessionStats`） |
