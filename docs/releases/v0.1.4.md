# v0.1.4

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对已撤下的 **0.1.0**（npm 已弃用、GitHub Release 已删）：**当前正式公开线**。在 0.1.0 功能基线上，用**新构建**替换 npm 上无法覆盖重发的旧 tarball；同步教科书双语体例与发行说明链接；社区插件兼容器与移动访问门禁继续收口。npm 公开包 **`@xrkseek/harness-cli`**（主 bin **`xrkh`**，亦 `xrk-harness`）。能力边界以 [status.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/status.md) 为准。

Relative to withdrawn **0.1.0** (deprecated on npm; GitHub Release removed): **the current formal public line**. Same 0.1.0 capability base with a **fresh build** tarball (npm cannot republish the same version); bilingual textbook and release-note links aligned; community adapter and mobile-access gating kept tight. Public npm package **`@xrkseek/harness-cli`** (primary bin **`xrkh`**, also `xrk-harness`). Capability truth: [status.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/status.md).

公开线：**正式 0.1.4** + 预览 [v0.0.11](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md)。`0.1.0`–`0.1.3` 与中间预览号已弃用。

Public line: formal **0.1.4** + preview [v0.0.11](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md). `0.1.0`–`0.1.3` and intermediate preview numbers are deprecated.

## 完善 / Improved

* 发行说明与教科书链接改为 GitHub **blob/main** 绝对 URL，Release 页可点开
* 预览线 [v0.0.11.md](https://github.com/xrkseek/XRK-harness/blob/main/docs/releases/v0.0.11.md) 补全定位、差异表与升级路径
* npm 弃用文案统一指向 **0.1.4** / **0.0.11**；`latest` 指向本版
