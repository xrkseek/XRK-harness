# v0.4.4

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.3](./v0.4.3.md)：补强生成与记忆工具面，硬化 Host 长跑与配置读盘，并让 Settings → Agent 循环露出完整软预算策略。

Relative to [v0.4.3](./v0.4.3.md): richer image/video and memory tools, Host long-run and settings-file hardening, and a full soft-budget strategy control on Settings → Agent loop.

### 新增

* 支持 `image_generate` **图生图 / 参考编辑**（`image_url` · `reference_image_urls` · `reference_attachment_ids`；按 Provider 能力动态出参）。
* 支持 `video_generate` **图生视频 / 首帧**、**edit/extend** 与 `action=catalog`（family）。
* 新增浏览器凭证库工具 `browser_vault_list` / `browser_vault_fill`（不透明句柄填表，密钥不进 tool result）。
* 新增策展记忆 **`sqlite` 后端**（`XRK_MEMORY_PROVIDER=sqlite` → `{XRK_HOME}/memories/curated-memory.sqlite`）。
* 新增 cron **运行账本**：`cronjob` action=`runs` → `~/.xrk/cron/executions.jsonl`（≤1000）。
* 新增壳层 **Ctrl+/ 快捷键面板**（查看与搜索已注册快捷键）。
* 新增会话级模型选择持久化：`/model` → `~/.xrk/session-models.json`，Host 重启回灌。
* 新增 Follow-up **时间上下文刷新**（默认 60s，`XRK_TIME_CONTEXT_REFRESH_MS`）。
* 新增受管 worktree Face **`worktree.merge`**（ff-only 合回；冲突 retain）。
* 新增 A2A 入站 opt-in（`XRK_A2A_INBOUND=1`：Agent Card + `POST /a2a` stub）。

### 完善

* 完善 Settings → Plugins → **Agent 循环**：新增 **压缩策略**（`compactionStrategy`：`prune-summary` · `prune-only` · `summary-only` · `off`），软预算 hint 与策略族对齐。
* 完善 soft-budget：图片 vision token 计入预算；阶段可在 Status / `/status` 观察。
* 完善 Settings 模型输入模态（text / image）；Custom text-only 可拦图。
* 完善轨迹 compact / detailed；DiffBlock 统一 / 分栏 + 同步滚动。
* 完善过期工作区 skill 自动归档到 `.archive/`。
* 完善 max-tokens **自动续写**（`autoContinueOnMaxTokens` / `autoContinueMaxRounds`）与外部 Agent 冷 resume sidecar。
* 完善 Cron 卡文案：总开关与跑史路径说明；Settings 热启停 ticker 并挂/卸 `cronjob`。
* 完善图 / 视频 Plugins 卡文案：标明参考生成与 catalog，不再只写「文生」。

### 修复

* 修复定时 **agent** 回合结束后 Agent 组合仍常驻 `agentCache`，Host 长跑数小时后堆顶约 4GB OOM；回合 `finally` 释放，session LRU 淘汰时同步 `invalidateAgent`。
* 修复 `~/.xrk/host-settings.json` 带 UTF-8 BOM 时 MCP / allowConnect 解析失败（读盘剥 BOM）。

### 其他变更

* Desktop 安装包 / 签名更新频道仍为**未稳**，本版不作为产品入口。
* 快捷键面板本版仅 **查看 + 搜索**；自定义 / 恢复默认仍为部分能力。
* 旧 Host 需 **`xrkh restart`** 加载本版行为。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.4.4
xrkh web
```

`@latest` 即本版。配置面与会话日志格式无需迁移。调参优先 **Settings → Plugins**（Agent 循环 · Cron · Image/Video gen）；`XRK_*` 仅作 Host/CI 旁路。
