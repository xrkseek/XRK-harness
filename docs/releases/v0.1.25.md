# v0.1.25

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.1.24](./v0.1.24.md)：产品建立时自动把默认 skills 写入用户主目录 system data；明确工作区归用户、产品不在项目树自动建 `.xrk`；附带能力挂载剧本与门禁修复。

Relative to [v0.1.24](./v0.1.24.md): on product establish, default skills are seeded into home system data; the workspace stays user-owned (no auto-`mkdir` of `.xrk` in the project tree); capability-attach playbooks and gate fixes ship with the CLI.

---

## 新增 / Added

* 新增 **`xrkh web` / `serve` 启动时**自动把打包种子 `seeds/skills/*` 装入 **`~/.xrk/skills`**（`XRK_HOME`；缺才装、不覆盖用户已改的 `SKILL.md`）
* 新增产品种子 skill：**`xrk-capability-attach`**（Settings 挂 MCP）、**`xrk-create-skill`**、**`xrk-adapt-workspace`**
* 新增教科书 [skills-layers](../skills-layers.md) 中的 **产品 vs 用户写盘边界**说明

---

## 完善 / Improved

* 完善 MCP 挂载路径：空白工作区也走 **Settings → MCP → `~/.xrk/host-settings.json`**，不依赖项目树 mkdir
* 完善 doctor：报告 home skills 种子状态
* 完善 CI / 门禁：`xrk-host-apiproxy/api` 从 src 解析；Vitest 非 ASCII 插件导入与相关断言对齐

---

## 其他变更 / Other changes

* **边界**：产品只写 system data（`XRK_HOME` / `~/.xrk`）；**绝不**在用户工作区自动创建 `.xrk` / `.agents`。工作区 skills 仅用户自愿自建

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.1.25
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`
