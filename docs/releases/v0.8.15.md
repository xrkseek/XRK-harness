# v0.8.15

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.14](./v0.8.14.md)：插队按发言族合并（老板与回传分开）、图文插队按文档顺序呈现，并堵住一批假「插队中」与崩溃丢正文洞。

### 完善

* **同族插队合并**：同一步的老板插队仍可合并进一轮；回传 / seat / 插件与老板分族，各自独立 promote，避免气泡身份与 echo 错绑。
* **图文插队呈现**：混合媒体按原文档顺序交错图与文；发送中的插队保持分条，不再把所有图抬到全部文字之上。
* **空 Host 文案保本地说明**：队列短暂投影出空 `text` 时，保留本地已打好的图文说明，避免「插队中」只剩图。

### 修复

* 纯图插队在 durable 已落地后仍钉着假「插队中」气泡（含附件 id 覆盖与 `Set.size` 误判）。
* 老板 durable 用正文子串 / 附件 id 误消掉尚在排队的回传「插队中」。
* Host 重启崩溃窗口里，老板 `user/message` 清掉异族悬挂 promote，导致回传正文静默丢失。
* 未带 `modelOnly` 的附件 caption 被当成 Host 正文，盖掉本地读者说明。

### 其他变更

* 公开线版本号对齐 **0.8.15**（npm / Desktop / 手机 / 官网下载同号）。
* 投递规格写明 speech family promote 与同族 dangling 关闭（[session-delivery](../session-delivery.md) · [session-api](../session-api.md)）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.14](./v0.8.14.md): speech-family steer coalesce (boss ≠ handoff), document-order multimedia steers, and several false 「插队中」 / crash-loss holes closed.

### Improved

* **Same-family steer coalesce**: same-step boss steers still merge into one turn; handoff / seat / plugin stay in their own families so chrome and echo ids do not smash together.
* **Multimedia steer layout**: mixed media keeps image↔text document order; pending steers stay one bubble each so every image is not hoisted above every caption.
* **Keep local prose on empty Host text**: when the queue briefly projects empty `text`, local image+caption prose stays painted instead of an image-only 「插队中」.

### Fixed

* Image-only steers no longer leave a ghost 「插队中」 after durable lands (attachment-id cover and `Set.size` mismatch).
* A stamped boss durable no longer retires a pending handoff row via text substring / shared media.
* Crash recovery no longer drops a dangling handoff promote when a boss `user/message` lands (close is per speech family).
* Attachment handle captions without `modelOnly` no longer overwrite local reader prose as Host queue text.

### Other

* Public line version **0.8.15** (npm / Desktop / phone / site download share the same number).
* Delivery docs spell out speech-family promote and same-family dangling close ([session-delivery](../session-delivery.md) · [session-api](../session-api.md)).
