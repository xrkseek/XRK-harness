# v0.5.0

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.4.12](./v0.4.12.md)：首发 `0.5.x` 正式线——**Desktop Face 改为 `127.0.0.1` 回环**（对标 DSH；开终端不再因 ConPTY 继承管道切断 Host）、**Desktop 整包与产品入口标为能跑**、插件清单/定时任务/概况与工具卡产品面加厚，社区 dsh-compat 与推理强度（含 DeepSeek thinking）可依赖。

Relative to [v0.4.12](./v0.4.12.md): opens the `0.5.x` formal line — **Desktop Face on `127.0.0.1` loopback** (DSH posture; opening a terminal no longer kills Host via ConPTY inheriting Face pipes), **Desktop full package and product entry marked Working**, thicker plugin inventory / schedule / Overview / tool-card surface, and dependable community dsh-compat plus reasoning-effort (including DeepSeek thinking).

### 新增

* 新增 Settings **定时任务**页签（`@xrkseek/client-ui-schedule`）：经 Host cron HTTP 列出任务、展开运行记录并支持重试失败加载。
* 新增 Host **cron HTTP** 面，供产品壳与集成方读写定时任务及跑史（与既有 `cronjob` 工具 / `cron/executions.jsonl` 账本衔接）。
* 新增 Settings → Plugins → Advanced **Host 运行时卡**与**进程通道卡**（只读 InfoRows）：一眼看到当前 Host 地址/工作区/已挂插件与通道接线。
* 新增 Face **会话 Agent preset** 存储与目录接线，对话侧可选用部署组合的 preset（含介绍动效座位）。
* 新增工具行 **`present` 专用视图**：折叠态显示「投递中 / 已投递」后缀，与路径摘要同构。
* 新增概况栏 **「改动」持久审阅页签**（`OverviewChangesPanel` + `ctx.changesReview`）：按回合选文件、拉 Face `fileDiff`、打开工作区路径。
* 新增概况 Status **子代理图板**（`SubagentGraphBoard`）：把 live 子代与边排成可读关系图。
* 新增 Desktop **私有 Host 捆绑 / boot-inject / web-root** 与打包烟雾脚本，Electron 壳可离线拉起内嵌 Host。
* 新增 Desktop **`desktop-host-attach`**：`xrk-app://` 闪屏先出壳，Host IPC `ready`（含 loopback `origin`）后再 `loadURL`；暴露 `starting` / `attaching` / `ready` 相位给首屏。
* 新增 Desktop Face **`127.0.0.1:<ephemeral>` 回环载波**（ADR-0008 / DSH）：退役 Electron 分帧 Face 管道；ConPTY 可进程内跑终端，不再继承 Face/IPC HANDLE。
* 新增产品 boot **渐进提示与 Host tip 轮播**（`boot-hints` / `boot-stamp`）：插件 → Host → Face 握手/流 → 会话列表各阶段文案；Host 未就绪时按相位轮换趣味提示。
* 新增 Desktop 首屏 **`BootWindowChrome`**：闪屏阶段即可拖拽标题区并使用刷新/窗控（不等产品壳装完）。
* 新增连接面 **`ConnectionPhase`**（`handshake:host` / `describe` / `streams` / `retry:backoff`）与可选 **`waitUntil`**，Desktop 可在 Host Fetch 附着后再握手，避免空转进退避。
* 新增 Settings 页脚 **连接进度 chrome**（`connection-chrome`）：握手与首份会话列表未 `ready` 前显示相位文案与转圈。
* 新增模型目录 **`reasoning` ladder**（Face `model-reasoning` + `@xrkseek/llm` `reasoning-effort`）：DeepSeek `off/low/high/max`；OpenAI/Codex 风格 ladder；Settings `llm-deepseek.reasoningEffort` / profile `reasoning` / `api: openai-responses` 可挂默认或强制。
* 新增对话模型选择器 **「思考强度」二级菜单**，把上述 ladder 写回会话模型选择（出站 DeepSeek thinking / OpenAI `off`→`none`）。
* 新增工具结果 **`type: "file"` 文件卡**（`tool.call.files` → `ToolFiles` / `file-card-model`），与用户气泡文件卡同组件。
* 新增图像/视频生成工具行的 **预览/媒体卡模型**：图生折叠可选缩略图、展开预览；视频完成后以文件/媒体卡呈现（无内嵌播放器）。
* 新增 A2A 入站 **tasks get/list/cancel**（内存 TaskStore），与既有 Agent Card / `POST /a2a` 同面可查可取消。
* 新增 `@xrkseek/exec-environment` **环境记忆**辅助与 sandbox doctor/resolve、computer-use / 浏览器 CDP 能力加厚（含 workspace-anchor / context-fragments 同步）。
* 新增社区 **dsh-compat 深适配面**：表面持久化、mnemon / git-graph / free-search / SSH TCP 等桥、皮肤/市场/技能管理等多插件 Host HTTP，并补齐审计与测例。
* 新增 HTTP **`host-owned-paths`**：`/sidebar/*`、`/plugins/*` 与 dsh-compat 前缀缺失时**不**回落 SPA `index.html`，避免社区探测被 HTML 假成功。
* 新增 Desktop 侧栏终端 **HTTP/SSE 载波**：`GET /sidebar/api/pty/stream` + input/control（与 WS 共用 `sidebar-pty` 槽；`xrk-app:` 下 TerminalView 走此路）。
* 新增首方薄工作台对社区侧栏的 **让位/唤醒辅助**（`betterSidebar` / community open）：内置面板让位后仍可一键唤起社区侧栏。
* 新增 shell **快捷键面板接线**（`Ctrl+/` / `⌘+/`）：查看、搜索，以及可改键/单条或全部恢复默认（本地覆盖）。
* 新增插件清单 **安装 UI session**（跨模态 remount 仍保留 TerminalBlock、成功态与「需刷新客户端半部」提示）。

### 完善

* 完善 Settings **插件清单（Manager）**：安装 / 更新 / 重载 / 启用禁用与 pane focus；托管插件 **Update 将 registry 钉到 `@latest`**；装完刷新 CTA 与配对 reconcile 文案更清晰。
* 完善 Desktop **自绘标题栏**：frameless 全宽细条 + `DesktopChrome`（拖拽 · 刷新 · 窗控）；窗口标题进中英文 locale，不再硬编码。
* 完善 Desktop **产品页同源 Host**：ready 后落在 loopback origin；mux/host 走 WebSocket（与 `xrkh web` 同构）；`xrk-app://` 仅闪屏/静态。
* 完善 Desktop 打包：启动恒绑旁路 **`@xrkseek/harness-cli`** 为独占 `XRK_HARNESS_BIN`（Settings 装/更/删插件不回落 PATH 全局 `xrkh`）。
* 完善新会话 **工作区归属**：创建后乐观加入目标 workspace，侧栏不再闪「未分组」。
* 完善概况 Status **摘要 hero**：健康点 + 实时节拍文案，并突出 jobs / 子代 / 回合或队列 / token；工具位挂 `details.status.utilities`。
* 完善 **会话日志导出**入口：从会话头 utilities 迁到概况 Status 工具区（`details.status.utilities`），与 Desktop 标题栏职责分离。
* 完善 **Open in App**：按「已连接世代」探测目录；Desktop 等 Host Fetch/`canOpenPath` 就绪后再探，避免闪屏期一次失败清空目录。
* 完善 Jobs / Deliverables / DiffBlock：作业列表与输出窥视、流内改动审阅与分栏 diff 同步滚动等产品面加厚。
* 完善工作区 Face/apiproxy 契约与客户端 workspace browser 行模型，Desktop web-api 路径与 runtime 对齐。
* 完善插件 mutate Face 错误投影：优先组合后的 mutate `error`，避免裸 stderr 盖住可读失败原因。
* 完善 MCP boot：idle 清单可在 boot / describe / `/mcp` 补连；文件 allow 等启动路径测例加厚。
* 完善社区教科书：Desktop 载波、侧栏 PTY SSE、ModLens 等路径说明与 **status** 能力表同步；标准侧栏包建议 **`xrkh-better-sidebar` ≥ 0.18.14**（见 [sidebar-workbench](../sidebar-workbench.md) · [community-plugins](../community-plugins.md)）。

### 修复

* 修复 Desktop 侧栏开终端切断 Host：根因是 ConPTY 继承 Electron Face/IPC 管道；改为 loopback Face 后进程内 PTY 可稳定存活（打包 smoke 含 pty SSE）。
* 修复 Desktop 侧栏 PTY：`/sidebar/api/pty/*` 被 JSON-RPC/SPA 抢答导致 **GET stream 405**——改为 Host `sidebar-pty` 早钩声明所有权，adapter 放行。
* 修复 Desktop 窗口标题 i18n 门禁：产品名进入 en/zh `windowTitle`，不再因硬编码失败 `verify-client-ui-i18n`。
* 修复对话 Composer 测例与 Lexical InputBar 语义漂移（contenteditable 草稿、intake 预检、剪贴板 chip、一键 Stop 等），产品路径与骨架/装配规格对齐。
* 修复 Deliverables / 侧栏样式快照与当前壳 chrome 不一致导致的客户端测红。
* 修复未签名 Desktop 打包被 **desktop-host `exactOptionalPropertyTypes`** 挡住的问题（随 dsh-compat / host 类型收口一并解开）。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.5.0`**（接管 npm `@latest`）；`0.4.x` 预览线以 v0.4.12 收口。
* npmjs 保留策略：仅保留 **0.5.0** 与回退钉 **0.3.11**；其余号撤回或弃用（GitHub Release 文稿可留档）。
* **Desktop 整包 / 产品入口由未稳改为能跑**（`package:desktop` 安装包可本地使用；内嵌 Host + Web；公开签名频道 / COS 上传仍凭据门控，不挡本机可用性）。
* `package:desktop` **产包前强制** `pnpm build:desktop`（host + client:bundle + web:assemble），无跳过壳构建的逃生口，避免打进过期 Web。
* 客户端 Vitest **独立 client lane** 与 Lexical composer host 测试桩（维护者测基础设施；不改变产品入口）。
* 同步 [status](../status.md) · [host-face](../host-face.md) · [community-plugins](../community-plugins.md) · [sidebar-workbench](../sidebar-workbench.md) · [llm-deepseek](../llm-deepseek.md) · [plugin-loader](../plugin-loader.md) 等教科书与模块笔记。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.5.0
xrkh web
```

侧栏（可选）：

```bash
xrkh plugin add xrkh-better-sidebar@0.18.14
```

然后整应用 / Host 重启，并硬刷新客户端半部。

* `xrkh web` 启动后 Settings 可见定时任务页签与插件清单 Update→`@latest`。
* Desktop：闪屏后 Host tip 轮播，`loadURL` 到 `http://127.0.0.1:<port>`；侧栏终端可开流且 Host 不退出。
* 概况摘要卡全宽指标格 + 节拍文案；工具区可见会话日志导出；Desktop 连上后可出现「打开文件夹」。
* DeepSeek 模型可选思考强度；出站 thinking wire 与 Settings/`openai-responses` 默认一致。
