# v0.3.3

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.2](./v0.3.2.md)：扩充 Settings 模型提供方目录（OpenCode Zen/Go 与一批 openai-chat 网关），并去掉首启强制 DeepSeek 密钥引导。

Relative to [v0.3.2](./v0.3.2.md): expand the Settings model provider catalog (OpenCode Zen/Go plus additional openai-chat gateways) and drop first-run forced DeepSeek key onboarding.

---

## 新增 / Added

* Registry BrandEntry：`opencode`（Zen）· `opencode-go`（Go），Settings 添加目录可选
* Registry BrandEntry：`xai` · `mistral` · `cerebras` · `deepinfra` · `novita-ai` · `siliconflow` / `siliconflow-cn` · `moonshotai` / `moonshotai-cn` · `minimax` / `minimax-cn` · `zai` · `zhipuai` · `perplexity` · `huggingface` · `nvidia` · `baseten` · `vercel` · `aihubmix` · `lmstudio`

## 完善 / Improved

* Settings 添加目录以 Registry `llm.providers` 为真源；`llm-pi-ai` base 仅保留零配置 `ollama`
* composer 模型目录只收录已配置 profile（及 DeepSeek）的提供方
* OpenCode Go 环境变量可回退 `OPENCODE_API_KEY`
* 教科书 [llm-provider-presets.md](../llm-provider-presets.md) 与 BrandEntry 表对齐

## 删除 / Removed

* 首启强制「填 DeepSeek 密钥」对话框（欢迎声明仍保留）

## 其他变更 / Other

* CLI / SDK 对齐 **0.3.3**（npm **`@latest`**）
* 公开双档：**v0.3.3** + **v0.2.7**

---

## 升级 / Upgrade

```bash
npm i -g @xrkseek/harness-cli@0.3.3
xrkh restart
```

浏览器硬刷新（Ctrl+Shift+R）。

---

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.3.3
xrkh web
```

或 / or：`npm i -g @xrkseek/harness-cli@latest`

离线：GitHub Release `xrkseek-harness-cli-0.3.3.tgz` · `xrkseek-harness-0.3.3.tgz`  
SDK：`pnpm add @xrkseek/harness@0.3.3`

---

## 验证 / Verify

- [ ] Settings → 模型 →「添加提供方」可见 OpenCode Zen / Go、SiliconFlow、MiniMax 等
- [ ] 配置 `OPENCODE_API_KEY` 后可选用 Zen 模型；本地 Ollama 仍可无密钥使用
- [ ] 首启不再弹出强制 DeepSeek 密钥卡（欢迎声明仍可出现）
