# v0.8.14

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.8.13](./v0.8.13.md)：工作区 SVG 可进对话图库、图片灯箱可缩放拖动、干员装扮槽位清残留，以及多端更新检查不再卡死。

### 新增

* **工作区 SVG**：`read_image` / `present` 接受 `.svg`；入库前栅格化为 PNG，对话行与模型侧同路径看图。
* **图片灯箱**：原图预览支持适配缩放、Ctrl/⌘+滚轮与双指捏合缩放、拖移 / 滚轮平移、双击切换、适配态下滑关闭，以及下载。

### 完善

* **装扮槽位解析**：内置帽子 / 眼镜 / 手持与自定义贴纸统一走「引擎占用则丢掉残留 overlay」；团队名册与添加干员共用同一套 look 解析。
* **名册 patch**：装扮写入按字段解析（不再整表浅合并），清贴纸 / 改回内置件时概况与左轨立刻对齐。
* **Desktop 更新检查**：探测失败只打日志、发布态回到 idle；侧栏版本胶囊不再钉死「检查失败」（弹层仍可看详情并重试）。
* **手机检查更新**：设置里点「检查更新」在未下载/安装中时**总是重新打源**；缓存的中间版（如 0.8.12）不再挡住已发布的更新版（如 0.8.13）。「跳过这个版本」仍可用。

### 修复

* 从自定义贴纸改回内置装扮后，概况 / 侧栏 / 表情球仍叠着旧 overlay。
* 目录默认手持补位时残留自定义 `overlayHeld`。
* Desktop 一次更新探测失败后设置底栏版本旁长期显示失败文案。
* 手机已提示旧补丁时无法再检查到更新的正式版。

### 其他变更

* 公开线版本号对齐 **0.8.14**（npm / Desktop / 手机 / 官网下载同号）。

---

> **Audience**: End users · maintainers (release notes).

Relative to [v0.8.13](./v0.8.13.md): workspace SVG in the chat gallery, pan/zoom lightbox, dress slots that drop stale overlays, and multi-end update checks that no longer stick.

### Added

* **Workspace SVG**: `read_image` / `present` accept `.svg`; rasterize to PNG on admit so chat tiles and the model share one image path.
* **Image lightbox**: original preview with fit-first scale, Ctrl/⌘+wheel and pinch zoom, drag / wheel pan, double-tap toggle, swipe-down dismiss at fit, and download.

### Improved

* **Dress slot resolve**: builtin hat / glasses / held and custom stickers share “engine owns slot → drop leftover overlay”; Team roster and Add-agent use one look helper.
* **Roster patches**: appearance writes parse field-wise (no shallow table merge) so clearing stickers / reverting to builtins sync Overview and the left rail immediately.
* **Desktop update check**: probe failures log only and publish `idle`; the Settings foot version chip no longer sticks on “check failed” (the sheet still shows detail and retries).
* **Phone check for updates**: Settings always re-hits the feed unless a download/install is in flight, so a cached mid-version offer (e.g. 0.8.12) can become a newer release (0.8.13). “Skip this version” remains available.

### Fixed

* Switching custom stickers back to builtin kits no longer leaves stale overlays on Overview / rail / presence ball.
* Catalog default held no longer keeps a leftover custom `overlayHeld`.
* Desktop no longer keeps a failed-check label next to Settings after one bad probe.
* Phone no longer blocks discovering a newer release while an older patch offer is still cached.

### Other

* Public line version **0.8.14** (npm / Desktop / phone / site download share the same number).
