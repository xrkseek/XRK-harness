# v0.6.10

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.9](./v0.6.9.md)：**向阳奇创补齐查网 / 语言服务 / 终端**，并修好高级干员 zip 在壳里拖入安装的通道。奇创（`qichuang`）改走 harness 组合，工具开关与编码面同档（`web` · `lsp` · `pty`），仍**无**嵌套子代理；桌面 / Web 的 `team.export` / `team.importPack` remotes 补挂后，公文包 zip（含大型技能树包）可从名册拖入落盘。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.10`（发包后）。

Relative to [v0.6.9](./v0.6.9.md): **Xiangyang Qichuang gains web / language-server / terminal**, and advanced 干员 zip drag-install in the shell works again. `qichuang` now uses the harness composition with the same tool flags as the coding plane (`web` · `lsp` · `pty`) while still having **no** nested subagents; wiring `team.export` / `team.importPack` into Face remotes lets briefcase zips (including large skill-tree packs) land from the roster UI. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.10` (after publish).

### 完善

* **奇创工具面 = harness 开关**：`web` / `lsp` / `pty` 全开；组合改为 `harness`（bash 等同档），编排边界不变——仍无 nested `subagent`，跨区靠 `workspace_*` / `thread_*`。
* **能力板 / 教科书对齐**：`<session_capability>` 奇创 brief 标明 `web+lsp+pty`；[profiles](../profiles.md) · [status](../status.md) · 场景文稿同步。

### 修复

* **壳内拖 zip 导入高级干员**：`xrk-api-remotes` 漏挂 `team.export` / `team.importPack`，UI 调用会报 `importPack is not a function`；补挂后名册「导入包」与导出对称可用。大型公文包（多 skill 树 + `env/SETUP.md` + `workspace/`）经 `loadAgentMemberPackBytes` → `materializeAgentMemberPack` 可完整落盘，导入后 `ready=false`，按 env 说明再 `team_ready`。

## 用户侧复杂情况

| 用户行为 | 风险 | 本工作树 | 覆盖 |
| --- | --- | --- | --- |
| 向阳里要查网 / 开终端 / 看语言服务 | 奇创以前关着，模型说「没有 web_fetch」 | `QICHUANG_TOOLS` + harness composition | presets-catalog · session-capability |
| 把朋友发的干员 zip 拖进名册 | UI 崩或「需要 Host」假失败 | remotes 挂上 `importPack` / `export` | xrk-api-remotes |
| 装超大技能包 zip | 白名单拒 / 半落盘 | 布局校验通过后整树 materialize，技能名回执齐全 | agent-member-pack |
