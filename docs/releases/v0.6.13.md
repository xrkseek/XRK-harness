# v0.6.13

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.12](./v0.6.12.md)：**流式回复时 Ctrl+Enter / 输入更跟手**；高级干员 **省略 playbook 的 `team_save` 不再用名册旧文盖掉磁盘 `playbook.md`**；干员名册「未就绪」面板不再挤成圆钮。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.13`（发包后）。

Relative to [v0.6.12](./v0.6.12.md): **streaming stays responsive under Ctrl+Enter / typing**; advanced 干员 **`team_save` without playbook no longer overwrites a fresher on-disk `playbook.md` with the lagging roster copy**; the Team roster **Not ready** panel no longer crushes capsule buttons into circles. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.13` (after publish).

### 完善

* **流式绘制让路给输入**：动画帧预算随 Markdown 成本自适应（约 48–160ms），`isInputPending` 让一次，Scheduler `user-visible` 优先于把流式当成后台任务。
* **同 run 文本 delta 合并 + 短时切片 drain**：一帧少做 matchInput，切片残留立刻续画（不再再等一整段 paint budget）。
* **插队回显软通知**：`beginSubmission` 同步画出 echo，不强制刷当前 Think/assistant Markdown。
* **未就绪干员编辑区**：环境说明独立成警告色面板；保存 / 导出 / 删除不再与 env 文挤在同一行。

### 修复

* **`team_save` 盖掉磁盘 playbook**：只改 brief / inject / tools / skills 时仍 `syncMemberPackPlaybook`，把手改或合并后的 `playbook.md`（如 42 skills）写回旧名册文（如 41）。现仅在显式传 `playbook` 时写盘；省略时从磁盘回写名册。
* **干员不热更新**：spawn / `team.dispatch` / `team.list` / export 优先读盘上的 `playbook.md`，并在名册落后时愈合，下一派发吃到最新说明。

### Improved

* **Stream paints yield to input**: adaptive animation-frame budget (~48–160ms), one `isInputPending` yield, Scheduler `user-visible` (not `background`) for on-screen Think/text.
* **Same-run text-delta merge + time-sliced drain**: fewer matchInput calls per paint; leftovers continue immediately without another full paint gap.
* **Soft steer/submit echo**: `beginSubmission` paints the pending echo without forcing the current Think/assistant Markdown flush.
* **Not-ready roster editor**: env prep sits in its own warn panel; Save / Export / Delete no longer share a flex row with the prep text.

### Fixed

* **`team_save` overwrote disk playbook**: brief/inject/tools/skills-only revises still called `syncMemberPackPlaybook`, restoring a stale roster copy over a fresher `playbook.md`. Sync only when `playbook` is explicit; omit adopts disk into the roster.
* **干员 not hot-updating**: spawn / `team.dispatch` / `team.list` / export prefer on-disk `playbook.md` and heal a lagging roster so the next spawn sees the live text.
