# v0.7.0-rc.1

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.23](./v0.6.23.md)：开启 **`0.7.x` 正式线**首个过程号（npm dist-tag **`@rc`**，**不**接管 `@latest`；`@latest` 仍为 **0.6.23** 直至正式 `0.7.0`）。这是一次**大版本向**变更：除大会话读写、席位壳与 Claude Code mods 外，**上下文工程整层重排**——Audience 只闸经理 ledger；家约定与 skill catalog 全席同注；`<instruction_authority>` 分 order/data；skill 渐进披露（无 `skill_search`）；经理 coding-light 与向阳管理面分家。

Relative to [v0.6.23](./v0.6.23.md): first process number on the **`0.7.x` formal line** (npm dist-tag **`@rc`**; **does not** take `@latest`; `@latest` stays **0.6.23** until formal `0.7.0`). A **major-line** cut: beyond large-session I/O, seat chrome, and Claude Code mods, **context engineering is re-laid** — Audience gates the manager ledger only; home convention and skill catalog inject for every seat; `<instruction_authority>` splits order vs data; progressive skill disclosure (no `skill_search`); manager coding-light vs 向阳 admin surface.

### 新增

* **经理专属 ledger `XRK.md`**：站立 `~/.xrk/XRK.md`（+ 遗留 `~/XRK.md`）与工作区 `.xrk/XRK.md` / 根遗留仅 **`audience=user`**（编码主会话）注入；干员家 / 委派子会话不注。产品站立与家约定**不**随 Audience 省略。
* **指令权威车道 `<instruction_authority>`**：内建 order（站立 · 家约定 · 工作区盘上规则 · 本回合用户口述）与 data（工具/网页/他会话正文）；软标签不能改车道；插件可 `register` 扩展。
* **席位碎片 `<seat_identity>` / `<boss_status>`**：员工席 turn-start 注入「我是谁 / 对谁汇报」与老板心情/状态线；Overview 老板球打开 `BossStatusSheet`（心情 · 状态 · 昵称）。
* **上下文碎片窗内 last-wins**：同 `fragmentId` 的活文案在模型窗只保留最新一条（日志全量仍在）。
* **子代理 capability `depth`**：委托子会话 `<session_capability>` 带嵌套深度与 L1 / Ln brief。
* **Claude Code mods 运行时**（`@xrkseek/claude-code-mods`）：按上架 Claude Code 的插件目录加载 hooks，观察 / 拒绝 / 改写工具调用；harness preset 可挂载。
* **输入区 Mods 带（`ModBandDock`）**：AbovePrompt 声明式 Box/Text/Button 树可点按回传会话。
* **添加干员工作区面板**：侧栏下半从名册 mint 干员家（与「干员团队」编辑名册分流）。
* **协作板 peer 字段**：同仓新会话委派可读的 peer 身份/路由提示（经理走 `workspace_session_prompt` 平行会话，不默认升向阳）。
* **`session.eventWindow` / `session_event_window`**：按 Face seq 取有界邻居（默认前后各 3，上限 50）；冷读后 `releaseResident`。
* **会话谱系 `session_trace`**：合并子代理与 UI fork，回报 `complete` / `truncated`。
* **影子 git `reclaim()`**：启动空闲时 `gc --auto` 收松散对象。

### 完善

* **编辑重发 / truncate 尾删（R7）**：同前缀 `replacePrefix` 物理尾删（干净库约 2.5×；packed 跨界仍全量重写）。
* **fork / seed SQL 拷前缀（R6）**：热库干净切点 `INSERT…SELECT`；跨 packed / 冷库回退。
* **冷开 history 尾读（R8）**：首屏扩 durable 后缀 + singles priming（大会话约 3–7×）。
* **history 投影盘缓存（R9）**：冷 `session.history` 命中走 `viewCheckpoint`。
* **写前 `flush` 检查点**：LLM / 工具前语义 flush；坏行 fail-closed；未来 schema 拒绝；冷观察可 `releaseResident`。
* **搜索**：短查询 LIKE 兜底；FTS 失败有诊断；水合封顶；list hints / list-tier 减侧栏冷扫。
* **Audience 闸口收窄**：**只**闸经理 ledger `XRK.md`。`subagent` / `minimal` **保留**产品站立（`~/.xrk`）且 **同注**家约定（`~/.agents` · `~/.claude` · `~/.codex`）；徽章与权限只管**工具运行时面**，不管上下文厚薄。
* **多厂商工作区约定叠加**：工作区 `.agents` / `.cursor` / `.claude`（及家同形）**增量同注**，不是互斥二选一。
* **Skill 渐进披露（无 `skill_search`）**：catalog 只列名+短 blurb → `skill` 按精确名拉正文；`tool_search` 只管延后工具。截断前优先序：**干员公文包** → **工作区 + 产品家 `xrk-*` 种子** → **全局殿后可截**；名冲突时 preferred / 公文包胜。
* **skill catalog ≡ `skill` / `skill.list` / `/skills` 根**：产品家 `{XRK_HOME}/skills`（种子+安装）/ 公文包 / 项目树同形候选。
* **经理 vs 向阳工具面**：经理默认 **coding-light**（可同仓平行会话委派）；**设置 / 管理面工具**挂在向阳（admin）。经理升权限走向阳，不靠加厚自身工具表。
* **站立种子**：知识面表、Instruction authority、经理 ledger 注入序；大活同会话 outline → ask → `todo_write`（产品 plan 模式与 `xrk-plan-build` 种子退役）。
* **Presence / 干员壳**：老板→经理 / 向日葵编排；帽·眼镜·手持分槽；关表情球时团队密列表、干员家只显示文件夹；TeamRoster / WorkspaceBrowser 加厚。
* **消息动作**：编辑重发 / 再生成 / 恢复分岔门控；turn-cut fork 锚定首个 ≥seq 的 `turn/end`。
* **Status / 投影**：`costUsage` · `contextTimeline` · `turnOutline` · list metadata / title 与 Status 快照缓存加厚。
* **会话身份教科书**：五种工程 `kind` 与许愿→动词表见 [session-identity](../session-identity.md)。

### 删除

* **产品 plan 模式**：`/plan` 仅退役提示并 settle `plan/mode` inactive（清投影 `pending`，不激活、不 steer）；目录去掉 `exit_plan_mode`。旧日志仍可 fold；Overview Canvas 等非 plan-mode 能力不受影响。
* **仓库内产品人格副本**：工作区不再依赖 `.agents/AGENTS.md` / `SOUL.md` 当产品站立真源（站立走 `~/.xrk` 种子；根维护者 `AGENTS.md` 带 `xrk-inject: false`）。

### 修复

* **投影 `asOfSeq`**：增量基线取最低水位。
* **FTS 读失败**：不再静默空结果；resident 兜底 + 诊断。
* **fork 血缘 / end-seed**：`session/end-seed` + `forked`；委托子跳过错误 title fallback；列表 identity / predecessorTitle 减贴旧标题。
* **模态焦点 / 原语**：Modal 焦点测例与 HoverCard / Menu / Toast 壳面微调。

### 其他变更

* 公开线目标 **`@xrkseek/harness-cli@0.7.0-rc.1`**（npm dist-tag **`rc`**；`@latest` 仍为 **0.6.23**）。
* Desktop 私有壳对齐 **0.7.0-rc.1**（与 `apps/cli` / `packages/sdk` 同号）。
* 教科书 / 笔记：[workspace-inject](../workspace-inject.md) · [context-fragments](../context-fragments.md) · [session](../session.md) · [session-log](../session-log.md) · [host-face](../host-face.md) · [status](../status.md) · [session-optimize](../session-optimize.md) · [claude-code-mods-wiring](../claude-code-mods-wiring.md) · [skills-layers](../skills-layers.md)。

# v0.7.0-rc.1

> **Audience**: End users · Integrators · Maintainers (release notes)

Relative to [v0.6.23](./v0.6.23.md): first process number on the **`0.7.x` formal line** (npm dist-tag **`@rc`**; **does not** take `@latest`; `@latest` stays **0.6.23** until formal `0.7.0`). A **major-line** cut: beyond large-session I/O, seat chrome, and Claude Code mods, **context engineering is re-laid** — Audience gates the manager ledger only; home convention and skill catalog inject for every seat; `<instruction_authority>` splits order vs data; progressive skill disclosure (no `skill_search`); manager coding-light vs 向阳 admin surface.

### Added

* **Manager-only ledger `XRK.md`**: standing `~/.xrk/XRK.md` (+ legacy `~/XRK.md`) and workspace `.xrk/XRK.md` / root legacy inject for **`audience=user`** (coding parent) only — not 干员家 / delegated children. Product standing and home convention are **not** Audience-gated.
* **Instruction authority `<instruction_authority>`**: built-in order lanes (standing · home convention · on-disk workspace rules · this-turn user ask) and data lanes (tool / web / other-session bodies); soft labels cannot reclassify lanes; plugins may `register`.
* **Seat fragments `<seat_identity>` / `<boss_status>`**: employee seats get who-you-are / report-line plus Boss mood/status on turn-start; Overview Boss ball opens `BossStatusSheet`.
* **In-window fragment last-wins**: living copy with the same `fragmentId` keeps only the latest row in the model window (full log retained).
* **Child capability `depth`**: delegated `<session_capability>` carries nesting depth and an L1 / Ln brief.
* **Claude Code mods runtime** (`@xrkseek/claude-code-mods`): load marketplace-shaped plugin dirs; observe / deny / rewrite tool calls; harness preset can attach.
* **Mods AbovePrompt band (`ModBandDock`)**: declarative Box/Text/Button tree with press-back into the session.
* **Add-agent workspace panel**: lower sidebar mints an agent-home from the roster (separate from Team Roster editing).
* **Collab-board peer fields**: peer identity/route hints for same-workspace new-session delegation (manager uses `workspace_session_prompt` peers; does not default-escalate to 向阳).
* **`session.eventWindow` / `session_event_window`**: bounded neighborhood around a Face seq (default ±3, max 50); cold reads `releaseResident`.
* **`session_trace` lineage**: merges subagent ∪ UI fork with `complete` / `truncated`.
* **Shadow-git `reclaim()`**: idle `gc --auto` so loose objects do not grow without bound.

### Improved

* **Edit-resubmit / truncate tail delete (R7)**: same-prefix `replacePrefix` physically deletes the suffix (~2.5× on clean DBs; packed boundary still full rewrite).
* **Fork / seed SQL prefix copy (R6)**: hot-store clean cut uses `INSERT…SELECT`; packed / cold falls back.
* **Cold history tail read (R8)**: first screen expands durable suffix + singles priming (~3–7× on large sessions).
* **History projection disk cache (R9)**: cold `session.history` hits skip heavy fold/hydrate via `viewCheckpoint`.
* **Pre-call `flush` checkpoints**: semantic flush before LLM / tools; fail-closed bad rows; refuse future schema; cold `releaseResident`.
* **Search**: short-query LIKE fallback; FTS failure diagnostics; hydrate caps; list hints / list-tier projection keep sidebar cold-scan cheap.
* **Audience gate narrowed**: gates **manager ledger `XRK.md` only**. `subagent` / `minimal` **keep** product standing (`~/.xrk`) **and inject** home convention (`~/.agents` · `~/.claude` · `~/.codex`); badge and permission control the **tool runtime surface**, not context thickness.
* **Multi-vendor workspace convention stack**: workspace `.agents` / `.cursor` / `.claude` (and home counterparts) inject **additively**.
* **Progressive skill disclosure (no `skill_search`)**: catalog = name + short blurb → `skill` loads body by exact name; `tool_search` is for deferred tools only. Truncate priority: **干员公文包** → **workspace + product-home `xrk-*` seeds** → **globals may drop**; preferred / briefcase wins name clashes.
* **Skill catalog ≡ `skill` / `skill.list` / `/skills` roots**: shared candidates for product-home `{XRK_HOME}/skills` (seeds + installs) / briefcase / project trees.
* **Manager vs 向阳 tool surfaces**: manager defaults to **coding-light** (same-workspace peer sessions OK); **Settings / admin tools** live on 向阳. Escalate via 向阳, not by thickening the manager tool table.
* **Standing seeds**: knowledge-surface table, Instruction authority, manager ledger in inject order; large work → same-session outline → ask → `todo_write` (product plan mode and `xrk-plan-build` seed retired).
* **Presence / agent chrome**: Boss→Manager / 向日葵 layout; hat · glasses · held slots; dense Team list and folder-only agent-home rows when presence is off; thicker TeamRoster / WorkspaceBrowser.
* **Message actions**: clearer edit-resubmit / regenerate / restore gating; turn-cut forks anchor on the first `turn/end` at or after the seq.
* **Status / projections**: thicker `costUsage` · `contextTimeline` · `turnOutline` · list metadata / title units and Status snapshot cache.
* **Session-identity textbook**: five engineering `kind`s and wish→verb table in [session-identity](../session-identity.md).

### Removed

* **Product plan mode**: `/plan` only returns a retirement hint and settles `plan/mode` inactive (clears `pending`; no activate / steer); catalogs drop `exit_plan_mode`. Old logs still fold; Overview canvas features unrelated to plan-mode stay.
* **In-repo product persona copies**: workspace no longer treats `.agents/AGENTS.md` / `SOUL.md` as the product standing source (standing comes from `~/.xrk` seeds; maintainer root `AGENTS.md` carries `xrk-inject: false`).

### Fixed

* **Projection `asOfSeq`**: incremental baseline uses the lowest watermark.
* **FTS read failures**: no silent empty results; resident fallback + diagnostics.
* **Fork lineage / end-seed**: `session/end-seed` + `forked`; delegated children skip bad title fallback; list identity / predecessorTitle reduce stale titles.
* **Modal focus / primitives**: Modal focus coverage and light HoverCard / Menu / Toast chrome tweaks.

### Other changes

* Public line target **`@xrkseek/harness-cli@0.7.0-rc.1`** (npm dist-tag **`rc`**; `@latest` stays **0.6.23**).
* Desktop private shell aligned to **0.7.0-rc.1** (moves with `apps/cli` / `packages/sdk` on publish).
* Textbook / maintainer sync: [workspace-inject](../workspace-inject.md) · [context-fragments](../context-fragments.md) · [session](../session.md) · [session-log](../session-log.md) · [host-face](../host-face.md) · [status](../status.md) · [session-optimize](../session-optimize.md) · [claude-code-mods-wiring](../claude-code-mods-wiring.md) · [skills-layers](../skills-layers.md).
