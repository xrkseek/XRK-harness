# v0.3.5

> **读者 / Audience**：终端用户 · 维护者（发行说明） / End users · Maintainers (release notes)

相对 [v0.3.4](./v0.3.4.md)：修复产品壳中心栏因 slot 竞态无法加载；侧栏建议升级 **`xrkh-better-sidebar@0.18.3`**。

Relative to [v0.3.4](./v0.3.4.md): fix product-shell center column failing to load from a slot race; prefer sidebar **`xrkh-better-sidebar@0.18.3`**.

---

## 修复 / Fixed

* 产品壳 **`@xrkseek/client-ui-conversation`** 在 `ui-layout` 声明 `conversation` slot 之前 apply，导致「Failed to load plugins / slot conversation is not declared」：fiber 注入对齐 `ui-sidebar`，等待 **`layout`** 后再注册中心栏
* 建议侧栏 **`xrkh-better-sidebar@0.18.3`**：client 同样等待 `layout`，避免拦截挂载竞态

## 完善 / Improved

* 教科书：侧栏建议版本与 Host 基线（community-plugins / 发行说明）指向 **0.18.3** · Host **≥ 0.3.4**（本版起 **≥ 0.3.5**）

## 其他变更 / Other

* CLI / SDK **0.3.5**（npm **`@latest`**）；公开双档 **v0.3.5** + **v0.2.7**

## 安装 / Install

```bash
npm install -g @xrkseek/harness-cli@0.3.5
xrkh web
# 侧栏（若已装旧版）
xrkh plugin add xrkh-better-sidebar@0.18.3
xrkh restart
```

或：`npx @xrkseek/harness-cli@0.3.5 web`

SDK：`pnpm add @xrkseek/harness@0.3.5`

GitHub Release 资源：`xrkseek-harness-cli-0.3.5.tgz` · `xrkseek-harness-0.3.5.tgz`
