# v0.6.11

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.6.10](./v0.6.10.md)：**高级干员派生不再把公文包里每条 skill 绝对路径灌进上下文**。spawn preamble 与每回合 `<session_capability>` 只保留短句（`公文包 (briefcase)` · `pack_home` · `skills_dir` · 可选 `materials`）；包内 skills 仍经 `extraSkillDirs` 进子会话 skill catalog（name+description），正文用 `skill` 工具按名加载。`xrk-delegate` 种子同步新契约。npm **`@latest`** 指向 `@xrkseek/harness-cli@0.6.11`（发包后）。

Relative to [v0.6.10](./v0.6.10.md): **spawning an advanced 干员 no longer dumps every skill absolute path into context**. The spawn preamble and per-turn `<session_capability>` keep a short briefcase note (`公文包 (briefcase)` · `pack_home` · `skills_dir` · optional `materials`); pack skills still reach the child via `extraSkillDirs` into the skill catalog (name+description), and full bodies load with the `skill` tool by name. The `xrk-delegate` seed matches this contract. npm **`@latest`** points at `@xrkseek/harness-cli@0.6.11` (after publish).

### 完善

* **公文包注入变瘦**：`formatMemberPackInventoryLines` 不再枚举 `skill: id @ abs · references=`；能力板与 preamble 只给锚点 +「用 skill 工具按名加载」。完整 inventory 仍在 `team_list` / `team_save` 回执里给人看。
* **委派种子对齐**：`xrk-delegate` 写明 lean 注入与 catalog / `skill` 分工，避免主会话再按「每条路径」理解 Host。

### 修复

* **大公文包（数十个 skill）上下文膨胀**：原先路径列表与 skill catalog 重复灌入；大型包（如文献检索类 zip）派生后每回合可少约一万字符的无用绝对路径。

## 用户侧复杂情况

| 用户行为 | 风险 | 本工作树 | 覆盖 |
| --- | --- | --- | --- |
| 派生带 40+ skill 的高级干员 | capability/preamble 塞满绝对路径，挤掉任务 | lean 五行锚点；技能靠 catalog + `skill` | agent-member-pack · session-capability |
| 以为要自己扫 `skills_dir` | 漏用 skill 工具 | 文案写明 load/search with skill tool by name | formatMemberPackInventoryLines · xrk-delegate |

## 验证

* 派生 advanced 成员：capability 含 `skills_dir` 与 `skill tool`，**不含** `skill: … @` 绝对路径行。
* `team_list` 回执 inventory 仍带每条 skill 路径（给人或工具，不进模型站立轴）。
* `pnpm` 相关 face 测例绿。

---

### Improved

* **Lean briefcase inject**: `formatMemberPackInventoryLines` no longer enumerates `skill: id @ abs · references=`; capability and preamble only keep anchors plus “load with the skill tool by name”. Full inventory remains on `team_list` / `team_save` receipts for humans.
* **Delegate seed aligned**: `xrk-delegate` documents lean inject and the catalog / `skill` split so parents do not expect a per-path dump from Host.

### Fixed

* **Context bloat on large briefcase packs**: the old path list duplicated the skill catalog; large packs (dozens of skills) no longer pay ~10k characters of useless absolute paths every turn.
