# v0.7.13

> **读者**：终端用户 · 维护者（发行说明）。

相对 [v0.7.12](./v0.7.12.md)：Desktop 可在设置 → 通用阻止系统休眠并在会话结束时发系统通知；Overview 老板球尺寸与经理球解耦；归档强制确认不再误闪；Host 重启后的排队回声与空压缩失败路径更稳。

### 新增

* Desktop（设置 → 通用）：可选「回合在跑时阻止系统休眠」（息屏后仍可继续跑；默认关）；会话结束时可发系统通知，并支持仅未聚焦 / 总是 两种时机。
* computer_use / browser_*：继续完善语义定位与会话作用域（与 0.7.12 同线）。

### 完善

* 睡眠抑制在后台 job 仍 `running`/`stopping` 时保持顶住，避免息屏后中途挂起。
* 压缩摘要遇到空/退化模型回复时走软失败提示，不再画成红色「空回复」。
* 提交排队：Host 重启后清理不会再被认领的本地回声；admit 中的提交不会被误退休。

### 修复

* Overview：调整老板球大小不再带动经理球（经理缺省尺寸保持 1×）。
* 归档：取消后安静归档不再弹出「强制归档」闪窗（仅在回合真正仍忙时确认）。
* Desktop 电源开关即时生效，并与 Face 设置 / 本机镜像对齐。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.13
xrkh web
```

桌面安装包见 GitHub Release `v0.7.13` 与站点下载页（AGT 上线后）。

# Release Notes

> **Audience**: End users · Maintainers

Relative to [v0.7.12](./v0.7.12.md): Desktop Settings → General can prevent system sleep while work runs and notify on session complete; Overview boss ball size no longer scales the manager ball; archive force-confirm no longer flashes; Host-restart queue echoes and empty-compact failures are steadier.

### Added

* Desktop (Settings → General): optional prevent-idle-sleep while a turn/job runs (screen may still blank; default off); OS notify on session complete with unfocused / always timing.
* computer_use / browser_* keep expanding semantic locate and session scoping (same line as 0.7.12).

### Improved

* Sleep inhibitor stays armed while background jobs are `running`/`stopping`.
* Compaction summarizer empty/degenerate finishes soft-fail instead of a red empty-response paint.
* Submission queue: retire local echoes the restarted Host will never claim; do not retire prompts still awaiting admit.

### Fixed

* Overview: boss ball size no longer drives the manager ball (omitted member size stays 1×).
* Archive: quiet archive no longer flashes the force-archive dialog (confirm only when a turn is still busy).
* Desktop power toggles apply immediately and stay aligned with Face settings / local mirror.
