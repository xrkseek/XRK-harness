# v0.7.3

> **读者 / Audience**：终端用户 · 插件与集成者 · 维护者（发行说明）

相对 [v0.7.2](./v0.7.2.md)：OFM Host 只把免费通道两条路由同步进 Face，避免 channel-pack 适配器拖垮状态轮询与网页。

Relative to [v0.7.2](./v0.7.2.md): OFM Host Face-syncs only the two free-lane routes, so channel-pack adapters no longer stall status polling or the web UI.

### 修复

* **OFM Face 同步白名单**：Cordis 根上 channel-pack（gemini / zcode / …）与免费通道共用 `ctx.llm`；Face 只同步 `our-free-model` / `our-free-model-region`。空目录与未白名单注册不再卡住 `settled`，也不再刷 `syncCommunityLlmProvider skip`。
* **转发端口**：盘面 `settings.json` 与 live `/summary` 同一套 `actualPort` 优先规则；boot 后 poll 到 listener 再 Face sync。
* **forwardKey**：不再用 `xrk-*` 占位写进 Face；等 summary/disk 真密钥；指纹含 apiKey，轮换会重同步。
* **空 region**：曾发布过的路由 catalog 变空时向 Face 推空列表清理。
* **WorkBuddy 状态 nudge**：未 settled 时 status GET 同步带冷却，避免刷屏拖死 Host。

## 安装

```bash
npm i -g @xrkseek/harness-cli@0.7.3
xrkh web
```

亦可 `npm i -g @xrkseek/harness-cli@latest`（发包后指向本版）。
